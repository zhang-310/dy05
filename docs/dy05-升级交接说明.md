## 3. P0 技术要点（供 Agent 执行清单）

1. **备份**：`pom.xml`、`src/` 或整库打 tag / 分支。
2. **新建父 POM**：`groupId`/`version` 与现有一致；`<modules><module>douyin-operations-app</module></modules>`。
3. **子模块目录** `douyin-operations-app/`：`pom.xml` 继承 `spring-boot-starter-parent`（与现 dy02 相同），**依赖与 `build` 插件**从原根 `pom.xml` 迁入；`artifactId` 改为 `douyin-operations-app`。
4. **移动**：`src` → `douyin-operations-app/src`；根目录 **不再**保留顶层 `src`。
5. **Spring Boot**：`mainClass` 仍为 `cn.gaifan.douyinOperations.DouyinOperationsApplication`。
6. **验证**：`mvn -f pom.xml -pl douyin-operations-app -am verify` 或根目录 `mvn verify`（视父 POM 是否传递模块而定）。
7. **文档**：更新 **`docs/BUILD.md`**「当前状态」为「已完成 P0」；必要时在 **`SSOT.md`** 修订记录中记一笔。
