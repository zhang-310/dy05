# 账号采集页面优化 - 添加账号跳转功能

**日期**: 2026-04-21  
**状态**: ✅ 完成

---

## 问题描述

用户在 `/admin/shortvideo/collect` 账号采集页面无法直接查看账号下的短视频，需要：
1. 在采集任务列表中显示账号信息
2. 提供快速跳转到账号详情页的入口
3. 在账号详情页查看该账号的所有采集视频

---

## 解决方案

### 1. 账号名称可点击跳转 ✅

**位置**: 账号/输入列

**实现**:
- 如果采集任务已关联账号（`svAccountId` 存在），账号名称显示为可点击的链接
- 点击后跳转到账号详情页 `/admin/shortvideo/accounts/:id`
- 鼠标悬停显示提示："点击查看账号详情"

**代码**:
```typescript
{hasSvAccountId ? (
  <Link
    component="button"
    variant="body2"
    onClick={() => navigate(shortvideoAccountDetailPath(row.svAccountId!))}
    sx={{ cursor: 'pointer' }}
    title={`${label} (点击查看账号详情)`}
  >
    {label}
  </Link>
) : (
  <Typography variant="body2" noWrap title={label}>
    {label}
  </Typography>
)}
```

### 2. 操作列添加"查看账号"按钮 ✅

**位置**: 操作列

**实现**:
- 添加账号图标按钮（AccountCircleIcon）
- 仅在任务已关联账号时显示
- 点击跳转到账号详情页
- Tooltip 提示："查看账号详情和视频列表"

**代码**:
```typescript
{hasSvAccountId && (
  <Tooltip title="查看账号详情和视频列表">
    <IconButton
      size="small"
      color="primary"
      onClick={() => navigate(shortvideoAccountDetailPath(row.svAccountId!))}
    >
      <AccountCircleIcon fontSize="small" />
    </IconButton>
  </Tooltip>
)}
```

### 3. 类型定义更新 ✅

**文件**: `front/src/api/shortvideo.ts`

添加 `svAccountId` 字段到 `AccountCollectTask` 接口：
```typescript
export interface AccountCollectTask {
  id: number
  ownerId?: number
  accountId?: number | null
  svAccountId?: number | null  // ← 新增
  accountUrl?: string | null
  accountName?: string | null
  // ...
}
```

## 使用流程

### 场景 1: 从采集任务查看账号视频

1. 访问 http://localhost:3000/admin/shortvideo/collect
2. 在任务列表中找到已完成的采集任务
3. **方式 A**: 点击账号名称（蓝色链接）
4. **方式 B**: 点击操作列的账号图标按钮 👤
5. 跳转到账号详情页
6. 切换到"采集视频" Tab
7. 查看该账号下所有采集的视频

### 场景 2: 查看账号统计数据

1. 从采集任务列表点击账号名称
2. 在账号详情页查看：
   - 粉丝数、获赞数、作品数
   - 平均播放量、平均点赞数
   - 平均爆款评分、最高爆款评分
   - 采集次数、采集视频数

### 场景 3: 编辑账号信息

1. 从采集任务列表点击账号名称
2. 在账号详情页点击"编辑"按钮
3. 修改账号分类、标签、备注
4. 点击"保存"

## 用户价值

### 1. 提升效率 ⚡

**之前**: 
- 采集完成后，不知道如何查看账号下的视频
- 需要手动记住账号名称，然后去账号列表搜索
- 流程繁琐，容易遗忘

**现在**:
- 一键跳转到账号详情页
- 直接查看该账号的所有采集视频
- 流程简化，体验流畅

### 2. 信息关联 🔗

**之前**:
- 采集任务和账号信息割裂
- 无法快速了解账号的整体情况

**现在**:
- 采集任务直接关联账号
- 可以查看账号的粉丝数、爆款评分等统计数据
- 信息完整，便于决策

### 3. 数据分析 📊

**之前**:
- 只能看到单次采集任务的视频
- 无法对比同一账号的多次采集

**现在**:
- 账号详情页聚合了该账号的所有采集视频
- 可以查看账号的平均数据和趋势
- 支持数据分析和内容策略优化
