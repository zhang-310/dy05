## 三、风险矩阵

| 风险 | 影响 | 应对 |
|------|------|------|
| tools 实现复杂度高 | 阻塞全链路 Agent 化 | 先支持 OpenAI 兼容模型，Ollama 继续回退 |
| 事实层改造范围大 | 容易拖慢业务功能推进 | 先做 evidence / snapshot 最小闭环 |
| 直播评分口径争议 | 影响业务认知 | 在 Phase 1 就统一指标定义 |
| 短视频实证依赖重 | 依赖 yt-dlp / whisper / ffmpeg / vision model | 先把 evidenceLevel 和降级口径做对 |
| 多租户知识污染修复影响旧逻辑 | 可能导致召回下降 | 采用灰度与回放验证 |
