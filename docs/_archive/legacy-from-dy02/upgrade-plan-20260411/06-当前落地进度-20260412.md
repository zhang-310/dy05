## 2.5 直播闭环继续推进

已完成：

1. `EffectivenessScoreServiceImpl` 已从“假设转化率 + 固定完播率”推进到优先使用真实场次/商品/脚本增量数据：
   - `LiveSessionData`
   - `LiveProductData`
   - `LiveEffectivenessConfig`
   - `LiveScript.viewerDelta / interactionDelta / conversionDelta / executionTime`
2. 商品绑定脚本评分时，优先按商品维度订单与收入计分，不再直接被整场 session 汇总数据覆盖。
3. `LiveRealtimeSuggestionServiceImpl` 现在只会在真实最近弹幕窗口存在时才调用意图分析，不再对空窗口调用 `analyzeBatchIntents(...)`。
4. `ShortVideoAiServiceImpl` 在存在 `deepAnalysisResult` 时，已开始优先消费结构化爆款拆解结果，而不只是拼接一段原始 `analysisResult` 文本。
   同时，在缺少结构化拆解但 transcript / scene 已带 `【推演口播】` / `【推演场景】` 前缀时，也会在降级 prompt 中显式标成“推演口播稿（非 ASR 实录）”“推演场景摘要（非真实抽帧）”。
5. `DailyContentServiceImpl` 已去掉固定“默认话题”回退：
   - `hot_topic` 使用热点话题
   - `viral_video` 使用用户高热视频标题
   - 其他来源使用热点 + 知识库兜底选题
   - 无可用数据时直接返回明确错误，不再静默造假
6. `ContentEffectPredictorImpl` 已开始叠加用户历史已发布短视频基线：
   - 返回 `historicalBaseline`
   - 返回 `baselineAdjustedViewRange`
   - 返回 `baselineAdjustedEngagementRate`
   - 不再只有纯 LLM 预测结果
7. `ViralDeepAnalyzeExecutor` 已修正一处关键降级口径：
   - 多轮分析不再返回 undocumented 的 `partial` evidenceLevel
   - “封面分析 / 无视频文件 / 封面兜底” 统一归入 `inferred`
   - evidenceLevel 现在与主文档里的 `empirical / inferred` 口径一致
8. 短视频下游消费方已开始真正消费 `deepAnalysisResult.evidenceDetails`：
   - `VideoBreakdownKbFormatter` 会输出“证据口径”，并把口播/场景明确标成 `实证`、`推演` 或通用标签
   - `PersonaViralFusionServiceImpl` 的 prompt 已不再把推演素材伪装成 `ASR 转写 / 抽帧分析`
   - 当 transcript / scene 标记为 `inferred` 时，提示词会明确写成“推演稿，非 ASR 实录”“推演场景，非真实抽帧”

## 四、当前仍未完成的关键项

以下项目仍应视为 `upgrade-plan-20260411` 的后续工作，不应误判为完成：

1. **B0 tools 真执行的端到端业务验收仍未补齐**
   `OpenAiCompatibleLlmClient.chatWithToolsStructured()` 现有实现已存在，但还缺完整的业务级验收闭环记录。
2. **直播评分口径仍未完全收口**
   `EffectivenessScoreServiceImpl` 已显著改善，但仍未做到“真实成交、真实观看、真实互动、真实完播”统一口径的最终版。
3. **实时建议链仍需继续实证化**
   `LiveRealtimeSuggestionServiceImpl` 的空窗口问题已修复，但建议命中率、动作追踪、采纳率回写仍未补齐。
4. **短视频专家仍偏“生成器”**
   `ShortVideoAiServiceImpl`、`DailyContentServiceImpl`、`ContentEffectPredictorImpl`、`ViralDeepAnalyzeExecutor` 已明显减少假闭环，但深度分析的实证覆盖率与效果学习链路仍未完全形成闭环。
5. **部分基础能力仍是 TODO**
   例如：
   - `ImageGenerationServiceImpl` 图像保存到对象存储
   - `LiveScriptServiceImpl` 中“接入话术库后实现”的逻辑
6. **行业大脑深层策略服务仍需继续去模板化**
   虽然 `industry/insights` 基线问题已被复核为已改善，但增长路径、协同、战略解释器等仍需继续增强。
