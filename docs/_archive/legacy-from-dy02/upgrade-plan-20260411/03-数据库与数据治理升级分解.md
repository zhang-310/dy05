# 数据库与数据治理升级分解

> 对应主方案：[`00-AI-三大专家系统全面升级计划`](./00-AI-三大专家系统全面升级计划.md)  
> 目标：补齐统一事实层、证据层、回流层、实验层的数据底座

---

## 一、数据升级目标

本轮数据库升级不是单纯加表，而是完成 5 个目标：

1. 让 AI 建议有 **证据链**
2. 让 AI 结果有 **执行回流**
3. 让 AI 策略有 **版本与实验**
4. 让直播/短视频/行业大脑共享 **统一事实快照**
5. 让租户、账号、场次、内容之间边界清晰

---

## 二、建议新增或扩展的数据对象

## D0：证据链

### 新增建议

1. `ai_evidence_trace`
   - 记录建议/分析/生成结果引用了哪些文档、趋势、竞品、直播数据、短视频数据
2. `ai_fact_snapshot`
   - 记录一次专家决策时看到的输入快照
3. `ai_tool_invocation_log`
   - 单次工具调用日志

### 关键字段建议

| 表 | 字段 |
|----|------|
| `ai_evidence_trace` | `trace_id` `owner_type` `owner_id` `evidence_type` `evidence_id` `evidence_level` `score` `summary_json` |
| `ai_fact_snapshot` | `snapshot_type` `snapshot_ref_id` `owner_id` `payload_json` `hash` |
| `ai_tool_invocation_log` | `call_log_id` `tool_name` `arguments_json` `result_json` `status` `latency_ms` `error_msg` |

---

## D1：执行回流

### 新增建议

1. `ai_recommendation_outcome`
   - AI 建议是否被采纳、如何执行、执行后效果如何
2. `ai_content_outcome_link`
   - 直播脚本 / 短视频脚本 / 标题 / 文案 与真实结果的关联

### 扩展建议

1. 扩展 `ai_call_log`
   - 增加 `trace_id`、`evidence_level`、`tool_rounds`、`strategy_version`
2. 扩展 `live_script_effectiveness`
   - 增加 `score_version`、`sample_confidence`、`evidence_json`
3. 扩展短视频表现表
   - 统一内容 ID 与表现归因字段

---

## D2：实验与策略版本

### 新增建议

1. `ai_strategy_version`
   - 记录 prompt / policy / agent workflow / score formula 的版本
2. `ai_experiment`
   - 实验定义
3. `ai_experiment_assignment`
   - 变体分配
4. `ai_experiment_outcome`
   - 实验效果

### 目标

1. Prompt A/B、直播建议、短视频标题策略都可统一纳管
2. 不再靠散落字段跟踪变体

---

## D3：租户与知识治理

### 必做任务

1. 明确平台知识、租户知识、账号知识、场次知识的 scope
2. 去除默认 `1L` 用户兜底带来的知识污染
3. 为知识、图谱、竞品、话术引用增加 scope 字段或统一解析规则

### 建议治理维度

1. `platform`
2. `tenant`
3. `user`
4. `account`
5. `session`
6. `project`

---

## D4：迁移顺序

建议分 4 批 Flyway：

1. **Batch A**
   evidence / tool / snapshot 表
2. **Batch B**
   recommendation outcome / content outcome link
3. **Batch C**
   strategy version / experiment 表
4. **Batch D**
   旧表字段补齐与回填

---

## 三、数据回填任务

1. 从现有 `ai_call_log` 回填 `trace_id`
2. 从知识检索与直播生成链路回补 evidence trace
3. 从 `live_script_effectiveness` 回填评分版本和样本置信度
4. 从短视频表现表建立内容结果关联

---

## 四、验收标准

1. 任一关键 AI 结果可追溯 evidence
2. 任一建议可看到是否采纳与执行结果
3. 任一策略版本可回查到实验结果
4. 不再依赖默认 `1L` 知识兜底
