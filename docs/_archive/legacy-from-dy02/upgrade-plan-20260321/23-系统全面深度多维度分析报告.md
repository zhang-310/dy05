## 二、需求层分析：从 GMV 千万级倒推

### 2.1 产品目标

> 打造护肤品与彩妆类**单场直播 GMV 千万级**，并持续向更高目标迈进。

这意味着系统必须支撑：
- **高单价转化**：客单价 200-2000 元，需精准话术+信任背书
- **大规模选品**：单场 50-120 个 SKU 快速过品
- **实时决策**：弹幕情绪→话术切换→GMV 响应的 <30s 闭环
- **内容矩阵**：5 主播 × 日更 5 条短视频 = 日产 25 条内容
- **数据驱动**：场次 ROI 对比、话术效果归因、产品利润率追踪

### 2.2 三大核心闭环验证

#### 闭环 A: 直播场次全生命周期

```
创建场次 → 选品(50-120品) → AI 生成话术 → 实时提词 → 弹幕监控 → GMV 追踪 → 复盘对比
```

| 步骤 | 代码存在 | 数据连通 | 前端可用 | 评估 |
|------|---------|---------|---------|------|
| 创建场次（含 live_format） | ✅ | ✅ | ✅ | 完整 |
| 批量选品 | ✅ | ✅ | ✅ | 完整 |
| AI 话术生成（SSE 流式） | ✅ | ✅ | ✅ | 完整，15 种 script_type |
| 实时提词面板 | ✅ | ✅ SSE | ✅ PWA | 完整 |
| 弹幕情绪解析 | ✅ DanmakuSentiment | ⚠️ 弹幕数据源不明确 | ✅ UI | 后端就绪，**数据灌入依赖外部** |
| 建议→执行动作 | ⚠️ 框架就绪 | ⚠️ 执行逻辑为 stub | ✅ 按钮有 | **关键缺口** |

## 五、预期与差距

### 5.1 与 GMV 千万级目标的差距

```
目标: 单场直播 GMV 10,000,000+ 元

当前系统能力:
├─ ✅ 高效话术生成（15 种类型 × 5 种直播形态 × SSE 流式）
├─ ✅ 内容矩阵（12 种短视频类型 × 日历排期 × 爆款二创）
├─ ✅ 知识自进化（6 类 Agent × Milvus+ES 混合检索）
├─ ⚠️ 实时 GMV 追踪（计算有/显示无）
├─ ⚠️ 弹幕→行动闭环（框架有/执行逻辑空）
├─ 🔴 支付网关（mock，无法真实交易）
├─ 🔴 AI 视频成片（接口定义有/workflow 是 stub）
├─ 🔴 自动发布抖音（零实现）
└─ 🔴 ROI 分析面板（缺按 format/产品/人设 维度聚合）
```
