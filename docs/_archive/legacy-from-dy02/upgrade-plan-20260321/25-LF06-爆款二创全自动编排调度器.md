# LF-06：爆款二创全自动编排调度器

> **优先级**: P0 | **复杂度**: L | **预计改动**: 后端 2 新文件 + 1 配置 + 前端 1 页面
> **前置依赖**: LF-05 已完成（深度分析+人设融合全部就绪）
> **目标**: 采集完成后自动串联「深度分析→人设匹配→脚本生成→合规检查→排入日历」，用户每天早上打开系统看到的是已生成的脚本草稿

---

## 一、现状问题

当前链路：
```
✅ 自动采集 (4:00-5:00AM)  →  ❌ 手动深度分析  →  ❌ 手动人设匹配  →  ❌ 手动生成脚本  →  ❌ 手动排入日历
```

每个零件都是**真实完整实现**（非 stub），但没有编排器串联。运营每天要手动点 4-5 次按钮。

## 二、目标架构

```
4:00-5:00 AM   ViralVideoCollectorScheduler（已有）
                    ↓ 采集完成，新爆款入库 autoCollected=true
6:00 AM        ViralAutoOrchestrationScheduler（新增）
                    ↓ 查找今日新采集 + 未分析的爆款
               Step 1: 批量深度分析（@Async，并发上限 3）
                    ↓ deepAnalyzeStatus = completed
               Step 2: 为每个爆款匹配所有用户的人设（取 top-1）
                    ↓ matchedPersonaIds 写入
               Step 3: 生成融合二创脚本
                    ↓ remakeStatus = 3 (script_generated)
               Step 4: 合规检查
                    ↓ 附带 complianceWarnings
               Step 5: 自动写入内容日历（status=draft）
                    ↓
8:00 AM        运营上班，看到今日待审核脚本草稿 ✅
```

### 3.1 新建 `ViralAutoOrchestrationScheduler.java`

**文件路径**: `src/main/java/cn/gaifan/douyinOperations/module/shortvideo/config/ViralAutoOrchestrationScheduler.java`

```java
package cn.gaifan.douyinOperations.module.shortvideo.config;

import cn.gaifan.douyinOperations.module.shortvideo.service.impl.ViralAutoOrchestrationService;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.autoconfigure.condition.ConditionalOnProperty;
import org.springframework.scheduling.annotation.Scheduled;
import org.springframework.stereotype.Component;

/**
 * LF-06: 爆款二创全自动编排调度器
 *
 * 在每日采集完成后（6:00 AM），自动串联：
 * 深度分析 → 人设匹配 → 脚本生成 → 合规检查 → 排入内容日历
 *
 * 通过 app.viral.auto-orchestration.enabled=true 开启
 */
@Component
@ConditionalOnProperty(name = "app.viral.auto-orchestration.enabled", havingValue = "true", matchIfMissing = false)
public class ViralAutoOrchestrationScheduler {

    private static final Logger log = LoggerFactory.getLogger(ViralAutoOrchestrationScheduler.class);

    @Autowired
    private ViralAutoOrchestrationService orchestrationService;

    /**
     * 每日 6:00 AM 执行全自动编排
     * 采集任务在 4:00-5:00 AM 完成，留 1 小时缓冲
     */
    @Scheduled(cron = "${app.viral.auto-orchestration.cron:0 0 6 * * ?}")
    public void orchestrate() {
        log.info("[LF-06] 开始执行爆款二创全自动编排...");
        try {
            var result = orchestrationService.runFullOrchestration();
            log.info("[LF-06] 编排完成: 处理 {} 条爆款, 深度分析 {} 成功/{} 失败, 生成脚本 {} 条, 排入日历 {} 条",
                    result.get("totalProcessed"),
                    result.get("analyzeSuccess"),
                    result.get("analyzeFailed"),
                    result.get("scriptsGenerated"),
                    result.get("calendarEntries"));
        } catch (Exception e) {
            log.error("[LF-06] 全自动编排执行失败", e);
        }
    }
}
```

### 3.2 新建 `ViralAutoOrchestrationService.java`

**文件路径**: `src/main/java/cn/gaifan/douyinOperations/module/shortvideo/service/impl/ViralAutoOrchestrationService.java`

```java
package cn.gaifan.douyinOperations.module.shortvideo.service.impl;

import cn.gaifan.douyinOperations.module.douyin.entity.DyPersona;
import cn.gaifan.douyinOperations.module.douyin.repository.DyPersonaRepository;
import cn.gaifan.douyinOperations.module.script.service.ViolationWordService;
import cn.gaifan.douyinOperations.module.shortvideo.entity.SvContentCalendar;
import cn.gaifan.douyinOperations.module.shortvideo.entity.SvViralVideo;
import cn.gaifan.douyinOperations.module.shortvideo.repository.SvContentCalendarRepository;
import cn.gaifan.douyinOperations.module.shortvideo.repository.SvViralVideoRepository;
import cn.gaifan.douyinOperations.module.shortvideo.service.PersonaViralFusionService;
import cn.gaifan.douyinOperations.module.shortvideo.service.ViralVideoDeepAnalysisService;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.transaction.annotation.Transactional;

import java.time.LocalDate;
import java.time.LocalDateTime;
import java.util.*;
import java.util.concurrent.TimeUnit;

/**
 * LF-06: 爆款二创全自动编排服务
 *
 * 全链路：采集后的爆款 → 深度分析 → 人设匹配 → 融合脚本生成 → 合规检查 → 写入内容日历
 */
@Service
public class ViralAutoOrchestrationService {

    private static final Logger log = LoggerFactory.getLogger(ViralAutoOrchestrationService.class);
    private static final ObjectMapper objectMapper = new ObjectMapper();

    @Autowired
    private SvViralVideoRepository viralVideoRepository;

    @Autowired(required = false)
    private ViralVideoDeepAnalysisService deepAnalysisService;

    @Autowired(required = false)
    private PersonaViralFusionService fusionService;

    @Autowired(required = false)
    private DyPersonaRepository personaRepository;

    @Autowired(required = false)
    private SvContentCalendarRepository calendarRepository;

    @Autowired(required = false)
    private ViolationWordService violationWordService;

    /** 每轮最多处理的爆款数量，防止资源耗尽 */
    @Value("${app.viral.auto-orchestration.batch-limit:20}")
    private int batchLimit;

    /** 深度分析超时等待时间（分钟） */
    @Value("${app.viral.auto-orchestration.analyze-timeout-minutes:60}")
    private int analyzeTimeoutMinutes;

    /** 自动生成脚本使用的默认二创类型 */
    @Value("${app.viral.auto-orchestration.default-remake-type:persona_adaptation}")
    private String defaultRemakeType;

    /**
     * 执行全自动编排
     * @return 执行结果统计
     */
    public Map<String, Object> runFullOrchestration() {
        Map<String, Object> result = new LinkedHashMap<>();
        int analyzeSuccess = 0, analyzeFailed = 0, scriptsGenerated = 0, calendarEntries = 0;

        // ────────────────────────────────────────────────
        // Step 0: 查找今日新采集 + 未深度分析的爆款
        // ────────────────────────────────────────────────
        List<SvViralVideo> candidates = findCandidates();
        result.put("totalProcessed", candidates.size());
        log.info("[LF-06] 找到 {} 条待处理爆款", candidates.size());

        if (candidates.isEmpty()) {
            result.put("analyzeSuccess", 0);
            result.put("analyzeFailed", 0);
            result.put("scriptsGenerated", 0);
            result.put("calendarEntries", 0);
            return result;
        }

        // ────────────────────────────────────────────────
        // Step 1: 批量深度分析
        // ────────────────────────────────────────────────
        log.info("[LF-06] Step 1: 开始批量深度分析 ({} 条)...", candidates.size());
        List<SvViralVideo> analyzed = new ArrayList<>();

        if (deepAnalysisService == null) {
            log.warn("[LF-06] ViralVideoDeepAnalysisService 不可用，跳过深度分析");
            analyzeFailed = candidates.size();
        } else {
            for (SvViralVideo viral : candidates) {
                try {
                    // 提交异步分析
                    deepAnalysisService.startDeepAnalyze(viral.getId(), 0L);
                    log.debug("[LF-06] 已提交深度分析: viralId={}", viral.getId());
                } catch (Exception e) {
                    log.warn("[LF-06] 提交深度分析失败: viralId={}, error={}", viral.getId(), e.getMessage());
                    analyzeFailed++;
                }
            }

            // 等待所有分析完成（轮询检查）
            analyzed = waitForAnalysisCompletion(candidates);
            analyzeSuccess = analyzed.size();
            analyzeFailed = candidates.size() - analyzeSuccess;
            log.info("[LF-06] Step 1 完成: {} 成功, {} 失败", analyzeSuccess, analyzeFailed);
        }

        // ────────────────────────────────────────────────
        // Step 2-4: 对每个分析完成的爆款执行人设匹配 + 脚本生成 + 合规检查
        // ────────────────────────────────────────────────
        if (fusionService == null) {
            log.warn("[LF-06] PersonaViralFusionService 不可用，跳过脚本生成");
        } else {
            // 获取所有可用人设（平台级 ownerId=0 + 各用户的）
            List<Long> personaOwnerIds = getActivePersonaOwnerIds();

            for (SvViralVideo viral : analyzed) {
                try {
                    for (Long personaOwnerId : personaOwnerIds) {
                        // Step 2: 人设匹配
                        List<Map<String, Object>> matches = fusionService.matchPersonas(
                                viral.getId(), personaOwnerId);

                        if (matches == null || matches.isEmpty()) {
                            log.debug("[LF-06] viralId={} 无匹配人设 (ownerId={})", viral.getId(), personaOwnerId);
                            continue;
                        }

                        // 取 top-1 最佳匹配
                        Map<String, Object> bestMatch = matches.get(0);
                        Long personaId = toLong(bestMatch.get("personaId"));
                        if (personaId == null) continue;

                        // Step 3: 生成融合二创脚本
                        Map<String, Object> scriptResult = fusionService.generatePersonaFusedScript(
                                viral.getId(), personaId, defaultRemakeType, personaOwnerId);

                        if (scriptResult == null || scriptResult.get("script") == null) {
                            log.warn("[LF-06] viralId={} 脚本生成返回空", viral.getId());
                            continue;
                        }

                        String scriptContent = String.valueOf(scriptResult.get("script"));
                        scriptsGenerated++;

                        // Step 4: 合规检查
                        String complianceNote = "";
                        if (violationWordService != null) {
                            try {
                                var checkResult = violationWordService.check(scriptContent, "video", personaOwnerId);
                                if (checkResult != null && !checkResult.isPassed()) {
                                    complianceNote = "合规检查未通过: " + Arrays.toString(checkResult.getHitWords());
                                    log.info("[LF-06] viralId={} 合规检查命中违规词", viral.getId());
                                }
                            } catch (Exception e) {
                                log.warn("[LF-06] 合规检查异常: {}", e.getMessage());
                            }
                        }

                        // Step 5: 写入内容日历
                        if (calendarRepository != null) {
                            saveToCalendar(viral, personaId, personaOwnerId, scriptContent, complianceNote);
                            calendarEntries++;
                        }

                        // 更新爆款状态为已生成脚本
                        viral.setRemakeStatus(3); // script_generated
                        viralVideoRepository.save(viral);
                    }
                } catch (Exception e) {
                    log.error("[LF-06] 处理 viralId={} 失败: {}", viral.getId(), e.getMessage(), e);
                }
            }
        }

        result.put("analyzeSuccess", analyzeSuccess);
        result.put("analyzeFailed", analyzeFailed);
        result.put("scriptsGenerated", scriptsGenerated);
        result.put("calendarEntries", calendarEntries);
        return result;
    }

    // ─── 内部方法 ──────────────────────────────────────

    /**
     * 查找候选爆款：今日自动采集 + 未深度分析的
     */
    private List<SvViralVideo> findCandidates() {
        // 查找 autoCollected=true, deepAnalyzeStatus IS NULL 或 idle, 最近 24 小时内采集的
        LocalDateTime since = LocalDateTime.now().minusHours(26); // 多留 2 小时缓冲
        // 使用 Repository 查询 — 根据实际 Repository 方法调整
        List<SvViralVideo> all = viralVideoRepository.findAll();
        return all.stream()
                .filter(v -> Boolean.TRUE.equals(v.getAutoCollected()))
                .filter(v -> v.getDeepAnalyzeStatus() == null
                        || "idle".equals(v.getDeepAnalyzeStatus())
                        || v.getDeepAnalyzeStatus().isEmpty())
                .filter(v -> v.getCreateTime() != null && v.getCreateTime().isAfter(since))
                .sorted(Comparator.comparing(SvViralVideo::getCreateTime).reversed())
                .limit(batchLimit)
                .toList();
    }

    /**
     * 等待深度分析完成（最长等待 analyzeTimeoutMinutes）
     */
    private List<SvViralVideo> waitForAnalysisCompletion(List<SvViralVideo> candidates) {
        List<Long> ids = candidates.stream().map(SvViralVideo::getId).toList();
        long deadline = System.currentTimeMillis() + TimeUnit.MINUTES.toMillis(analyzeTimeoutMinutes);
        List<SvViralVideo> completed = new ArrayList<>();

        while (System.currentTimeMillis() < deadline) {
            completed.clear();
            List<SvViralVideo> current = viralVideoRepository.findAllById(ids);
            long pendingCount = 0;

            for (SvViralVideo v : current) {
                String status = v.getDeepAnalyzeStatus();
                if ("completed".equals(status)) {
                    completed.add(v);
                } else if ("failed".equals(status)) {
                    // 失败的不再等待
                } else {
                    pendingCount++;
                }
            }

            if (pendingCount == 0) {
                // 全部完成或失败
                break;
            }

            log.debug("[LF-06] 等待深度分析完成: {} 完成, {} 待处理", completed.size(), pendingCount);

            try {
                Thread.sleep(15_000); // 15 秒轮询一次
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            }
        }

        return completed;
    }

    /**
     * 获取所有有活跃人设的用户 ID
     */
    private List<Long> getActivePersonaOwnerIds() {
        if (personaRepository == null) {
            return List.of(0L); // 仅平台级
        }
        try {
            List<DyPersona> personas = personaRepository.findAll();
            Set<Long> ownerIds = new LinkedHashSet<>();
            for (DyPersona p : personas) {
                if (p.getOwnerId() != null) {
                    ownerIds.add(p.getOwnerId());
                }
            }
            if (ownerIds.isEmpty()) ownerIds.add(0L);
            return new ArrayList<>(ownerIds);
        } catch (Exception e) {
            log.warn("[LF-06] 查询人设列表失败: {}", e.getMessage());
            return List.of(0L);
        }
    }

    /**
     * 将生成的脚本写入内容日历
     */
    @Transactional
    protected void saveToCalendar(SvViralVideo viral, Long personaId,
                                   Long ownerId, String scriptContent, String complianceNote) {
        SvContentCalendar entry = new SvContentCalendar();
        entry.setOwnerId(ownerId);
        entry.setPersonaId(personaId);
        entry.setScheduleDate(LocalDate.now().plusDays(1)); // 排到明天
        entry.setContentType("viral_remake");
        entry.setTitle("[自动] " + truncate(viral.getTitle(), 40));
        // 将脚本内容和合规提示存入备注
        String note = scriptContent;
        if (complianceNote != null && !complianceNote.isEmpty()) {
            note = "⚠️ " + complianceNote + "\n\n" + scriptContent;
        }
        entry.setNote(note);
        entry.setStatus(0); // draft — 待人工审核
        entry.setViralVideoId(viral.getId());
        calendarRepository.save(entry);
    }

    private static String truncate(String s, int max) {
        if (s == null) return "";
        return s.length() > max ? s.substring(0, max) + "..." : s;
    }

    private static Long toLong(Object obj) {
        if (obj == null) return null;
        if (obj instanceof Number n) return n.longValue();
        try { return Long.parseLong(String.valueOf(obj)); }
        catch (NumberFormatException e) { return null; }
    }
}
```

## 六、关键设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 默认关闭 | `enabled: false` | 避免未配置 AI 的环境意外触发 |
| 定时 6:00 AM | 采集 4:00-5:00，留 1 小时缓冲 | 确保采集全部完成 |
| 批量上限 20 | `batch-limit: 20` | 防止 LLM Token 消耗过大 |
| 脚本状态 draft | `status=0` | 人工审核后才发布 |
| 合规检查前置 | 生成后立即检查 | 违规脚本标记但不删除，人工决定 |
| `@ConditionalOnProperty` | Bean 级别控制 | 配置关闭时完全不注册调度器 |
| 可选依赖注入 | `@Autowired(required=false)` | AI 服务未部署时不影响启动 |

## 七、验收标准

1. `mvn compile` 通过（零错误）
2. `cd frontend-react && npx tsc --noEmit` 通过
3. `app.viral.auto-orchestration.enabled=false` 时，`ViralAutoOrchestrationScheduler` Bean 不注册
4. `app.viral.auto-orchestration.enabled=true` 时：
   - 每天 6:00 AM 自动执行
   - 新采集的爆款被深度分析
   - 分析完成后自动匹配人设
   - 生成的脚本写入 `sv_content_calendar`（status=0, title 以 `[自动]` 开头）
   - 合规检查结果附在 note 中
5. V107 Flyway 迁移幂等执行
6. 日志输出 `[LF-06]` 前缀，便于排查
