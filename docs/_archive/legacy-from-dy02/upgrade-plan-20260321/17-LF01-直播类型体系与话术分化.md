# 升级项 LF-01: 直播类型体系 + 话术 SYSTEM_PROMPT 分化

> **优先级**: P0 最高 | **复杂度**: M | **前置**: 无
> **改动范围**: 后端 Entity/SQL + LivePromptBuilder + 前端 LiveSessionFormPage

---

## 问题

`LiveSession.sessionType` 只有 `standard` / `chat_2h`，`LivePromptBuilder.SYSTEM_PROMPT` 是一套通用模板（"亏品3-10秒…"），只适用于重付费过品直播。娱乐直播、自然流、仓播、单品直播**没有对应的话术生成策略**，AI 生成质量受限。

---

## 改动

### 1. SQL Migration: `sql/live/migration-live-format.sql` — 新建

```sql
-- live_format: 直播形式（与 script_style 语气风格解耦）
ALTER TABLE live_session ADD COLUMN IF NOT EXISTS live_format VARCHAR(32) DEFAULT 'heavy_paid_category';
COMMENT ON COLUMN live_session.live_format IS
  '直播形式：content_led=娱乐聊天, organic_micro_paid=自然流+微付费, heavy_paid_category=重付费过品, warehouse=仓播, single_sku=单品';

-- 迁移历史数据：chat_2h → content_led
UPDATE live_session SET live_format = 'content_led' WHERE session_type = 'chat_2h' AND (live_format IS NULL OR live_format = 'heavy_paid_category');

CREATE INDEX IF NOT EXISTS idx_live_session_format ON live_session(live_format) WHERE deleted = 0;
```

**注意**: 枚举值使用 `11-方向基线与防漂移.md` §2.1 冻结的值：`content_led` / `organic_micro_paid` / `heavy_paid_category` / `warehouse` / `single_sku`

### 5. `LivePromptBuilder.java` — 修改 `getSystemPrompt()` 接受 `liveFormat`

在现有 `getSystemPrompt(String platformCode)` 方法中，增加 `liveFormat` 参数：

```java
/**
 * 获取系统提示（含直播形式 + 平台级模板注入）
 * 回退链：ai_prompt_template 表 → sys_config → 按 liveFormat 选择 → 硬编码常量
 */
public String getSystemPrompt(String platformCode, String liveFormat) {
    String base = null;

    // 第一优先：从 ai_prompt_template 表查找（按 liveFormat 查特定模板）
    if (promptTemplateService != null) {
        try {
            String templateCode = liveFormat != null ? "live_system_prompt_" + liveFormat : "live_system_prompt";
            AiPromptTemplate tpl = promptTemplateService.getActiveTemplate(templateCode, "default", 0L);
            if (tpl == null) {
                tpl = promptTemplateService.getActiveTemplate("live_system_prompt", "default", 0L);
            }
            if (tpl != null && tpl.getSystemPrompt() != null && !tpl.getSystemPrompt().isBlank()) {
                base = tpl.getSystemPrompt();
                promptTemplateService.incrementUsage(tpl.getId());
            }
        } catch (Exception ignored) {
        }
    }

    // 第二优先：从 sys_config 读取
    if (base == null) {
        try {
            String val = configService.getRawValueByKey(SYSTEM_PROMPT_CONFIG_KEY);
            if (val != null && !val.isBlank()) base = val;
        } catch (Exception ignored) {
        }
    }

    // 第三优先：按 liveFormat 选择
    if (base == null) {
        base = getSystemPromptByFormat(liveFormat);
    }

    if (platformCode != null && !platformCode.isBlank()) {
        String platformPrompt = platformRuleService.getPlatformPromptTemplate(platformCode);
        if (platformPrompt != null && !platformPrompt.isBlank()) {
            base = base + "\n\n【平台规则】\n" + platformPrompt;
        }
    }
    return base;
}
```

**兼容处理**：保留无参 `getSystemPrompt()` 和单参 `getSystemPrompt(String platformCode)` 不变，内部调用 `getSystemPrompt(platformCode, null)`。

private String buildFormatConstraint(String liveFormat, String scriptType) {
    return switch (liveFormat) {
        case "content_led" ->
            "\n【内容直播约束】\n- 本场以内容留人为主，不急于卖货\n- 聊家常话术禁止强推销\n- 突出主播独特个性，拉停留拉互动\n- 利润品话术集中在高在线时段";
        case "organic_micro_paid" ->
            "\n【自然流约束】\n- 产品用故事化方式自然引入\n- 避免硬性推销语气\n- 每个品先铺垫问题/痛点再引出产品";

            "\n【仓播约束】\n- 极简话术，每品不超过60秒\n- 只报品名+核心卖点+价格+链接号\n- 语速快、有冲击力";
