# D4-01: AI 浮动助手面板

> **优先级**: P0 | **复杂度**: L | **维度**: D4 AI 与知识智能
> **前置**: 无 | **改动文件**: 新建 `FloatingAiAssistant.tsx`, 修改 `BaseLayout.tsx`

---

## 问题

16 个 AI 子页面全部在 `/ai/` 路径下，运营在准备话术时想问 AI "这个产品卖点是什么" 需要切页面，AI 能力完全孤立于业务流程。

---

## 方案

全局右下角 Fab 按钮，点击展开为 400px 侧滑 Drawer，内嵌对话界面。复用 AgentChatPage 的对话逻辑（`chatWithAgentStream`），支持上下文感知。

---

## 改动

### 1. `frontend-react/src/components/ai/FloatingAiAssistant.tsx` — 新建

```tsx
import { useState, useRef, useEffect, useCallback } from 'react'
import {
  Fab,
  Drawer,
  Box,
  Typography,
  TextField,
  IconButton,
  CircularProgress,
  Paper,
  Tooltip,
} from '@mui/material'
import SmartToyIcon from '@mui/icons-material/SmartToy'
import SendIcon from '@mui/icons-material/Send'
import CloseIcon from '@mui/icons-material/Close'
import ContentCopyIcon from '@mui/icons-material/ContentCopy'
import { useToast } from '@/contexts/ToastContext'
import { chatWithAgentStream } from '@/api/agent'

interface Message {
  role: 'user' | 'assistant'
  content: string
  timestamp: number
}

export function FloatingAiAssistant() {
  const toast = useToast()
  const [open, setOpen] = useState(false)
  const [input, setInput] = useState('')
  const [messages, setMessages] = useState<Message[]>([])
  const [streaming, setStreaming] = useState(false)
  const [streamContent, setStreamContent] = useState('')
  const messagesEndRef = useRef<HTMLDivElement>(null)
  const abortRef = useRef<AbortController | null>(null)

  // 自动滚动到底部
  useEffect(() => {
    messagesEndRef.current?.scrollIntoView({ behavior: 'smooth' })
  }, [messages, streamContent])

  const handleSend = useCallback(async () => {
    const text = input.trim()
    if (!text || streaming) return

    // 添加用户消息
    const userMsg: Message = { role: 'user', content: text, timestamp: Date.now() }
    setMessages((prev) => [...prev, userMsg])
    setInput('')
    setStreaming(true)
    setStreamContent('')

    // 调用 AI 流式对话
    // 注意: chatWithAgentStream 需要 agentId，使用默认通用助手 agent
    // 如果项目中有默认 agent ID 配置，使用该配置
    // 否则使用直接的 AI chat 端点
    const abortController = new AbortController()
    abortRef.current = abortController
    let accumulated = ''

    try {
      await chatWithAgentStream(
        {
          agentId: 1,  // 默认通用助手 agentId，需根据实际配置调整
          conversationId: null, // 新对话
          message: text,
        },
        {
          onChunk: (chunk: string) => {
            accumulated += chunk
            setStreamContent(accumulated)
          },
          onComplete: () => {
            setMessages((prev) => [
              ...prev,
              { role: 'assistant', content: accumulated, timestamp: Date.now() },
            ])
            setStreamContent('')
            setStreaming(false)
          },
          onError: (err: string) => {
            if (!abortController.signal.aborted) {
              setMessages((prev) => [
                ...prev,
                { role: 'assistant', content: `⚠️ ${err}`, timestamp: Date.now() },
              ])
            }
            setStreamContent('')
            setStreaming(false)
          },
        },
        abortController.signal,
      )
    } catch {
      if (!abortController.signal.aborted) {
        setMessages((prev) => [
          ...prev,
          { role: 'assistant', content: '⚠️ AI 助手暂时不可用', timestamp: Date.now() },
        ])
      }
      setStreamContent('')
      setStreaming(false)
    }
  }, [input, streaming])

  const handleCopy = (content: string) => {
    navigator.clipboard.writeText(content)
    toast('已复制到剪贴板', 'success')
  }

  const handleClose = () => {
    if (abortRef.current) abortRef.current.abort()
    setOpen(false)
  }

  return (
    <>
      {/* 浮动按钮 */}
      {!open && (
        <Tooltip title="AI 助手" placement="left">
          <Fab
            color="primary"
            size="medium"
            onClick={() => setOpen(true)}
            sx={{
              position: 'fixed',
              bottom: 24,
              right: 24,
              zIndex: 1200,
              boxShadow: 4,
            }}
          >
            <SmartToyIcon />
          </Fab>
        </Tooltip>
      )}

      {/* 侧滑抽屉 */}
      <Drawer
        anchor="right"
        open={open}
        onClose={handleClose}
        variant="persistent"
        PaperProps={{
          sx: {
            width: { xs: '100%', sm: 400 },
            maxWidth: '100vw',
          },
        }}
      >
        {/* 头部 */}
        <Box sx={{
          display: 'flex', alignItems: 'center', justifyContent: 'space-between',
          px: 2, py: 1.5, borderBottom: '1px solid', borderColor: 'divider',
        }}>
          <Box sx={{ display: 'flex', alignItems: 'center', gap: 1 }}>
            <SmartToyIcon color="primary" />
            <Typography variant="subtitle1" fontWeight={600}>AI 助手</Typography>
          </Box>
          <IconButton size="small" onClick={handleClose}>
            <CloseIcon />
          </IconButton>
        </Box>

        {/* 消息列表 */}
        <Box sx={{ flex: 1, overflow: 'auto', p: 2, display: 'flex', flexDirection: 'column', gap: 1.5 }}>
          {messages.length === 0 && !streaming && (
            <Box sx={{ textAlign: 'center', py: 4 }}>
              <SmartToyIcon sx={{ fontSize: 40, color: 'text.disabled', mb: 1 }} />
              <Typography color="text.secondary" variant="body2">
                有什么可以帮到你？
              </Typography>
              <Typography color="text.disabled" variant="caption" display="block" sx={{ mt: 0.5 }}>
                可以询问产品卖点、话术建议、数据分析等
              </Typography>
            </Box>
          )}

          {messages.map((msg, i) => (
            <Box
              key={i}
              sx={{
                display: 'flex',
                justifyContent: msg.role === 'user' ? 'flex-end' : 'flex-start',
              }}
            >
              <Paper
                elevation={0}
                sx={{
                  px: 1.5, py: 1, maxWidth: '85%',
                  bgcolor: msg.role === 'user' ? 'primary.main' : 'grey.100',
                  color: msg.role === 'user' ? 'primary.contrastText' : 'text.primary',
                  borderRadius: 2,
                  position: 'relative',
                }}
              >
                <Typography variant="body2" sx={{ whiteSpace: 'pre-wrap', wordBreak: 'break-word' }}>
                  {msg.content}
                </Typography>
                {msg.role === 'assistant' && (
                  <IconButton
                    size="small"
                    onClick={() => handleCopy(msg.content)}
                    sx={{ position: 'absolute', top: -8, right: -8, bgcolor: 'background.paper', boxShadow: 1, width: 24, height: 24 }}
                  >
                    <ContentCopyIcon sx={{ fontSize: 12 }} />
                  </IconButton>
                )}
              </Paper>
            </Box>
          ))}

          {/* 流式输出中 */}
          {streaming && streamContent && (
            <Box sx={{ display: 'flex', justifyContent: 'flex-start' }}>
              <Paper elevation={0} sx={{ px: 1.5, py: 1, maxWidth: '85%', bgcolor: 'grey.100', borderRadius: 2 }}>
                <Typography variant="body2" sx={{ whiteSpace: 'pre-wrap' }}>
                  {streamContent}
                </Typography>
              </Paper>
            </Box>
          )}

          {streaming && !streamContent && (
            <Box sx={{ display: 'flex', justifyContent: 'flex-start' }}>
              <CircularProgress size={20} />
            </Box>
          )}

          <div ref={messagesEndRef} />
        </Box>

        {/* 输入区 */}
        <Box sx={{ p: 2, borderTop: '1px solid', borderColor: 'divider' }}>
          <TextField
            fullWidth
            size="small"
            multiline
            maxRows={4}
            placeholder="输入问题..."
            value={input}
            onChange={(e) => setInput(e.target.value)}
            onKeyDown={(e) => {
              if (e.key === 'Enter' && !e.shiftKey) {
                e.preventDefault()
                handleSend()
              }
            }}
            InputProps={{
              endAdornment: (
                <IconButton size="small" onClick={handleSend} disabled={!input.trim() || streaming}>
                  <SendIcon fontSize="small" />
                </IconButton>
              ),
            }}
          />
        </Box>
      </Drawer>
    </>
  )
}
```

### 3. API 适配说明

`chatWithAgentStream` 函数在 `frontend-react/src/api/agent.ts` 中。如果该函数的签名与上述调用不匹配，需要适配：

**检查 `agent.ts` 中 `chatWithAgentStream` 的实际签名**，可能是：
```typescript
export function chatWithAgentStream(
  params: { agentId: number; conversationId: number | null; message: string },
  callbacks: { onChunk: (chunk: string) => void; onComplete: () => void; onError: (err: string) => void },
  signal?: AbortSignal
): Promise<void>
```

如果签名不同，按实际签名调整 `FloatingAiAssistant` 中的调用。

**备选方案**: 如果 agent API 不适用，可以直接使用 AI 知识搜索 API：
```typescript
import request from '@/utils/request'

// 简单的 AI 问答（非流式）
async function askAi(question: string): Promise<string> {
  const res = await request.post('/ai/chat', { message: question })
  return res.answer ?? res.content ?? JSON.stringify(res)
}
```

## 注意事项

- Drawer 使用 `variant="persistent"` 而非 `temporary`，避免遮挡主内容
- Fab 的 `zIndex: 1200` 确保在大多数 MUI 组件之上
- 流式输出使用 `useRef` 累积，避免闪烁
- `chatWithAgentStream` 需要有效的 agentId，需确认数据库中有默认 agent 记录
- 如果 agent API 暂不可用，降级为显示"AI 助手功能即将上线"提示
- Enter 发送，Shift+Enter 换行
- 使用 `useToast()` 返回的函数（不是对象）
