## D3-01: 脚本策划分步向导（最大 UX 瓶颈修复）

### 问题

`ScriptPlanningPage.tsx` Tab 0 一次性显示 13+ 输入区（type/theme/viralUrl/viralFormula/remakeType/contentStrategy/contrastType/bgmStyle/comedyDensity/ipType/emotionCurve/duration/shotCount/useKbRef），每个区都是平铺的 Chip 选择器，总高度 2000px+，移动端完全不可用。

### 方案

将 Tab 0 重构为 **Stepper 分步向导**：

| 步骤 | 标题 | 字段 | 必填 |
|------|------|------|------|
| Step 1 | 基础设置 | type + theme + duration | ✅ 必填 |
| Step 2 | 风格选择 | ipType + viralFormula + emotionCurve | ❌ 可选，默认"AI 自动" |
| Step 3 | 高级参数 | remakeType + contentStrategy + contrastType + bgmStyle + comedyDensity + viralUrl + shotCount + useKbRef | ❌ 折叠 |
| Step 4 | 生成结果 | 进度条 + 结果预览 | — |

增加**"快速模式"**按钮：跳过 Step 2/3 直接到 Step 4 开始生成。

### 改动方案

#### 1. 在 Tab 0 区域引入 MUI Stepper

```tsx
import { Stepper, Step, StepLabel, StepContent } from '@mui/material'

// 在 Tab 0 的 JSX 中
const [activeStep, setActiveStep] = useState(0)
const [quickMode, setQuickMode] = useState(false)

const steps = [
  { label: '基础设置', description: '选择类型、主题和时长' },
  { label: '风格选择', description: '选择 IP 类型和风格（可选）' },
  { label: '高级参数', description: '爆款复刻、BGM 等进阶选项' },
  { label: '生成结果', description: '查看生成进度和结果' },
]
```

#### 2. 步骤导航按钮

```tsx
{/* 步骤底部导航 */}
<Box sx={{ display: 'flex', gap: 1, mt: 2 }}>
  {activeStep > 0 && activeStep < 3 && (
    <Button onClick={() => setActiveStep((s) => s - 1)}>上一步</Button>
  )}
  {activeStep < 2 && (
    <Button variant="contained" onClick={() => setActiveStep((s) => s + 1)}>
      下一步
    </Button>
  )}
  {activeStep === 2 && (
    <Button variant="contained" onClick={() => { setActiveStep(3); handleGenerate() }}>
      开始生成
    </Button>
  )}
  {activeStep < 3 && (
    <Button
      variant="outlined"
      color="success"
      onClick={() => { setQuickMode(true); setActiveStep(3); handleGenerate() }}
    >
      ⚡ 快速生成（仅需基础设置）
    </Button>
  )}
</Box>
```

#### 3. 各步骤内容分组

**Step 1 — 基础设置**（从现有代码中提取 type/theme/duration 相关 JSX）：
```tsx
{activeStep === 0 && (
  <Box>
    {/* type 选择器 - 保留现有 RadioGroup/Chip 选择器 */}
    {/* theme 选择器 - 保留现有 6 个场景 Chip */}
    {/* duration 数字输入 */}
  </Box>
)}
```

**Step 2 — 风格选择**（ipType/viralFormula/emotionCurve）：
```tsx
{activeStep === 1 && (
  <Box>
    <Alert severity="info" sx={{ mb: 2 }}>
      此步骤可选。留空则由 AI 自动选择最佳风格。
    </Alert>
    {/* ipType Chip 选择器 */}
    {/* viralFormula Chip 选择器 */}
    {/* emotionCurve 编辑器 */}
  </Box>
)}
```

**Step 3 — 高级参数**（所有其他字段）：
```tsx
{activeStep === 2 && (
  <Box>
    {/* 使用 Accordion 分组展示 */}
    <Accordion defaultExpanded={form.type === 'viral-clone'}>
      <AccordionSummary>爆款复刻参数</AccordionSummary>
      <AccordionDetails>
        {/* viralUrl + remakeType + contentStrategy */}
      </AccordionDetails>
    </Accordion>
    <Accordion>
      <AccordionSummary>视觉与音乐</AccordionSummary>
      <AccordionDetails>
        {/* contrastType + bgmStyle + comedyDensity */}
      </AccordionDetails>
    </Accordion>
    <Accordion>
      <AccordionSummary>生成选项</AccordionSummary>
      <AccordionDetails>
        {/* shotCount + useKbRef + useStreaming */}
      </AccordionDetails>
    </Accordion>
  </Box>
)}
```

**Step 4 — 生成结果**（保留现有的进度条和结果展示代码）：
```tsx
{activeStep === 3 && (
  <Box>
    {/* 保留现有的 progress steps 展示 */}
    {/* 保留现有的 StreamingText 展示 */}
    {/* 生成完成后显示"重新生成"和"保存"按钮 */}
    <Button onClick={() => { setActiveStep(0); resetForm() }}>
      重新开始
    </Button>
  </Box>
)}
```

#### 4. 移动端适配

```tsx
// 移动端使用垂直 Stepper + StepContent
const isMobile = useMediaQuery(theme.breakpoints.down('md'))

{isMobile ? (
  <Stepper activeStep={activeStep} orientation="vertical">

      <Step key={step.label}>
        <StepLabel>{step.label}</StepLabel>

  <>
    <Stepper activeStep={activeStep} sx={{ mb: 3 }}>
```

## D3-02: 模板画廊

### 问题

每次创作都从零开始，没有"护肤品测评""开箱视频""前后对比"等成功模板。

### 方案

在 ScriptPlanningPage **Step 1 上方** 增加模板画廊卡片行。点击模板自动填充表单参数。

### API 来源

已有 API（在 `frontend-react/src/api/sv-script.ts` 中）：
- `listScriptTemplatesByScene(scene: string)` → `ScriptTemplateVO[]`
- `searchScriptTemplates(data?)` → `{ total, list: ScriptTemplateVO[] }`
- `getScriptTemplate(id: number)` → `ScriptTemplateVO`

### 改动

#### 1. 在 Step 1 上方添加模板画廊

```tsx
const [templates, setTemplates] = useState<ScriptTemplateVO[]>([])
const [templatesLoading, setTemplatesLoading] = useState(false)

// 页面加载时获取热门模板
useEffect(() => {
  setTemplatesLoading(true)
  searchScriptTemplates({ page: 0, rows: 8, sortName: 'usageCount', sortOrder: 'desc' })
    .then((res) => setTemplates(res.list ?? []))
    .catch(() => setTemplates([]))
    .finally(() => setTemplatesLoading(false))
}, [])

// 点击模板填充表单
const handleTemplateSelect = (tpl: ScriptTemplateVO) => {
  setForm((prev) => ({
    ...prev,
    type: tpl.type ?? prev.type,
    theme: tpl.theme ?? prev.theme,
    duration: tpl.duration ?? prev.duration,
    ipType: tpl.ipType ?? prev.ipType,
    emotionCurve: tpl.emotionCurve ?? prev.emotionCurve,
    // ... 填充所有匹配字段
  }))
  toast('已应用模板设置', 'success')
}
```

#### 2. 模板画廊 UI

```tsx
{/* 模板画廊 - 放在 Stepper 上方 */}
{templates.length > 0 && (
  <Box sx={{ mb: 3 }}>
    <Typography variant="subtitle1" fontWeight={600} gutterBottom>
      从模板开始
    </Typography>
    <Box sx={{
      display: 'flex',
      gap: 1.5,
      overflowX: 'auto',
      pb: 1,
      '&::-webkit-scrollbar': { height: 4 },
    }}>
      {templates.map((tpl) => (
        <Card
          key={tpl.id}
          variant="outlined"
          sx={{
            minWidth: 160, maxWidth: 200, cursor: 'pointer', flexShrink: 0,
            '&:hover': { borderColor: 'primary.main', boxShadow: 2 },
            transition: 'all 0.2s',
          }}
          onClick={() => handleTemplateSelect(tpl)}
        >
          <CardContent sx={{ py: 1.5, '&:last-child': { pb: 1.5 } }}>
            <Typography variant="subtitle2" fontWeight={600} noWrap>
              {tpl.title ?? tpl.name}
            </Typography>
            <Typography variant="caption" color="text.secondary" noWrap>
              {tpl.theme ?? '通用'}
            </Typography>
            <Box sx={{ display: 'flex', gap: 0.5, mt: 0.5 }}>
              {tpl.usageCount != null && (
                <Chip size="small" label={`${tpl.usageCount}次使用`} variant="outlined" />
              )}
            </Box>
          </CardContent>
        </Card>
      ))}
    </Box>
  </Box>
)}
```

## 注意事项

- 不要删除现有的输入字段代码，只是将其重新组织到不同步骤中
- `handleGenerate` 等现有函数保持不变
- `useStreaming` 开关移到 Step 3 的"生成选项" Accordion 中
- 表单状态 `form` 和 `setForm` 保持不变，只改 JSX 布局
- MUI `Stepper`/`Step`/`StepLabel`/`StepContent` 需要新导入
- MUI `Accordion`/`AccordionSummary`/`AccordionDetails` 需要新导入
- `searchScriptTemplates` 已在 `@/api/shortvideo` 中导出
- `ScriptTemplateVO` 类型需要从 `@/api/sv-script` 或通过 types 文件导出
