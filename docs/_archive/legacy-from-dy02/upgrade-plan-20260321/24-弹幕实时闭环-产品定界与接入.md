# 弹幕 → 实时建议 → 话术执行：产品定界与接入说明

> 与「全面升级总路线图」Phase 2 对齐：区分**手动采纳**与**自动执行**，明确数据源与审计要求。

## 1. 现状（代码已具备）

- **弹幕 ingest**：中间件/Webhook → 既有 `danmaku-ingest` 路径（部署与鉴权按环境配置）。
- **建议生成**：`LiveRealtimeSuggestionServiceImpl` 基于情绪与上下文生成建议。
- **手动执行**：`POST .../live-realtime-panel/execute-suggestion`，`actionType`：`next_slot` / `jump_slot` / `inject_interaction`。

## 2. 产品定界

| 模式 | 说明 | 典型工作量 |
|------|------|------------|
| **A. 手动采纳（默认）** | 运营在实时面板点击采纳后再触发执行；与现有接口一致。 | 已满足 |
| **B. 半自动** | 仅高亮建议，一键采纳（UX 优化），仍不自动调 `execute-suggestion`。 | 小 |
| **C. 全自动** | 建议产生后由策略引擎自动调用 `execute-suggestion`（需阈值、冷却、上限）。 | 中–大 |

**默认策略**：生产环境关闭全自动（见 `app.live.realtime.suggestion.auto-execution-enabled`），避免无人值守误跳转槽位。

## 3. 数据源

- **抖音开放平台弹幕**：需按平台能力接入（长连接/Webhook）；未接入时建议链仅依赖模拟或内部测试流。
- **鉴权**：ingest 与内部 API 分离，ingest 侧使用独立密钥或 mTLS（按部署文档执行）。

## 4. 审计与风控（全自动启用前必做）

- 每次执行记录：`liveSessionId`、`actionType`、`executionSource`（`manual` / `auto` / `system`）、`traceId`、时间戳。
- 风控建议：冷却时间（秒）、单小时最大自动跳转次数、异常熔断（连续失败暂停自动策略）。

## 5. 配置项（application）

见主配置 `app.live.realtime.suggestion.*`：自动执行开关、冷却、单小时最大自动跳转次数。前端调用 `execute-suggestion` 时建议传 `executionSource`，便于日志区分。
