# D2-04: 场次克隆

> **优先级**: P0 | **复杂度**: M | **维度**: D2 直播工作区
> **前置**: 无 | **改动文件**: `LiveSessionPage.tsx`, `live-session.ts`, 后端 Controller/Service

---

## 问题

上一场直播卖了 800 万，想复制同样的商品+话术组合开一场新的直播，但没有克隆功能，需要全部重新选品选话术。

---

### 前端改动

#### 1. `frontend-react/src/api/live-session.ts` — 新增 cloneSession

```typescript
/**
 * 克隆场次（复制基本信息 + 商品 + 话术）
 * @returns 新场次 ID

export function cloneSession(id: number): Promise<number> {
  return request.post('/live/session/clone', { id })
}
```

在 `LiveSessionPage` 组件内增加克隆处理函数：
```typescript
const [cloneLoading, setCloneLoading] = useState<number | null>(null)

const handleClone = async (row: Record<string, unknown>) => {
  const id = row.id as number
  if (!id) return
  setCloneLoading(id)
  try {
    const newId = await cloneSession(id)
    toast('克隆成功，已创建新场次', 'success')
    navigate(`${sessionsBase}/${newId}/edit`)
  } catch (e) {
    toast(e instanceof Error ? e.message : '克隆失败', 'error')
  } finally {
    setCloneLoading(null)
  }
}
```

### 后端改动

#### 1. `LiveSessionController.java` — 新增克隆端点

```java
@PostMapping("/clone")
public RESTResult<Long> cloneSession(@RequestBody Map<String, Object> body,
                                      @CurrentUserId Long userId) {
    Long id = Long.valueOf(body.get("id").toString());
    Long newId = liveSessionService.cloneSession(id, userId);
    return RESTResult.ok(newId);
}
```

#### 2. `LiveSessionService.java` — 新增接口方法

```java
/**
 * 克隆场次，复制基本信息 + 商品 + 话术
 * @param sourceId 源场次 ID
 * @param userId 当前用户 ID
 * @return 新场次 ID
 */
Long cloneSession(Long sourceId, Long userId);
```

#### 3. `LiveSessionServiceImpl.java` — 实现克隆

```java
@Override
@Transactional
public Long cloneSession(Long sourceId, Long userId) {
    // 1. 查询源场次（含权限校验）
    LiveSession source = getByIdWithScope(sourceId, userId);
    if (source == null) {
        throw new BusinessException(ErrorCode.LIVE_SESSION_NOT_FOUND, "场次不存在");
    }

    // 2. 创建新场次（复制基本信息）
    LiveSession target = new LiveSession();
    target.setUserId(userId);
    target.setAccountId(source.getAccountId());
    target.setPersonaId(source.getPersonaId());
    target.setLiveTitle(source.getLiveTitle() + "（副本）");
    target.setLiveDescription(source.getLiveDescription());
    target.setScriptStyle(source.getScriptStyle());
    target.setSessionType(source.getSessionType());
    target.setStatus(0); // 新场次始终为"准备中"
    // 不复制 scheduledTime/startTime/endTime/viewers/likes/totalRevenue
    target = liveSessionRepository.save(target);

    // 3. 复制商品
    List<LiveProduct> products = liveProductRepository.findBySessionIdAndDeleted(sourceId, 0);
    for (LiveProduct p : products) {
        LiveProduct np = new LiveProduct();
        np.setSessionId(target.getId());
        np.setUserId(userId);
        np.setProductId(p.getProductId());
        np.setProductName(p.getProductName());
        np.setPosition(p.getPosition());
        np.setProductType(p.getProductType());
        // 不复制 revenue/saleQuantity（数据归零）
        liveProductRepository.save(np);
    }

    // 4. 复制话术
    List<LiveScript> scripts = liveScriptRepository.findBySessionIdAndDeleted(sourceId, 0);
    for (LiveScript s : scripts) {
        LiveScript ns = new LiveScript();
        ns.setSessionId(target.getId());
        ns.setUserId(userId);
        ns.setScriptContent(s.getScriptContent());
        ns.setScriptType(s.getScriptType());
        ns.setStyle(s.getStyle());
        ns.setRequirement(s.getRequirement());
        ns.setDurationLimitSec(s.getDurationLimitSec());
        ns.setProductId(s.getProductId());
        ns.setSequenceNo(s.getSequenceNo());
        // 不复制 effectivenessScore/executed/executionTime
        liveScriptRepository.save(ns);
    }

    return target.getId();
}
```

## 注意事项

- 克隆不复制时间字段（scheduledTime/startTime/endTime）
- 克隆不复制数据字段（viewers/likes/totalRevenue/saleQuantity）
- 新场次 status 固定为 0（准备中）
- 克隆需要校验当前用户对源场次的访问权限（通过 `getByIdWithScope`）
- `ContentCopyIcon` 来自 `@mui/icons-material/ContentCopy`
- 需要在 `LiveProductRepository` 中确认有 `findBySessionIdAndDeleted` 方法，若无需新增
- 需要在 `LiveScriptRepository` 中确认有 `findBySessionIdAndDeleted` 方法，若无需新增
