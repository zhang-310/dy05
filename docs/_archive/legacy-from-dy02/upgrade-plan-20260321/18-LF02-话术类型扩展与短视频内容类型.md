# 升级项 LF-02: 话术类型扩展 + 短视频内容类型扩展

> **优先级**: P0 高 | **复杂度**: M | **前置**: LF-01 完成后可独立实施
> **改动范围**: 后端 Entity/SQL + LivePromptBuilder + ScriptGenerationService + 前端 ScriptPlanningPage + LiveSessionDetailPage

---

## 问题

### A. 直播话术类型只有 6 种

`LiveScript.scriptType` 只有 `opening / product / transition / closing / chat / custom`，缺少**互动引导、福利话术、逼单促单、憋单蓄水、情绪价值、快速过品（仓播）、深度单品、痛点放大、用户证言**等关键类型。运营在创建话术时找不到匹配的类型，全部堆到 `custom`。

### B. 短视频脚本类型只有 3 种

`SvScript.scriptType` 只有 `viral_clone / daily / soft_ad`，日更 5 条短视频需要测评、教程、开箱、种草、段子等类型区分，目前全部混在 `daily` 里，无法按类型统计和优化。

## 注意事项

- `script_type` 是 VARCHAR(32)，新类型值直接使用即可，**无需 ALTER TABLE**
- 现有 6 种话术类型和 3 种脚本类型**保持不变**，不改语义
- `emotional` 类型复用已有的 `buildEmotionalUserPrompt` 逻辑
- `rapid_intro` 主要搭配 `warehouse` 直播形式使用
- `deep_sell` 主要搭配 `single_sku` 直播形式使用
- 短视频脚本类型的 Prompt 策略可后续通过 `ai_prompt_template` 表热更新
