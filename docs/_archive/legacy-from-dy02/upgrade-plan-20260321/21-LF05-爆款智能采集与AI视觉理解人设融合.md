### 关键缺失（❌ 本次升级）

| 缺失 | 影响 | 升级目标 |
|------|------|----------|
| **ASR 未接入爆款分析** | `analyzeViralWithLlm` 只用标题文本，不提取口播台词 | 视频 URL → ffmpeg 抽音频 → Whisper 转写 → 全文口播稿 |
| **抽帧未接入爆款分析** | 有 `extractFrames` + `analyzeFrames` 但爆款分析不调用 | 视频 URL → ffmpeg 抽帧 → 视觉模型逐帧描述场景 |
| **无垂直类目采集** | 只有泛热搜，缺少"护肤/彩妆/美妆"垂类爆款 | 行业关键词 + 标签过滤 + 多数据源 |
| **无"可替换变量表"** | 二创是泛泛的 SOP 文本，不是"保留结构+替换变量" | 输出：必须保留的结构 + 可替换变量（人设/产品/场景/口头禅） |
| **爆款→人设融合断裂** | 检测到爆款后没有自动匹配人设 + 生成人设化脚本 | 爆款×人设 自动匹配 + 融合生成 |
| **脚本生成单一** | 只有 `replicateViral` 的通用 SOP 文本，没有结构化脚本 | 生成分镜级脚本（hook/body/cta + shots） |
| **无实时热点二创** | 热点有时效性，但没有"热点+人设+产品"三要素融合 | 热点感知的即时二创管线 |
| **二创后无合规校验** | 生成脚本后没有过合规检测 | 接入已有 `ViolationCheckResultVO` |
| **无 AI 成片入口** | `SvVideoGenerationTask` 存在但无前端触发闭环 | 一键从脚本生成 AI 参考成片（Seedance/Kling） |

## 二、整体架构设计（升级后）

```
视频输入层              AI 理解层（核心增量）        融合创作层              输出层
┌────────────┐     ┌───────────────────┐      ┌───────────────┐     ┌──────────────┐
│ 爆款视频 URL │     │ ① ffmpeg 抽音频    │      │ 人设匹配引擎   │     │ 结构化脚本    │
│ (平台/手动) │──→  │    ↓              │      │ (向量/LLM)    │     │ (分镜+台词)  │
├────────────┤     │ ② Whisper ASR     │      ├───────────────┤     ├──────────────┤
│ 抖音热搜    │     │    → 全文口播稿    │  ──→ │ 可替换变量表   │ ──→ │ 人设化二创    │
│ (TianAPI)  │     │    + 按句时间戳    │      │ (结构保留     │     │ (口癖重写)   │
├────────────┤     ├───────────────────┤      │  +变量替换)   │     ├──────────────┤
│ 垂类关键词  │     │ ③ ffmpeg 抽帧     │      ├───────────────┤     │ AI 参考成片   │
│ (护肤/彩妆) │     │    (每2-5秒1帧)   │      │ 热点融合引擎   │     │ (Seedance/   │
├────────────┤     │ ④ 视觉模型逐帧分析 │      │ (热点×人设×品) │     │  Kling)      │
│ 竞品监控    │     │    → 场景/人物/    │      ├───────────────┤     ├──────────────┤
│ (二期)     │     │      道具/镜头描述  │      │ 合规校验      │     │ 拍摄任务单    │
└────────────┘     ├───────────────────┤      │ (禁用词+行业) │     │ (Shooting)   │
                   │ ⑤ LLM 综合拆解    │      └───────────────┘     └──────────────┘
                   │  文案+场景+结构    │
                   │  → 爆款亮点假设    │
                   │  → 可替换变量表    │
                   └───────────────────┘
```

### 核心理念（来自 Cursor 分析，已验证）

**没有"魔法一键"**：文案靠**听**（ASR），场景靠**看**（抽帧+视觉模型），合在一起 LLM 才能稳定讲清"这条为什么在爆"。

**不需要火山"短视频专用模型"**：ASR + 多模态视觉 Chat + 文本 LLM 三者组合即可。视频生成模型（Seedance/Kling）只用于"AI 出片"阶段，不是"读懂"的必要条件。

**二创 = 结构借鉴 + 原创表达**：先输出"可替换变量"（人设、产品、场景、口头禅）和"必须保留的结构"（钩子类型、信息顺序），再按主播口癖重写——不是逐句抄袭。

#### A-2. `ViralVideoCollectorScheduler.java` — 新增垂类采集定时任务

```java
/**
 * 垂类爆款采集：按行业关键词过滤热搜 + 主动标签匹配
 * 每日 5:00 AM（在现有 4:00/4:30 采集之后）
 */
@Scheduled(cron = "${app.viral-collector.vertical-cron:0 0 5 * * ?}")
public void collectVerticalVirals() {
    log.info("[垂类采集] 开始");
    VerticalCollector config = businessParamConfig.getVerticalCollector();
    if (config == null) return;
    List<String> keywords = config.getIndustryKeywords();
    if (keywords == null || keywords.isEmpty()) return;

    int collected = 0;

    // 策略1: 从热搜中过滤含行业关键词的条目
    List<SvHotTopic> topics = hotTopicRepository.findAll();
    for (SvHotTopic topic : topics) {
        if (!"active".equals(topic.getStatus())) continue;
        if (topic.getHeatScore() < config.getMinHeatScore()) continue;

        boolean matchesIndustry = keywords.stream()
                .anyMatch(kw -> topic.getTitle() != null && topic.getTitle().contains(kw));
        if (!matchesIndustry) continue;

        // 去重检查
        if (viralVideoRepository.findByOwnerIdAndDouyinVideoIdAndDeleted(
                0L, "topic_" + topic.getId(), 0).isPresent()) continue;

        SvViralVideo viral = new SvViralVideo();
        viral.setOwnerId(0L);
        viral.setTitle(topic.getTitle());
        viral.setAutoCollected(true);
        viral.setCollectSource("vertical_industry");
        viral.setDouyinVideoId("topic_" + topic.getId());
        viral.setIndustryTags(buildIndustryTagsJson(topic.getTitle(), keywords));
        viral.setRemakeStatus(0);
        viralVideoRepository.save(viral);
        collected++;

        if (collected >= config.getBatchLimit()) break;
    }

    // 策略2: 从已有 douyin_video 中按标签/描述匹配
    // （与现有 collectViralFromDouyinVideos 类似，但增加关键词过滤）
    // 此处省略，逻辑同上但数据源为 dy_video 表

    log.info("[垂类采集] 完成，新增 {} 条垂类爆款", collected);
}

private String buildIndustryTagsJson(String title, List<String> keywords) {
    List<String> matched = keywords.stream()
            .filter(kw -> title != null && title.contains(kw))
            .toList();
    try {
        return new com.fasterxml.jackson.databind.ObjectMapper().writeValueAsString(matched);
    } catch (Exception e) {
        return "[]";
    }
}
```

#### B-1. 新建 `ViralVideoDeepAnalysisServiceImpl.java` — 核心实现

```java
package cn.gaifan.douyinOperations.module.shortvideo.service.impl;

import cn.gaifan.douyinOperations.module.ai.service.VideoAnalysisService;
import cn.gaifan.douyinOperations.module.ai.service.LlmClient;
import cn.gaifan.douyinOperations.module.ai.service.AiModelConfigService;
import cn.gaifan.douyinOperations.module.shortvideo.entity.SvViralVideo;
import cn.gaifan.douyinOperations.module.shortvideo.repository.SvViralVideoRepository;
import cn.gaifan.douyinOperations.module.shortvideo.service.ViralVideoDeepAnalysisService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Service;

import java.util.*;

@Slf4j
@Service
@RequiredArgsConstructor
public class ViralVideoDeepAnalysisServiceImpl implements ViralVideoDeepAnalysisService {

    private final SvViralVideoRepository viralVideoRepository;

    @Autowired(required = false)
    private VideoAnalysisService videoAnalysisService;

    @Autowired(required = false)
    private LlmClient llmClient;

    @Autowired(required = false)
    private AiModelConfigService aiModelConfigService;

    /**
     * 固定输出结构模板 — LLM 按此模板拆解，便于主播执行和二次生成
     */
    private static final String DEEP_ANALYSIS_PROMPT = """
        你是短视频爆款分析专家。请基于以下信息，按固定结构输出分析报告 JSON。

        【口播文案（ASR 转写）】
        %s

        【画面场景描述（逐帧）】
        %s

        【视频元数据】
        标题: %s
        点赞: %s | 分享: %s | 评论: %s | 播放: %s

        请输出以下固定结构 JSON：
        {
          "transcript": {
            "fullText": "完整口播稿（清洗后）",
            "sentences": [
              {"time": "0:00-0:03", "text": "台词内容", "role": "hook/content/cta"}
            ],
            "goldenSentences": ["金句1", "金句2"]
          },
          "structure": {
            "hook": {"time": "0-3s", "type": "悬念/冲突/提问/反转/共情", "text": "钩子内容", "score": 0-100},
            "painPoint": {"time": "3-8s", "description": "痛点/好奇引发"},
            "proof": {"time": "8-20s", "description": "证明/演示/对比"},
            "trust": {"time": "20-25s", "description": "信任/背书/用户证言"},
            "cta": {"time": "最后3s", "text": "互动/转化句", "type": "点赞/关注/购买/评论"}
          },
          "scenes": [
            {"time": "0-3s", "environment": "场景", "person": "人物", "props": "道具", "camera": "镜头类型", "mood": "情绪氛围"}
          ],
          "viralHypotheses": {
            "emotionTrigger": "踩中什么情绪/身份认同",
            "infoDensity": "high/medium/low",
            "rhythmPattern": "节奏特征",
            "visualContrast": "视觉对比/反差",
            "controversyFactor": "争议点（如有）",
            "trendAlignment": "是否与当前热点/音乐/模板同构",
            "replicability": "easy/medium/hard"
          },
          "remakeVariableTable": {
            "mustKeep": ["必须保留的结构元素1", "元素2"],
            "replaceable": [
              {"variable": "人设", "original": "原视频人设", "suggestion": "替换为你的人设风格"},
              {"variable": "产品", "original": "原视频产品", "suggestion": "替换为你的产品"},
              {"variable": "场景", "original": "原场景", "suggestion": "可替换场景"},
              {"variable": "口头禅", "original": "原口头禅", "suggestion": "替换为主播口癖"},
              {"variable": "BGM", "original": "原BGM风格", "suggestion": "同风格替换"}
            ]
          },
          "viralScore": 0-100,
          "bestRemakeType": "form_imitation/content_flip/element_recombination/dimensional_upgrade",
          "complianceNotes": ["合规注意事项"]
        }
        只输出 JSON，不要其他文字。
        """;

    @Override
    public Map<String, Object> deepAnalyze(Long viralVideoId, Long userId) {
        SvViralVideo viral = viralVideoRepository.findById(viralVideoId).orElse(null);
        if (viral == null) return Map.of("error", "视频不存在");

        Map<String, Object> result = new LinkedHashMap<>();
        result.put("viralVideoId", viralVideoId);

        // Step 1: ASR 提取口播文案
        String transcript = "（无视频文件，仅有标题和元数据）";
        if (videoAnalysisService != null && viral.getVideoUrl() != null && !viral.getVideoUrl().isBlank()) {
            try {
                log.info("[深度分析] Step 1: ASR 转写 viralId={}", viralVideoId);
                // VideoAnalysisService: downloadVideo → extractAudio → transcribeAudio
                String videoPath = videoAnalysisService.downloadVideo(viral.getVideoUrl());
                if (videoPath != null) {
                    String audioPath = videoAnalysisService.extractAudio(videoPath);
                    if (audioPath != null) {
                        transcript = videoAnalysisService.transcribeAudio(audioPath);
                    }
                }
            } catch (Exception e) {
                log.warn("[深度分析] ASR 失败 viralId={}: {}", viralVideoId, e.getMessage());
                transcript = "（ASR 转写失败：" + e.getMessage() + "）";
            }
        }
        result.put("transcript", transcript);

        // Step 2: 抽帧 + 视觉模型场景描述
        String sceneDescriptions = "（无视频文件）";
        if (videoAnalysisService != null && viral.getVideoUrl() != null && !viral.getVideoUrl().isBlank()) {
            try {
                log.info("[深度分析] Step 2: 抽帧+视觉分析 viralId={}", viralVideoId);
                String videoPath = videoAnalysisService.downloadVideo(viral.getVideoUrl());
                if (videoPath != null) {
                    // 每 2 秒抽 1 帧（短视频通常 15-60 秒，产生 8-30 帧，取前 10 帧）
                    List<String> framePaths = videoAnalysisService.extractFrames(videoPath, 0.5); // 0.5 fps = 每2秒1帧
                    if (framePaths != null && !framePaths.isEmpty()) {
                        List<String> descriptions = videoAnalysisService.analyzeFrames(
                                framePaths.subList(0, Math.min(10, framePaths.size())),
                                "描述这一帧的场景：环境、人物表情动作、道具产品、镜头构图、文字覆盖、情绪氛围。用中文，一句话概括。"
                        );
                        sceneDescriptions = String.join("\n", descriptions);
                    }
                }
            } catch (Exception e) {
                log.warn("[深度分析] 抽帧分析失败 viralId={}: {}", viralVideoId, e.getMessage());
                sceneDescriptions = "（抽帧分析失败：" + e.getMessage() + "）";
            }
        }
        // 如果没有视频文件但有封面，至少分析封面
        if ("（无视频文件）".equals(sceneDescriptions) && viral.getCoverUrl() != null) {
            try {
                if (llmClient != null && aiModelConfigService != null) {
                    var model = aiModelConfigService.getDefaultModel();
                    var resp = llmClient.chatWithImage(model, "你是视觉分析专家。",
                            "描述这张短视频封面：场景、人物、产品、文字、构图、色调。用中文。",
                            List.of(viral.getCoverUrl()));
                    if (resp != null && resp.success()) {
                        sceneDescriptions = "封面分析: " + resp.content();
                    }
                }
            } catch (Exception e) {
                log.warn("[深度分析] 封面分析失败: {}", e.getMessage());
            }
        }
        result.put("sceneDescriptions", sceneDescriptions);

        // Step 3: LLM 综合拆解 — 按固定结构模板输出
        if (llmClient != null && aiModelConfigService != null) {
            try {
                log.info("[深度分析] Step 3: LLM 综合拆解 viralId={}", viralVideoId);
                String prompt = String.format(DEEP_ANALYSIS_PROMPT,
                        transcript,
                        sceneDescriptions,
                        viral.getTitle() != null ? viral.getTitle() : "",
                        viral.getLikeCount() != null ? viral.getLikeCount() : "N/A",
                        viral.getShareCount() != null ? viral.getShareCount() : "N/A",
                        "N/A", // commentCount (if available)
                        viral.getViewCount() != null ? viral.getViewCount() : "N/A"
                );

                var resp = llmClient.chat(
                        aiModelConfigService.getDefaultModel(),
                        "你是短视频爆款分析专家，擅长拆解爆款结构并输出可执行的二创变量表。",
                        prompt
                );

                if (resp != null && resp.success()) {
                    result.put("analysis", resp.content());
                    result.put("tokensUsed", resp.tokensUsed());

                    // 保存分析结果到 sv_viral_video
                    viral.setAnalysisResult(resp.content());
                    viralVideoRepository.save(viral);
                }
            } catch (Exception e) {
                log.error("[深度分析] LLM 拆解失败: {}", e.getMessage());
                result.put("error", "LLM 分析失败: " + e.getMessage());
            }
        }

        result.put("status", "completed");
        return result;
    }

    @Override
    public String extractTranscript(Long viralVideoId) {
        SvViralVideo viral = viralVideoRepository.findById(viralVideoId).orElse(null);
        if (viral == null || viral.getVideoUrl() == null) return null;
        if (videoAnalysisService == null) return null;

        try {
            String videoPath = videoAnalysisService.downloadVideo(viral.getVideoUrl());
            String audioPath = videoAnalysisService.extractAudio(videoPath);
            return videoAnalysisService.transcribeAudio(audioPath);
        } catch (Exception e) {
            log.error("[ASR] viralId={} 失败: {}", viralVideoId, e.getMessage());
            return null;
        }
    }

    @Override
    public String extractSceneDescriptions(Long viralVideoId) {
        SvViralVideo viral = viralVideoRepository.findById(viralVideoId).orElse(null);
        if (viral == null || viral.getVideoUrl() == null) return null;
        if (videoAnalysisService == null) return null;

        try {
            String videoPath = videoAnalysisService.downloadVideo(viral.getVideoUrl());
            List<String> framePaths = videoAnalysisService.extractFrames(videoPath, 0.5);
            if (framePaths == null || framePaths.isEmpty()) return null;
            List<String> descriptions = videoAnalysisService.analyzeFrames(
                    framePaths.subList(0, Math.min(10, framePaths.size())),
                    "描述场景：环境、人物、道具、镜头、情绪。中文一句话。"
            );
            return String.join("\n", descriptions);
        } catch (Exception e) {
            log.error("[抽帧] viralId={} 失败: {}", viralVideoId, e.getMessage());
            return null;
        }
    }
}
```

## 七、注意事项

- **深度分析依赖 ffmpeg + Whisper**：服务器必须安装 `ffmpeg`（音频/帧提取）和 `whisper`（OpenAI Whisper CLI，ASR 转写）。Docker 镜像需包含这两个工具。缺少时自动降级为纯文本分析
- **视觉模型要求**：`vision-model-name` 必须配置为支持 `chatWithImage` 的多模态模型（如 GPT-4o、Claude 3.x、Qwen-VL 等），否则视觉分析降级为纯文本
- **视频下载临时文件**：`VideoAnalysisService.downloadVideo()` 会下载视频到临时目录，分析完成后需清理（已有机制）
- **封面 URL 可达性**：`chatWithImage` 要求图片 URL 为**公网可访问**，内部存储需先生成临时签名 URL
- **Token 消耗**：深度分析（ASR+抽帧+LLM 拆解）+ 人设融合生成一套流程约消耗 5000-8000 tokens，注意配额监控
- **人设匹配准确性**：MVP 版本基于文本描述匹配，二期可升级为向量相似度（Milvus）
- 所有新 Service 可选依赖用 `@Autowired(required = false)` + null 检查
- `VerticalCollector` 配置在 `BusinessParamConfig` 中新增，需同步更新 `application.yml` 和 `application-docker.yml`
- **旧服务迁移**：如项目中存在 `ViralVideoVisionAnalysisService`（仅封面分析），应删除并统一到 `ViralVideoDeepAnalysisService`
- **`deepAnalyze` 耗时较长**：下载+ASR+抽帧+多模态分析可能需要 30-120 秒，前端应显示进度提示或改为异步任务+轮询
