# 升级方向基线与防漂移（策划冻结件）

> **日期**: 2026-03-21 | **性质**: 决策备忘，先于大规模开发对齐  
> **目的**: 方向一次定准，减少「先做 A 再发现与 B 冲突」导致的连锁重构。

---

## 1. 北极星（唯一产品叙事）

**内部护肤彩妆直播 GMV 千万级** 依赖两条并行能力，**缺一不可但职责分离**：

| 轨道 | 回答的问题 | 成功判据 |
|------|------------|----------|
| **内容产能轨** | 每天有没有足够好的**短视频文案**、**直播话术**、**爆款二创**落地？ | 策划 → 审核 → 拍摄/开播 **不断档**；形态（娱乐/付费/仓播/单品等）**可复用模板** |
| **经营看数轨** | 钱和场次是否**可见、可对比、可复盘**？ | GMV/场次/实时中控 **不靠口口相传** |

**防漂移规则**：任何功能需求先归类到上表某一轨；若同时涉及两轨，**拆成两个用户故事**，避免一个 PR 里混写两套成功标准。

## 2. 必须先冻结的「数据契约」（改一次全员疼）

下列字段/枚举应在**第一版实现前就写入本页并同步 Entity / OpenAPI**，后续只**加值不改语义**：

### 2.1 直播场次：`live_format`（建议新增，与 `script_style` 解耦）

- **`script_style`**：保留为「语气/人设表达」（如 professional、casual），**不承载**排品结构。  
- **`live_format`**：承载**排品与流量策略**，与话术结构模板一一对应（示例枚举，可再评审后定稿）：

| 值 | 含义（业务） |
|----|----------------|
| `content_led` | 娱乐/内容向，弱带货穿插 |
| `organic_micro_paid` | 自然流为主 + 微付费，话术拉停留、低频挂车 |
| `heavy_paid_category` | 重付费、过品类、高密度卖点与过款 |
| `warehouse` | 仓播：库存/规格/发货话术为主 |
| `single_sku` | 单品打爆：单 SKU 深度循环 |

**防漂移**：话术生成、排品建议、短视频预热类型**只读 `live_format`**，不要再用自由文本或混在 `live_description` 里。

### 2.2 短视频项目/脚本：已有类型保持不变

- `viral_clone` / `daily` / `soft_ad`（及与 `SvProject.projectType`、`SvScriptSaveVO.scriptType` 一致）**语义冻结**。  
- 新增类型须：**补本表 + 错误码/前端枚举 + 生成服务分支**，禁止「字符串悄悄多一个值」。

### 2.3 爆款二创：状态机冻结

最小集合（可与 `10-内部运营体系战略规划.md` §7.3 对齐，编号可调整但**含义不变**）：

```
0 未处理 → 1 已推荐 → 2 运营已确认 → 3 脚本已生成 → 4 已进拍摄/任务 → 5 已完成
```

**防漂移**：前端列表筛选、企微推送、调度任务**只依赖该状态**，不另起「字符串阶段」。

## 3. 架构层面：单一事实来源（避免 Dashboard 双轨）

- **角色首页**：以 `10-内部运营体系战略规划.md` 为准——**按 `roleCode` 分发首屏**（6 角色路径）。  
- **01-Dashboard业务重构.md** 中的业务卡片、GMV 环比、在播横幅、就绪度等 **作为可复用模块/组件**，嵌入各角色首页或统一的 `DashboardPage` 容器，**禁止**长期维护两套互不等价的「大盘页面」。

**防漂移口令**：「**指标与组件只有一份实现，角色页只做组合与权限裁剪**」。

## 5. 明确延后（防止范围膨胀导致方向偏移）

以下**不进入 F0/F1**，避免拖累主线：

- 跨模块 KPI 大屏的**全量**数据打通（P1 D5-03 可整页后移）。  
- 进化引擎**表单化规则构建器**（P1 D4-03）可与内容轨**解耦排期**。  
- 企微 **10 种推送场景一次上齐**——先 **晨报 + 二创确认** 两条，其余按迭代加。
