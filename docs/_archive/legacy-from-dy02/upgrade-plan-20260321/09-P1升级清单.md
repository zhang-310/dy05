## D2-05: "下一步行动"引导

**复杂度**: M | **改动文件**: `LiveSessionDetailPage.tsx`, `useLiveSessionDetail.ts`

**问题**: 场次详情页没有明确的"下一步"指引，新用户不知道创建场次后该做什么。

**方案**: 在 SessionDetailPage 顶部增加 Stepper 组件，显示当前进度和下一步按钮。

```
步骤: 创建场次 → 选品 → 生成话术 → 合规检查 → 开播
```

**改动**:
1. 在 `LiveSessionDetailPage.tsx` 顶部（Card 上方）增加 MUI `Stepper`
2. 步骤状态从 session 数据计算（productCount > 0 → 步骤2完成，scriptCount > 0 → 步骤3完成 等）
3. 当前步骤高亮 + "下一步"按钮（跳转到对应操作页面）

## D8-02: 操作失败重试

**复杂度**: M | **改动文件**: `request.ts`, `ToastContext.tsx`

**问题**: API 调用失败后只显示错误 toast，用户需要手动重新操作。

**方案**:
1. Toast 组件增加"重试"按钮支持
2. AI 生成类操作（话术/脚本）失败时自动重试 1 次

**改动**:
1. `ToastContext.tsx` 的 show 函数增加可选 action 参数: `toast('失败', 'error', { action: { label: '重试', onClick: retryFn } })`
2. `request.ts` 增加可选的重试中间件（仅对 AI 生成端点生效）

## D8-03: 错误消息上下文化

**复杂度**: S | **改动文件**: `error-codes.ts`

**问题**: 错误消息只说"操作失败"，不告诉用户该怎么做。

**方案**: `error-codes.ts` 每个错误码增加 `suggestion` 字段。

```typescript
// 示例
export const ERROR_CODES: Record<number, { message: string; suggestion?: string }> = {
  2001: { message: '用户名或密码错误', suggestion: '请检查登录信息后重试' },
  3001: { message: '直播场次不存在', suggestion: '可能已被删除，请刷新页面' },
  4001: { message: 'AI 配额已用完', suggestion: '请联系管理员增加配额' },
  // ...
}
```

前端错误处理时优先显示 suggestion。
