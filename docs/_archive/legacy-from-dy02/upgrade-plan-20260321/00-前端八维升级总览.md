## 验证方式

1. **编译检查**: `cd frontend-react && npm run type-check` 通过（测试文件与 `@testing-library/react` 类型已对齐）
2. **Lint**: `npm run lint`（jsx-a11y 等 warn，当前 `--max-warnings 500`）
3. **E2E**: `npm run test:e2e -- e2e/golden-paths.spec.ts e2e/a11y-i18n.spec.ts`
4. **视觉验证**: Dashboard、ScriptPlanningPage、LiveSessionPage、LiveRealtimePanel 四个核心页面
5. **移动端**: Chrome DevTools 模拟 375px / 768px 宽度
6. **用户流**: "创建场次→选品→生成话术→开播→查看 GMV" 完整流程
