# P2 占位项规格（季度前排期用）

对应 `00-前端八维升级总览` 中 D1-04、D5-02、D7-03、D8-04 占位。实施前需产品/研发共同补齐本节「验收要点」后再排入迭代。

## D1-04 全局搜索扩展

- **范围**：命令面板之外的全局搜索（含跨模块实体：场次、商品、脚本标题等）。
- **依赖**：统一搜索 API 或 Elasticsearch 索引契约；分页与权限过滤策略。
- **验收**：单框输入、200ms 内首屏结果、无权限数据不可见。
- **落地（2026-03）**：`POST /api/v1/search/global` + `GlobalSearchServiceImpl`（JPA Specification，`DataScopeService` 隔离）；前端 Ctrl/⌘+K 命令面板 200ms 防抖拉取实体结果（与 W-06 话术混合检索 `api/search.ts` 并存）。

## D5-02 经营驾驶舱（多维度下钻）

- **范围**：在 `POST /dashboard/business` 之上增加多维度切片（账号/品类/时段）与导出。
- **依赖**：分析事实表或物化视图；与 `app.scope` 行业范围一致。
- **验收**：筛选器 ≥3 维、导出 CSV、大屏 1080p 可读。
- **落地（2026-03）**：`POST /api/v1/dashboard/cockpit-export` 返回 UTF-8 CSV（场次 id、标题、账号、用户、状态、时间、GMV、排品条数）；统一 KPI 页提供日期/账号/状态/时段/品类 ≥3 维筛选 + 导出；大屏可读依赖 MUI Grid 响应式布局。

## D7-03 国际化（i18n）骨架

- **范围**：路由级语言前缀或账户级语言偏好；文案外置 JSON；日期/数字本地化。
- **依赖**：`react-i18next` 或等价方案；关键页面清单（≤20 页先行）。
- **验收**：中/英切换无硬编码中文漏网；E2E 覆盖登录+Dashboard。

## D8-04 可访问性（a11y）专项

- **范围**：焦点顺序、ARIA 标签、对比度 AA、键盘可操作 DataGrid/Dialog。
- **依赖**：eslint-plugin-jsx-a11y 规则集；设计令牌对比度。
- **验收**：axe 核心页面 0 critical；键盘可完成「创建场次」主路径。
