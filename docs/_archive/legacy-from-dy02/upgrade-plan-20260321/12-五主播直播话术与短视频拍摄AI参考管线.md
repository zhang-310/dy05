## 1. 目标（一句话）

每位主播：**每场直播有可生成、可审核的话术**；**每个工作日有可拍的短视频脚本**；摄影师到手 **脚本 + 分镜要点 +（可选）AI 参考成片**，实拍成片仍以人为准。

## 3. 三条流水线（并列）

### 3.1 流水线 A — 直播话术构建

**现有能力（可直接用）**

- 建 `live_session`：绑定 `persona_id`、商品排品、`session_type`（如 `standard` / `chat_2h`）、`script_style`。
- `LiveScriptGenerationService` / 流式槽位生成；`LivePromptContextBuilderImpl` 已按主播姓名注入策略块。
- 模板：`template_id` → `LiveSessionTemplate` 蓝图槽位（M-1/M-2）。
- 合规与质量：`LiveScriptQualityService` 等。

**建议增强（与 `11` 一致）**

- 商业形态（自然流/重付费/仓播/单品等）与现有 **`session_type`（结构节奏，如 chat_2h）** 易混淆。实施时在 **`11` §2.1** 定稿：要么扩展 `session_type` 枚举，要么新增 `live_format`，且 **Prompt 只读一个「形态」字段**，避免 `live_description` 里口头描述。

**五主播日常操作**

1. 运营/主播创建场次 → 选对主播人设 → 选对 **场次结构类型** + **商业形态**（定稿后）。  
2. 选品就绪 → 生成全场/分槽话术 → 审核 → 开播走实时面板（PWA 离线见 `08-PWA离线提词.md`）。

---

### 3.2 流水线 B — 每日短视频脚本 → 摄影师拍摄

**现有能力**

- `ScriptPlanningPage` + `ShortVideoAiServiceImpl`：多参数脚本生成；项目类型 `daily` / `soft_ad` / `viral_clone`（`11` §2.2 冻结）。  
- 人设：`personaId` 注入上下文；主播名解析 `hostCode`（肖瑶/肖蝉/田玲红等）。  
- `CONTENT-04`：直播场次可 **导出到短视频项目**（`export-to-short-video`），便于「播后切片/预热」延续同一盘货。

**MVP 已落地（2026-03，默认调度关闭）**

- 表 **`sv_shooting_task`**、工单 CRUD、**机构/达人**与管理员同路径 **`/shortvideo/shooting-tasks`**。  
- **`DailyScriptGenerationScheduler`**（`app.shortvideo.daily-script-generation.enabled`，默认 `false`）：`live_session.scheduled_time` 落在 **明日** 且 **`persona_id` 非空** → 调用 `DailyShootService#generateDaily` 落 **一条 `daily`**，并创建拍摄工单（说明含 **`[daily-scheduler]`** 幂等）。  
- 拍摄任务页 **一键生成参考样片**：`VideoGenerationTask` 提交 + 回写 **`reference_video_task_id`** / 轮询或手填 **`reference_video_url`**。

**仍属二期 / 计划边界外**

- 企微晨报、视频任务 **Webhook 自动回写**、与 `generateDaily` **全自动**联动、每人每日配额落库等（见执行计划排除项）。

**五主播默认日更组合（可配置）**

| 类型 | 用途 |
|------|------|
| `soft_ad` | 明日直播/主推品预热 |
| `daily` | 人设向内容、拉自然流 |
| `viral_clone` | 有匹配爆款分析时由运营或调度触发 |

---

### 3.3 流水线 C — AI 参考成片（非终稿）

**含义**：给摄影师 **节奏、景别、时长、字幕风格** 的参考，**不替代**实拍与法务/合规终审。

**现有能力**

- **文生/图生视频任务**：`VideoGenerationTaskService` + `SvVideoGenerationTask`（多 Provider，含方舟等）。  
- **工程向成片**：`VideoEditServiceImpl` 自动剪辑、`WorkflowExecutionService` 合成（配音/字幕/BGM/上传）— 需 **分镜/时间线/素材** 输入。  
- 短视频工作流、时间线 `timelineJson` 等已在模块内迭代（见模块文档与 V088 等）。

**推荐最小产品路径（MVP）**

1. 脚本定稿（`SvScript`）后，运营一键 **「生成参考样片」**：  
   - **轻量**：仅生成 **15～30s** 单段或 2～3 卡视频任务（文案转分镜提示词 → 视频任务队列），产出 URL 写入 **拍摄任务**或脚本备注。  
   - **重量**（后续）：脚本 → 自动分镜 → 多段任务 → 简单时间线合成 → 一条参考 MP4。

2. 元数据：**`reference_video_url`**（拍摄任务或脚本扩展字段）+ **`reference_generated_at`**，标明 **AI 参考 / 非发布版**。

**注意**：成本、时长、版权（BGM/人像）需在运营侧设 **每人每日配额**（可 `sys_config`），避免无界调用。

## 4. 数据与权限（五主播规模）

- **名单短**：Dashboard/任务列表可 **固定展示 5 人 + 按人筛选**，不必先做复杂搜索。  
- **隔离**：`owner_id` / 主播账号与 `persona_id` 绑定；运营角色可看五人，主播角色只看 **本人** 场次与任务（与 `10` 六角色矩阵一致）。

---

## 5. 实施顺序建议（减少返工）

1. **契约**：确认 `session_type` 与规划中的 **`live_format`** 分工（见 `11`，避免两字段语义重叠）。  
2. **拍摄任务表 + API + 极简列表页**：无调度也能手工「脚本 → 派摄影师」。  
3. **日更调度**：按主播 + 明日场次 + `ai_host_persona` 内容矩阵生成 `daily/soft_ad`。  
4. **参考成片**：先接单段 `VideoGenerationTask`，再考虑工作流合成。  
5. **企微推送**：晨报里带「今日拍摄单」链接（`10` §4）。
