# 业务范围与产品目标

> 与 `application.yml` app.scope、`docs/development/04-文档代码同步清单.md` 同步。

## 一、产品目标

**本系统的目标是打造护肤品与彩妆类直播场次 GMV 千万级，并持续向更高目标迈进。**

- **品类**：护肤、彩妆、美妆
- **GMV 目标**：单场千万级（1000w+），向 2000w、3000w 突破
- **能力方向**：高客单价转化、专业形象、成分科普、供应链深度、大场运营

## 二、当前业务 Scope

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `app.scope.industries` | 护肤,彩妆,美妆 | 行业范围 |
| `app.scope.shortvideo-types` | 护肤达人短视频,彩妆达人短视频,美妆综合,语言口播文案类 | 短视频类型 |

## 三、已排除品类
