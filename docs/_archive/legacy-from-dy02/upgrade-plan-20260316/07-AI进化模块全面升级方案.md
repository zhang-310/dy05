## 四、P1 系统质量提升（7 项）

### P1-1 统一评分体系

**问题**：三套评分（KnowledgeQualityScoring, LiveScript.effectivenessScore, ContentEffectiveness）各自独立

**方案**：
- `QualityScoreServiceImpl.getOverallQuality()` 改为：
  - `libraryScore` → 从 `KnowledgeQualityScoringService` 取（已接入真实数据后）
  - `scriptScore` → 从 `LiveScript.effectivenessScore` 取均值
  - `ragEffectiveness` → 从 `ContentEffectivenessService` 取引用率
  - 公式：`overall = library*0.3 + script*0.4 + rag*0.3`
  - Grade: S(≥90), A(≥75), B(≥60), C(≥40), D(<40)

### P1-2 DeepEvolve 支持多 KB

for (Long kbId : kbIds) {

        if (done > 0) log.info("深度进化 kbId={}: 入库 {} 篇", kbId, done);
    } catch (Exception e) {
        log.error("深度进化 kbId={} 失败", kbId, e);
