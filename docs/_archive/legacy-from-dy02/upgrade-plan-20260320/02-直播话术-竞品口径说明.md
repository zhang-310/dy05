# 02 直播话术 · 竞品能力口径（C-1）

**结论**：竞品监控与对标能力当前落在 **短视频模块**（`CompetitorMonitorService`、`POST /api/v1/short-video/competitor/*`），与「直播话术」文档中的竞品并排指标（R-6 等）并非同一套 UI/数据域。

**复用方式**：若运营需在直播策划侧参考竞品素材或账号动态，可直接使用短视频侧竞品 API 与页面；直播面板暂不重复建设「多直播间实时并排」以免数据源双轨。

**对照表**：`P0-P1-完成度对照表.md` 中 **C-1** 标 ⚠️ 时，含义为「直播话术独立模块未单列」，而非系统无竞品能力。

**前端路由**（与 `router/index.tsx` 一致）：**Admin** `/admin/shortvideo/competitor`、**Org** `/org/shortvideo/competitor`、**Talent** `/talent/shortvideo/competitor`，均挂载 `CompetitorMonitorPage`。

## 手工维护竞品数据（替代「无开放平台」时的数据入口）

在 **未取得** 抖音开放平台竞品批量接口的前提下，运营通过 **短视频 · 竞品监控** 页完成录入与对齐，直播侧经 **`POST /api/v1/live/competitor-monitor/list`** 等桥接读取同一owner 域数据。

建议 UI 流程（与实现一致时可作为验收脚本）：

1. **登录与角色**：使用 Admin / 机构 / 达人任一角色的账号登录；确保菜单可见 **短视频 → 竞品监控**（三端路由见上文）。
2. **新增竞品账号**：在 `CompetitorMonitorPage` 将目标抖音号加入监控列表（填写账号标识/别名等页面要求的字段）；保存后列表应出现该条目并可再次编辑。
3. **同步或补数据**：按页面提供的「同步 / 刷新」能力拉取可得的公开侧数据；若接口失败，依赖 **手工补录** 字段（如近期爆款标题、均价带、备注）——具体表单项以当前前端表单为准。
4. **与直播策划协作**：直播运营在话术或场次策划文档中记录竞品账号 ID；需要对照时打开同一 **竞品监控** 页查看，或通过 **直播侧竞品 list 桥接** 在直播相关管理界面引用（若已接 UI）。
5. **边界**：不提供实时「全网爬虫」式竞品 GMV；**R-6 多直播间并排** 与 **C-2/C-3/C-5 `live_competitive_insight`**（手工价/份额/胜负备注）是 **不同** 数据集——前者偏实时会话，后者偏运营结构化录入，勿混排口径。
