> **评估基准**：2026-03-20 master 分支代码 | **当前完成度**：95% | **目标完成度**：99%

## 一、现状总览

### 核心能力矩阵

| 能力 | 状态 | 关键实现 |
|------|------|---------|

## 二、6 大维度差距分析

### 2.1 效果评分系统（EffectivenessScoreServiceImpl）

| # | 差距 | 影响 | 优先级 |
|---|------|------|--------|
| L-1 | 评分权重硬编码 | `conversion*0.4 + likes*0.3 + comments*0.2 + completion*0.1`，无法按用户/账号自定义 | P0 |
| L-2 | 转化率为占位计算 | 使用 `productImpressions/viewers` 而非实际销售数据 | P0 |
| L-3 | 完成率回退可配置 | 监控不足时回退百分比由 `completion-fallback-percent` 配置（默认 85） | P0 |
| L-4 | 时间衰减因子 | 已落地：按 `update_time` 半衰期缩放总分（`app.live.effectiveness.time-decay`） | P1 |
| L-5 | 无分段评分 | 仅整条话术评分，无法定位哪个段落效果好/差 | P2 |
| L-6 | 小样本低置信（工程策略） | 已落地：以 `executed` 为样本量，低于 `app.live.effectiveness.low-sample.threshold` 时 API 标 `confidenceLow`、可抑制 `hot/recommend/emerging`、可选排名置后；**非**严格统计置信区间 | P1 |
| L-7 | 无异常检测 | 无法标记可疑分数飙升 | P2 |
| L-8 | 定时更新未实现 | `scheduleScoreUpdate()` 已定义但无 `@Scheduled` 注解 | P0 |

**关键文件**：`EffectivenessScoreServiceImpl.java`、`LiveScriptEffectiveness.java`

### 2.2 实时面板（LiveRealtimePanelServiceImpl）

| # | 差距 | 影响 | 优先级 |
|---|------|------|--------|
| R-1 | 无抖音 API 实时数据同步 | 仅手动 `updateRealtimeData()`，无自动拉取 | P0 |
| R-2 | 建议引擎实现不明确 | `getSuggestionsForSession()` 存在但实现深度未知 | P1 |
| R-3 | 倒计时无持久化 | ✅ Redis：`timer-state/save|load` + 提词器防抖同步，可关 `app.live.realtime-panel.timer.enabled` | P1 |
| R-4 | 无演讲备注/提词卡 | 仅展示话术内容，无独立备注字段 | P2 |
| R-5 | 表演指导高亮 | 已落地：`ScriptContentWithPerformanceCues` + `performanceCueText`（与质量服务一致 2–30 字）；实时面板 / 提词器内联高亮 + 提示芯片；话术列表预览内联 | P1 |
| R-6 | 无竞品实时指标 | 无法与其他直播间数据并排对比 | P2 |
| R-7 | SSE 断线无自动重连 | 连接中断后无恢复策略 | P1 |

**关键文件**：`LiveRealtimePanelServiceImpl.java`、`LiveRealtimePanel.tsx`

### 2.3 质量自动评分

| # | 差距 | 影响 | 优先级 |
|---|------|------|--------|
| Q-1 | 无自动质量评分 | 仅合规检测，无可读性/吸引力/关键词密度评分 | P0 |
| Q-2 | 无抄袭检测 | 无法检测复制话术 | P1 |

### 2.4 竞品对标分析

### 2.5 场次模板系统（LiveScriptServiceImpl）

| # | 差距 | 影响 | 优先级 |
|---|------|------|--------|
| M-1 | 模板不可自定义 | `standard`（8 槽）+ `chat_2h`（14 槽）硬编码，无法创建新类型 | P1 |
| M-2 | 无动态槽位分配 | 槽位数固定，无法根据商品数量自适应 | P1 |

| M-5 | 无槽位时长校验 | 不检查生成内容是否匹配槽位时长 | P1 |
| M-6 | 无模板版本管理 | 无法 A/B 测试不同 `chat_2h` 结构 | P2 |
| M-7 | 商品不足无降级 | `chat_2h` 假设 5+ 商品，不足时无处理 | P1 |
| M-8 | 无聊天话题库 | 聊天槽位仅文本提示，无结构化话题池 | P1 |

**关键文件**：`LiveScriptServiceImpl.java`（lines 477-530）

### 2.6 生成策略优化

| # | 差距 | 影响 | 优先级 |

## 三、分阶段实施计划

### Phase 1：评分与数据闭环（Week 1-2，约 14h）

| 任务 | 工时 | 涉及文件 | 验收标准 |
|------|------|---------|---------|
| L-1 评分权重配置化 | 3h | `EffectivenessScoreServiceImpl`、`sys_config` | 权重存入 `sys_config`，支持按账号覆盖 |
| L-2+L-3 真实转化率/完成率 | 4h | `EffectivenessScoreServiceImpl`、`LiveSessionRealtimeData` | 从实际销售数据和直播时长计算 |
| L-8 定时评分更新 | 2h | `EffectivenessScoreServiceImpl` | `@Scheduled` 每日凌晨批量更新 |
| R-1 抖音 API 数据同步 | 5h | `LiveRealtimePanelServiceImpl`、`DouyinApiService` | 定时拉取观看/点赞/评论/分享数据 |

### Phase 2：质量与实时体验（Week 3-4，约 16h）

| 任务 | 工时 | 涉及文件 | 验收标准 |
|------|------|---------|---------|
| Q-1 自动质量评分 | 5h | `LiveScriptQualityServiceImpl`、新增 `QualityScoreVO` | 可读性/吸引力/关键词密度 3 维评分 |
| Q-6 质量分持久化 | 2h | 新增 `live_script_quality_score` 表 | 评分结果存库，支持历史查询 |
| R-5 表演指导高亮 | 3h | `LiveRealtimePanel.tsx`、`LivePromptDisplay.tsx`、`ScriptSection.tsx`、utils | 【】内联高亮 + 文下提示芯片（2–30 字规则） |
| R-7 SSE 自动重连 | 2h | `LiveRealtimePanel.tsx`、`useLiveRealtimePanel.ts` | 断线后指数退避重连（最多 5 次） |
| Q-4 时长/节奏校验 | 2h | `LiveScriptQualityServiceImpl` | 按字数估算时长，超出槽位时长告警 |
| R-3 倒计时持久化 | 2h | `LiveRealtimePanelServiceImpl` | 计时器状态存入 Redis，刷新后恢复 |

### Phase 3：模板与竞品（Week 5-6，约 16h）

| 任务 | 工时 | 涉及文件 | 验收标准 |
|------|------|---------|---------|
| M-1 自定义场次模板 | 5h | `LiveScriptServiceImpl`、新增 `live_session_template` 表 | 用户可创建/编辑模板，定义槽位数/类型/时长 |
| M-7+M-8 商品不足降级 + 话题库 | 3h | `LiveScriptServiceImpl`、`sys_config` | 商品不足时自动合并槽位；聊天话题从配置读取 |
| C-1 竞品账号追踪 | 4h | 新增 `CompetitorTrackingService` | 录入竞品账号，定时抓取公开数据 |
| C-4 竞品话术库 | 4h | 新增 `competitor_script` 表 | 手动录入/AI 提取竞品话术，支持对比分析 |

### Phase 4：策略优化与闭环（Week 7-8，约 14h）

| 任务 | 工时 | 涉及文件 | 验收标准 |
|------|------|---------|---------|
| G-4 A/B 测试生成策略 | 4h | `LiveScriptGenerationServiceImpl`、`AbTestService` | 同一槽位生成 2 个变体，追踪效果差异 |
| G-3 Prompt 指纹 | 3h | `LiveScript`、`V075`、`Sha256Hex` | 每次非流式 AI 写槽写 hash；改文清空 |
| L-4 时间衰减因子 | 2h | `EffectivenessScoreServiceImpl` | 30 天半衰期，旧话术权重递减 |
| L-6 小样本策略 | 3h | `EffectivenessScoreServiceImpl` | 默认阈值 3：低样本标 `confidenceLow`、可选 `demote-in-ranking` / `suppress-tags`；显著性检验仍属后续增强 |
| M-5 槽位时长校验 | 2h | `LiveScriptServiceImpl` | 生成后自动校验，超时告警 |
