# 模块03：商品管理 — 选品武器库

> 文档版本：v3.0 | 2026-03-30（第三轮升级：新增GMV贡献路径/导出短视频/场次关联视图/API补齐）

---

## 一、产品目标

**核心目标**：建立完整的商品信息库，通过AI自动提炼卖点、效果评分、就绪度评估，让每件商品都具备「可直播」的完整信息，直接驱动话术生成质量。

**成功指标**：
- 商品AI卖点提炼准确率 ≥ 85%
- 商品就绪度达标（≥80%）后话术生成一次通过率提升 30%
- 商品信息录入时间 ≤ 3 分钟/件

## 二、产品远景

> "每件商品都是一个知识节点，AI能从中自动提炼最有说服力的卖点"

| 阶段 | 能力 |
|------|------|
| 现阶段 | 手动录入 + AI卖点提炼 + 效果评分 |
| 6个月 | 抖音平台自动同步商品数据 + 竞品对标分析 |
| 1年 | 供应链深度打通（库存/成本/利润实时同步）|

## 三、用户需求

```
运营策划: 快速找到「最适合本场直播」的商品组合
主播:     在台上需要的卖点信息一键查看
供应链:   实时看到库存和利润率，避免卖断货
AI系统:   从商品信息中提取知识，丰富知识库
```

## 五、数据接口（完整版）

| 功能 | 接口 |
|------|------|
| 商品搜索/列表 | `productApi.list(params)` |
| 商品详情 | `productApi.get(id)` |
| 商品保存/删除 | `productApi.save/delete(id)` |
| 批量删除 | `productApi.batchDelete(ids[])` |
| AI提炼卖点 | `productApi.extractSellingPoints(id)` |
| 批量AI提炼 | `productApi.batchExtractSellingPoints(ids[])` |
| 效果评分列表 | `productApi.effectivenessScoreList(params)` |
| 效果评分详情 | `productApi.effectivenessScoreGet(id)` |
| 就绪度检查 | `productApi.readiness(id)` |
| 话术版本列表 | `productApi.scriptVersionList(productId)` |
| 话术版本激活 | `productApi.scriptVersionActivate(versionId)` |
| 销售历史 | `productApi.salesHistory(productId, params)` |
| 库存更新 | `productApi.updateInventory(id, delta)` |
| 风格预设列表 | `productApi.stylePresetList()` |
| 商品-话术使用统计 | `productApi.scriptUsageList(productId)` |
| 话术优化分析 | `productApi.scriptOptimizationAnalyze(scriptId)` |
| 话术优化建议 | `productApi.scriptOptimizationSuggestions(scriptId)` |
| 重新生成优化 | `productApi.scriptOptimizationRegenerate(scriptId)` |
| 优化历史 | `productApi.scriptOptimizationHistory(scriptId)` |
| 采纳建议 | `productApi.scriptOptimizationAccept(id, suggestionId)` |
| 拒绝建议 | `productApi.scriptOptimizationReject(id, suggestionId)` |
| 应用重生成结果 | `productApi.scriptOptimizationApplyRegenerated(id)` |
| 效果排行榜 | `productApi.effectivenessRanking(params)` |
| 效果对比 | `productApi.effectivenessCompare(ids[])` |
| 效果趋势 | `productApi.effectivenessTrend(productId, params)` |
| 效果风格对比 | `productApi.effectivenessStyleComparison(productId)` |
| 效果重算 | `productApi.effectivenessRecalculate(productId)` |
| 导出为短视频脚本 | `productApi.exportProductToShortVideo(productId, params)` |

## 七、导出短视频（v3.0 新增）

在商品详情抽屉底部操作栏新增「导出为短视频脚本」按钮：

点击 → 弹窗选择：
- 选择当前激活话术版本或指定版本
- 目标短视频风格：种草 / 测评 / 成分解析 / 对比实测
- 时长目标：30s / 60s / 90s

→ 调用 `productApi.exportProductToShortVideo(productId, { versionId, style, duration })` → 跳转短视频项目新建页（预填脚本内容）
