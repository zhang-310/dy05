# 模块09：Agent 智能体 — AI 运营助理

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：agentApi（list/get/save/delete/chat/conversationList/messageList/conversationDelete）+ 新增：智能体性能指标 / 工具调用可视化 / 对话质量评分 / 多智能体协作规划

## 一、产品目标

提供可配置 AI 智能体管理与实时流式对话，支持多轮上下文、知识库 RAG 检索、工具调用，让运营人员随时可访问 AI 专家助理。

**成功指标**：首次回答满意率 ≥ 80%；首 token 响应 ≤ 5s；日均对话 ≥ 10 轮/人

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 单智能体对话 + RAG 检索 + 工具调用 + 历史记录 |
| 6个月 | 多智能体协作（话术生成 → 违规检测 → 优化三段式流水线）|
| 1年 | 自主 Agent（自动监控直播数据异常，主动推送优化建议）|

### 左栏详细规范

- **智能体下拉**：Emoji图标 + 名称 + 模型标签（顶部固定）
- **「新建对话」按钮**：点击清空消息流，创建新 conversationId
- **历史对话列表**（`agentApi.conversationList(agentId)`）：
  - 按日期分组（今天 / 昨天 / 更早）
  - 每项：● 活跃(蓝) / ○ 历史(灰) + 标题（取首条消息前20字）+ 相对时间
  - 右键菜单：重命名 / 删除（`agentApi.conversationDelete(id)`）
  - 切换对话：加载 `agentApi.messageList(conversationId)`

### 中栏：消息流详细规范

**顶部标题栏**：智能体名称 + 知识库标签 + 模型标签（灰色小字）

**消息气泡**：
- 用户消息：右对齐，蓝色背景，白色文字，最大宽度 70%
- AI 回复：左对齐，白色 Paper（elevation=1），Markdown 完整渲染（含粗体/代码/代码块语法高亮/引用块）
- 工具调用结果：折叠 Accordion（默认折叠），标题「🔧 工具调用：{工具名}」，展开显示调用参数（JSON格式化）+ 返回结果摘要
- 流式输出：逐字追加，末尾光标 `|` 闪烁动画
- 每条 AI 消息底部：👍 👎 评分按钮

**输入区（底部固定）**：
- 📎 附件按钮（支持 PDF/TXT/MD，≤10MB）
- 多行 TextField（Shift+Enter 换行，Enter 发送）
- 发送/停止切换按钮：发送中变为 ⏹ 停止（中断 SSE 流）

**流式对话**：SSE POST `/api/v1/agent/chat`，事件 `message` 追加内容，`tool_call` 显示工具折叠卡，`done` 完成，`error` 展示错误+重试

## 五、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 无智能体（首次使用）| 空状态图 + 「创建第一个智能体」按钮 |
| 智能体已禁用 | 对话按钮置灰 + Tooltip 提示 |
| SSE 连接超时（>30s）| Toast 警告 + 自动停止 + 重试按钮 |
| SSE 流中断 | 显示已接收内容 + 「[传输中断]」标记 |
| 附件过大（>10MB）| 上传前校验，Toast 提示 |
| 工具调用失败 | 折叠卡片标题变红，展开显示错误详情 |
| 对话历史为空 | 中栏显示引导卡（含3条示例问题）|
| Token 超限 | 提示「上下文过长，已自动截断早期对话」|

## 六、数据接口对照（v3.0）

| 操作 | API 方法 | 说明 |
|------|----------|------|
| 列表 | `agentApi.list(params)` | 支持 agentType / keyword 过滤 |
| 详情 | `agentApi.get(id)` | 含工具调用配置 |
| 保存 | `agentApi.save(form)` | 新建/编辑通用 |
| 删除 | `agentApi.delete(id)` | 二次确认后执行 |
| 历史对话列表 | `agentApi.conversationList(agentId)` | 含最后一条消息摘要 |
| 历史消息列表 | `agentApi.messageList(conversationId)` | 含工具调用记录 |
| 删除对话 | `agentApi.conversationDelete(id)` | — |
| 流式对话 | SSE POST `/agent/chat` | 事件: message/tool_call/done/error |

> ⚠️ 注意：`agentApi.stats()` 当前未实现，智能体使用统计从 `agentApi.list()` 的 `conversationCount` 字段获取。

## 七、状态管理

  selectedAgentId: number | null
  selectedConversationId: number | null
  messages: ChatMessage[]

interface ChatMessage {
  id: number

  toolCalls?: { name: string; args: unknown; result: string }[]
