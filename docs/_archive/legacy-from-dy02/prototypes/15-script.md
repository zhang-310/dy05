# 模块15：话术脚本库 — 内容生产工具箱

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：scriptApi（list/get/save/delete/generate/updateUseCount/templateSearch/templateGet/templateSave/templateDelete/violationList/violationSave/violationDelete/violationToggle/violationPublicList/violationCheck/violationCheckBatch/violationSuggestReplacement/complianceCheck/complianceRules/searchHybrid/searchSemantic/searchSuggest）+ 新增：违规检测报告可视化 / 批量替换建议 / 合规评分面板 / 模板效果分析 / 搜索相关度可视化

## 一、产品目标

提供话术模板管理、违规词检测、混合搜索（向量+关键词）等工具，支撑直播工作台话术生产，通过合规检测降低违规风险。

**成功指标**：违规检测准确率 ≥ 95%；模板复用率 ≥ 30%；搜索响应 ≤ 200ms

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 违规词库管理 + 单条/批量检测 + 模板库 + 混合搜索 |
| 6个月 | AI 实时辅助（输入话术自动标红违规词，不需手动触发）|
| 1年 | 行业合规知识图谱（关联监管政策变更自动更新违规词库）|

### 搜索区规范

- 搜索框：宽度 100%，placeholder「搜索话术、知识库、商品信息...」
- 输入时（debounce 300ms）调用 `scriptApi.searchSuggest(prefix)` 展示下拉建议（最多8条）
- 搜索模式 RadioGroup：混合（向量+关键词 RRF 融合）/ 纯语义 / 纯关键词
- 来源 Checkbox 组：话术库 / 知识库 / 商品 / 文案库（至少选1个）
- 按 Enter 或点击 [搜索] 触发搜索

### 搜索结果卡片规范

**结果 Tab**：全部 + 各来源（含数量徽章），Tab 切换过滤当前结果列表

每条结果卡片（Paper）：
- **来源 Chip**（话术库=蓝/知识库=绿/商品=橙/文案库=紫）+ 相关度进度条（%）
- **标题**：关键词命中词黄色高亮（`<mark>` 样式）
- **内容摘要**：前 200 字，关键词命中词黄色高亮
- **操作**：[引用到话术]（复制内容到剪贴板）/ [查看原文]（跳转原始页面）

**搜索 API**：
- 混合搜索：`scriptApi.searchHybrid(query, { sources, mode })`
- 纯语义：`scriptApi.searchSemantic(query)`
- 搜索建议：`scriptApi.searchSuggest(prefix)`（输入时 debounce 300ms 调用）

## 七、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 话术库为空 | 空状态图 + 「新增第一条话术」按钮 |
| 违规检测无问题 | 检测面板显示「✓ 合规评分 98 分，未发现违规词」绿色 |
| 批量检测部分失败 | 弹窗表格中失败行标红，显示具体错误原因 |
| 搜索无结果 | 空状态 + 「换个关键词试试」+ 建议相关词 Chip |
| 语义搜索服务不可用 | 自动降级为关键词搜索，Toast「语义搜索暂不可用，已切换为关键词搜索」|
| 模板变量未填写 | 「使用」模板时必填校验，未填不允许确认 |
| 批量导入格式错误 | 弹窗显示每行错误原因，支持「跳过错误行继续导入」|
