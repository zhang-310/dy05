# 模块11：账号管理 — 流量入口配置

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：douyinApi（accountSearch/videoSearch/videoSave/syncVideos/fanProfileGet/fanProfileSync/fanProfileStats/listPersonas/savePersona/deletePersona/oauthUrl/tokenStatus）+ 新增：竞品账号对标 / 粉丝画像趋势 / Token 自动刷新 / 账号健康评分 / 批量授权管理

## 一、产品目标

管理所有绑定抖音账号，同步粉丝画像和视频数据，配置人设（Persona），为直播场次提供账号基础和话术风格基调。

**成功指标**：数据同步延迟 ≤ 1 小时；人设配置完整率 ≥ 95%；Token 过期主动提醒率 ≥ 99%

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 账号列表 + 粉丝画像 + 人设配置 + OAuth 管理 |
| 6个月 | 跨账号粉丝重叠分析 + 账号健康评分自动诊断 |
| 1年 | 多账号矩阵统一调度（同一人设跨账号直播）|

**Token 到期预警规则**：
- 剩余 > 30 天：进度条蓝色
- 剩余 ≤ 30 天：进度条橙色 + 首页 Banner 提醒
- 已过期：进度条红色 + 所有功能入口显示警告 Tooltip

**重新授权流程**：
```
点击「重新授权」
  ↓
douyinApi.oauthUrl(accountId) → 返回授权链接
  ↓
打开新窗口（OAuth 2.0 抖音授权页）
  ↓
用户确认授权 → 回调 URL → 后端保存 Token
  ↓
前端轮询 tokenStatus(accountId) 5s × 12次
  ↓
授权成功 → Toast「授权成功！」→ 卡片状态刷新
```

**数据**：`douyinApi.tokenStatus(accountId)` 逐个查询

## 六、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| Token 过期 | 账号行红色 Chip + 操作列「重新授权」按钮高亮 |
| 同步进行中 | 操作列「同步」按钮变为 Spinner，禁用重复点击 |
| 同步失败 | Toast 错误提示 + 「重试」按钮 |
| 粉丝画像未同步 | Tab 2 显示空状态「暂无粉丝数据，点击同步」|
| 人设未配置 | 直播工作台创建场次时弹出引导「请先为账号配置人设」|
| 网络错误 | Skeleton + 「重试」按钮 |
