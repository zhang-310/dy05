# 模块07：归因分析 — 增长决策中心

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：attributionApi（report）/ liveApi（scriptAttributionList/sessionSearch/sessionAnalysis/getVersionsByScriptId）/ shortvideoApi（recommendPublishTime）+ 新增：GMV 归因漏斗可视化 / 话术 A/B 版本对比 / 时段热力图增强 / AI 差异诊断 / 归因报告导出

## 一、产品目标

清晰呈现各渠道对 GMV 的贡献，以及话术版本、商品排列、时段对转化率的影响，为运营决策提供数据依据。

**成功指标**：归因准确率 ≥ 90%；运营人员依据归因做决策比例 ≥ 60%；报告导出使用率 ≥ 30%

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 渠道 GMV 归因 + 话术版本对比 + 时段热力图 + 场次对比 |
| 6个月 | 多触点归因模型（首次 / 最终 / 线性加权）|
| 1年 | 实时归因（直播中每分钟更新贡献数据）|

## 二、布局结构

```
┌────────────────────────────────────────────────────────────────┐
│ 归因分析 — 增长决策中心                      [导出报告 PDF▼]   │
├────────────────────────────────────────────────────────────────┤
│ 全局筛选：时间范围 [7天▼]  账号 [全部▼]  归因模型 [末次接触▼]  │
├────────────────────────────────────────────────────────────────┤
│ Tab：[渠道归因] [话术归因] [时段分析] [场次对比]               │
├────────────────────────────────────────────────────────────────┤
│ Tab 内容区                                                     │
└────────────────────────────────────────────────────────────────┘
```

**归因模型说明**：
- **末次接触**（默认）：最后一次触点获得 100% 归因
- **首次接触**：第一次触点获得 100% 归因（用于品牌认知分析）
- **线性加权**（6个月路线图）：所有触点平均分配归因

### GMV 渠道漏斗图

- 库：ECharts Funnel（`sort: 'descending'`，`gap: 4`）
- 数据：`attributionApi.report({ days, channel: 'all' })`
- 渠道：直播带货 / 短视频 / 搜索 / 推荐流
- 每层显示：渠道名 + GMV 绝对值（¥万元格式）+ 占比 %
- 点击某层：高亮该渠道对应折线图系列
- Tooltip：悬停显示 GMV / 订单数 / 转化率 / 环比变化

### 各渠道趋势折线图

- 多系列折线（4 条），配色与漏斗图一致
- X 轴：按选定时间范围的日期（7天/30天/90天切换）
- Y 轴：GMV（万元），双 Y 轴右侧显示订单量
- 支持图例点击显隐单条渠道
- 区域填充（`areaStyle`，透明度 0.1）增强视觉层次

### 渠道详情卡片（2 列 Grid）

每张卡片：
- 渠道名（带颜色圆点）+ GMV（¥格式）+ 环比箭头（↑绿12.3% / ↓红2.1%）
- 订单数 + 转化率（点击购买 %）
- 占比进度条（MUI LinearProgress，颜色与渠道一致）

**数据**：`attributionApi.report({ days, channel })` 按渠道分别请求或一次返回全部

**渠道颜色规范**：直播带货 #F44336 / 短视频 #9C27B0 / 搜索 #FF9800 / 推荐流 #4CAF50

## 七、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 无归因数据（新账号）| 空状态图 + 「先完成一场直播以获得归因数据」提示 |
| 渠道 API 超时 | 漏斗图显示 Skeleton + Toast「数据加载失败，显示缓存数据」|
| 场次选择后无话术版本 | DataGrid 空状态 + 「该场次暂无多版本话术对比数据」|
| 热力图数据稀疏（<7天）| 提示「数据量不足，建议查看30天以上时间范围」|
| 场次对比超5个 | Toast 警告「最多同时对比5个场次」，阻止添加 |
| 导出报告生成中 | Button Loading 状态，完成后触发浏览器下载 |
| AI 分析接口失败 | 卡片显示「AI 分析暂不可用」+ 重试按钮 |
