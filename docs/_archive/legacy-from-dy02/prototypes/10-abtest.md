# 模块10：A/B 实验 — 科学决策引擎

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：abtestApi（list/get/save/delete/start/stop/pause/setWinner/result/dailyTrend/variantSave/variantDelete/eventRecord）+ 新增：样本量计算 / 多变体 / 实验模板 / 分群分析 / 获胜者推广流程

## 一、产品目标

通过受控实验科学验证话术版本、排品策略、直播时段等变量对 GMV 和转化率的影响，用统计显著性替代主观判断。

**成功指标**：每月 ≥ 5 个有效实验；结论与实际吻合率 ≥ 85%；推广后转化率平均提升 ≥ 15%

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 话术 A/B 对比 + 统计显著性 + 场次联动 |
| 6个月 | 多变体自动淘汰（Bandit 算法） |
| 1年 | 全链路实验：选品策略 × 话术 × 时段三维交叉实验 |

### 新建实验向导（4步 Stepper）

1. **基础信息**：实验名称 / 假设描述 / 指标（转化率/GMV/点击率）/ 最小样本量
2. **添加变体**：对照组 A（选择已有话术）+ 实验组 B（选择对比话术），支持最多 4 个变体（A/B/C/D）
3. **流量配置**：分配比例（多变体时自动均分，可手动调）/ 绑定场次
4. **确认启动**：预览配置摘要 → 「启动实验」

### 样本量计算器（步骤1嵌入面板）

```
┌──────────────────────────────────────────────────────────┐
│ 样本量计算器                              [折叠▲]         │
├──────────────────────────────────────────────────────────┤
│ 基准转化率（当前历史均值）  [3.8 %]                        │
│ 期望最小可检测效果（MDE）  [15 %]  → 即 ≥ 0.57% 提升      │
│ 统计功效（Power）          [80%▼]                         │
│ 显著性水平（α）            [0.05▼]                        │
├──────────────────────────────────────────────────────────┤
│ 每个变体最少需要：  ████████████  1,243 样本              │
│ 预计达到所需时间：  约 2.5 场次（按历史均值 500 UV/场）    │
└──────────────────────────────────────────────────────────┘
```

计算公式（本地实现）：
- `n = (Z_α/2 + Z_β)² × p(1-p) / (MDE)²`
- `Z_0.05 = 1.96`，`Z_power_0.8 = 0.842`

### 统计分析面板

```
┌────────────────────────────────────────────────────────────┐
│ 统计结论                                                    │
│ ✅ 变体B显著优于变体A（p = 0.023，置信度 97.7%）           │
│ 相对提升: +18.4%  |  绝对提升: +0.7%  |  效果量 d = 0.24  │
├────────────────────────────────────────────────────────────┤
│ 当前样本: A=1,247  B=1,251  |  目标: 各 1,243  ✅ 已达标  │
│ 置信区间（95%）: [+0.2%, +1.2%]                            │
├────────────────────────────────────────────────────────────┤
│ [🏆 设为获胜变体] [📋 保存为模板] [推广到所有场次]          │
└────────────────────────────────────────────────────────────┘
```

- p 值显示（`abtestApi.result(id)` → `pValue`）
- 置信度百分比
- 效果量（相对提升 %）
- 显著性结论：✅ 统计显著（p < 0.05）/ ⚠️ 尚未显著
- p 值本地计算：`(p1-p2)/sqrt(p*(1-p)*(1/n1+1/n2))`，Z → 正态分布 CDF
- 置信区间：`CI = (p1-p2) ± 1.96 × SE`

### 获胜者推广流程

点击「推广到所有场次」→ 弹窗：
```
将变体B（情感共鸣型话术）推广为：
◉ 替换当前所有草稿场次的对应槽位话术
○ 仅推荐（运营手动确认）
○ 保存为文案库标准模板

影响范围：12 个草稿场次 / 3 个话术槽位
[确认推广]  [取消]
```
→ 调用 `abtestApi.setWinner(id, variantId)` + `liveApi.bulkReplaceScript(params)`

## 五、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 样本量不足（< 50%目标）| 统计面板显示「数据不足，结论不可信」灰色遮罩 |
| 实验运行超过 30 天 | 黄色提示「实验时间过长，可能存在季节性偏差」|
| p 值 = NaN（分母为0）| 显示「—」，不显示置信度 |
| 变体样本量严重不均（>2x差）| 橙色警告「流量分配异常，请检查场次绑定」|
| 网络加载失败 | Skeleton + 「重试」按钮 |
