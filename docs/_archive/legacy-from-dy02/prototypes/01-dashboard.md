# Dashboard 运营指挥中心

> 版本：v3.0 | 更新：2026-03-30 | 对齐 API：dashboardApi（adminDashboard/kpiUnified/conversionFunnel/liveFormatGmv）/ liveApi / aiApi / authApi

管理员首页，聚合全局 GMV、场次、内容、AI 四维核心指标，提供快捷操作入口与智能推荐。

## 一、产品目标

**核心目标**：为运营团队提供全局实时视角，在一个页面内掌握所有直播场次状态、AI 系统健康度、待处理事项，快速跳转到任意工作模块。

**成功指标**：
- 从 Dashboard 跳转到目标页面的平均点击数 ≤ 2
- 核心数据延迟 ≤ 30 秒
- 运营人员每日首次打开率 > 90%

**产品远景**：让每个运营人员在 5 秒内知道——今天状态如何、最紧急的事是什么、下一步做什么。

| 阶段 | 时间 | 能力 |
|------|------|------|
| 现阶段 | 当前 | 数据汇总展示 + 快捷跳转 |
| 近期 | 6个月 | AI 驱动「今日运营建议」 |
| 远期 | 1年 | 预测性预警（提前 24h 预测 GMV 风险）|

## 二、组件详细设计

### 1. 顶部 Header

**团队切换下拉**
- 选项：全部团队 / 各 Org 机构名称列表
- 切换后所有 KPI 卡与图表均按 orgId 过滤重新加载
- API：`authApi.orgList()` 获取机构列表

**刷新**：点击手动触发全页重载，右上角显示「最后更新时间」

**通知铃铛**：未读数角标，点击展开通知抽屉（告警 + 审批 + 进化任务）

**全局命令面板**：Ctrl+K 快捷键入口，复用 `GlobalCommandPalette` 组件

### 2. KPI 卡片行（4张）

| 卡片 | 主数值 | 环比 | 辅助信息 |
|------|--------|------|----------|
| 今日 GMV | ¥xxx,xxx | 较昨日 ±% | 目标完成率进度条 |
| 直播场次 | 进行中 N 场 | 今日累计 M 场 | 计划中 K 场 |
| 话术生成 | 今日 N 条 | 较昨日 ±% | 累计总量 |
| 知识库质量 | 平均 x.x 分 | 本周趋势箭头 | 文档总数 |

**数据字段对齐（`dashboardApi.adminDashboard()` 返回）**：
- `AdminStats.todayRevenue`：今日GMV
- `kpiUnified.aiCallCount`：今日AI调用数
- `kpiUnified.publishedVideos`：今日短视频发布数
- `kpiUnified.activeSessionCount`：进行中场次数
- `kpiUnified.docCount`：知识库文档总数

**GMV 预测**：当今日 GMV < 目标 60% 且时间已过 50% 时，进度条变橙色并显示「预计完成率 xx%」预测文字。

**数据来源**：`dashboardApi.adminDashboard()` 返回 `DashboardVO`，包含上述所有字段。

```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────────────────┐
│今日 GMV  │ │进行中场次│ │ 话术生成 │ │ 知识库质量           │

│ ↑23% 昨  │ │峰值 2.1w │ │  ↑12%    │ │  ↑0.3 本周          │

```

### 3. GMV 趋势折线图

- 库：ECharts `ReactECharts`
- X 轴：近 7 天日期（含今日）
- Y 轴：GMV 金额（万元），自动缩放
- 多线叠加：实际 GMV（蓝实线）+ 目标 GMV（灰虚线）+ AI 预测 GMV（橙虚线，未来 3 天）
- 支持直播带货 vs 短视频引流双线对比模式（图例切换）
- 交互：Tooltip 悬停显示当日详细；图例点击显隐
- 数据：`dashboardApi.adminDashboard().gmvTrend`（7 天数组），预测线来自 `.gmvForecast`

```
¥20w ┤                         ╭──●
¥15w ┤      ●──●               │
¥10w ┤ ●────╯  ╰──●──●────●──╯
 ¥5w ┤ · · · · · · · （短视频引流 虚线）
     └─────────────────────────────────
     周一  周二  周三  周四  周五  周六  周日
```

### 4. AI 调用类型分布饼图

### 7. AI 智能推荐面板（v2.0 新增）

右下区域，纵向卡片列表，由 AI 根据近期数据生成 3-5 条建议：

```
[建议类型 Chip] 建议标题
建议详情（2行文字）
[执行建议] 按钮  [忽略] 按钮
```

**建议类型**：
- 「话术优化」：某场次话术效果评分偏低，建议重新生成
- 「商品排品」：建议调整高利润商品出场顺序
- 「知识库更新」：检测到 N 篇文档质量分<60，建议触发进化
- 「发布时机」：短视频最佳发布时间预测

**数据**：`dashboardApi.adminDashboard().aiRecommendations`（后端 AI 预计算）

## 五-B、状态管理

```typescript
interface DashboardState {
  orgId: number | null;          // null = 全部团队
  lastRefreshed: Date;
  kpi: DashboardVO | null;
  kpiUnified: KpiUnifiedVO | null;
  conversionFunnel: ConversionFunnelVO | null;
  liveFormatGmv: LiveFormatGmvVO[] | null;
  liveSessions: LiveSessionVO[];
  pendingItems: PendingItem[];
  recommendations: AiRecommendation[];
  loading: boolean;
}
```

使用 Zustand store `useDashboardStore`，挂载时触发 `fetchAll()`，团队切换时重新拉取。

## 六、错误处理

- KPI 卡加载失败：显示 `--` 占位，卡片右上角红色感叹号 Tooltip 说明原因
- 折线图数据为空：显示空状态插画 + 「暂无数据」
- 场次列表为空：显示「当前无进行中场次」+ 「新建场次」快捷按钮
- 网络断开：顶部 `OfflineBanner` 提示（复用现有组件）
