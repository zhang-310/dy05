# 模块14：企微推送 — 团队协作通知

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：wecomApi（robotList/robotSave/robotUpdateStatus/testSend/ruleList/ruleSave/ruleUpdateStatus/manualPush/logList）+ 新增：推送成功率 KPI / 规则触发频率分析 / 消息模板实时预览 / 推送渠道健康检查

## 一、产品目标

通过企业微信机器人将直播关键事件（开播提醒、GMV 里程碑、话术审批、异常告警）自动推送给相关运营人员，实现团队实时协作。

**成功指标**：关键事件推送延迟 ≤ 30s；到达率 ≥ 99%；误报率 ≤ 5%

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 企微机器人推送 + 规则配置 + 推送日志 + 消息模板 |
| 6个月 | 双向交互（运营人员在企微内直接回复审批/操作）|
| 1年 | 智能聚合（同类事件合并推送，避免消息轰炸）|

## 七、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 无机器人（首次使用）| 空状态图 + 「添加第一个企微机器人」按钮 |
| Webhook URL 格式错误 | 保存前校验，红色错误提示 |
| 测试发送失败（403）| 显示「Webhook URL 无效或机器人已被删除」+ 企微文档链接 |
| 规则触发但机器人已禁用 | 日志记录「目标机器人已禁用，跳过推送」|
| 冷却期内重复触发 | 日志记录「冷却期内，忽略本次触发（距上次Xs）」|
| 推送成功率 < 90% | KPI 卡片成功率变红 + Toast 警告 |
| 消息模板超过企微限制（4096字）| 保存前字数统计，超出红色警告 |
