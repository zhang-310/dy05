# 模块06：文案库 — 内容资产沉淀

> 文档版本：v3.0 | 更新：2026-03-30 | 对齐 API：copyApi（list/save/delete/aiGenerate/approvalSearch/approve/reject/templateSearch/templateSave/templateDelete）+ 新增：批量操作 / 使用统计分析 / 文案复用率看板 / 审批 SLA 监控 / 模板变量预览

## 一、产品目标

将历次直播中通过审批、效果验证的优质话术沉淀为可复用文案资产，通过标签体系和语义搜索快速检索，形成「生产→验证→沉淀→复用」内容飞轮。

**成功指标**：文案库复用率 ≥ 40%；检索满意文案 ≤ 30 秒；审批通过率 ≥ 85%；审批 SLA（24小时内）达成率 ≥ 95%

**产品远景**

| 阶段 | 能力 |
|------|------|
| 现阶段 | 文案沉淀 + 标签检索 + 审批流 + 模板库 |
| 6个月 | 语义聚类（自动发现相似文案）+ 效果归因 |
| 1年 | 个性化推荐（按人设/商品/场次自动推荐最适文案）|

**数据**：`copyApi.approvalSearch({ status, page, rows })`

**操作**：
- 通过：`copyApi.approve(id)` → 卡片移入「已通过」列，Toast「已通过」
- 拒绝：弹出原因输入框（必填）→ `copyApi.reject(id, reason)` → 移入「已拒绝」列
- 重新提交：将已拒绝文案修改后重新进入待审批

### 批量操作
- 列顶部「全选」复选框 → 「批量通过」「批量拒绝」（拒绝需统一填写原因）
- 支持按提交人/提交时间/SLA 超时状态排序

## 七、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| 文案库为空 | 空状态图 + 「立即生成第一条文案」按钮 |
| 语义搜索无结果 | 「未找到相似文案，切换关键词搜索试试」|
| AI 生成失败 | Toast 错误 + 「重试」按钮，保留填写的参数 |
| 审批超 SLA（24h）| 卡片红色边框 + ⚠️ Badge |
| 模板变量未填写 | 使用模板时弹出变量填写对话框，不允许跳过 |
| 批量操作数量 > 50 | 提示「最多批量操作 50 条」|
| 网络错误 | Skeleton + 「重试」按钮 |
