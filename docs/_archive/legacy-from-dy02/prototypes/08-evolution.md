# 模块08：进化引擎 — 知识自我更新系统

> 文档版本：v3.0 | 更新：2026-03-30 | 第三轮深度升级：新增进化地图可视化 / 知识质量热力图 / Agent 执行日志详情 / 进化效果 A/B 对比 / 自动暂停与熔断机制

## 一、产品目标

通过6类AI Agent定时巡检知识库，自动发现知识缺口、淘汰过期内容、提升质量评分，使知识库始终保持高质量状态，持续提升话术生成效果。

**成功指标**：
- 知识库质量分年度提升 ≥ 1.0（从8.0到9.0+）
- 过期知识检出率 ≥ 95%
- 自动进化产出的知识被话术引用率 ≥ 30%

## 二、产品远景

> "知识库会自己生长，每天都比昨天更懂护肤"

| 阶段 | 能力 |
|------|------|
| 现阶段 | 6类Agent定时巡检 + 人工审核 |
| 6个月 | 实时爬取学术论文/品牌发布 自动更新 |
| 1年 | 跨品牌知识迁移（A品牌成功经验→B品牌）|

## 三、6类进化Agent

| Agent | 职责 | 触发周期 |
|-------|------|----------|
| 知识缺口Agent | 发现话术生成时找不到支撑的知识点 | 每次生成后 |
| 时效性Agent | 标记90天未更新的文档 | 每日 |
| 质量评分Agent | 重新评估文档质量分 | 每周 |
| 自动分类Agent | 将新文档分配到合适知识库 | 实时 |
| 跨域共享Agent | 发现可跨知识库复用的内容 | 每周 |
| 深度进化Agent | 基于主题池深度扩展知识 | 每日 |

## 五、边界状态与错误处理

| 状态 | UI 表现 |
|------|--------|
| Agent 熔断（连续3次失败）| 任务行显示🔴熔断图标，操作列「重启Agent」按钮，企微推送通知 |
| 进化内容质量分 < 6.0 | 审核列表标注「⚠️ 低质量」红色 Chip，不建议通过 |
| 深度进化队列积压 > 50条 | 顶部黄色 Banner「进化队列积压，建议增加运行频率」|
| LLM Token 不足 | 任务失败，详情日志显示「Token配额不足，请充值」|
| 主题池为空 | 任务队列显示「暂无主题，请添加进化主题后再运行」|
| 知识库文档数 = 0 | 质量热力图显示空状态「暂无数据」|
| 网络错误 | Skeleton + 「重试」按钮 |

## 六、数据接口（v3.0 完整版）

|------|------|
| 进化 ROI 指标 | `aiApi.evolveRoi()` |
