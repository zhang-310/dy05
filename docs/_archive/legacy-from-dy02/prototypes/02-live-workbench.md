# 模块02：直播工作台 — 核心话术生产系统

> 文档版本：v4.0 | 2026-03-30（第四轮升级：补齐GMV大计数器UX/克隆场次流程/话术评论解决状态/@mention/场次总览/导出短视频接口）

---

## 一、产品目标

**核心目标**：以「场次」为单位，提供从选品排品→AI话术生成→话术审核管理→直播就绪度检查→数据分析的完整闭环工作流，使单场GMV达到千万级。

**成功指标**：
- 话术生成到可用的时间 ≤ 5 分钟（原人工 30 分钟）
- AI生成话术一次通过率 ≥ 70%
- 场次就绪度达标（≥85%）后的GMV转化率 ↑35%

## 二、产品远景

> "把10年经验老运营的直播打法，固化为可复制的AI工作台"

| 阶段 | 能力 |
|------|------|
| 现阶段 | AI生成话术 + 人工精修 + 审批流 |
| 6个月 | 实时弹幕分析自动推荐话术调整 |
| 1年 | 数字人自动执行话术，运营只需监控 |

## 三、核心工作流

```
创建场次
  │
  ├── 绑定账号（抖音OAuth） + 选择人设
  │
  ▼
选品排品（Tab1）
  ├── 从商品库批量选品
  ├── AI智能排品（基于历史转化+商品利润率+时段策略）
  └── 手动拖拽调整顺序
  │
  ▼
AI话术生成（Tab2）
  ├── 配置全局参数（风格/时长/知识库/模型）
  ├── 每个商品独立槽位配置（可覆盖全局参数）
  └── 并行生成 → SSE进度推送 → 完成后进入Tab3
  │
  ▼
话术管理（Tab3）
  ├── 查看/编辑每条话术
  ├── AI精修 + 违规检测
  ├── 提交审批 → 审批通过
  └── 存入文案库（复用）
  │
  ▼
就绪度检查（Tab4）
  ├── 系统自动评估8个维度
  └── 就绪度 ≥ 85% 可开播
  │
  ▼
直播执行
  └── 实时面板（提词 + 数据监控）
  │
  ▼
数据分析（Tab5）
  └── 场次复盘 + 话术效果分析
```

**场次总览悬浮卡（v4.0 新增）**：
- 鼠标悬停「场次名称」显示 Tooltip：总GMV / 总订单 / 话术数 / 商品数 / 就绪度
- **数据**：`liveApi.getSessionOverview(sessionId)` → `{ gmv, orderCount, scriptCount, productCount, readiness }`
