# 模块05：短视频工作台 — 内容矩阵生产线

> 文档版本：v3.0 | 2026-03-30（第三轮升级：新增天API数据来源标注/自动合成视频/字幕生成/人设爆款融合UX规范）

---

## 一、产品目标

**核心目标**：以「项目」为单位管理短视频内容生产全流程，从选题策划到发布分析，实现护肤/彩妆品类短视频矩阵规模化生产，为直播场次引流。

**成功指标**：
- 单个运营人员可管理 ≥ 10 个短视频项目
- 从选题到发布周期 ≤ 3 天
- 短视频为直播场次带来的自然流量 ≥ 20%

## 二、产品远景

> "把直播间的最佳话术片段，自动剪辑成高转化短视频"

| 阶段 | 能力 |
|------|------|
| 现阶段 | 项目管理 + 脚本生成 + 素材管理 |
| 6个月 | 直播回放自动剪辑高光片段 |
| 1年 | AI全自动生成完整短视频（数字人+配音+字幕）|

## 四、数据接口（完整版）

| 功能 | 接口 |
|------|------|
| 项目列表/搜索 | `shortvideoApi.list(params)` |
| 项目保存/删除 | `shortvideoApi.save/delete(id)` |
| 热点话题 | `shortvideoApi.hotTopicList(params)` |

| 分镜脚本列表/保存 | `shortvideoApi.svScriptList/save()` |
| 素材列表 | `shortvideoApi.materialList(params)` |
| 素材上传 | `shortvideoApi.materialUpload(file)` |
| 素材删除 | `shortvideoApi.materialDelete(id)` |
| 视频生成提交 | `shortvideoApi.videoTaskSubmit(params)` |
| 生成任务状态 | `shortvideoApi.videoTaskStatus(taskId)` |
| 取消/重试任务 | `shortvideoApi.videoTaskCancel/retry(id)` |
| 拍摄任务列表/保存 | `shortvideoApi.shootingTaskList/save()` |

## 八、升级优先级与验收标准（v3.0）

| 优先级 | 功能 | 原因 |
