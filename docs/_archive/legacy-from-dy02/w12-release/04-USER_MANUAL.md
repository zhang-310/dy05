## 1. 新手入门指南 (15 分钟)

### 第一步：注册账户 (2 分钟)

```
访问 https://app.example.com
  ↓
点击 「注册」
  ↓
填写以下信息:
  - 邮箱地址
  - 密码 (至少 8 位，需要大小写和数字)
  - 公司名称 (可选)
  ↓
点击 「发送验证邮件」
  ↓
检查邮件，点击验证链接
  ↓
✓ 账户创建成功
```

### 第二步：登录和个人设置 (3 分钟)

```
1. 使用邮箱和密码登录
2. 进入 「我的账户」 → 「个人设置」
3. 配置以下项目：
   ☐ 头像上传
   ☐ 昵称设置
   ☐ 个人简介
   ☐ 时区选择 (默认: 中国标准时间)
   ☐ 语言选择 (默认: 中文)
4. 点击 「保存」
```

### 第三步：创建工作空间 (5 分钟)

```
1. 进入 「工作空间」 → 「创建新空间」
2. 填写工作空间名称 (如: "2026年春季营销")
3. 选择工作空间类型:
   • 个人空间 (仅自己使用)
   • 团队空间 (邀请他人协作)
4. 添加团队成员 (可选):
   - 邮箱地址
   - 角色选择 (管理员/编辑者/查看者)
5. 点击 「创建」
```

### 第四步：首次任务体验 (5 分钟)

```
在新工作空间中：

1. 创建第一个产品:
   导航: 产品管理 → 新建产品
   填写: 产品名称、分类、描述

2. 创建话术版本:
   导航: 直播话术 → 新建话术
   编写: 产品介绍、价格说明、购买引导

3. 运行 AI 内容生成:
   导航: AI 助手 → 内容生成
   输入: 原始话术内容
   选择: 生成风格 (专业/简洁/热情)

4. 查看结果:
   检查生成的多个版本
   选择满意的版本，添加到库

✓ 完成第一个完整工作流
```

## 3. 常见问题 (FAQ)

### 账户和登录

**Q: 忘记密码怎么办？**

A: 登录页面点击「忘记密码」
  → 输入注册邮箱
  → 检查邮件，点击重置链接
  → 设置新密码
  → 重新登录

**Q: 如何更换登录邮箱？**

A:
  1. 进入 「我的账户」 → 「账户设置」
  2. 点击邮箱字段旁的 「修改」
  3. 输入新邮箱
  4. 验证码确认 (两个邮箱各验证一次)
  5. 点击「保存」

**Q: 支持两步验证吗？**

A: 支持！进入 「安全设置」→ 「启用 2FA」
  - 下载 Google Authenticator (推荐)
  - 或使用短信验证码
  - 妥善保管备用码 (丢失后无法恢复)

### 产品和话术

**Q: 话术版本过多，如何清理？**

A:
  1. 点击话术 → 「版本管理」
  2. 选中不用的版本
  3. 点击「删除」
  4. 删除后 30 天内可在「回收站」恢复

**Q: AI 生成的文案质量不好，怎么办？**

A:
  1. 检查输入是否清晰 (不要用太多行业术语)
  2. 尝试调整「文案风格」参数
  3. 在「额外要求」中明确指出希望突出的要点
  4. 联系客服，我们可以人工优化

**Q: 可以导入竞品的话术吗？**

A:
  不建议。除了版权问题，直接使用竞品话术也不会得到好效果。

  建议方案:
  1. 学习竞品的结构和逻辑
  2. 用自己的语言重新表达
  3. 利用 AI 优化工具润色
  4. A/B 测试找出最优版本

## 4. 故障排查指南

### 登录问题

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| 验证码错误 | 重复提示验证码错误 | 清除浏览器缓存，重新登录 |
| 账号被锁定 | 显示「账号已锁定」 | 等 1 小时或联系客服 |
| 页面加载缓慢 | 30 秒还没显示内容 | 检查网络，尝试换浏览器 |

### 上传文件问题

| 问题 | 症状 | 解决方案 |
|------|------|---------|
| 文件过大 | 显示「文件超过 10MB」| 压缩或选择较小的文件 |
| 格式不支持 | 文件选择器禁用 | 转换为支持的格式 (JPG/PDF) |
| 上传中断 | 上传卡住不动 | 刷新页面重新上传 |

### AI 生成缓慢

**症状**: 提交生成请求后，长时间无响应

**排查步骤**:

```
1. 检查输入数据
   - 是否包含特殊字符?
   - 字数是否过长 (>10,000)?
   - 是否有乱码?

2. 检查网络
   - 打开浏览器控制台 (F12)
   - 查看网络标签中的请求
   - 如果请求挂起，说明是网络问题

3. 刷新重试
   - F5 刷新页面
   - 重新提交请求

4. 检查队列
   - 如果有很多人同时生成，会排队等待
   - 实时生成数超过 50 个时，额外请求会排队
   - 每个队列任务约 2-3 分钟

5. 联系支持
   如果卡住超过 10 分钟:
   - 截图保存当前状态
   - 发送至 support@example.com
   - 包含账户信息和生成内容
```

### 直播卡顿

**症状**: 观众反馈直播不流畅或延迟大

**解决方案**:

```
主播端:
  1. 检查网络速度 (建议 > 5 Mbps)
  2. 关闭其他占用带宽的应用
  3. 尝试降低视频分辨率 (720p → 480p)
  4. 检查 CPU 使用率 (保持 < 70%)

观众端:
  1. 刷新页面或重新打开链接
  2. 尝试换浏览器 (Chrome/Firefox)
  3. 清除浏览器缓存
  4. 检查网络连接质量

后台检查:
  - 登录后台，查看直播健康度指标
  - 如果丢包率 > 2%，说明网络问题
  - 联系 ISP 或更换网络
```

## 5. 最佳实践

```

  • 为产品添加高质量图片 (≥ 1080×1080)

  • 创建空白产品 (信息不完整)

```
黄金结构:

1. 开场 (10-15 秒)
   ✓ 吸引注意力
   ✓ 建立信任
   ✗ 不要直接推销

2. 产品介绍 (1-2 分钟)
   ✓ 强调核心卖点 (3 个左右)

   ✓ 强烈的行动号召
   ✓ 消除购买障碍
