**交互说明：**

| 操作 | 触发 | 说明 |
|------|------|------|
| 上架 | 点击「上架」按钮 | 调用 /publish，按钮变为「下架」 |
| 下架 | 点击「下架」按钮 | 调用 /unpublish，按钮变为「上架」 |
| 设为推荐 | 点击「★推荐」 | 调用 /set-featured（featured=1） |
| 取消推荐 | 点击「取消推荐」 | 调用 /set-featured（featured=0） |
| 编辑库存 | 点击「编辑库存」 | 弹出库存编辑弹窗，调用 /update-inventory |
| 编辑 | 点击「编辑」 | 弹出商品编辑弹窗，调用 /save（带 id） |
| 删除 | 点击「删除」 | 二次确认后调用 /delete |

## 6.3 组件复用

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| ProductFormModal | 商品库 | 新增/编辑商品弹窗 |
| InventoryEditModal | 商品库 | 库存编辑弹窗 |
| ProductStatusTag | 商品库、销售历史 | 上架/下架状态标签 |
| FeaturedBadge | 商品库 | 推荐标记徽章（★） |
| SalesRecordFormModal | 销售历史 | 录入销售记录弹窗 |
| ChannelSourceTag | 销售历史 | 渠道来源标签（抖音直播/门店/手动） |
| ProductSelector | 销售历史录入弹窗 | 商品下拉选择器（调用 /search） |
