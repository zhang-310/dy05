## 一、模块概述

### 1.1 模块定位

**商品话术版本效果评分系统** 对 W-02 产生的话术版本进行效果评估，通过数据聚合、评分计算、排行榜生成、对比分析和趋势追踪，帮助运营者快速识别高效话术，指导后续话术优化和使用决策。

### 1.2 核心价值

- 📊 **效果评分计算**：基于使用频次、转化率、社交互动等多维度计算综合评分
- 📈 **版本排行榜**：按效果评分排序，快速识别 Top 话术
- 🔀 **效果对比**：对比不同版本、不同产品、不同风格的话术效果
- 📉 **历史趋势**：追踪话术效果变化，发现优化机会

### 1.3 业务场景

**场景 1：发现高效话术**
```
运营者进入"效果评分"页面
     ↓
查看话术排行榜（按评分排序）
     ↓
看到 Top 5 最高效的话术
     ↓
参考最高效话术的风格和结构，优化低效话术
```

**场景 2：对比分析**
```
产品 A 有 3 个版本话术
     ↓
进入对比视图
     ↓
对比 3 个版本的效果评分、使用次数、转化率
     ↓
发现版本 B 效果最好，下次直播优先使用版本 B
```

**场景 3：趋势追踪**
```
查看近 10 场直播中产品 X 的话术效果变化
     ↓
发现第 5 场直播后评分下降
     ↓
分析那场直播发生了什么
     ↓
优化话术内容，提升后续效果
```

## 二、数据模型

### 2.1 效果评分计算规则

#### 2.1.1 综合评分算法

```
综合评分（total_score） =
    基础分（50 分）
    + 使用频次加分（max 25 分）
    + 转化率加分（max 15 分）
    + 社交互动加分（max 10 分）

分项计算：

1. 使用频次加分（use_score）
   IF usage_count = 0:
       use_score = 0
   ELSE:
       use_score = min(usage_count / max_usage * 25, 25)
       其中 max_usage = 该产品所有版本的最高 usage_count

2. 转化率加分（conversion_score）
   IF conversion_rate = 0 OR conversion_rate IS NULL:
       conversion_score = 0
   ELSE:
       conversion_score = min(conversion_rate * 100 / max_conversion * 15, 15)
       其中 max_conversion = 该产品所有版本的最高转化率

3. 社交互动加分（interaction_score）
   interaction_score =
       (likes_count / max_likes * 5) + (comments_count / max_comments * 5)
       其中 max_likes / max_comments = 该产品所有版本的最高值

最终评分 = ROUND(total_score, 2)，范围 [0, 100]
```

#### 2.1.2 评分等级

| 分数 | 等级 | 说明 |
|------|------|------|
| 80-100 | A | 非常高效，强烈推荐使用 |
| 70-79 | B | 高效，可优先选用 |
| 60-69 | C | 中等效果，可改进 |
| 40-59 | D | 低效，建议优化或替换 |
| 0-39 | F | 非常低效，强烈建议替换 |

### 2.2 核心表结构（拓展）

**ProductScriptVersion（W-02 已有字段）**
```
id, product_id, version_number, content, style
effectiveness_score（已有） ← 需要实现计算逻辑
usage_count（已有）
conversion_rate（已有）
likes_count（已有）
comments_count（已有）
created_at, updated_at
```

**新增：ProductScriptEffectivenessRecord（效果评分历史记录）**
```sql
CREATE TABLE product_script_effectiveness_record (
  id BIGSERIAL PRIMARY KEY,
  product_id BIGINT NOT NULL,
  script_version_id BIGINT NOT NULL,
  calculated_at TIMESTAMP NOT NULL,  -- 评分计算时间
  score_value DECIMAL(5,2),          -- 当时的评分值
  usage_count_snapshot INTEGER,      -- 当时的使用次数快照
  conversion_rate_snapshot DECIMAL(5,2),
  likes_snapshot INTEGER,
  comments_snapshot INTEGER,
  score_level VARCHAR(10),           -- A/B/C/D/F
  owner_id BIGINT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

  INDEX idx_product_id,
  INDEX idx_script_version_id,
  INDEX idx_calculated_at DESC,
  INDEX idx_owner_id
);
```

**新增：ProductScriptComparisonCache（对比缓存）**
```sql
CREATE TABLE product_script_comparison_cache (
  id BIGSERIAL PRIMARY KEY,
  product_id BIGINT NOT NULL,
  comparison_type VARCHAR(32),  -- version/style/trend
  comparison_data JSONB,        -- 对比数据（JSON 缓存）
  cached_at TIMESTAMP,
  ttl_minutes INTEGER DEFAULT 60,  -- 缓存有效期
  owner_id BIGINT NOT NULL,

  INDEX idx_product_id,
  INDEX idx_comparison_type,
  INDEX idx_cached_at DESC
);
```

         └─→ 用于趋势分析

ProductScriptComparisonCache
