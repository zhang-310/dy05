# W-05：AI 话术自动优化建议系统

## 1. 模块概述

AI 话术自动优化建议系统通过分析历史话术的直播效果数据、观众互动指标、转化率等维度，自动识别话术的弱点，对标行业最佳实践，为主播提供精准的话术优化建议。该系统支持多种风格（亲民、高端、幽默等）的话术优化，帮助主播持续改进直播表现。

**目标用户**：直播主播、话术管理员
**核心价值**：从事后分析 → 事中优化 → 事前预防，提升转化率
**关键指标**：采纳率 > 60%、优化后转化率提升 > 15%

---

## 2. 核心功能模块

### 2.1 话术效果分析

| 功能 | 说明 | 数据来源 |
|------|------|--------|
| 弱点识别 | 识别话术的互动低谷、观众评论负面词、转化率低段 | 实时监控数据 + 评论分析 |
| 效果评分 | 综合评分（0-100）：互动率、转化率、粉丝增长、评论情绪 | LiveMonitor + 评论库 |
| 对标分析 | 与同类别高效话术对比，定位差距 | ScriptVersion 库 + 历史数据 |
| 风格识别 | 自动识别当前话术风格（亲民/高端/幽默/励志） | 文本分类模型 |

### 2.2 优化建议生成

| 类型 | 示例 | AI 方案 |
|------|------|--------|
| 内容优化 | "互动环节太短，建议加长提问时间" | DeepSeek 文本生成 + 规则引擎 |
| 节奏优化 | "中间 5 分钟缺乏高能时刻，建议插入爆料/互动" | 时间序列分析 + 模板匹配 |
| 风格调整 | "粉丝反馈更喜欢幽默风格，建议增加段子比例" | 评论情绪分析 + A/B 测试结果 |
| 话题优化 | "推荐加入热点话题 XXX，提升参与度" | 热点识别 + 行业知识库 |

### 2.3 话术重新生成

- 基于优化建议，调用 ScriptGenerationService 重新生成话术
- 保留核心框架，改进具体内容、节奏、互动点
- 自动生成 3 个不同风格的版本供选择

## 4. 数据模型设计

### 4.1 ScriptAnalysisResult（话术分析结果）

```sql
CREATE TABLE dy_script_analysis_result (
  id BIGINT PRIMARY KEY,
  script_version_id BIGINT NOT NULL,
  owner_id BIGINT NOT NULL,
  overall_score DECIMAL(5,2),
  interaction_rate DECIMAL(5,2),
  conversion_rate DECIMAL(5,2),
  fan_growth INTEGER,
  comment_sentiment DECIMAL(3,2),
  dominant_style VARCHAR(50),
  weak_points JSONB,
  analysis_type VARCHAR(50),
  data_source VARCHAR(50),
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP,
  deleted INTEGER DEFAULT 0,
  FOREIGN KEY (script_version_id) REFERENCES live_script_version(id)
);

CREATE INDEX idx_script_version_id ON dy_script_analysis_result(script_version_id);
CREATE INDEX idx_owner_id ON dy_script_analysis_result(owner_id);
```

### 4.2 OptimizationSuggestion（优化建议）

```sql
CREATE TABLE dy_optimization_suggestion (
  id BIGINT PRIMARY KEY,
  script_version_id BIGINT NOT NULL,
  analysis_result_id BIGINT NOT NULL,
  owner_id BIGINT NOT NULL,
  category VARCHAR(50),
  priority VARCHAR(20),
  suggestion_content TEXT,
  related_weak_point VARCHAR(100),
  expected_improvement JSONB,
  adoption_status VARCHAR(20),
  adopted_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP,
  deleted INTEGER DEFAULT 0
);

CREATE INDEX idx_script_version_id ON dy_optimization_suggestion(script_version_id);
CREATE INDEX idx_analysis_result_id ON dy_optimization_suggestion(analysis_result_id);
```

### 4.3 ScriptVariant（生成的话术变体）

```sql
CREATE TABLE dy_script_variant (
  id BIGINT PRIMARY KEY,
  script_version_id BIGINT NOT NULL,
  suggestion_id BIGINT,
  owner_id BIGINT NOT NULL,
  style VARCHAR(50),
  content TEXT,
  ai_score DECIMAL(5,2),
  estimated_metrics JSONB,
  is_applied BOOLEAN DEFAULT FALSE,
  applied_at TIMESTAMP,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP,
  deleted INTEGER DEFAULT 0
);

CREATE INDEX idx_script_version_id ON dy_script_variant(script_version_id);
```

## 5. 实现清单

### 5.1 Service 层（2 个）

| 服务 | 职责 | 关键方法 |
|------|------|--------|
| `ScriptAnalysisService` | 话术效果分析 | `analyzeScript()` / `evaluateMetrics()` / `identifyWeakPoints()` |
| `OptimizationSuggestionService` | 生成优化建议 | `generateSuggestions()` / `regenerateScript()` |

**依赖**：LiveMonitorRepository, ScriptVersionRepository, Redis缓存

### 5.2 Controller 层（1 个）

| 控制器 | 接口 |
|-------|------|
| `ScriptOptimizationController` | analyzeScript / optimizationSuggestion / regenerateOptimized / optimizationHistory |

### 5.3 VO 层（3 个）

| VO | 用途 |
|----|------|
| `ScriptAnalysisSearchVO` | 查询分析结果 |
| `OptimizationSuggestionSaveVO` | 保存建议 |
| `ScriptVariantVO` | 返回变体 |

### 5.4 Repository 层

- `ScriptAnalysisResultRepository` extends JpaRepository, JpaSpecificationExecutor
- `OptimizationSuggestionRepository` extends JpaRepository, JpaSpecificationExecutor
- `ScriptVariantRepository` extends JpaRepository, JpaSpecificationExecutor
