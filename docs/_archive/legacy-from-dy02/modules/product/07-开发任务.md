## 7.1 后端任务

### P0 — 核心功能

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B01 | 数据库初始化 | 2 张表 DDL + 索引（dy_product, dy_product_sales_history） | 无 |
| B02 | Product 实体 + Repository | Product.java, ProductRepository.java | B01 |
| B03 | ProductSalesHistory 实体 + Repository | ProductSalesHistory.java, ProductSalesHistoryRepository.java | B01 |
| B04 | ProductService | 商品 CRUD + 状态管理（publish/unpublish）+ 推荐管理（set-featured）+ 库存更新（update-inventory）+ 搜索筛选 | B02 |
| B05 | ProductSalesHistoryService | 销售记录 CRUD + 搜索 + 累计统计（getTotalSalesAmount, getTotalSalesQuantity） | B03 |
| B06 | ProductController | 8 个接口（/search, /get, /save, /delete, /update-inventory, /publish, /unpublish, /set-featured） | B04 |
| B07 | ProductSalesHistoryController | 5 个接口（/search, /get, /save, /total-sales-amount, /total-sales-quantity） | B05 |

---

### 任务详细说明

#### B01 — 数据库初始化

- 创建 `dy_product` 表（19 个字段）
- 创建 `dy_product_sales_history` 表（9 个字段）
- 创建所有索引（共 9 个）
- 参考：[02-数据库设计.md](02-数据库设计.md) 中的初始化 SQL

#### B02 — Product 实体 + Repository

```
输出文件：
  - entity/Product.java（@Entity, @Table("dy_product")）
  - repository/ProductRepository.java（JpaRepository<Product, Long>）

关键字段注解：
  - @Column(name = "user_id")
  - @Column(name = "product_name")
  - @Column(name = "price", nullable = false)
  - @Column(name = "status")
  - @Column(name = "featured")
  - @Column(name = "deleted", nullable = false)
  - @CreationTimestamp / @UpdateTimestamp

自定义查询方法：
  - findByIdAndDeletedFalse(Long id)
  - findByUserIdAndDeletedFalse(Long userId, Pageable pageable)
```

#### B03 — ProductSalesHistory 实体 + Repository

```
输出文件：
  - entity/ProductSalesHistory.java（@Entity, @Table("dy_product_sales_history")）
  - repository/ProductSalesHistoryRepository.java

自定义查询方法：
  - findByProductIdAndDeletedFalse(Long productId, Pageable pageable)
  - sumSaleAmountByProductId(Long productId)  → BigDecimal
  - sumSaleQuantityByProductId(Long productId) → Long
```

#### B04 — ProductService

```
方法清单：
  - search(ProductSearchReqVO req) → PageResultVO<ProductVO>
  - get(Long id) → ProductVO
  - save(ProductSaveReqVO req) → Long
  - delete(Long id) → void
  - updateInventory(Long id, Long quantity) → void
  - publish(Long id) → void
  - unpublish(Long id) → void
  - setFeatured(Long id, Integer featured) → void

通用逻辑（私有方法）：
  - checkExists(Long id) → Product（不存在抛 3105）
  - checkOwnership(Product product) → void（不属于当前用户抛 3112）
  - getCurrentUserId() → Long（从 SecurityContext 获取）
```

#### B05 — ProductSalesHistoryService

```
方法清单：
  - search(SalesHistorySearchReqVO req) → PageResultVO<ProductSalesHistoryVO>
  - get(Long id) → ProductSalesHistoryVO
  - save(SalesHistorySaveReqVO req) → Long
  - getTotalSalesAmount(Long productId) → BigDecimal
  - getTotalSalesQuantity(Long productId) → Long
```

#### B06 — ProductController

```java
@RestController
@RequestMapping("/api/v1/product")
public class ProductController {
    POST /search         → search(ProductSearchReqVO)
    POST /get            → get(IdReqVO)
    POST /save           → save(ProductSaveReqVO)
    POST /delete         → delete(IdReqVO)
    POST /update-inventory → updateInventory(UpdateInventoryReqVO)
    POST /publish        → publish(IdReqVO)
    POST /unpublish      → unpublish(IdReqVO)
    POST /set-featured   → setFeatured(SetFeaturedReqVO)
}
```

#### B07 — ProductSalesHistoryController

```java
@RestController
@RequestMapping("/api/v1/product/sales-history")
public class ProductSalesHistoryController {
    POST /search                  → search(SalesHistorySearchReqVO)
    POST /get                     → get(IdReqVO)
    POST /save                    → save(SalesHistorySaveReqVO)
    GET  /total-sales-amount      → getTotalSalesAmount(@RequestParam Long productId)
    GET  /total-sales-quantity    → getTotalSalesQuantity(@RequestParam Long productId)
}
```

### 任务详细说明

#### F01 — product API 模块（api/product.ts）

```typescript
// 商品管理
export const productSearch = (data: ProductSearchReq) => post('/api/v1/product/search', data)
export const productGet = (id: number) => post('/api/v1/product/get', { id })
export const productSave = (data: ProductSaveReq) => post('/api/v1/product/save', data)
export const productDelete = (id: number) => post('/api/v1/product/delete', { id })
export const productUpdateInventory = (id: number, quantity: number) =>
    post('/api/v1/product/update-inventory', { id, quantity })
export const productPublish = (id: number) => post('/api/v1/product/publish', { id })
export const productUnpublish = (id: number) => post('/api/v1/product/unpublish', { id })
export const productSetFeatured = (id: number, featured: number) =>
    post('/api/v1/product/set-featured', { id, featured })

// 销售历史
export const salesHistorySearch = (data: SalesHistorySearchReq) =>
    post('/api/v1/product/sales-history/search', data)
export const salesHistoryGet = (id: number) => post('/api/v1/product/sales-history/get', { id })
export const salesHistorySave = (data: SalesHistorySaveReq) =>
    post('/api/v1/product/sales-history/save', data)
export const salesHistoryTotalAmount = (productId: number) =>
    get('/api/v1/product/sales-history/total-sales-amount', { productId })
export const salesHistoryTotalQuantity = (productId: number) =>
    get('/api/v1/product/sales-history/total-sales-quantity', { productId })
```

#### F02 — 商品库页（ProductManagement.vue）

```
功能点：
  - 搜索栏（keyword / productCategory / status / featured）
  - 商品表格（图片/名称/SKU/分类/售价/库存/状态/推荐/操作）
  - 新增/编辑商品弹窗（ProductFormModal）
  - 库存编辑弹窗（InventoryEditModal）
  - 上架/下架切换按钮
  - 推荐/取消推荐切换按钮
  - 删除二次确认
  - 分页组件
```

#### F03 — 销售历史页（SalesHistoryPage.vue）

```
功能点：
  - 筛选栏（productId / channelSource / sessionId / 时间范围）
  - 销售记录表格（商品名/数量/金额/渠道/场次/时间）
  - 录入销售记录弹窗（SalesRecordFormModal）
  - 页面底部汇总（总销售额/总销售量）
  - 分页组件
```

## 7.4 VO / ReqVO 清单

| 类名 | 用途 |
|------|------|
| ProductVO | 商品详情响应 |
| ProductSaveReqVO | 新增/更新商品请求 |
| ProductSearchReqVO | 商品搜索请求（含分页） |
| UpdateInventoryReqVO | 更新库存请求（id + quantity） |
| SetFeaturedReqVO | 设置推荐请求（id + featured） |
| ProductSalesHistoryVO | 销售记录详情响应 |
| SalesHistorySaveReqVO | 新增销售记录请求 |
| SalesHistorySearchReqVO | 销售历史搜索请求（含分页） |
