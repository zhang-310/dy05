## 5.1 销售记录流程

### 5.1.1 手动录入销售记录

```
前端提交销售表单
    │
    ▼
ProductSalesHistoryController.save(SalesHistorySaveReqVO)
    │
    ├─ 校验必填字段（productId, saleAmount, saleTime）
    ├─ 校验 productId 对应商品存在且属于当前用户
    │
    ▼
ProductSalesHistoryService.save(salesHistory)
    │
    ▼
ProductSalesHistoryRepository.save(entity)
    │
    ▼
返回销售记录 ID（Long）
```

### 5.1.2 直播场次自动记录销售

```
直播场次结束（live 模块触发）
    │
    ▼
live 模块调用 ProductSalesHistoryService.save()
    │
    ├─ productId = 场次中的商品 ID
    ├─ saleQuantity = 该场次该商品销售数量
    ├─ saleAmount = 该场次该商品 GMV
    ├─ saleTime = 场次结束时间
    ├─ channelSource = "douyin_live"
    ├─ sessionId = 直播场次 ID
    │
    ▼
写入 dy_product_sales_history
```

### 5.1.3 销售记录查询流程

```
前端请求销售历史列表
    │
    ▼
ProductSalesHistoryController.search(SalesHistorySearchReqVO)
    │
    ├─ 如果传入 productId，校验商品归属（user_id 隔离）
    ├─ 构建查询条件（productId / channelSource / sessionId / 时间范围）
    │
    ▼
ProductSalesHistoryService.search(条件, 分页)
    │
    ▼
返回 PageResultVO<ProductSalesHistoryVO>
```

## 5.2 渠道来源（channel_source）

### 5.2.1 渠道类型定义

| channel_source 值 | 含义 | 触发方式 |
|-------------------|------|---------|
| douyin_live | 抖音直播 | 直播场次结束后由 live 模块自动写入 |
| store | 线下门店 | 用户手动录入 |
| manual | 手动录入 | 用户手动录入，来源不明确时使用 |

### 5.2.2 渠道数据价值

| 渠道 | 分析价值 |
|------|---------|
| douyin_live | 追踪直播带货效果，对比不同场次 GMV |
| store | 线上线下销售对比，了解商品全渠道表现 |
| manual | 补录历史数据，保证统计完整性 |

## 5.3 场次关联（session_id）

### 5.3.1 session_id 说明

session_id 字段存储直播场次的唯一标识，格式由 live 模块定义（如 `session_20260226_001`）。

通过 session_id 可以：
- 查询某场直播的所有商品销售记录
- 汇总某场直播的总 GMV
- 对比不同场次的销售表现

### 5.3.2 场次销售汇总查询

```sql
-- 查询某场直播的所有商品销售记录
SELECT
    p.product_name,
    psh.sale_quantity,
    psh.sale_amount,
    psh.channel_source
FROM dy_product_sales_history psh
JOIN dy_product p ON p.id = psh.product_id
WHERE psh.session_id = 'session_20260226_001'
  AND psh.deleted = 0
ORDER BY psh.sale_amount DESC;

-- 汇总某场直播总 GMV
SELECT
    SUM(sale_amount) AS total_gmv,
    SUM(sale_quantity) AS total_quantity,
    COUNT(*) AS product_count
FROM dy_product_sales_history
WHERE session_id = 'session_20260226_001'
  AND deleted = 0;
```

### 5.3.3 live 模块集成关系

```
dy_live_session（live 模块）
    │
    ├─── live_session_product（选品关联）
    │         │
    │         └─── product_id → dy_product.id
    │
    └─── 场次结束时 → 写入 dy_product_sales_history
              ├─ product_id（每个商品一条记录）
              ├─ session_id（场次标识）
              ├─ channel_source = "douyin_live"
              └─ sale_amount（该商品在本场次的 GMV）
```

## 5.4 累计销售统计

### 5.4.1 累计销售额（getTotalSalesAmount）

```
GET /api/v1/product/sales-history/total-sales-amount?productId=1
    │
    ▼
ProductSalesHistoryService.getTotalSalesAmount(productId)
    │
    ▼
SELECT SUM(sale_amount)
FROM dy_product_sales_history
WHERE product_id = ? AND deleted = 0
    │
    ▼
返回 BigDecimal（精确到分）
```

**说明：** 统计该商品所有渠道、所有时间的累计销售金额，deleted=0 的记录才计入统计。

### 5.4.2 累计销售量（getTotalSalesQuantity）

```
GET /api/v1/product/sales-history/total-sales-quantity?productId=1
    │
    ▼
ProductSalesHistoryService.getTotalSalesQuantity(productId)
    │
    ▼
SELECT SUM(sale_quantity)
FROM dy_product_sales_history
WHERE product_id = ? AND deleted = 0
    │
    ▼
返回 Long
```

## 5.5 销售趋势分析

### 5.5.1 按时间维度分析

通过 sale_time 字段可以进行多维度时间分析：

```sql
-- 按月汇总销售额
SELECT
    DATE_FORMAT(sale_time, '%Y-%m') AS month,
    SUM(sale_amount) AS monthly_gmv,
    SUM(sale_quantity) AS monthly_quantity
FROM dy_product_sales_history
WHERE product_id = ?
  AND deleted = 0
GROUP BY DATE_FORMAT(sale_time, '%Y-%m')
ORDER BY month DESC;

-- 按渠道汇总
SELECT
    channel_source,
    SUM(sale_amount) AS channel_gmv,
    SUM(sale_quantity) AS channel_quantity,
    COUNT(*) AS record_count
FROM dy_product_sales_history
WHERE product_id = ?
  AND deleted = 0
GROUP BY channel_source;
```

### 5.5.2 商品销售排行

```sql
-- 用户商品销售额排行
SELECT
    p.id,
    p.product_name,
    p.product_category,
    COALESCE(SUM(psh.sale_amount), 0) AS total_gmv,
    COALESCE(SUM(psh.sale_quantity), 0) AS total_quantity
FROM dy_product p
LEFT JOIN dy_product_sales_history psh
    ON psh.product_id = p.id AND psh.deleted = 0
WHERE p.user_id = ?
  AND p.deleted = 0
GROUP BY p.id, p.product_name, p.product_category
ORDER BY total_gmv DESC
LIMIT 10;
```

## 5.6 与直播模块的集成

### 5.6.1 数据流向

```
直播前：
  用户在直播选品页面 → 查询 dy_product（featured=1 优先）
  → 添加到 live_session_product

直播中：
  实时展示商品信息（product_name, price, image_url）

直播后：
  live 模块统计每个商品的销售数据
  → 调用 ProductSalesHistoryService.save()
  → 写入 dy_product_sales_history（session_id 关联）
  → 可选：调用 update-inventory 扣减库存
```

### 5.6.2 推荐商品在选品中的作用

```
直播选品接口（live 模块调用）：
    │
    ▼
查询 dy_product
WHERE user_id = ? AND status = 1 AND deleted = 0
ORDER BY featured DESC, create_time DESC
    │
    ├─ featured=1 的商品排在最前面
    └─ 方便主播快速找到重点推广商品
```
