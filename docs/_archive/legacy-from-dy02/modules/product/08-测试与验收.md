### 8.2.5 边界测试

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T27 | 价格为负数 | POST /save，price=-10 | 返回参数校验错误 |
| T28 | 价格为零 | POST /save，price=0 | 根据业务规则决定（建议允许，0 元商品） |
| T29 | 库存为负数 | POST /update-inventory，quantity=-1 | 返回参数校验错误 |
| T30 | 商品不存在 | POST /get，id=99999 | 返回 3105（PRODUCT_NOT_FOUND） |
| T31 | 销售金额为零 | POST /sales-history/save，saleAmount=0 | 根据业务规则决定（建议允许，0 元记录） |
| T32 | 无销售记录时统计 | GET /total-sales-amount?productId=新商品 | 返回 0.00（不报错） |
| T33 | 关键词为空 | POST /search，keyword="" | 返回全部商品（不过滤） |
| T34 | 分页越界 | POST /search，pageNum=9999 | 返回空列表，不报错 |
