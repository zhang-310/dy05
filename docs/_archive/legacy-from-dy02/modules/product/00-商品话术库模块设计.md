## 一、模块概述

### 1.1 模块定位

**商品话术库** 是面向电商直播场景的话术模板管理系统，允许用户为每个产品创建和管理多个话术版本，并通过推荐算法帮助选择最优版本。

### 1.2 核心价值

- 📦 **商品维度的话术管理**：每个产品可拥有独立的话术库
- 📊 **版本管理与对比**：支持多版本管理，可对比效果差异
- 🎯 **智能推荐**：基于效果评分、使用频率推荐最优版本
- 🔄 **快速引用**：在直播场景中快速引用库内话术，自动保存快照

### 1.3 业务场景

**场景 1：建立产品话术库**
```
电商主播 → 为产品 A 创建 5 个不同风格的话术
     ↓
系统自动记录使用次数、效果评分
     ↓
下次直播时查看推荐 → 选用效果最好的版本
```

**场景 2：快速引用和对比**
```
直播中需要讲产品 B
     ↓
打开话术库 → 搜索产品 B → 查看推荐版本
     ↓
一键引用到当前直播场次
     ↓
自动创建快照备份
```

## 二、数据模型

### 2.1 核心表：product_script_version

存储产品的话术版本数据。

```sql
CREATE TABLE product_script_version (
  id BIGSERIAL PRIMARY KEY,
  product_id BIGINT NOT NULL,  -- 关联产品 ID
  script_id BIGINT NOT NULL,   -- 关联话术 ID（如果来自话术库）
  version_number INTEGER NOT NULL DEFAULT 1,  -- 版本号
  content TEXT NOT NULL,        -- 话术内容
  style VARCHAR(64),            -- 风格（激情/温柔/专业/幽默）
  effectiveness_score DECIMAL(5,2) DEFAULT 0,  -- 效果评分（0-100）
  usage_count INTEGER DEFAULT 0,  -- 使用次数
  conversion_rate DECIMAL(5,2) DEFAULT 0,  -- 转化率（%）
  likes_count INTEGER DEFAULT 0,  -- 点赞数
  comments_count INTEGER DEFAULT 0,  -- 评论数
  is_active BOOLEAN DEFAULT true,  -- 是否启用
  is_recommended BOOLEAN DEFAULT false,  -- 是否推荐
  archived BOOLEAN DEFAULT false,  -- 是否归档
  owner_id BIGINT NOT NULL,  -- 数据隔离：所有者 ID
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  deleted_at TIMESTAMP,
  deleted INTEGER DEFAULT 0,

  UNIQUE (product_id, version_number, deleted),
  INDEX idx_product_script_version_product_id (product_id),
  INDEX idx_product_script_version_owner_id (owner_id),
  INDEX idx_product_script_version_effectiveness_score (effectiveness_score DESC),
  INDEX idx_product_script_version_usage_count (usage_count DESC),
  INDEX idx_product_script_version_is_active (is_active),
  INDEX idx_product_script_version_created_at (created_at DESC)
);

COMMENT ON TABLE product_script_version IS '商品话术版本表';
COMMENT ON COLUMN product_script_version.product_id IS '关联产品 ID';
COMMENT ON COLUMN product_script_version.style IS '话术风格分类';
COMMENT ON COLUMN product_script_version.effectiveness_score IS '效果评分（0-100）';
```

### 2.2 关系表：product_script_snapshot

记录直播场次中引用话术库的快照。

```sql
CREATE TABLE product_script_snapshot (
  id BIGSERIAL PRIMARY KEY,
  live_session_id BIGINT NOT NULL,  -- 直播场次 ID
  product_script_version_id BIGINT NOT NULL,  -- 话术版本 ID
  content_snapshot TEXT NOT NULL,  -- 快照内容（引用时的内容）
  referenced_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  owner_id BIGINT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  deleted INTEGER DEFAULT 0,

  INDEX idx_product_script_snapshot_live_session_id (live_session_id),
  INDEX idx_product_script_snapshot_product_script_version_id (product_script_version_id)
);

COMMENT ON TABLE product_script_snapshot IS '商品话术引用快照表';
```

## 八、风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|--------|
| 推荐分数算法不合理 | 推荐效果差 | 中 | 预留调整权重参数的接口 |
| 版本号并发冲突 | 数据不一致 | 低 | 使用数据库序列 + 唯一索引 |
| 搜索性能不足 | 查询卡顿 | 低 | 建立复合索引，考虑 ES 全文搜索 |
| 前端组件复杂 | 开发周期延长 | 中 | 简化 UI，采用分步实现 |
