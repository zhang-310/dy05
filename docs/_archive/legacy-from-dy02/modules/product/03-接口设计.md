## 3.2 接口详细说明

### 3.2.1 POST /api/v1/product/search — 分页搜索商品

**请求体：**

```json
{
  "keyword": "护肤",
  "productCategory": "美妆",
  "status": 1,
  "featured": 1,
  "pageNum": 1,
  "pageSize": 20
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| keyword | String | 否 | 关键词，匹配 product_name / sku / barcode |
| productCategory | String | 否 | 商品分类精确匹配 |
| status | Integer | 否 | 状态筛选：0=下架，1=上架 |
| featured | Integer | 否 | 推荐筛选：0=普通，1=推荐 |
| pageNum | Integer | 是 | 页码，从 1 开始 |
| pageSize | Integer | 是 | 每页条数，最大 100 |

**响应体：**

```json
{
  "code": 0,
  "data": {
    "total": 50,
    "list": [
      {
        "id": 1,
        "userId": 100,
        "productName": "保湿精华液",
        "productCategory": "护肤",
        "imageUrl": "https://...",
        "price": 199.00,
        "costPrice": 80.00,
        "inventory": 500,
        "sku": "SKU-001",
        "status": 1,
        "featured": 1,
        "createTime": "2026-02-01T10:00:00"
      }
    ]
  }
}
```

**说明：** admin 查看全部商品；institution 自动过滤机构范围内的商品（institution_id 隔离）；talent 不直接管理商品。推荐商品（featured=1）排在前面。

---

### 3.2.2 POST /api/v1/product/get — 获取商品详情

**请求体：**

```json
{
  "id": 1
}
```

**响应体：** 返回完整 ProductVO，包含所有字段。

**错误：** 商品不存在返回 3105（PRODUCT_NOT_FOUND），不属于当前用户或机构返回 3112（PRODUCT_FORBIDDEN）。

---

### 3.2.3 POST /api/v1/product/save — 新增/更新商品

**请求体（新增，id 为空）：**

```json
{
  "productName": "保湿精华液",
  "productCategory": "护肤",
  "description": "适合敏感肌的保湿精华",
  "imageUrl": "https://...",
  "price": 199.00,
  "costPrice": 80.00,
  "inventory": 500,
  "sku": "SKU-001",
  "barcode": "6901234567890",
  "manufacturer": "XX化妆品有限公司",
  "tags": "保湿,敏感肌,精华"
}
```

**请求体（更新，id 不为空）：**

```json
{
  "id": 1,
  "productName": "保湿精华液（升级版）",
  "price": 219.00
}
```

**响应体：** 返回商品 ID（Long）。

**说明：** id 为空时新增，id 不为空时更新。新增时 user_id 自动设为当前登录用户，institution_id 自动设为所属机构，status 默认 1，featured 默认 0。仅 admin 和 institution 可操作。

---

### 3.2.4 POST /api/v1/product/delete — 删除商品

**请求体：**

```json
{
  "id": 1
}
```

**说明：** 逻辑删除（deleted=1）。校验商品归属，不属于当前用户或机构返回 3112。

---

### 3.2.5 POST /api/v1/product/update-inventory — 更新库存

**请求体：**

```json
{
  "id": 1,
  "quantity": 300
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 商品 ID |
| quantity | Long | 是 | 新库存数量（直接设置，非增减） |

**说明：** 直接将 inventory 设置为 quantity 值，不做增减运算。quantity 不能为负数。

---

### 3.2.6 POST /api/v1/product/publish — 上架商品

**请求体：**

```json
{
  "id": 1
}
```

**说明：** 将 status 设置为 1。校验商品归属。

### 3.2.7 POST /api/v1/product/unpublish — 下架商品

### 3.2.9 POST /api/v1/product/sales-history/search — 分页搜索销售历史

**请求体：**

```json
{
  "productId": 1,
  "channelSource": "douyin_live",
  "sessionId": "session_20260226_001",
  "startTime": "2026-02-01T00:00:00",
  "endTime": "2026-02-28T23:59:59",
  "pageNum": 1,
  "pageSize": 20
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| productId | Long | 否 | 商品 ID 精确筛选 |
| channelSource | String | 否 | 渠道来源筛选 |
| sessionId | String | 否 | 场次 ID 精确筛选 |
| startTime | String | 否 | 销售时间起始（ISO 8601） |
| endTime | String | 否 | 销售时间截止（ISO 8601） |
| pageNum | Integer | 是 | 页码 |
| pageSize | Integer | 是 | 每页条数 |

## 3.3 错误码

| 错误码 | 常量名 | 说明 | HTTP 状态 |
|--------|--------|------|-----------|
| 3105 | PRODUCT_NOT_FOUND | 商品不存在 | 404 |
| 3112 | PRODUCT_FORBIDDEN | 无权访问该商品（不属于当前用户或机构） | 403 |

**说明：** 错误码位于 douyin 错误码段（3100-3199），因为 product 模块是抖音运营生态的一部分。

---

## 3.4 通用约定

| 约定 | 说明 |
|------|------|
| 认证 | 所有接口需携带有效 JWT Token |
| 角色 | admin 和 institution 角色可访问，talent 不直接管理商品 |
| 数据隔离 | admin 查看全部；institution 查询自动附加 institution_id 条件 |
| 分页 | pageNum 从 1 开始，pageSize 默认 20，最大 100 |
| 时间格式 | ISO 8601（yyyy-MM-dd'T'HH:mm:ss） |
| 金额精度 | DECIMAL(12,2)，保留两位小数 |
