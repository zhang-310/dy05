# 商品模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

product 模块是平台的商品管理核心模块，围绕用户的商品库，提供商品全生命周期管理：商品录入 → 上下架管理 → 库存维护 → 直播选品 → 销售记录 → 数据统计。

商品数据按用户隔离，推荐商品在直播选品时优先展示，销售历史记录每场直播的 GMV 数据，支持多渠道来源追踪。

## 1.2 用户故事

| 编号 | 角色 | 故事 | 验收条件 |
|------|------|------|----------|
| **商品管理** | | | |

| PR-06 | 达人 | 我要能更新商品库存 | 输入新库存数量后更新成功 |
| PR-07 | 达人 | 我要能搜索和筛选商品 | 支持按关键词/分类/状态/推荐标记筛选 |

| **销售数据** | | | |

| PR-10 | 达人 | 我要能查看商品的销售历史 | 按商品查询历史销售记录列表 |
| PR-11 | 达人 | 我要能查看商品的累计销售额 | 返回指定商品的总销售金额 |

## 1.3 功能清单

```
product 模块
├── 商品管理
│   ├── 商品 CRUD（新增/查询/更新/删除）
│   ├── 商品上架（publish）
│   ├── 商品下架（unpublish）
│   ├── 推荐标记管理（set-featured）
│   ├── 库存更新（update-inventory）
│   └── 多维度搜索（关键词/分类/状态/推荐）
│
└── 销售数据
    ├── 销售记录 CRUD（新增/查询/删除）
    ├── 按商品查询销售历史
    ├── 按渠道来源筛选
    ├── 按场次关联查询（session_id）
    ├── 累计销售额统计（getTotalSalesAmount）
    └── 累计销售量统计（getTotalSalesQuantity）
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **数据隔离** | | |
| BR-01 | 用户数据隔离 | talent 只能看到自己的商品（user_id）；institution 可查看自己+旗下达人的商品（DataScopeService）；admin 可查看全部 |
| BR-02 | 跨用户访问禁止 | 访问不属于当前用户的商品返回 3112（PRODUCT_FORBIDDEN） |
| **商品管理** | | |
| BR-03 | 价格必填 | price 字段 NOT NULL，创建商品时必须提供价格 |
| BR-04 | 库存默认值 | inventory 默认为 0，不能为负数 |
| BR-05 | 状态默认上架 | 新建商品默认 status=1（上架），可手动下架 |
| BR-06 | 推荐商品优先 | featured=1 的商品在直播选品列表中排在前面 |
| BR-07 | 软删除 | 删除操作为逻辑删除（deleted=1），数据不物理删除 |
| **销售数据** | | |
| BR-08 | 销售时间必填 | sale_time 字段 NOT NULL，记录销售时必须提供时间 |
| BR-09 | 销售金额必填 | sale_amount 字段 NOT NULL，记录销售时必须提供金额 |
| BR-10 | 场次关联 | session_id 关联直播场次，支持按场次汇总 GMV 数据 |

## 1.5 模块依赖

```
依赖关系：
auth ← product（用户认证）
storage ← product（商品图片）
product ← live（直播选品与销售记录）
```

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| auth | 用户认证、获取当前 user_id | 登录态校验 |
| storage | 商品图片上传与管理 | StorageService |
| live（被依赖） | 直播场次关联商品、记录销售 | live_session_product.product_id |
