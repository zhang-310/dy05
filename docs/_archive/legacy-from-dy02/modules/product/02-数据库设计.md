## 2.2 表结构

### dy_product — 商品库表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| user_id | BIGINT | NOT NULL | — | 所属用户 ID |
| product_name | VARCHAR(256) | NOT NULL | — | 商品名称 |
| product_category | VARCHAR(128) | | — | 商品分类 |
| description | TEXT | | — | 商品描述 |
| image_url | VARCHAR(256) | | — | 商品图片 URL |
| price | DECIMAL(12,2) | NOT NULL | — | 售价 |
| cost_price | DECIMAL(12,2) | | — | 成本价 |
| inventory | BIGINT | | 0 | 库存数量 |
| sku | VARCHAR(64) | | — | SKU 编码 |
| barcode | VARCHAR(128) | | — | 条形码 |
| manufacturer | VARCHAR(256) | | — | 生产厂商 |
| tags | VARCHAR(512) | | — | 标签（逗号分隔或 JSON） |
| status | INTEGER | | 1 | 状态：0=下架，1=上架 |
| featured | INTEGER | | 0 | 推荐：0=普通，1=推荐 |
| profit_margin_pct | DECIMAL(5,4) | | — | 利润百分比（如 0.45=45%），与 loss_per_unit 二选一 |
| loss_per_unit | DECIMAL(10,2) | | — | 每单亏损金额（元），正数表示亏多少；与 profit_margin_pct 二选一 |
| control_strategy | VARCHAR(128) | | — | 控单策略：控3单、不控单1分钟下、控单憋单等 |
| product_link | VARCHAR(512) | | — | 商品链接（抖音/淘宝等），用于 AI 提取信息 |
| ai_selling_points | TEXT | | — | AI 从链接提炼的卖点（多行文本） |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常，1=删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(user_id, status, featured)` — 用户商品列表（推荐优先）
- `(user_id, product_category)` — 按分类筛选
- `(sku)` — SKU 查询
- `(barcode)` — 条形码查询
- `(user_id, product_name)` — 关键词搜索辅助

### dy_product_sales_history — 销售历史表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGINT | PK | 自增 | 主键 |
| product_id | BIGINT | NOT NULL | — | 关联商品 ID |
| sale_quantity | BIGINT | | 0 | 销售数量 |
| sale_amount | DECIMAL(12,2) | NOT NULL | — | 销售金额（GMV） |
| sale_time | TIMESTAMP | NOT NULL | — | 销售时间 |
| channel_source | VARCHAR(64) | | — | 渠道来源（如 douyin_live / store / manual） |
| session_id | VARCHAR(128) | | — | 直播场次 ID |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常，1=删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |

索引：
- `(product_id, sale_time DESC)` — 商品销售历史列表
- `(product_id, channel_source)` — 按渠道筛选
- `(session_id)` — 按场次查询销售记录
- `(sale_time)` — 按时间范围查询

## 2.3 状态值说明

### dy_product.status

| 值 | 含义 | 说明 |
|----|------|------|
| 0 | 下架 | 商品不在直播选品中展示 |
| 1 | 上架 | 商品正常展示，可被选入直播场次 |

### dy_product.featured

| 值 | 含义 | 说明 |
|----|------|------|
| 0 | 普通商品 | 正常排序展示 |
| 1 | 推荐商品 | 在直播选品列表中优先展示 |

### dy_product_sales_history.channel_source

| 值 | 含义 | 说明 |
|----|------|------|
| douyin_live | 抖音直播 | 通过抖音直播间产生的销售 |
| store | 门店 | 线下门店销售 |
| manual | 手动录入 | 人工录入的销售数据 |

## 2.4 初始化 SQL

```sql
-- ============================================
-- product 模块数据库初始化脚本（PostgreSQL）
-- ============================================

-- 1. dy_product（商品库）
CREATE TABLE IF NOT EXISTS dy_product (
    id               BIGSERIAL       PRIMARY KEY,
    user_id          BIGINT          NOT NULL,
    product_name     VARCHAR(256)    NOT NULL,
    product_category VARCHAR(128),
    description      TEXT,
    image_url        VARCHAR(256),
    price            DECIMAL(12,2)   NOT NULL,
    cost_price       DECIMAL(12,2),
    inventory        BIGINT          DEFAULT 0,
    sku              VARCHAR(64),
    barcode          VARCHAR(128),
    manufacturer     VARCHAR(256),
    tags             VARCHAR(512),
    status           INTEGER         DEFAULT 1,
    featured         INTEGER         DEFAULT 0,
    deleted          INTEGER         NOT NULL DEFAULT 0,
    create_time      TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time      TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_product_user_status   ON dy_product(user_id, status, featured);
CREATE INDEX idx_product_user_category ON dy_product(user_id, product_category);
CREATE INDEX idx_product_sku           ON dy_product(sku);
CREATE INDEX idx_product_barcode       ON dy_product(barcode);
CREATE INDEX idx_product_user_name     ON dy_product(user_id, product_name);

-- 2. dy_product_sales_history（销售历史）
CREATE TABLE IF NOT EXISTS dy_product_sales_history (
    id             BIGSERIAL       PRIMARY KEY,
    product_id     BIGINT          NOT NULL,
    sale_quantity  BIGINT          DEFAULT 0,
    sale_amount    DECIMAL(12,2)   NOT NULL,
    sale_time      TIMESTAMP       NOT NULL,
    channel_source VARCHAR(64),
    session_id     VARCHAR(128),
    deleted        INTEGER         NOT NULL DEFAULT 0,
    create_time    TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_sales_product_time    ON dy_product_sales_history(product_id, sale_time DESC);
CREATE INDEX idx_sales_product_channel ON dy_product_sales_history(product_id, channel_source);
CREATE INDEX idx_sales_session         ON dy_product_sales_history(session_id);
CREATE INDEX idx_sales_time            ON dy_product_sales_history(sale_time);
```

**扩展字段 migration（若表已存在）：**

```sql
-- dy_product 扩展字段（直播控品、AI 卖点）
ALTER TABLE dy_product ADD COLUMN IF NOT EXISTS profit_margin_pct DECIMAL(5,4);
ALTER TABLE dy_product ADD COLUMN IF NOT EXISTS loss_per_unit DECIMAL(10,2);
ALTER TABLE dy_product ADD COLUMN IF NOT EXISTS control_strategy VARCHAR(128);
ALTER TABLE dy_product ADD COLUMN IF NOT EXISTS product_link VARCHAR(512);
ALTER TABLE dy_product ADD COLUMN IF NOT EXISTS ai_selling_points TEXT;
```

### dy_product_script — 商品话术表

> 供 live 模块引用，产品话术可直接引用或为当场直播重新 AI 生成（BR-09）

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| product_id | BIGINT | NOT NULL | — | 关联商品 ID（dy_product.id） |
| script_type | VARCHAR(32) | NOT NULL | — | 话术类型：live_intro / live_promotion / live_transition 等 |
| script_content | TEXT | NOT NULL | — | 话术内容 |
| persona_id | BIGINT | | — | 关联人设 ID |
| style | VARCHAR(32) | | — | 话术风格 |
| version | INTEGER | | 1 | 版本号 |
| is_active | BOOLEAN | | false | 是否当前激活 |
| duration | INTEGER | | — | 预计时长（秒） |
| token_usage | INTEGER | | — | AI 生成 Token 消耗 |
| created_by | BIGINT | | — | 创建人 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | |

索引：
- `(product_id, script_type, deleted)` — 按商品+类型查询
- `(product_id, is_active, deleted)` — 激活话术查询

**与 live 模块关系：** live_product.script_source=product 时，product_script_id 引用本表 id。

## 2.5 字段命名规范

| 规范 | 说明 |
|------|------|
| 表名前缀 | `dy_product` |
| 主键 | `id`（BIGSERIAL） |
| 外键 | `xxx_id`（如 product_id, user_id） |
| 时间字段 | `xxx_time`（TIMESTAMP） |
| 金额字段 | DECIMAL(12,2) |
| 状态字段 | INTEGER，0/1 枚举 |
| 逻辑删除 | `deleted`（INTEGER，0=正常 1=删除） |
| 创建/更新时间 | `create_time` / `update_time` |
