# 对标账号分析系统 - 使用指南

## 快速开始

### 1. 启动服务

```bash
# 启动依赖服务
docker compose -f docker/docker-compose.yml up -d postgres redis

# 启动后端
mvn spring-boot:run

# 启动前端
cd front
npm run dev
```

访问：`http://localhost:3000`

### 2. 基本流程

```
添加 Cookie → 搜索账号 → 采集视频 → 分析视频 → 查看结果
```

## 详细使用步骤

### 步骤 1：添加抖音 Cookie

**为什么需要 Cookie？**
- 抖音账号搜索和视频采集需要登录态
- Cookie 用于模拟浏览器登录，绕过反爬虫限制

**如何获取 Cookie？**

1. 打开浏览器，访问 `https://www.douyin.com`
2. 登录你的抖音账号
3. 按 F12 打开开发者工具
4. 切换到 Network 标签
5. 刷新页面，找到任意请求
6. 在 Request Headers 中找到 `Cookie` 字段
7. 复制整个 Cookie 值

**添加 Cookie：**

1. 访问 `http://localhost:3000/benchmark/cookie`
2. 点击"添加 Cookie"
3. 填写：
   - Cookie 名称：自定义名称（如"主账号"）
   - Cookie 值：粘贴刚才复制的 Cookie
4. 点击"保存"
5. 点击"验证"按钮，确认 Cookie 有效

**注意事项：**
- Cookie 有效期通常为 7-30 天
- Cookie 失效后需要重新获取
- 建议添加多个 Cookie 作为备份

---

### 步骤 2：搜索对标账号

**方式 1：按关键词搜索**

1. 访问 `http://localhost:3000/benchmark/accounts`
2. 点击"按关键词搜索"
3. 填写：
   - 关键词：如"护肤"、"彩妆"
   - 最低粉丝数：如 50000（5万粉丝）
   - 最多结果数：如 10
4. 点击"搜索"
5. 系统会自动搜索抖音，找到符合条件的账号
6. 搜索结果会自动保存到账号列表

**方式 2：按 URL 分析**

1. 访问 `http://localhost:3000/benchmark/accounts`
2. 点击"按 URL 分析"
3. 填写账号 URL：
   - 格式：`https://www.douyin.com/user/MS4wLjABAAAA...`
   - 如何获取：打开抖音 APP 或网页版，进入账号主页，复制 URL
4. 点击"分析"
5. 系统会自动抓取账号信息并保存

**账号信息包括：**
- 账号名称
- 粉丝数
- 视频数
- 点赞数
- 简介
- 头像

---

### 步骤 3：采集账号视频

1. 在账号列表中，点击某个账号的"查看视频"
2. 进入视频列表页面
3. 点击"采集视频"
4. 配置采集参数：
   - **最低点赞数**：如 1000（只采集点赞 ≥1000 的视频）
   - **最多采集数量**：如 50（最多采集 50 个视频）
5. 点击"确定"
6. 系统开始采集，进度会实时显示
7. 采集完成后，视频列表会自动刷新

**采集规则：**
- 按点赞数从高到低排序
- 自动去重（已采集的视频不会重复）
- 只采集符合点赞数条件的视频
- 采集到的视频状态为"待分析"

**视频信息包括：**
- 视频标题
- 封面图
- 时长
- 点赞数、评论数、分享数
- 发布时间
- 视频 URL

---

### 步骤 4：分析视频

**单个视频分析：**

1. 在视频列表中，找到想要分析的视频
2. 点击"分析"按钮
3. 配置分析参数：
   - **内容提取配置**：
     - ✅ ASR 语音识别：提取视频中的语音内容
     - ✅ OCR 字幕识别：提取视频中的字幕文字
     - ☐ 抖音 API：通过抖音 API 获取视频描述（需要 accessToken）
   - **AI 模型**：选择分析模型
     - GPT-4：最强大，分析最准确，但成本较高
     - GPT-3.5 Turbo：速度快，成本低，适合批量分析
     - Claude 3 Opus：综合能力强
     - Claude 3 Sonnet：平衡性能和成本
   - **强制重新分析**：如果视频已分析过，勾选此项会覆盖旧结果
4. 点击"确定"
5. 系统开始分析，状态变为"分析中"
6. 分析完成后，状态变为"已完成"
7. 点击"查看分析"查看结果

**批量分析：**

1. 在视频列表中，勾选多个视频
2. 点击"批量分析"
3. 配置分析参数（同上）
4. 系统会依次分析每个视频
5. 可以在任务列表中查看进度

**分析时间：**
- 单个视频分析时间：2-5 分钟
- 影响因素：
  - 视频时长
  - 是否启用 ASR/OCR
  - AI 模型选择
  - 网络速度

### 步骤 5：查看分析结果

点击"查看分析"后，会进入分析详情页面，包含 6 个维度：

#### 5.1 文案内容

展示视频的文字内容，包括：

- **ASR 语音识别**：视频中说的话（带时间轴）
- **OCR 字幕识别**：视频中的字幕文字
- **抖音 API 获取**：视频描述、标签等
- **合并后文案**：将上述内容合并，去重整理

**用途：**
- 学习爆款视频的话术
- 提取关键词和卖点
- 分析文案结构

#### 5.2 场景分析

展示视频的场景信息，包括：

- **场景数量**：视频共有多少个场景
- **场景描述**：每个场景的时间段和特点
- **关键帧**：每个场景的代表性画面（带时间戳）

**用途：**
- 了解视频的镜头切换节奏
- 学习场景设计和构图
- 分析视觉呈现方式

#### 5.3 创意分析

深度分析视频的创意手法，包括：

- **创意类型**：情感共鸣、知识科普、娱乐搞笑、产品展示等
- **钩子策略**：前 3 秒如何吸引注意力
- **内容结构**：起承转合的叙事结构
- **情绪曲线**：情绪变化的节奏和高潮点
- **节奏分析**：镜头切换、语速、音乐节奏等

**用途：**
- 学习爆款视频的创意套路
- 掌握吸引用户的技巧
- 优化自己的内容结构

#### 5.4 爆款因素

分析视频为什么能火，包括：

- **爆款因素**：核心传播要素（话题性、共鸣点、实用性等）
- **优势**：做得好的地方
- **弊端**：可以改进的地方
- **可复制要素**：可以直接借鉴的技巧

**用途：**
- 找到爆款的核心原因
- 避免常见错误
- 提取可复制的成功经验

#### 5.5 竞品对比

对比分析竞品视频，包括：

- **竞品对比报告**：与同类视频的差异
- **差异化要点**：独特的竞争优势

**用途：**
- 了解竞争格局
- 找到差异化方向
- 制定内容策略

#### 5.6 AI 深度分析

AI 综合分析报告，包括：

- **AI 综合分析**：整体评价和建议
- **话术拆解**：逐句分析话术的作用
- **改进建议**：具体可行的优化方向
- **目标受众**：适合什么人群观看
- **元数据**：AI 模型、Token 消耗、分析耗时

**用途：**
- 获得专业的分析意见
- 学习话术设计技巧
- 明确改进方向

## 高级功能

**批量采集：**
- 可以同时采集多个账号的视频
- 在账号列表中勾选多个账号

**账号筛选：**
- 按关键词搜索账号名称
- 按粉丝数筛选

**视频筛选：**
- 按标题关键词搜索
- 按点赞数范围筛选
- 按分析状态筛选（待分析、分析中、已完成、失败）

**导出分析报告：**
- 在分析详情页面，点击"导出报告"

- 在视频列表页面，点击"导出"

- 系统会自动选择可用的 Cookie

- 建议每周验证一次 Cookie 有效性

**多账号管理：**
- 可以添加多个抖音账号的 Cookie
- 不同 Cookie 可以用于不同的采集任务

## 常见问题

### Q1：为什么搜索不到账号？

**可能原因：**
1. Cookie 失效 → 重新获取 Cookie
2. 关键词太宽泛 → 使用更精确的关键词
3. 粉丝数设置太高 → 降低粉丝数要求
4. 网络问题 → 检查网络连接

### Q2：为什么采集不到视频？

**可能原因：**
1. 账号没有符合条件的视频 → 降低点赞数要求
2. 账号设置了隐私保护 → 更换其他账号
3. Playwright 未安装 → 安装 Playwright 浏览器驱动
4. Cookie 失效 → 更换 Cookie

### Q3：为什么分析失败？

**可能原因：**
1. 视频下载失败 → 检查网络，重试
2. ASR/OCR 服务未启动 → 检查服务状态
3. AI API 配额不足 → 检查 API Key 和配额
4. 视频格式不支持 → 更换其他视频

### Q4：如何提高分析准确度？

**建议：**
1. 同时启用 ASR 和 OCR
2. 选择更强大的 AI 模型（如 GPT-4）
3. 确保视频质量清晰
4. 提供更多上下文信息

### Q5：如何节省成本？

**建议：**
1. 使用 GPT-3.5 Turbo 进行批量分析
2. 只对重点视频使用 GPT-4
3. 关闭不必要的内容提取（如 OCR）
4. 缓存分析结果，避免重复分析

## 最佳实践

### 1. 账号选择

**选择标准：**
- 粉丝数 5 万 - 50 万（中腰部账号，更有参考价值）
- 近期活跃（最近 7 天有发布视频）
- 内容垂直（专注某个细分领域）
- 互动率高（点赞、评论、分享比例高）

**避免选择：**
- 头部大号（内容难以复制）
- 僵尸账号（长期不更新）
- 泛娱乐账号（内容不垂直）

### 2. 视频筛选

**筛选标准：**
- 点赞数 ≥ 1000（有一定传播度）
- 发布时间 < 30 天（内容时效性）
- 时长 15-60 秒（适合短视频）
- 完播率高（内容质量好）

**重点关注：**
- 近期爆款视频（点赞数突然增长）
- 系列视频（有持续性）
- 转化型视频（带购物车）

### 3. 分析策略

**初步筛选：**
- 使用 GPT-3.5 Turbo 快速分析 50 个视频
- 找出点赞数 Top 10 的视频

**深度分析：**
- 使用 GPT-4 深度分析 Top 10 视频
- 启用所有内容提取功能
- 对比分析，找出共性

**持续跟踪：**
- 每周采集一次新视频
- 关注账号的内容变化
- 及时调整自己的策略

### 4. 结果应用

**学习话术：**
- 提取高频关键词
- 学习开场白和结尾
- 模仿语气和节奏

**优化内容：**
- 借鉴爆款的创意类型
- 学习钩子策略
- 优化内容结构

**制定计划：**
- 根据分析结果制定内容计划
- 测试不同的创意方向
- 持续迭代优化
