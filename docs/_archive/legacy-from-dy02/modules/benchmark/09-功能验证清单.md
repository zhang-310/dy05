# 对标账号分析系统 - 功能验证清单

## 1. 环境准备

### 1.1 必需服务
- [x] PostgreSQL 15+ (端口 5433)
- [x] Redis 7 (端口 6380)
- [x] Playwright (浏览器自动化)

### 1.2 可选服务
- [ ] BOS 存储服务 (视频上传)
- [ ] FFmpeg (场景检测)
- [ ] Whisper (ASR 语音识别)
- [ ] LLM API (AI 深度分析)

### 1.3 数据库迁移
```bash
# 执行迁移脚本
psql -h localhost -p 5433 -U postgres -d dy02 -f sql/benchmark/schema.sql
```

## 2. 后端功能验证

### 2.1 Cookie 管理
- [ ] 添加抖音 Cookie
  ```bash
  POST /api/v1/benchmark/cookie/save
  {
    "cookieName": "测试Cookie",
    "cookieValue": "your_cookie_value_here"
  }
  ```
- [ ] 验证 Cookie 有效性
  ```bash
  POST /api/v1/benchmark/cookie/validate
  { "cookieId": 1 }
  ```
- [ ] 查询 Cookie 列表
  ```bash
  POST /api/v1/benchmark/cookie/list
  { "page": 0, "rows": 30 }
  ```

### 2.2 账号搜索与分析
- [ ] 按关键词搜索账号
  ```bash
  POST /api/v1/benchmark/account/search-by-keyword
  {
    "keyword": "护肤",
    "minFollowerCount": 50000,
    "maxResults": 10
  }
  ```
- [ ] 按 URL 分析账号
  ```bash
  POST /api/v1/benchmark/account/analyze-by-url
  {
    "accountUrl": "https://www.douyin.com/user/MS4wLjABAAAA..."
  }
  ```
- [ ] 查询账号列表
  ```bash
  POST /api/v1/benchmark/account/list
  {
    "page": 0,
    "rows": 30,
    "keyword": "护肤"
  }
  ```

### 2.3 视频采集
- [ ] 采集账号视频
  ```bash
  POST /api/v1/benchmark/video/collect
  {
    "benchmarkAccountId": 1,
    "minLikeCount": 1000,
    "maxVideos": 50
  }
  ```
- [ ] 查询视频列表
  ```bash
  POST /api/v1/benchmark/video/list
  {
    "page": 0,
    "rows": 30,
    "benchmarkAccountId": 1,
    "analysisStatus": "pending"
  }
  ```

### 2.4 视频深度分析
- [ ] 分析单个视频
  ```bash
  POST /api/v1/benchmark/analysis/analyze
  {
    "benchmarkVideoId": 1,
    "forceReanalyze": false,
    "enableAsr": true,
    "enableOcr": true,
    "enableApi": false,
    "aiModel": "gpt-4"
  }
  ```
- [ ] 批量分析视频
  ```bash
  POST /api/v1/benchmark/analysis/batch-analyze
  {
    "videoIds": [1, 2, 3],
    "forceReanalyze": false,
    "aiModel": "gpt-4"
  }
  ```
- [ ] 查询分析结果
  ```bash
  POST /api/v1/benchmark/analysis/get-by-video
  1
  ```

## 11. 已知限制

1. **Playwright 依赖**：账号搜索和视频采集依赖 Playwright，需要安装浏览器驱动
2. **Cookie 管理**：需要手动获取抖音 Cookie，暂不支持自动登录
3. **抖音 API**：需要 accessToken，当前实现暂不支持
4. **视频下载**：依赖 yt-dlp，需要确保网络可访问抖音
5. **AI 分析**：需要配置 LLM API Key，否则跳过 AI 分析
6. **BOS 存储**：需要配置百度云 BOS，否则跳过上传
