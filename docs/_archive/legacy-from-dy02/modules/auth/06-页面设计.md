```

│                                      │
│  ┌──────────────────────────────┐    │
│  │                              │    │
│  │  ┌─ 密码登录 ─┬─ 短信登录 ─┐ │    │
│  │  │            │            │ │    │
│  │  │ (当前 Tab)  │            │ │    │
│  │  └────────────┴────────────┘ │    │
│  │                              │    │
│  │  用户名  [__________________] │    │
│  │  密  码  [__________________] │    │
│  │  验证码  [________] [图片]    │    │  ← 密码错误后出现
│  │                              │    │
│  │       [    登  录    ]        │    │
│  │                              │    │
│  │  忘记密码？                   │    │
│  │                              │    │
│  │  ────── 第三方登录 ──────     │    │
│  │  [微信] [QQ] [抖音] [火山]    │    │
│  │                              │    │
│  └──────────────────────────────┘    │
│                                      │
└──────────────────────────────────────┘
```

**交互说明：**

| 操作 | 调用接口 | 说明 |
|------|---------|------|
| 密码登录 | `POST /api/v1/auth/login` | loginType=password |
| 短信登录 Tab | 切换为手机号+验证码输入框 | — |
| 发送验证码 | `POST /api/v1/auth/sms/send` | 60 秒倒计时 |
| 短信登录 | `POST /api/v1/auth/login` | loginType=sms |
| 密码错误后 | `GET /api/v1/auth/captcha` | 自动显示验证码输入框 |
| 忘记密码 | 跳转 /forgot-password | — |
| 第三方登录 | `GET /api/v1/auth/oauth/authorize` | 获取 URL 后浏览器跳转 |
| 登录成功 | Token 存 localStorage | 跳转管理端首页 |

**前端逻辑：**
- 登录失败返回 2004 时，自动调用 captcha 接口显示验证码
- 短信登录 Tab 切换时，表单字段动态切换（username/password → target/code）
- 第三方登录图标根据后端配置动态显示（未配置的 provider 隐藏）

```
┌──────────────────────────────────────┐
│          忘记密码                      │
│                                      │
│  ┌──────────────────────────────┐    │
│  │                              │    │
│  │  手机号/邮箱 [______________] │    │
│  │  验证码     [______] [发送]   │    │
│  │  新密码     [______________]  │    │
│  │  确认密码   [______________]  │    │
│  │                              │    │
│  │       [   重置密码   ]        │    │
│  │                              │    │
│  │  ← 返回登录                   │    │
│  │                              │    │
│  └──────────────────────────────┘    │
│                                      │
└──────────────────────────────────────┘
```

**交互说明：**

| 操作 | 调用接口 | 说明 |
|------|---------|------|
| 发送验证码 | `POST /api/v1/auth/sms/send` | type=forgot_password，60 秒倒计时 |
| 重置密码 | `POST /api/v1/auth/forgot-password` | 成功后跳转登录页 |
| 返回登录 | 跳转 /login | — |

**前端校验：**
- 新密码最低 6 位
- 确认密码与新密码一致
- 发送按钮 60 秒倒计时防重复点击

**交互说明：**

| 操作 | 调用接口 |
|------|---------|
| 角色列表 | `POST /api/v1/auth/role/search` |
| 新增/编辑 | `POST /api/v1/auth/role/save` |
| 删除 | `POST /api/v1/auth/role/delete` |

3. 使用 jstree + checkbox 展示，已授权的节点默认勾选
4. 保存时收集所有勾选节点的 ID，调用 `/auth/role/resources/save`

| Offcanvas 侧滑窗 | 用户管理、角色管理、资源管理 | 统一的编辑表单容器 |

| 搜索栏组件 | 用户管理 | 关键词 + 筛选条件 |
