## 模块定位

auth 模块是整个系统的基础支撑，负责用户身份认证（Authentication）和访问授权（Authorization）。所有其他业务模块都依赖 auth 模块提供的登录态和权限校验。

核心职责：
1. **身份认证** — 密码登录、短信/邮箱验证码登录、OAuth 第三方登录
2. **访问授权** — RBAC 权限模型，角色→资源多对多关联
3. **用户管理** — 用户 CRUD、封禁/解封、在线用户、登录日志
4. **安全防护** — 防暴力破解、图片验证码、Token 管理、密码加密

> 系统不设独立注册端点。新用户由管理员创建，或通过 OAuth 首次登录时自动创建。

## 安全架构概览

| 安全机制 | 实现方式 | 说明 |
|---------|---------|------|
| 认证方式 | Token-based（Bearer） | UUID Token，Authorization Header 传递，24h 过期 |
| 密码存储 | BCrypt | 不可逆加密，最低 6 位 |
| 权限模型 | RBAC | 角色→资源多对多，admin 超级权限 |
| 防暴力破解 | IP 级别限制 | 密码错误后同 IP 15 分钟内需图片验证码 |
| 第三方登录 | OAuth 2.0 | 微信/QQ/抖音/火山 |
| CSRF | 已禁用 | Token 认证模式不需要 CSRF 保护 |
| 白名单 | AuthTokenFilter | 6 条公开路径免认证 |
| 数据脱敏 | 手机号/邮箱 | 展示时脱敏（138****0001） |
| Token 存储 | ConcurrentHashMap | 单机部署；集群环境需改 Redis |
