## 模块定位

wecom 模块是平台的增值功能模块，围绕企业微信（WeCom/WeChat Work）机器人 Webhook，提供消息推送全链路管理：

1. **机器人配置** — 管理企业微信机器人 Webhook，支持多机器人、多类型（数据报告/告警/任务提醒/自定义）
2. **推送规则管理** — 配置定时推送（Cron）和事件驱动推送（Event），支持消息模板变量
3. **消息推送执行** — 调用企业微信 Webhook API 发送 text/markdown/news card 消息，失败自动重试
4. **消息日志与监控** — 记录每条消息的发送状态、内容、错误信息，支持失败重试

所有推送数据来源于 shortvideo（视频数据）、live（直播数据）、ai（AI 报告）模块，机器人凭证通过 config 模块统一管理。

## 模块依赖

```
auth（用户认证/owner_id 隔离）← wecom
config（企业微信凭证配置）← wecom
shortvideo（视频数据摘要推送）← wecom
live（直播数据摘要推送）← wecom
ai（AI 报告推送）← wecom
```

---

## 依赖关系表

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| auth | 用户认证、owner_id 数据隔离 | SecurityContext |
| config | 企业微信 AppID/Secret 等全局配置 | ConfigService |
| shortvideo | 视频数据摘要（播放量/互动/爆款） | ShortVideoDataService |
| live | 直播场次数据摘要（观看/互动/GMV） | LiveSessionService |
| ai | AI 任务完成通知、AI 报告内容 | AiTaskService |

## 推送场景总览

| 场景 | 触发方式 | 消息类型 | 机器人类型 |
|------|---------|---------|-----------|
| 每日数据报告 | 定时（每天 08:00） | markdown | data_report |
| 爆款视频提醒 | 事件（爆款检测） | markdown | alert |
| 直播结束报告 | 事件（直播结束） | markdown | data_report |
| 负面评论预警 | 事件（负面评论超阈值） | text | alert |
| AI 任务完成 | 事件（AI 任务完成） | text | task_reminder |
| 自定义手动推送 | 手动触发 | text/markdown | custom |
