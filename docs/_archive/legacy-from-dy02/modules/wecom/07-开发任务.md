### B03 — 机器人配置 Service + Controller

| 项目 | 内容 |
|------|------|
| 任务 | 实现机器人 CRUD、Webhook 校验、脱敏逻辑 |
| 输出 | `WcRobotService`, `WcRobotController` |
| 依赖 | B02 |
| 估时 | 1 天 |

接口（5个）：
- `POST /api/v1/wecom/robot/list` — 机器人列表（含脱敏）
- `POST /api/v1/wecom/robot/get` — 机器人详情（含关联规则数）
- `POST /api/v1/wecom/robot/save` — 新增/编辑（含 Webhook URL 格式校验）
- `POST /api/v1/wecom/robot/delete` — 删除（含关联规则保护）
- `POST /api/v1/wecom/robot/test` — 连通性测试

关键逻辑：
- `WebhookUrlValidator` — Webhook URL 格式校验工具类
- `WebhookUrlMasker` — Webhook URL 脱敏工具类（key 替换为 ****）
- 编辑时若传入脱敏 URL（含 ****），保留数据库原值

### B04 — 推送规则 Service + Controller

| 项目 | 内容 |
|------|------|
| 任务 | 实现推送规则 CRUD、Cron 校验、启停 |
| 输出 | `WcPushRuleService`, `WcPushRuleController` |
| 依赖 | B02, B03 |
| 估时 | 1 天 |

接口（4个）：
- `POST /api/v1/wecom/rule/list` — 规则列表
- `POST /api/v1/wecom/rule/save` — 新增/编辑（含 Cron 校验、机器人归属校验）
- `POST /api/v1/wecom/rule/delete` — 删除（逻辑删除）
- `POST /api/v1/wecom/rule/toggle` — 启用/禁用

关键逻辑：
- `CronExpressionValidator` — 使用 `CronExpression.parse()` 校验 Cron 合法性
- `TriggerConfigParser` — 解析 trigger_config JSON，提取 cron 或 eventType
- 保存时校验 robot_id 属于当前用户且 status=1

---

### B05 — WeCom Webhook 客户端

| 项目 | 内容 |
|------|------|
| 任务 | 封装企业微信 Webhook HTTP 调用，含限流和重试 |
| 输出 | `WecomWebhookClient`, `WecomMessageBuilder`, `WecomSendResult` |
| 依赖 | B02 |
| 估时 | 1 天 |

内容：
- `WecomWebhookClient` — RestTemplate 封装，POST JSON 到 Webhook URL，超时 10 秒
- `WecomMessageBuilder` — 构建 text/markdown/news 类型的 WeCom API 请求体 JSON
- `MessageTemplateRenderer` — 模板变量渲染（`{{变量名}}` 替换）
- `WecomRateLimiter` — 基于 Guava RateLimiter，每个 robot_id 每分钟最多 18 次
- `WecomSendResult` — 发送结果封装（success, errorMessage, responseTime）
- Spring Retry 配置（最多 3 次，指数退避 1min/3min/5min）

---

### B06 — 消息推送 Service（定时 + 事件）

| 项目 | 内容 |
|------|------|
| 任务 | 实现定时推送调度和事件驱动推送监听 |
| 输出 | `WecomPushService`, `WecomScheduledPushJob`, `WecomEventListener` |
| 依赖 | B04, B05 |
| 估时 | 1.5 天 |

内容：
- `WecomPushService.executeRule(rule, extraData)` — 核心推送执行方法（数据采集 → 模板渲染 → Webhook 调用 → 日志记录）
- `WecomPushService.handleEvent(eventType, ownerId, eventData)` — 事件处理入口（查规则 → filter 匹配 → executeRule）
- `WecomScheduledPushJob` — `@Scheduled(cron="0 * * * * ?")` 每分钟扫描 scheduled 规则
- `WecomEventListener` — 监听 4 种业务事件（ViralVideoDetected / LiveSessionEnded / NegativeCommentAlert / AiTaskCompleted）
- 数据采集适配器：`ShortVideoDataAdapter`、`LiveDataAdapter`、`AiDataAdapter`（调用对应模块 Service 获取模板变量数据）

---

### B07 — 消息日志 Service + Controller

| 项目 | 内容 |
|------|------|
| 任务 | 实现消息日志查询、重试、统计、定时清理 |
| 输出 | `WcMessageLogService`, `WcMessageLogController` |
| 依赖 | B05, B06 |
| 估时 | 0.5 天 |

接口（2个）：
- `POST /api/v1/wecom/message/list` — 消息历史列表（含统计数据）
- `POST /api/v1/wecom/message/retry` — 重试失败消息

其他：
- `WcMessageLogCleanJob` — `@Scheduled(cron="0 0 3 * * ?")` 每天凌晨清理超期日志
- 今日统计查询（总数/成功数/失败数/成功率）
