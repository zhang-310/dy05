# 企业微信对接模块 — 页面设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 6.1 页面总览

| 路由 | 页面名称 | 说明 |
|------|---------|------|
| /wecom/robots | 机器人配置 | 机器人列表、新增/编辑、测试连通性 |
| /wecom/rules | 推送规则 | 规则列表、新增/编辑、启停 |
| /wecom/messages | 消息记录 | 消息发送历史、内容预览、失败重试 |

## 6.2 /wecom/robots — 机器人配置页

### 6.2.1 页面功能

- 展示当前用户的所有机器人，支持按类型筛选
- 新增/编辑机器人（弹窗表单）
- 测试机器人连通性（发送测试消息）
- 启用/禁用机器人（行内切换）
- 删除机器人（有关联规则时提示先删除规则）

| 组件 | 说明 |
|------|------|
| `el-table` | 机器人列表，支持按类型筛选 |

### 6.4.5 前端组件说明

## 6.5 路由配置

```typescript
// frontend/src/router/modules/wecom.ts
export default [
  {
    path: '/wecom',
    meta: { title: '企业微信对接', icon: 'ChatDotRound' },
    children: [
      {
        path: 'robots',
        component: () => import('@/views/wecom/robots/index.vue'),
        meta: { title: '机器人配置' }
      },
      {
        path: 'rules',
        component: () => import('@/views/wecom/rules/index.vue'),
        meta: { title: '推送规则' }
      },
      {
        path: 'messages',
        component: () => import('@/views/wecom/messages/index.vue'),
        meta: { title: '消息记录' }
      }
    ]
  }
]
```
