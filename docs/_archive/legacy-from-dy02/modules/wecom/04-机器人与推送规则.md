# 企业微信对接模块 — 机器人与推送规则

> 版本：3.0 | 更新日期：2026-02-26

---

## 4.1 机器人配置

### 4.1.1 机器人类型说明

wecom 模块支持四种机器人类型，每种类型对应不同的推送场景：

| 类型值 | 中文名 | 典型用途 | 推荐消息类型 |
|--------|--------|---------|------------|
| data_report | 数据报告机器人 | 每日/每周数据摘要推送 | markdown |
| alert | 告警机器人 | 负面评论预警、异常告警 | text / markdown |
| task_reminder | 任务提醒机器人 | AI 任务完成通知、待办提醒 | text |
| custom | 自定义机器人 | 用户自定义场景 | text / markdown / news |

> 机器人类型仅作为分类标签，不限制实际发送的消息类型。一个机器人可以关联多条推送规则。

### 4.1.2 Webhook URL 格式

企业微信机器人 Webhook URL 固定格式：

```
https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key={UUID}
```

校验规则（后端 + 前端双重校验）：
- 必须以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头
- key 参数必须存在且非空
- 整体 URL 长度不超过 512 字符

校验正则（Java）：
```java
private static final Pattern WEBHOOK_PATTERN = Pattern.compile(
    "^https://qyapi\\.weixin\\.qq\\.com/cgi-bin/webhook/send\\?key=[a-zA-Z0-9\\-]+$"
);
```

### 4.1.3 Webhook URL 脱敏

列表和详情接口返回时，对 webhook_url 中的 key 参数进行脱敏处理：

```
原始：https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=abc12345-xxxx-xxxx-xxxx-xxxxxxxxxxxx
脱敏：https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=****
```

脱敏逻辑（Java）：
```java
public static String maskWebhookUrl(String webhookUrl) {
    int keyIndex = webhookUrl.indexOf("?key=");
    if (keyIndex == -1) return webhookUrl;
    return webhookUrl.substring(0, keyIndex + 5) + "****";
}
```

> 编辑机器人时，前端若不修改 Webhook URL，传回脱敏值，后端检测到 `****` 则保留数据库原值不更新。

### 4.1.4 连通性测试流程

```
用户点击"测试"
    │
    ▼
后端查询 webhook_url（原始值，不脱敏）
    │
    ▼
构建测试消息（text 类型）：
{
  "msgtype": "text",
  "text": {
    "content": "【连通性测试】来自抖音运营平台的测试消息\n发送时间：2026-02-26 10:00:00\n如收到此消息，说明机器人配置正确。"
  }
}
    │
    ▼
POST {webhook_url}（超时 5 秒）
    │
    ├── 成功（HTTP 200，errcode=0）→ 返回 success=true，responseTime
    │
    └── 失败（HTTP 非200 或 errcode≠0）→ 返回 success=false，errorDetail
    │
    ▼
写入 wc_message_log（rule_id=NULL，标记为测试消息）
```

## 4.2 推送规则

### 4.2.1 规则结构

每条推送规则包含：
- **触发条件**：何时触发（定时 Cron 或业务事件）
- **目标机器人**：推送到哪个 Webhook
- **消息模板**：推送什么内容（支持变量占位符）

### 4.2.2 定时推送规则（scheduled）

trigger_config 格式：
```json
{
  "cron": "0 0 8 * * ?"
}
```

Cron 表达式说明（Spring 6位格式：秒 分 时 日 月 周）：

| 场景 | Cron 表达式 | 说明 |
|------|------------|------|
| 每天 08:00 | `0 0 8 * * ?` | 每日数据报告 |
| 每天 09:00 | `0 0 9 * * ?` | 早间提醒 |
| 每周一 09:00 | `0 0 9 ? * MON` | 周报推送 |
| 每小时整点 | `0 0 * * * ?` | 高频监控 |

Cron 校验（后端）：
```java
// 使用 Spring CronExpression 校验
try {
    CronExpression.parse(cron);
} catch (IllegalArgumentException e) {
    throw new BizException(ErrorCode.WECOM_RULE_INVALID_CRON);
}
```

### 4.2.3 事件驱动规则（event）

trigger_config 格式：
```json
{
  "eventType": "VIRAL_VIDEO_DETECTED",
  "filter": {
    "minPlayCount": 50000
  }
}
```

支持的事件类型及 filter 参数：

| eventType | 说明 | 可用 filter |
|-----------|------|------------|
| VIRAL_VIDEO_DETECTED | 爆款视频检测到 | minPlayCount（最低播放量） |
| LIVE_SESSION_ENDED | 直播场次结束 | minDuration（最短直播时长，分钟） |
| NEGATIVE_COMMENT_ALERT | 负面评论超阈值 | minRatio（最低负面比例，0-1） |
| AI_TASK_COMPLETED | AI 任务完成 | taskType（任务类型，可选） |

filter 为可选字段，不填则所有该类型事件都触发。

### 4.2.4 规则与机器人的关系

```
一个用户
    ├── 机器人 A（data_report）
    │       ├── 规则 1：每日数据报告（scheduled, 08:00）
    │       └── 规则 2：每周数据周报（scheduled, 周一09:00）
    │
    ├── 机器人 B（alert）
    │       ├── 规则 3：爆款视频提醒（event, VIRAL_VIDEO_DETECTED）
    │       ├── 规则 4：负面评论预警（event, NEGATIVE_COMMENT_ALERT）
    │       └── 规则 5：直播结束报告（event, LIVE_SESSION_ENDED）
    │
    └── 机器人 C（task_reminder）
            └── 规则 6：AI 任务完成通知（event, AI_TASK_COMPLETED）
```

## 4.3 消息模板

### 4.3.1 模板变量系统

模板变量使用 `{{变量名}}` 语法，渲染时由 `MessageTemplateRenderer` 替换：

```java
public class MessageTemplateRenderer {
    public String render(String template, Map<String, String> variables) {
        String result = template;
        for (Map.Entry<String, String> entry : variables.entrySet()) {
            result = result.replace("{{" + entry.getKey() + "}}", entry.getValue());
        }
        return result;
    }
}
```

### 4.3.2 变量来源

| 变量 | 来源 | 说明 |
|------|------|------|
| {{date}} | 系统自动 | 当前日期 yyyy-MM-dd |
| {{datetime}} | 系统自动 | 当前时间 yyyy-MM-dd HH:mm:ss |
| {{owner_name}} | auth 模块 | 用户昵称 |
| {{video_count}} | shortvideo 模块 | 昨日发布视频数 |
| {{total_play}} | shortvideo 模块 | 昨日总播放量（格式化，如 12.3万） |
| {{total_like}} | shortvideo 模块 | 昨日总点赞数 |
| {{total_comment}} | shortvideo 模块 | 昨日总评论数 |
| {{viral_video_title}} | shortvideo 事件 | 爆款视频标题 |
| {{viral_play_count}} | shortvideo 事件 | 爆款视频播放量 |
| {{live_duration}} | live 模块 | 直播时长（分钟） |
| {{live_watch_count}} | live 模块 | 直播观看人数 |
| {{live_peak_watch}} | live 模块 | 直播最高同时在线 |
| {{negative_ratio}} | shortvideo 事件 | 负面评论占比（如 35%） |
| {{negative_video_title}} | shortvideo 事件 | 触发预警的视频标题 |
| {{ai_task_type}} | ai 模块 | AI 任务类型（中文） |
| {{ai_task_result}} | ai 模块 | AI 任务结果摘要（前100字） |

### 4.3.3 内置消息模板示例

**每日数据报告（markdown）：**

## 4.4 企业微信消息类型

### 4.4.1 text — 文本消息

```json
{
  "msgtype": "text",
  "text": {
    "content": "消息内容，支持换行符 \n"
  }
}
```

适用场景：简单通知、告警、任务提醒。

### 4.4.2 markdown — Markdown 消息

```json
{
  "msgtype": "markdown",
  "markdown": {
    "content": "## 标题\n\n**加粗** 内容\n- 列表项1\n- 列表项2\n\n> 引用文字"
  }
}
```

企业微信 Markdown 支持的语法：
- 标题：`# H1` `## H2` `### H3`
- 加粗：`**文字**`
- 链接：`[文字](URL)`
- 引用：`> 文字`
- 列表：`- 项目`
- 换行：`\n`

> 注意：企业微信 Markdown 不支持表格、代码块等复杂语法。

### 4.4.3 news — 图文卡片消息

```json
{
  "msgtype": "news",
  "news": {
    "articles": [
      {
        "title": "标题（最多128字节）",
        "description": "描述（最多512字节）",
        "url": "点击跳转的链接",
        "picurl": "图片链接（可选）"
      }
    ]
  }
}
```

适用场景：带链接跳转的数据报告、爆款视频详情推送。

> 当前版本 wecom 模块主要使用 text 和 markdown 类型，news 类型预留供后续扩展。
