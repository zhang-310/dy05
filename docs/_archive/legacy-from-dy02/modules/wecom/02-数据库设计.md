# 企业微信对接模块 — 数据库设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 2.1 ER 关系总览

```
sys_user (auth 模块)
    │
    ├─── wc_robot_config（机器人配置）
    │        │
    │        └─── wc_push_rule（推送规则）
    │                 │
    │                 └─── wc_message_log（消息日志）
    │
    └─── wc_message_log（消息日志，直接关联 owner_id）
```

---

## 2.2 表结构

### wc_robot_config — 机器人配置表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID |
| robot_name | VARCHAR(128) | NOT NULL | — | 机器人名称 |
| webhook_url | VARCHAR(512) | NOT NULL | — | 企业微信 Webhook 地址 |
| robot_type | VARCHAR(32) | NOT NULL | 'custom' | 机器人类型：data_report/alert/task_reminder/custom |
| status | SMALLINT | NOT NULL | 1 | 状态：0=禁用，1=启用 |
| description | VARCHAR(256) | | — | 备注描述 |
| deleted | SMALLINT | NOT NULL | 0 | 逻辑删除：0=正常，1=已删除 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(owner_id, deleted)` — 用户机器人列表查询
- `(owner_id, robot_type, status)` — 按类型筛选启用机器人

---

### wc_push_rule — 推送规则表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID |
| robot_id | BIGINT | NOT NULL | — | 关联机器人 ID（wc_robot_config.id） |
| rule_name | VARCHAR(128) | NOT NULL | — | 规则名称 |
| trigger_type | VARCHAR(16) | NOT NULL | — | 触发类型：scheduled/event |
| trigger_config | TEXT | NOT NULL | — | 触发配置（JSON）：Cron 表达式或事件类型 |
| message_template | TEXT | NOT NULL | — | 消息模板（支持 {{变量}} 占位符） |
| status | SMALLINT | NOT NULL | 1 | 状态：0=禁用，1=启用 |
| last_trigger_time | TIMESTAMP | | — | 最后触发时间 |
| deleted | SMALLINT | NOT NULL | 0 | 逻辑删除：0=正常，1=已删除 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(owner_id, deleted)` — 用户规则列表查询
- `(trigger_type, status, deleted)` — 定时任务扫描启用的 scheduled 规则
- `(robot_id)` — 按机器人查规则（删除机器人前校验）

---

### wc_message_log — 消息日志表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID |
| robot_id | BIGINT | NOT NULL | — | 关联机器人 ID |
| rule_id | BIGINT | | — | 关联规则 ID（手动推送时为 NULL） |
| message_type | VARCHAR(16) | NOT NULL | 'text' | 消息类型：text/markdown/news |
| message_content | TEXT | NOT NULL | — | 消息完整内容（JSON） |
| status | SMALLINT | NOT NULL | 0 | 发送状态：0=失败，1=成功 |
| error_message | VARCHAR(512) | | — | 失败原因（status=0 时填写） |
| send_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 发送时间 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |

索引：
- `(owner_id, send_time DESC)` — 用户消息历史列表
- `(owner_id, status, send_time DESC)` — 按状态筛选（查失败消息）
- `(rule_id, send_time DESC)` — 按规则查消息历史
- `(robot_id, send_time DESC)` — 按机器人查消息历史

> 注意：wc_message_log 无 deleted 字段，消息日志不支持逻辑删除，超过保留期限的日志由定时任务物理清理。

## 2.3 完整 DDL

```sql
-- ============================================================
-- wecom 模块数据库初始化脚本
-- 版本：3.0 | 日期：2026-02-26
-- ============================================================

-- 机器人配置表
CREATE TABLE wc_robot_config (
    id           BIGSERIAL     PRIMARY KEY,
    owner_id     BIGINT        NOT NULL,
    robot_name   VARCHAR(128)  NOT NULL,
    webhook_url  VARCHAR(512)  NOT NULL,
    robot_type   VARCHAR(32)   NOT NULL DEFAULT 'custom',
    status       SMALLINT      NOT NULL DEFAULT 1,
    description  VARCHAR(256),
    deleted      SMALLINT      NOT NULL DEFAULT 0,
    create_time  TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time  TIMESTAMP     NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_robot_type CHECK (robot_type IN ('data_report', 'alert', 'task_reminder', 'custom')),
    CONSTRAINT chk_robot_status CHECK (status IN (0, 1)),
    CONSTRAINT chk_robot_deleted CHECK (deleted IN (0, 1))
);

CREATE INDEX idx_wc_robot_owner ON wc_robot_config (owner_id, deleted);
CREATE INDEX idx_wc_robot_type ON wc_robot_config (owner_id, robot_type, status);

COMMENT ON TABLE wc_robot_config IS '企业微信机器人配置表';
COMMENT ON COLUMN wc_robot_config.owner_id IS '所属用户 ID';
COMMENT ON COLUMN wc_robot_config.robot_name IS '机器人名称';
COMMENT ON COLUMN wc_robot_config.webhook_url IS '企业微信 Webhook 地址';
COMMENT ON COLUMN wc_robot_config.robot_type IS '机器人类型：data_report=数据报告, alert=告警, task_reminder=任务提醒, custom=自定义';
COMMENT ON COLUMN wc_robot_config.status IS '状态：0=禁用, 1=启用';

-- 推送规则表
CREATE TABLE wc_push_rule (
    id               BIGSERIAL    PRIMARY KEY,
    owner_id         BIGINT       NOT NULL,
    robot_id         BIGINT       NOT NULL,
    rule_name        VARCHAR(128) NOT NULL,
    trigger_type     VARCHAR(16)  NOT NULL,
    trigger_config   TEXT         NOT NULL,
    message_template TEXT         NOT NULL,
    status           SMALLINT     NOT NULL DEFAULT 1,
    last_trigger_time TIMESTAMP,
    deleted          SMALLINT     NOT NULL DEFAULT 0,
    create_time      TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time      TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_rule_trigger_type CHECK (trigger_type IN ('scheduled', 'event')),
    CONSTRAINT chk_rule_status CHECK (status IN (0, 1)),
    CONSTRAINT chk_rule_deleted CHECK (deleted IN (0, 1)),
    CONSTRAINT fk_rule_robot FOREIGN KEY (robot_id) REFERENCES wc_robot_config (id)
);

CREATE INDEX idx_wc_rule_owner ON wc_push_rule (owner_id, deleted);
CREATE INDEX idx_wc_rule_trigger ON wc_push_rule (trigger_type, status, deleted);
CREATE INDEX idx_wc_rule_robot ON wc_push_rule (robot_id);

COMMENT ON TABLE wc_push_rule IS '企业微信推送规则表';
COMMENT ON COLUMN wc_push_rule.trigger_type IS '触发类型：scheduled=定时, event=事件驱动';
COMMENT ON COLUMN wc_push_rule.trigger_config IS '触发配置 JSON：scheduled 时为 {"cron":"0 0 8 * * ?"}, event 时为 {"eventType":"VIRAL_VIDEO_DETECTED"}';
COMMENT ON COLUMN wc_push_rule.message_template IS '消息模板，支持 {{变量}} 占位符';
COMMENT ON COLUMN wc_push_rule.last_trigger_time IS '最后一次触发时间';

-- 消息日志表
CREATE TABLE wc_message_log (
    id              BIGSERIAL    PRIMARY KEY,
    owner_id        BIGINT       NOT NULL,
    robot_id        BIGINT       NOT NULL,
    rule_id         BIGINT,
    message_type    VARCHAR(16)  NOT NULL DEFAULT 'text',
    message_content TEXT         NOT NULL,
    status          SMALLINT     NOT NULL DEFAULT 0,
    error_message   VARCHAR(512),
    send_time       TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,
    create_time     TIMESTAMP    NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_msg_type CHECK (message_type IN ('text', 'markdown', 'news')),
    CONSTRAINT chk_msg_status CHECK (status IN (0, 1)),
    CONSTRAINT fk_msg_robot FOREIGN KEY (robot_id) REFERENCES wc_robot_config (id),
    CONSTRAINT fk_msg_rule FOREIGN KEY (rule_id) REFERENCES wc_push_rule (id)
);

CREATE INDEX idx_wc_log_owner_time ON wc_message_log (owner_id, send_time DESC);
CREATE INDEX idx_wc_log_owner_status ON wc_message_log (owner_id, status, send_time DESC);
CREATE INDEX idx_wc_log_rule ON wc_message_log (rule_id, send_time DESC);
CREATE INDEX idx_wc_log_robot ON wc_message_log (robot_id, send_time DESC);

COMMENT ON TABLE wc_message_log IS '企业微信消息发送日志表';
COMMENT ON COLUMN wc_message_log.rule_id IS '关联规则 ID，手动推送时为 NULL';
COMMENT ON COLUMN wc_message_log.message_type IS '消息类型：text=文本, markdown=Markdown, news=图文卡片';
COMMENT ON COLUMN wc_message_log.status IS '发送状态：0=失败, 1=成功';
COMMENT ON COLUMN wc_message_log.error_message IS '失败原因描述';
```

## 2.4 trigger_config JSON 格式说明

### 定时触发（scheduled）

```json
{
  "cron": "0 0 8 * * ?"
}
```

### 事件触发（event）

```json
{
  "eventType": "VIRAL_VIDEO_DETECTED",
  "filter": {
    "minPlayCount": 10000
  }
}
```

支持的 eventType 枚举：

| 事件类型 | 说明 | 来源模块 |
|---------|------|---------|
| VIRAL_VIDEO_DETECTED | 爆款视频检测到 | shortvideo |
| LIVE_SESSION_ENDED | 直播场次结束 | live |
| NEGATIVE_COMMENT_ALERT | 负面评论超阈值 | shortvideo |
| AI_TASK_COMPLETED | AI 任务完成 | ai |
| DAILY_REPORT | 每日数据报告（也可用 scheduled） | 内部 |

## 2.5 message_template 变量说明

模板使用 `{{变量名}}` 语法，推送时由系统自动替换：

| 变量 | 说明 | 适用场景 |
|------|------|---------|
| {{date}} | 当前日期（yyyy-MM-dd） | 所有场景 |
| {{owner_name}} | 用户昵称 | 所有场景 |
| {{video_count}} | 昨日发布视频数 | 每日报告 |
| {{total_play}} | 昨日总播放量 | 每日报告 |
| {{total_like}} | 昨日总点赞数 | 每日报告 |
| {{viral_video_title}} | 爆款视频标题 | 爆款提醒 |
| {{viral_play_count}} | 爆款视频播放量 | 爆款提醒 |
| {{live_duration}} | 直播时长（分钟） | 直播报告 |
| {{live_watch_count}} | 直播观看人数 | 直播报告 |
| {{negative_ratio}} | 负面评论占比（%） | 负面预警 |
| {{ai_task_type}} | AI 任务类型 | AI 通知 |
| {{ai_task_result}} | AI 任务结果摘要 | AI 通知 |
