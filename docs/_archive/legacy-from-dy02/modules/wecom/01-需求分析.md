# 企业微信对接模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

wecom 模块是平台的 P2 增值功能模块，围绕企业微信机器人 Webhook，为用户提供运营数据的自动推送能力。用户配置好机器人 Webhook 后，平台自动将每日数据报告、爆款提醒、直播结束报告、负面评论预警、AI 任务完成通知等关键信息推送到企业微信群或个人会话，实现运营数据的实时感知。

所有推送数据来源于 shortvideo、live、ai 等业务模块，机器人凭证由用户自行配置并存储在本模块，不依赖 config 模块的全局配置。

| WC-05 | 达人 | 我要能配置每日数据报告的推送时间和目标机器人 | 设置 Cron 表达式，选择机器人，保存后生效 |

| WC-11 | 达人 | 我要能重试发送失败的消息 | 点击重试，重新调用 Webhook 发送 |

## 1.3 功能清单

```
wecom 模块
├── 机器人配置（wc_robot_config）
│   ├── 机器人 CRUD（名称/Webhook URL/类型/描述）
│   ├── Webhook URL 格式校验（必须是企业微信 Webhook 格式）
│   ├── 连通性测试（发送测试消息到 Webhook）
│   ├── 启用/禁用机器人
│   └── 机器人列表（按类型筛选）
│
├── 推送规则（wc_push_rule）
│   ├── 规则 CRUD（名称/机器人/触发类型/触发配置/消息模板）
│   ├── 定时推送规则（trigger_type=scheduled，Cron 表达式）
│   ├── 事件驱动规则（trigger_type=event，事件类型配置）
│   ├── 消息模板变量支持（{{date}}/{{video_count}} 等）
│   ├── 启用/禁用规则（toggle）
│   └── 规则列表（显示最后触发时间）
│
├── 消息推送执行
│   ├── 定时推送（@Scheduled，读取 scheduled 类型规则）
│   ├── 事件驱动推送（Spring Events，监听业务事件）
│   ├── 消息构建（模板变量渲染 + 数据填充）
│   ├── WeCom Webhook API 调用（POST JSON）
│   ├── 失败自动重试（最多 3 次，指数退避）
│   └── 手动触发推送（/api/v1/wecom/push）
│
└── 消息日志（wc_message_log）
    ├── 消息发送记录（机器人/规则/类型/内容/状态/错误信息）
    ├── 消息历史列表（按状态/时间筛选）
    ├── 消息内容预览
    └── 失败消息重试
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **机器人管理** | | |
| BR-01 | Webhook URL 格式校验 | 保存时校验 URL 必须以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头 |
| BR-02 | 机器人数据隔离 | 用户只能查看和操作自己的机器人（owner_id 隔离） |
| BR-03 | 禁用机器人保护 | 机器人禁用后，所有关联的推送规则自动暂停执行，不删除规则 |
| BR-04 | 机器人删除保护 | 有关联推送规则的机器人不能直接删除，需先删除或迁移规则 |
| **推送规则** | | |
| BR-05 | 定时规则 Cron 校验 | trigger_type=scheduled 时，trigger_config 必须是合法的 Cron 表达式（6位） |
| BR-06 | 事件规则类型枚举 | trigger_type=event 时，trigger_config.eventType 必须是已定义的事件类型枚举值 |
| BR-07 | 规则关联机器人校验 | 规则关联的 robot_id 必须属于当前用户且状态为启用 |
| **消息推送** | | |
| BR-08 | 推送失败重试 | 调用 Webhook 失败后自动重试，最多重试 3 次，间隔 1min/3min/5min（指数退避） |
| BR-09 | 消息日志必记录 | 每次推送（无论成功失败）都必须写入 wc_message_log |
| BR-10 | 手动推送权限 | /api/v1/wecom/push 接口仅限内部服务调用（通过 IP 白名单或内部 Token 鉴权） |

## 1.5 模块依赖

```
依赖关系：
auth（用户认证）← wecom
shortvideo（视频数据摘要）← wecom
live（直播数据摘要）← wecom
ai（AI 任务通知）← wecom
```

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| auth | 用户认证、owner_id 数据隔离 | SecurityContext |
| shortvideo | 每日视频数据摘要、爆款检测事件 | ShortVideoDataService, ViralVideoEvent |
| live | 直播场次结束事件、场次数据摘要 | LiveSessionEndEvent, LiveSessionService |
| ai | AI 任务完成事件、AI 报告内容 | AiTaskCompletedEvent, AiReportService |

## 1.6 环境变量

| 变量名 | 级别 | 默认值 | 说明 |
|--------|------|--------|------|
| WC_DAILY_REPORT_CRON | 🟢 可选 | 0 0 8 * * ? | 每日数据报告推送 Cron |
| WC_RETRY_MAX_TIMES | 🟢 可选 | 3 | 推送失败最大重试次数 |
| WC_RETRY_INTERVAL_SECONDS | 🟢 可选 | 60,180,300 | 重试间隔（秒，逗号分隔） |
| WC_MESSAGE_LOG_RETENTION_DAYS | 🟢 可选 | 90 | 消息日志保留天数 |
| WC_INTERNAL_PUSH_TOKEN | 🔴 必填（内部推送） | — | 内部推送接口鉴权 Token |
