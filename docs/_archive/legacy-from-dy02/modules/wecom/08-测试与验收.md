## 8.3 验收标准

### 功能验收

| 验收项 | 标准 |
|--------|------|
| 机器人配置 | 能完成机器人 CRUD，Webhook URL 格式校验正确，脱敏显示正常 |
| 连通性测试 | 测试消息能正确发送到企业微信，失败时返回明确错误信息 |
| 推送规则 | 能配置定时和事件两种规则，Cron 校验正确，启停功能正常 |
| 定时推送 | Cron 时间点到达时自动触发推送，last_trigger_time 正确更新 |
| 事件推送 | 4 种业务事件均能正确触发对应规则，filter 过滤逻辑正确 |
| 消息模板 | 模板变量正确渲染，text/markdown 类型自动判断正确 |
| 消息日志 | 每次推送均有日志记录，失败重试功能正常 |
| 数据隔离 | 用户只能操作自己的机器人和规则，跨用户访问返回正确错误码 |

### 性能验收

| 验收项 | 标准 |
|--------|------|
| 机器人列表响应 | < 200ms（单用户 10 个机器人） |
| 消息日志列表响应 | < 500ms（单用户 1000 条日志） |
| Webhook 调用超时 | 10 秒超时，超时后记录失败日志 |
| 定时任务扫描 | 每分钟扫描耗时 < 1 秒（100 个用户，每用户 5 条规则） |
