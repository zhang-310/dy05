# 企业微信对接模块 — 接口设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 3.1 接口总览

| 分组 | 接口数 | 说明 |
|------|--------|------|
| 机器人管理 | 5 | 机器人 CRUD + 连通性测试 |
| 推送规则 | 4 | 规则 CRUD + 启停 |
| 消息日志 | 2 | 消息历史 + 失败重试 |
| 手动推送 | 1 | 内部手动触发推送 |
| **合计** | **12** | |

所有接口统一前缀：`/api/v1/wecom`
请求方式：全部为 `POST`
认证方式：Bearer Token（除 `/push` 接口使用内部 Token）

---

## 3.2 通用响应格式

```json
{
  "code": 0,
  "message": "success",
  "data": { ... }
}
```

错误响应：
```json
{
  "code": 3901,
  "message": "企业微信机器人未配置",
  "data": null
}
```

## 3.3 机器人管理接口

### 3.3.1 机器人列表

```
POST /api/v1/wecom/robot/list
```

**请求体：**
```json
{
  "robotType": "data_report",
  "status": 1,
  "page": 1,
  "size": 20
}
```

字段说明：
- `robotType`：可选，按类型筛选（data_report/alert/task_reminder/custom）
- `status`：可选，按状态筛选（0=禁用/1=启用）
- `page`/`size`：分页参数，默认 page=1, size=20

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 3,
    "list": [
      {
        "id": 1,
        "robotName": "运营数据机器人",
        "webhookUrl": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=****",
        "robotType": "data_report",
        "status": 1,
        "description": "每日数据报告推送",
        "createTime": "2026-02-01T10:00:00",
        "updateTime": "2026-02-20T08:30:00"
      }
    ]
  }
}
```

> 注意：响应中 webhookUrl 的 key 参数脱敏显示（替换为 ****）。

### 3.3.3 保存机器人（新增/编辑）

```
POST /api/v1/wecom/robot/save
```

**请求体（新增，id 为空）：**
```json
{
  "robotName": "告警机器人",
  "webhookUrl": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "robotType": "alert",
  "description": "负面评论和爆款告警"
}
```

**请求体（编辑，id 不为空）：**
```json
{
  "id": 2,
  "robotName": "告警机器人（更新）",
  "webhookUrl": "https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx",
  "robotType": "alert",
  "description": "负面评论和爆款告警"
}
```

字段校验：
- `robotName`：必填，1-128 字符
- `webhookUrl`：必填，必须以 `https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=` 开头
- `robotType`：必填，枚举值之一

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 2
  }
}
```

**错误码：**
- `3907`：WECOM_WEBHOOK_INVALID — Webhook URL 格式不合法

---

### 3.3.4 删除机器人

```
POST /api/v1/wecom/robot/delete
```

**请求体：**
```json
{
  "id": 2
}
```

**处理逻辑：**
1. 校验机器人属于当前用户
2. 检查是否有关联的未删除推送规则，若有则返回错误
3. 逻辑删除（deleted=1）

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": null
}
```

**错误码：**
- `3904`：WECOM_ROBOT_NOT_FOUND
- `3905`：WECOM_ROBOT_FORBIDDEN
- `3901`：WECOM_NOT_CONFIGURED — 机器人下有关联规则，无法删除（复用错误码语义）

---

### 3.3.5 测试机器人连通性

```
POST /api/v1/wecom/robot/test
```

**请求体：**
```json
{
  "id": 1
}
```

**处理逻辑：**
1. 查询机器人 Webhook URL
2. 构建测试消息（text 类型，内容："【连通性测试】来自抖音运营平台的测试消息，发送时间：2026-02-26 10:00:00"）
3. 调用 WeCom Webhook API
4. 记录测试结果到 wc_message_log（rule_id=NULL）

**响应（成功）：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "success": true,
    "responseTime": 320
  }
}
```

**响应（失败）：**
```json
{
  "code": 3902,
  "message": "企业微信消息发送失败：errcode=93000, errmsg=invalid webhook url",
  "data": {
    "success": false,
    "errorDetail": "errcode=93000, errmsg=invalid webhook url"
  }
}
```

**错误码：**
- `3902`：WECOM_SEND_FAIL — Webhook 调用失败

### 3.4.2 保存规则（新增/编辑）

```
POST /api/v1/wecom/rule/save
```

**请求体：**
```json
{
  "id": null,
  "robotId": 1,
  "ruleName": "每日数据报告",
  "triggerType": "scheduled",
  "triggerConfig": "{\"cron\":\"0 0 8 * * ?\"}",
  "messageTemplate": "## 📊 {{date}} 运营日报\n\n**视频数据**\n- 昨日发布：{{video_count}} 条\n- 总播放量：{{total_play}}\n- 总点赞数：{{total_like}}"
}
```

字段校验：
- `robotId`：必填，机器人必须属于当前用户且状态为启用
- `ruleName`：必填，1-128 字符
- `triggerType`：必填，scheduled/event
- `triggerConfig`：必填，JSON 格式，scheduled 时校验 cron 合法性
- `messageTemplate`：必填，不能为空

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1
  }
}
```

**错误码：**
- `3904`：WECOM_ROBOT_NOT_FOUND
- `3905`：WECOM_ROBOT_FORBIDDEN
- `3906`：WECOM_RULE_NOT_FOUND（编辑时规则不存在）

---

## 3.5 消息日志接口

```
POST /api/v1/wecom/message/list
```

**请求体：**
```json
{
  "robotId": 1,
  "ruleId": null,
  "status": null,
  "startTime": "2026-02-01T00:00:00",
  "endTime": "2026-02-26T23:59:59",
  "page": 1,
  "size": 20
}
```

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "total": 48,
    "list": [
      {
        "id": 101,
        "robotId": 1,
        "robotName": "运营数据机器人",
        "ruleId": 1,
        "ruleName": "每日数据报告",
        "messageType": "markdown",
        "contentPreview": "## 📊 2026-02-25 运营日报\n\n**视频数据**...",

```

---

### 3.5.2 重试失败消息

```
POST /api/v1/wecom/message/retry
```

**请求体：**
```json
{
  "id": 88
}
```

**处理逻辑：**
1. 查询消息日志，校验 status=0（失败）
2. 取出 message_content，重新调用对应机器人的 Webhook
3. 新增一条 wc_message_log 记录（不修改原记录）
4. 返回新消息日志 ID

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "newLogId": 102,
    "success": true
  }
}
```

**错误码：**
- `3902`：WECOM_SEND_FAIL — 重试仍然失败

## 3.6 手动推送接口

### 3.6.1 手动触发推送

```
POST /api/v1/wecom/push
```

**鉴权：** 请求头携带 `X-Internal-Token: {WC_INTERNAL_PUSH_TOKEN}`，不使用 Bearer Token。

**请求体：**
```json
{
  "ownerId": 1001,
  "ruleId": 3,
  "extraData": {
    "viral_video_title": "这条视频爆了！",
    "viral_play_count": "128万"
  }
}
```

字段说明：
- `ownerId`：目标用户 ID（内部服务指定）
- `ruleId`：要执行的规则 ID
- `extraData`：额外模板变量，覆盖系统自动填充的同名变量

**处理逻辑：**
1. 校验内部 Token
2. 查询规则和关联机器人
3. 构建消息（模板渲染 + extraData 合并）
4. 调用 Webhook 发送
5. 写入 wc_message_log

**响应：**
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "logId": 103,
    "success": true
  }
}
```

## 3.7 错误码汇总

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 3901 | WECOM_NOT_CONFIGURED | 企业微信未配置（机器人不存在或无可用机器人） |
| 3902 | WECOM_SEND_FAIL | 消息发送失败（Webhook 调用失败） |
| 3903 | WECOM_AUTH_FAIL | 内部推送鉴权失败（Token 无效） |
| 3904 | WECOM_ROBOT_NOT_FOUND | 机器人不存在或已删除 |
| 3905 | WECOM_ROBOT_FORBIDDEN | 无权访问该机器人（非本人） |
| 3906 | WECOM_RULE_NOT_FOUND | 推送规则不存在或已删除 |
| 3907 | WECOM_WEBHOOK_INVALID | Webhook URL 格式不合法 |
