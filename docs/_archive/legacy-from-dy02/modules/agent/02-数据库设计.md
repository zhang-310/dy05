# AI 智能体模块 — 数据库设计

## 2.1 ER 关系总览

```
auth_user（auth 模块）
    │
    └─── agent_config（智能体配置）
             │
             └─── agent_task（智能体任务）
                      │
                      └─── agent_report（智能体报告）
```

---

## 2.2 表结构

### agent_config — 智能体配置表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID |
| agent_type | VARCHAR(32) | NOT NULL | — | 智能体类型：data_analysis / script_planning / live_review |
| agent_name | VARCHAR(128) | NOT NULL | — | 智能体名称（用户可自定义） |
| description | TEXT | | — | 智能体描述 |
| config_json | TEXT | | — | 智能体专属配置（JSON，各类型 Schema 不同） |
| status | SMALLINT | NOT NULL | 1 | 状态：0=禁用 / 1=启用 |
| schedule_cron | VARCHAR(64) | | — | 定时触发 Cron 表达式（为空则不自动触发） |
| last_run_time | TIMESTAMP | | — | 上次执行时间 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常 / 1=已删除 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(owner_id, deleted)` — 用户智能体列表
- `(owner_id, agent_type, deleted)` UNIQUE — 同用户同类型唯一约束
- `(status, schedule_cron)` — 定时调度器扫描启用且有 Cron 的配置

---

### agent_task — 智能体任务表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| agent_id | BIGINT | NOT NULL | — | 关联 agent_config.id |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID（冗余，方便查询） |
| task_type | VARCHAR(16) | NOT NULL | — | 触发类型：scheduled / manual / triggered |
| input_params | TEXT | | — | 任务输入参数（JSON） |
| status | SMALLINT | NOT NULL | 0 | 状态：0=待执行 / 1=执行中 / 2=已完成 / 3=失败 |
| result_summary | TEXT | | — | 结果摘要（简短文字，用于列表展示） |
| result_data | TEXT | | — | 结果数据（JSON，详细结构化数据） |
| ai_call_log_id | BIGINT | | — | 关联 ai 模块调用日志 ID |
| error_message | TEXT | | — | 失败时的错误信息 |
| start_time | TIMESTAMP | | — | 任务开始执行时间 |
| end_time | TIMESTAMP | | — | 任务结束时间 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(agent_id, create_time DESC)` — 按智能体查任务历史
- `(owner_id, status, create_time DESC)` — 用户任务列表+状态筛选
- `(agent_id, status)` — 防重复执行检查（查询 status=1 的任务）
- `(ai_call_log_id)` — 关联 AI 调用日志

---

### agent_report — 智能体报告表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| agent_id | BIGINT | NOT NULL | — | 关联 agent_config.id |
| task_id | BIGINT | NOT NULL | — | 关联 agent_task.id（唯一） |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID（冗余） |
| report_type | VARCHAR(32) | NOT NULL | — | 报告类型：weekly_analysis / content_plan / live_review |
| report_title | VARCHAR(256) | NOT NULL | — | 报告标题（如"2026年第8周数据分析报告"） |
| report_content | TEXT | | — | 报告正文（Markdown 格式富文本） |
| report_data | TEXT | | — | 报告结构化数据（JSON，用于前端图表渲染） |
| period_start | DATE | | — | 报告覆盖周期开始日期 |
| period_end | DATE | | — | 报告覆盖周期结束日期 |
| is_read | SMALLINT | NOT NULL | 0 | 是否已读：0=未读 / 1=已读 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | NOT NULL | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(owner_id, is_read, create_time DESC)` — 用户报告列表+未读筛选
- `(agent_id, create_time DESC)` — 按智能体查报告
- `(task_id)` UNIQUE — 任务与报告一对一关联
- `(owner_id, report_type, create_time DESC)` — 按报告类型筛选

## 2.3 完整 DDL

```sql
-- ============================================================
-- agent 模块数据库初始化脚本
-- 版本：3.0 | 日期：2026-02-26
-- ============================================================

-- 智能体配置表
CREATE TABLE agent_config (
    id              BIGSERIAL       PRIMARY KEY,
    owner_id        BIGINT          NOT NULL,
    agent_type      VARCHAR(32)     NOT NULL,
    agent_name      VARCHAR(128)    NOT NULL,
    description     TEXT,
    config_json     TEXT,
    status          SMALLINT        NOT NULL DEFAULT 1,
    schedule_cron   VARCHAR(64),
    last_run_time   TIMESTAMP,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_agent_type CHECK (agent_type IN ('data_analysis', 'script_planning', 'live_review')),
    CONSTRAINT chk_agent_status CHECK (status IN (0, 1))
);

CREATE INDEX idx_agent_config_owner ON agent_config (owner_id, deleted);
CREATE UNIQUE INDEX idx_agent_config_owner_type ON agent_config (owner_id, agent_type, deleted)
    WHERE deleted = 0;
CREATE INDEX idx_agent_config_schedule ON agent_config (status, schedule_cron)
    WHERE status = 1 AND schedule_cron IS NOT NULL AND deleted = 0;

COMMENT ON TABLE agent_config IS '智能体配置表';
COMMENT ON COLUMN agent_config.agent_type IS '智能体类型：data_analysis/script_planning/live_review';
COMMENT ON COLUMN agent_config.config_json IS '智能体专属配置 JSON，各类型 Schema 不同';
COMMENT ON COLUMN agent_config.status IS '状态：0=禁用 1=启用';
COMMENT ON COLUMN agent_config.schedule_cron IS 'Spring Cron 表达式（6位），为空则不自动触发';


-- 智能体任务表
CREATE TABLE agent_task (
    id              BIGSERIAL       PRIMARY KEY,
    agent_id        BIGINT          NOT NULL,
    owner_id        BIGINT          NOT NULL,
    task_type       VARCHAR(16)     NOT NULL,
    input_params    TEXT,
    status          SMALLINT        NOT NULL DEFAULT 0,
    result_summary  TEXT,
    result_data     TEXT,
    ai_call_log_id  BIGINT,
    error_message   TEXT,
    start_time      TIMESTAMP,
    end_time        TIMESTAMP,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_task_type CHECK (task_type IN ('scheduled', 'manual', 'triggered')),
    CONSTRAINT chk_task_status CHECK (status IN (0, 1, 2, 3))
);

CREATE INDEX idx_agent_task_agent ON agent_task (agent_id, create_time DESC);
CREATE INDEX idx_agent_task_owner ON agent_task (owner_id, status, create_time DESC);
CREATE INDEX idx_agent_task_running ON agent_task (agent_id, status)
    WHERE status IN (0, 1) AND deleted = 0;
CREATE INDEX idx_agent_task_ai_log ON agent_task (ai_call_log_id)
    WHERE ai_call_log_id IS NOT NULL;

COMMENT ON TABLE agent_task IS '智能体任务表';
COMMENT ON COLUMN agent_task.task_type IS '触发类型：scheduled=定时 manual=手动 triggered=事件触发';
COMMENT ON COLUMN agent_task.status IS '状态：0=待执行 1=执行中 2=已完成 3=失败';
COMMENT ON COLUMN agent_task.input_params IS '任务输入参数 JSON';
COMMENT ON COLUMN agent_task.result_data IS '结果结构化数据 JSON';
COMMENT ON COLUMN agent_task.ai_call_log_id IS '关联 ai 模块 ai_call_log.id';


-- 智能体报告表
CREATE TABLE agent_report (
    id              BIGSERIAL       PRIMARY KEY,
    agent_id        BIGINT          NOT NULL,
    task_id         BIGINT          NOT NULL,
    owner_id        BIGINT          NOT NULL,
    report_type     VARCHAR(32)     NOT NULL,
    report_title    VARCHAR(256)    NOT NULL,
    report_content  TEXT,
    report_data     TEXT,
    period_start    DATE,
    period_end      DATE,
    is_read         SMALLINT        NOT NULL DEFAULT 0,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,

    CONSTRAINT chk_report_type CHECK (report_type IN ('weekly_analysis', 'content_plan', 'live_review')),
    CONSTRAINT chk_report_is_read CHECK (is_read IN (0, 1))
);

CREATE INDEX idx_agent_report_owner ON agent_report (owner_id, is_read, create_time DESC);
CREATE INDEX idx_agent_report_agent ON agent_report (agent_id, create_time DESC);
CREATE UNIQUE INDEX idx_agent_report_task ON agent_report (task_id)
    WHERE deleted = 0;
CREATE INDEX idx_agent_report_type ON agent_report (owner_id, report_type, create_time DESC);

COMMENT ON TABLE agent_report IS '智能体报告表';
COMMENT ON COLUMN agent_report.report_type IS '报告类型：weekly_analysis/content_plan/live_review';
COMMENT ON COLUMN agent_report.report_content IS '报告正文，Markdown 格式';
COMMENT ON COLUMN agent_report.report_data IS '结构化数据 JSON，用于前端图表渲染';
COMMENT ON COLUMN agent_report.is_read IS '是否已读：0=未读 1=已读';
```
