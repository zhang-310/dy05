## 6.1 页面总览

| 路由 | 页面名称 | 说明 |
|------|---------|------|
| /agent/dashboard | 智能体总览 | 3 个智能体卡片，状态/上次运行/下次运行/未读报告数 |

## 6.2 智能体总览页（/agent/dashboard）

### 6.2.1 页面功能

- 展示当前用户的 3 类智能体配置卡片
- 每张卡片显示：智能体名称、类型、启用状态、上次运行时间、下次运行时间、未读报告数
- 支持直接在卡片上手动触发、启用/禁用、进入配置
- 顶部显示全局未读报告数角标

## 6.3 任务历史页（/agent/tasks）

## 6.4 报告中心页（/agent/reports）

### 6.4.1 页面功能

- 展示当前用户所有智能体生成的报告列表
- 未读报告显示蓝色角标
- 支持按报告类型、已读状态、时间范围筛选
- 点击报告标题在右侧展开报告详情（含 Markdown 正文 + 图表）
- 支持批量标记已读、删除报告

### 6.4.3 报告类型标签样式

| 报告类型 | 标签文字 | 标签颜色 |
|---------|---------|---------|
| weekly_analysis | 数据分析 | 蓝色（primary） |
| content_plan | 内容策划 | 绿色（success） |
| live_review | 直播复盘 | 橙色（warning） |

### 6.4.4 未读状态视觉设计

- 未读报告：列表项左侧显示蓝色圆点（●），标题字体加粗
- 已读报告：列表项左侧显示灰色勾（✓），标题字体正常
- 导航菜单「报告中心」显示未读数角标（红色，超过 99 显示 99+）

## 6.6 前端 API 封装

```typescript
// api/agent.ts

// 配置管理
export const agentConfigList = (params) => post('/agent/config/list', params)
export const agentConfigGet = (id: number) => post('/agent/config/get', { id })
export const agentConfigSave = (data) => post('/agent/config/save', data)

export const agentConfigToggle = (id: number, status: 0 | 1) =>
  post('/agent/config/toggle', { id, status })

export const agentTaskList = (params) => post('/agent/task/list', params)
export const agentTaskGet = (id: number) => post('/agent/task/get', { id })
export const agentTaskTrigger = (agentId: number, inputParams?) =>
  post('/agent/task/trigger', { agentId, inputParams })
export const agentTaskCancel = (id: number) => post('/agent/task/cancel', { id })

// 报告中心
export const agentReportList = (params) => post('/agent/report/list', params)

export const agentReportMarkRead = (ids: number[]) =>
  post('/agent/report/mark-read', { ids })
export const agentReportDelete = (id: number) => post('/agent/report/delete', { id })

// 状态总览
export const agentStatus = () => post('/agent/status', {})
```

## 6.7 前端 Store 设计

```typescript
// stores/agent.ts
export const useAgentStore = defineStore('agent', {
  state: () => ({
    unreadReportCount: 0,
    agentStatusList: [] as AgentStatusVO[]
  }),
  actions: {
    async fetchStatus() {
      const res = await agentStatus()
      this.unreadReportCount = res.data.unreadReportCount
      this.agentStatusList = res.data.agents
    },
    decreaseUnread(count = 1) {
      this.unreadReportCount = Math.max(0, this.unreadReportCount - count)
    }
  }
})
```
