# AI 智能体模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

agent 模块是平台的 AI 自动化运营层，为达人提供三类自主智能体，将原本需要人工完成的数据分析、内容策划、直播复盘工作自动化。智能体可按计划定时运行，也可由用户手动触发，执行结果以结构化报告形式沉淀在报告中心。

所有 AI 生成能力通过调用 ai 模块实现，数据来源分别来自 douyin、shortvideo、live 模块。

## 1.2 用户故事

| 编号 | 角色 | 故事 | 验收条件 |
|------|------|------|----------|
| **智能体配置** | | | |
| AG-01 | 达人 | 我要能查看我的智能体列表及其状态 | 展示 3 类智能体的启用状态、上次运行时间、下次运行时间 |
| AG-02 | 达人 | 我要能配置智能体的运行参数 | 可设置 config_json 中的参数（如分析周期、账号范围） |
| AG-03 | 达人 | 我要能启用或禁用某个智能体 | 禁用后不再自动触发，已在执行的任务不受影响 |
| AG-04 | 达人 | 我要能设置智能体的定时计划 | 可配置 Cron 表达式，系统显示下次执行时间 |
| **任务管理** | | | |
| AG-05 | 达人 | 我要能手动触发某个智能体立即执行 | 创建 manual 类型任务，进入执行队列 |
| AG-06 | 达人 | 我要能查看智能体的任务历史 | 展示任务列表，含状态、触发方式、执行时长、结果摘要 |

| **报告中心** | | | |
| AG-09 | 达人 | 我要能查看智能体生成的报告列表 | 展示报告列表，含未读标记、报告类型、生成时间 |
| AG-10 | 达人 | 我要能查看某份报告的详细内容 | 展示报告正文（富文本）+ 结构化数据图表 |
| AG-11 | 达人 | 我要能标记报告为已读 | 点击后未读标记消失，is_read 更新为 1 |
| AG-12 | 达人 | 我要能删除不需要的报告 | 软删除，报告从列表中消失 |
| **状态总览** | | | |
| AG-13 | 达人 | 我要能在一个页面看到所有智能体的运行状态 | 展示 3 个智能体卡片，含状态、最近任务、未读报告数 |
| AG-14 | 达人 | 我要能看到未读报告的数量提醒 | 导航栏或总览页显示未读报告数量角标 |

## 1.3 功能清单

```
agent 模块
├── 智能体配置管理
│   ├── 智能体配置列表（按 owner_id 查询）
│   ├── 智能体配置详情
│   ├── 创建/更新智能体配置（config_json 参数化）
│   ├── 删除智能体配置（软删除）
│   └── 启用/禁用智能体（toggle status）
│
├── 任务管理
│   ├── 任务列表（按 agent_id / status / 时间范围筛选）
│   ├── 任务详情（含 input_params、result_data、error_message）
│   ├── 手动触发任务（manual 类型，立即入队）
│   └── 取消任务（待执行直接取消；执行中发送中断信号）
│
├── 报告中心
│   ├── 报告列表（按 agent_id / report_type / is_read 筛选）
│   ├── 报告详情（report_content 富文本 + report_data JSON 图表数据）
│   ├── 标记已读（单条 / 批量）
│   └── 删除报告（软删除）
│
├── 状态总览
│   └── 所有智能体状态概览（3 个智能体 + 未读报告数 + 最近任务状态）
│
├── 智能体执行引擎（内部）
│   ├── 数据分析智能体执行逻辑
│   ├── 脚本策划智能体执行逻辑
│   ├── 直播复盘智能体执行逻辑
│   ├── RabbitMQ 任务队列（agent.task.execute）
│   └── 定时调度器（AgentScheduler，读取 schedule_cron）
│
└── 报告生成（内部）
    ├── 报告内容生成（调用 ai 模块 LLM）
    ├── 报告数据结构化（report_data JSON）
    └── 报告写入 agent_report
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **配置管理** | | |
| BR-01 | 智能体类型唯一性 | 同一用户下同一 agent_type 只能有一个未删除的配置 |
| BR-02 | 禁用不中断 | 禁用智能体（status=0）不影响已在执行中的任务，仅阻止新任务触发 |
| BR-03 | Cron 格式校验 | schedule_cron 必须是合法的 Spring Cron 表达式（6 位），为空则不自动触发 |
| **任务执行** | | |
| BR-04 | 防重复执行 | 同一智能体已有 status=1（执行中）的任务时，不允许再次触发（返回 4106 AGENT_ALREADY_RUNNING） |
| BR-05 | 任务超时 | 单个任务执行超时 10 分钟，超时后标记为 status=3（失败），error_message 写入超时原因 |
| BR-06 | 数据隔离 | 用户只能查看和操作自己的智能体配置、任务、报告（owner_id 校验） |
| BR-07 | 任务取消限制 | status=2（已完成）或 status=3（失败）的任务不可取消 |
| **报告管理** | | |
| BR-08 | 报告与任务关联 | 每次任务成功完成后生成一份报告，task_id 唯一关联（一任务一报告） |
| BR-09 | 报告不可修改 | 报告生成后内容不可编辑，只能标记已读或删除 |
| BR-10 | 软删除 | 所有业务表使用逻辑删除（deleted 字段），数据不物理删除 |

## 1.5 模块依赖

```
依赖关系：
auth ← agent（用户认证）
ai（LLM 调用）← agent
douyin（账号/人设数据）← agent
shortvideo（视频数据/热点/爆款）← agent
live（直播场次数据）← agent
```

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| auth | 用户认证、owner_id 获取 | SecurityContext |
| ai | LLM 文本生成、ai_call_log 记录 | AiGenerateService |
| douyin | 账号信息、人设信息 | DouyinAccountService, DouyinPersonaService |
| shortvideo | 视频数据快照、热点话题、爆款视频 | SvVideoDataService, SvHotTopicService, SvViralVideoService |
| live | 直播场次、场次数据 | LiveSessionService, LiveSessionDataService |
