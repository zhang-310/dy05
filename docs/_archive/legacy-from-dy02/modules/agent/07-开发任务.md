## 7.1 后端任务

### P0 — 基础设施

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B01 | 数据库初始化 | 3 张表 DDL + 索引（agent_config / agent_task / agent_report） | 无 |
| B02 | 实体与 Repository | AgentConfig、AgentTask、AgentReport 实体类 + JpaRepository | B01 |
| B03 | 错误码定义 | AgentErrorCode 枚举（4101~4107）+ AgentException | 无 |

### P1 — 配置管理

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B04 | AgentConfigService | 配置 CRUD、toggle、Cron 格式校验、同类型唯一性校验 | B02, B03 |
| B05 | AgentConfigController | 5 个接口：list / get / save / delete / toggle | B04 |

### P2 — 任务管理与调度

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B06 | AgentTaskService | 任务创建、状态更新、取消、列表查询、防重复执行检查 | B02, B03 |
| B07 | AgentTaskController | 4 个接口：list / get / trigger / cancel | B06 |
| B08 | AgentScheduler | 定时调度器（每分钟扫描 Cron 到期配置）+ LiveSessionEndEvent 监听 | B06 |

### P3 — 智能体执行引擎

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B09 | AgentExecutionEngine | RabbitMQ Consumer + 3 类 Agent 实现（DataAnalysisAgent / ScriptPlanningAgent / LiveReviewAgent）+ 报告写入 + 超时控制 | B06, B02, ai 模块, douyin 模块, shortvideo 模块, live 模块 |

### P4 — 报告中心与状态总览

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B10 | AgentReportService | 报告列表、详情、标记已读（批量）、删除 | B02, B03 |
| B11 | AgentReportController + AgentStatusController | 4 个报告接口 + 1 个状态总览接口 | B10, B06 |

### 核心接口定义

```java
// 智能体执行接口（所有 Agent 实现此接口）
public interface AgentExecutor {
    AgentExecuteResult execute(AgentTask task, AgentConfig config);
}

// 执行结果
public class AgentExecuteResult {
    private String reportTitle;
    private String reportContent;    // Markdown
    private String reportData;       // JSON
    private String resultSummary;
    private LocalDate periodStart;
    private LocalDate periodEnd;
}
```

## 7.5 开发优先级与工时估算

| 任务 | 优先级 | 估算工时 | 说明 |
|------|--------|---------|------|
| B01 数据库初始化 | P0 | 0.5h | DDL 脚本 |
| B02 实体与 Repository | P0 | 1h | 3 个实体类 |
| B03 错误码定义 | P0 | 0.5h | 枚举 + 异常类 |
| B04 AgentConfigService | P1 | 2h | CRUD + 校验逻辑 |
| B05 AgentConfigController | P1 | 1h | 5 个接口 |
| B06 AgentTaskService | P1 | 2h | 任务管理 + 防重复 |
| B07 AgentTaskController | P1 | 1h | 4 个接口 |
| B08 AgentScheduler | P2 | 2h | Cron 调度 + 事件监听 |
| B09 AgentExecutionEngine | P2 | 8h | 3 类 Agent + MQ + 超时 |
| B10 AgentReportService | P2 | 1.5h | 报告 CRUD |
| B11 报告 + 状态接口 | P2 | 1h | 5 个接口 |
| F01 API + 类型 | P1 | 1h | 封装 + TS 类型 |
| F02 Store | P1 | 0.5h | Pinia Store |
| F03 总览页 | P2 | 4h | 卡片 + 配置抽屉 + 触发弹窗 |
| F04 任务历史页 | P2 | 3h | 列表 + 筛选 + 详情抽屉 |
| F05 报告中心页 | P2 | 5h | 列表 + 详情 + Markdown + 图表 |
| **合计** | | **~34h** | |

> B09（执行引擎）是最复杂的任务，包含 3 类 Agent 的数据拉取、Prompt 构建、LLM 调用、结果解析，建议优先开发数据分析智能体作为原型验证，再复用模式开发另外两类。
