## 8.2 功能测试用例

### 8.2.1 智能体配置管理

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T01 | 创建智能体配置 | 创建 data_analysis 类型配置，填写合法 config_json | 创建成功，返回 id |
| T02 | 同类型唯一性 | 同一用户再次创建 data_analysis 类型配置 | 返回 4105 AGENT_CONFIG_INVALID |
| T03 | Cron 格式校验 | 创建配置时传入非法 Cron 表达式（如 "invalid"） | 返回 4105 AGENT_CONFIG_INVALID |
| T04 | 更新配置 | 更新 agentName 和 config_json | 更新成功，返回最新数据 |
| T05 | 禁用智能体 | toggle status=0 | status 更新为 0，定时调度不再触发 |

| T08 | 跨用户访问 | 用户 A 访问用户 B 的配置 | 返回 4102 AGENT_FORBIDDEN |
| T09 | 配置列表 | 查询当前用户配置列表 | 只返回当前用户的配置 |

## 8.4 验收标准

### 功能验收

| 验收项 | 标准 |
|--------|------|
| 智能体配置 CRUD | 5 个接口全部正常，同类型唯一性约束生效 |
| 任务触发与执行 | 手动触发后任务进入队列，状态正确流转 |
| 防重复执行 | 执行中时触发返回 4106，不创建重复任务 |
| 3 类智能体执行 | 每类智能体至少成功执行一次，生成对应类型报告 |
| 报告内容质量 | report_content 为有效 Markdown，report_data 为有效 JSON |
| 定时调度 | Cron 配置后按时触发，禁用后不触发 |
| 未读报告统计 | unreadReportCount 实时准确 |
| 数据隔离 | 跨用户操作全部返回 4102 |

### 性能验收

| 指标 | 标准 |
|------|------|
| 接口响应时间 | 配置/任务/报告列表接口 P99 < 500ms |
| 任务执行时间 | 正常情况下（LLM 响应正常）< 3 分钟 |
| 并发任务 | 不同用户的任务可并发执行，互不影响 |
