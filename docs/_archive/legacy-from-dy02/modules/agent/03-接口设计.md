> 版本：3.0 | 更新日期：2026-02-26

---

## 3.1 接口总览

| 分组 | 接口数 | 说明 |
|------|--------|------|
| 智能体配置管理 | 5 | 配置 CRUD + 启用/禁用 |
| 任务管理 | 4 | 任务列表 + 详情 + 触发 + 取消 |
| 报告中心 | 4 | 报告列表 + 详情 + 标记已读 + 删除 |

所有接口均需登录认证（Bearer Token），owner_id 从 SecurityContext 中获取，不由前端传入。

### 3.3.3 创建/更新智能体配置

```
POST /api/v1/agent/config/save
```

id 为空时创建，id 有值时更新。

**请求体：**
```json
{
  "id": null,
  "agentType": "data_analysis",
  "agentName": "我的数据分析助手",
  "description": "每周自动分析账号数据",
  "configJson": {
    "accountIds": [101],
    "analysisPeriodDays": 7,
    "includeViralAnalysis": true,
    "includePublishTimeRecommend": true
  },
  "scheduleCron": "0 0 9 ? * MON"
}
```

**字段说明：**
- agentType：创建时必填，更新时不可修改
- agentName：必填，最长 128 字符
- configJson：各智能体类型的专属配置，详见第 4 章
- scheduleCron：可选，为空则不自动触发

**响应：**
```json
{
  "code": 0,
  "data": {
    "id": 1
  }
}
```

**错误码：**
- 4105：AGENT_CONFIG_INVALID — 配置参数无效（Cron 格式错误、必填字段缺失等）
- 4102：AGENT_FORBIDDEN — 无权修改

### 3.4.3 手动触发智能体

```
POST /api/v1/agent/task/trigger
```

**请求体：**
```json
{
  "agentId": 1,
  "inputParams": {
    "periodStart": "2026-02-17",
    "periodEnd": "2026-02-23"
  }
}
```

inputParams 为可选，不传则使用智能体默认配置推算参数。

**处理流程：**
1. 校验 agentId 归属当前用户
2. 检查是否有 status=0 或 status=1 的任务（防重复执行）
3. 创建 agent_task（status=0，task_type=manual）
4. 发送 MQ 消息到 agent.task.execute 队列
5. 返回 taskId

**响应：**
```json
{
  "code": 0,
  "data": {
    "taskId": 102
  }
}
```

**错误码：**
- 4101：AGENT_NOT_FOUND
- 4102：AGENT_FORBIDDEN
- 4105：AGENT_CONFIG_INVALID — 智能体配置不完整，无法执行
- 4106：AGENT_ALREADY_RUNNING — 已有任务在执行中

---

### 3.4.4 取消任务

```
POST /api/v1/agent/task/cancel
```

**请求体：**
```json
{
  "id": 102
}
```

**处理逻辑：**
- status=0（待执行）：直接更新为 status=3（失败），error_message="用户取消"
- status=1（执行中）：发送取消信号，Consumer 检测到后中断执行，更新 status=3
- status=2/3：返回错误，不可取消

**响应：**
```json
{
  "code": 0,
  "data": null
}
```

**错误码：**
- 4103：AGENT_TASK_NOT_FOUND
- 4102：AGENT_FORBIDDEN
- 4104：AGENT_TASK_FAIL — 任务已完成或已失败，不可取消

## 3.7 错误码汇总

| 错误码 | 常量名 | HTTP 状态 | 说明 |
|--------|--------|-----------|------|
| 4101 | AGENT_NOT_FOUND | 200 | 智能体配置不存在 |
| 4102 | AGENT_FORBIDDEN | 200 | 无权操作该智能体/任务/报告 |
| 4103 | AGENT_TASK_NOT_FOUND | 200 | 任务不存在 |
| 4104 | AGENT_TASK_FAIL | 200 | 任务状态不允许此操作（如取消已完成任务） |
| 4105 | AGENT_CONFIG_INVALID | 200 | 智能体配置无效（Cron 格式错误、必填参数缺失） |
| 4106 | AGENT_ALREADY_RUNNING | 200 | 已有任务在执行中，不允许重复触发 |
| 4107 | AGENT_REPORT_NOT_FOUND | 200 | 报告不存在 |
