## 模块定位

agent 模块是平台的 AI 自动化运营层，在 ai 模块提供基础 LLM 能力的基础上，封装三类面向业务场景的自主智能体：

1. **数据分析智能体** — 自动分析账号运营数据，每周生成数据分析报告，识别增长机会与风险
2. **脚本策划智能体** — 结合热点话题与历史数据，自动规划内容日历，生成下周拍摄脚本建议
3. **直播复盘智能体** — 直播结束后自动拉取场次数据，生成结构化复盘报告与改进建议

智能体支持定时自动触发（Cron）和手动触发两种模式，任务异步执行，结果以结构化报告形式呈现。模块可独立部署，通过内部服务接口调用 ai、douyin、shortvideo、live 等模块数据。

## 智能体数据流

```
触发（定时/手动）
      │
      ▼
agent_task 创建（status=0 待执行）
      │
      ▼
发送 MQ 消息（agent.task.execute）
      │
      ▼
AgentTaskConsumer 消费
      │
      ├── 拉取数据（douyin / shortvideo / live）
      │
      ├── 构建 Prompt（config_json + 数据上下文）
      │
      ├── 调用 ai 模块（LLM 生成报告内容）
      │
      ├── 解析结果 → 写入 agent_report
      │
      └── 更新 agent_task（status=2 已完成 / 3 失败）
```

## 模块依赖

```
auth ← agent（用户认证与权限）
ai（LLM 调用：报告生成、内容策划）← agent
douyin（账号数据、人设信息）← agent
shortvideo（视频数据、爆款数据、热点数据）← agent
live（直播场次数据）← agent
```

## 与其他模块的协同

| 依赖模块 | 依赖内容 | 用途 |
|---------|---------|------|
| ai | LLM 文本生成、ai_call_log 记录 | 生成报告正文、策划建议 |
| douyin | dy_account、dy_persona | 获取账号基础信息和人设 |
| shortvideo | sv_video_data、sv_hot_topic、sv_viral_video | 数据分析智能体的数据源；脚本策划的热点和爆款参考 |
| live | live_session、live_session_data | 直播复盘智能体的数据源 |

## 数据规模预估

| 数据 | 预估量 | 增长速度 | 存储策略 |
|------|--------|---------|---------|
| agent_config | 每用户 ~3 条（3 类智能体各 1 个） | 低增长 | 热数据 |
| agent_task | 每智能体每周 ~1 条（定时） + 手动触发 | 每月 ~15 条/用户 | 超过 90 天归档 |
| agent_report | 与 agent_task 1:1 | 每月 ~15 条/用户 | 超过 180 天归档 |

## 错误码段

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 4101 | AGENT_NOT_FOUND | 智能体配置不存在 |
| 4102 | AGENT_FORBIDDEN | 无权操作该智能体 |
| 4103 | AGENT_TASK_NOT_FOUND | 任务不存在 |
| 4104 | AGENT_TASK_FAIL | 任务执行失败 |
| 4105 | AGENT_CONFIG_INVALID | 智能体配置无效 |
| 4106 | AGENT_ALREADY_RUNNING | 智能体已有任务在执行中 |
| 4107 | AGENT_REPORT_NOT_FOUND | 报告不存在 |
