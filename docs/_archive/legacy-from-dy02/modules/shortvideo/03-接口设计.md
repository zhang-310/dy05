## 3.2 视频管理接口

### 3.2.1 视频列表

```
GET /api/v1/shortvideo/videos?accountId=1&page=1&size=20&sort=publishTime,desc
```

**筛选参数：**
- accountId：按账号筛选（必填）
- categoryId：按分类筛选
- isViral：是否爆款
- keyword：标题/描述关键词搜索
- startDate / endDate：按发布时间范围

---

### 3.2.2 视频详情

```
GET /api/v1/shortvideo/videos/{id}
```

**响应包含：** 视频基本信息 + 最新数据 + 最近 7 天数据趋势 + 评论摘要

---

### 3.2.3 手动同步视频列表

```
POST /api/v1/shortvideo/videos/sync
```

**请求体：**
```json
{
  "accountId": 1
}
```

**处理流程：**
1. 调用抖音 API 拉取该账号的视频列表
2. 新视频插入 sv_video，已有视频更新数据
3. 通过 douyin_video_id 去重

---

### 3.2.4 更新视频信息

```
PUT /api/v1/shortvideo/videos/{id}
```

**可更新字段：** categoryId、tags（本地管理字段，不影响抖音端）

---

### 3.2.5 删除视频

```
DELETE /api/v1/shortvideo/videos/{id}
```

逻辑删除，仅从本平台移除，不影响抖音端。

---

### 3.2.6 批量更新分类

```
PUT /api/v1/shortvideo/videos/batch-category
```

**请求体：**
```json
{
  "videoIds": [1, 2, 3],
  "categoryId": 5
}
```

---

### 3.2.7 视频数据概览

```
GET /api/v1/shortvideo/videos/overview?accountId=1
```

## 3.5 AI 创作接口

### 3.5.1 AI 生成文案

```
POST /api/v1/shortvideo/ai/generate-copy
```

**请求体：**
```json
{
  "accountId": 1,
  "personaId": 2,
  "topic": "春季护肤",
  "style": "种草",
  "keywords": ["保湿", "敏感肌"],
  "referenceVideoId": null
}
```

**处理流程：**
1. 读取人设信息（dy_persona）
2. 调用 ai 模块 AiGenerateService（模板：sv_copy）
3. 创建 sv_plan（plan_type=original），记录 ai_call_log_id
4. 返回生成的文案

---

### 3.5.2 AI 生成拍摄脚本

```
POST /api/v1/shortvideo/ai/generate-script
```

**请求体：**
```json
{
  "planId": 1,
  "duration": 60,
  "scenes": 5
}
```

**响应：**
```json
{
  "script": [
    { "sceneNo": 1, "shot": "近景", "content": "开场自我介绍", "duration": 5, "notes": "面带微笑，看镜头" },
    { "sceneNo": 2, "shot": "特写", "content": "展示产品外观", "duration": 8, "notes": "慢慢旋转产品" }
  ]
}
```

---

### 3.5.3 爆款复刻

```
POST /api/v1/shortvideo/ai/viral-copy
```

**请求体：**
```json
{
  "viralVideoId": 1,
  "accountId": 1,
  "personaId": 2,
  "adaptStyle": "种草"
}
```

**处理流程：**
1. 读取爆款视频信息 + AI 拆解报告
2. 读取人设信息
3. 调用 ai 模块（模板：sv_viral_copy），传入爆款方法论 + 人设
4. 创建 sv_plan（plan_type=viral_copy, source_video_id=爆款ID）

---

### 3.5.4 热点创作

```
POST /api/v1/shortvideo/ai/hot-topic-create
```

**请求体：**
```json
{
  "topicId": 1,
  "accountId": 1,
  "personaId": 2,
  "angle": "测评角度"
}
```

**处理流程：**
1. 读取热点话题信息
2. 读取人设信息
3. 调用 ai 模块（模板：sv_hot_topic），传入热点 + 人设
4. 创建 sv_plan（plan_type=hot_topic, source_topic_id=热点ID）

---

### 3.5.5 每日拍摄脚本推荐

```
GET /api/v1/shortvideo/ai/daily-script?accountId=1
```

**处理流程：**
1. 读取该账号的内容日历（已有计划）
2. 读取最近发布的视频主题（避免重复）
3. 读取当前热点话题
4. 调用 ai 模块推荐今日拍摄主题和脚本

---

### 3.5.6 AI 复盘报告

```
POST /api/v1/shortvideo/ai/review
```

**请求体：**
```json
{
  "videoId": 1
}
```

**处理流程：**
1. 收集视频数据（sv_video + sv_video_data 趋势 + sv_comment 情感分析）
2. 调用 ai 模块（模板：sv_review）
3. 返回复盘报告（表现评级 + 分析 + 改进建议）

## 附录 B：设计路径 vs 实际路径对照表

> 3.2～3.12 节设计为 REST 风格（GET/PUT/DELETE）；实现统一为 POST + JSON body。下表供前端对接参考。

| 设计路径 | 实际路径 | 说明 |
|----------|----------|------|
| GET /api/v1/shortvideo/videos | POST /api/v1/short-video/content/search | 分页筛选参数放 body |
| GET /api/v1/shortvideo/videos/{id} | POST /api/v1/short-video/content/get?id= |  |
| POST /api/v1/shortvideo/videos/sync | POST /api/v1/douyin/video/sync | 抖音模块，账号归属校验 |
| PUT /api/v1/shortvideo/videos/{id} | POST /api/v1/short-video/content/save | body 含 id |
| DELETE /api/v1/shortvideo/videos/{id} | POST /api/v1/short-video/content/delete?id= |  |
