# 短视频模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

shortvideo 模块是平台的核心业务模块，围绕用户绑定的抖音账号，提供短视频全生命周期管理：数据同步 → 爆款发现 → 热点追踪 → AI 创作 → 视频制作 → 发布管理 → 数据复盘 → 效果归因。

所有 AI 能力通过调用 ai 模块实现，人设信息来自 douyin 模块，生成的图片/视频/音频存储到 storage 模块。

## 1.3 功能清单

```
shortvideo 模块
├── 数据同步
│   ├── 抖音视频列表同步（绑定账号后自动拉取）
│   ├── 视频数据每日快照（VideoStatistics 每日定时同步）
│   ├── 发布后高频同步（发布后 1h 内每 10 分钟同步一次）
│   ├── 评论同步（定时拉取最新评论）
│   └── 手动触发同步
│
├── 爆款与热点
│   ├── 爆款自动发现（播放量 > 账号均值 3x 自动标记）
│   ├── 爆款拆解报告（对接 ai 模块爆款拆解 Agent）
│   ├── 热点自动追踪（对接抖音热搜 API / 第三方数据源）
│   ├── 热点过期自动下架（expiryTime 到期自动标记过期）
│   ├── 爆款库管理（手动录入 + 自动发现）
│   └── 同行业爆款推荐
│
├── AI 创作
│   ├── AI 文案生成（按人设+主题+风格）
│   ├── AI 拍摄脚本生成（分镜：场景/镜头/台词/时长）
│   ├── 爆款复刻（选择爆款 → AI 分析 → 生成同类型内容）
│   ├── 热点创作（选择热点 → AI 结合人设生成内容）
│   ├── 每日拍摄脚本推荐（AI 根据日历+历史数据推荐）
│   ├── 创作方案管理（方案 CRUD、版本管理）
│   └── 效果归因（记录 ai_call_log_id，发布后追踪效果）
│
├── 视频制作（调用 ai 模块视频生成链路）
│   ├── 关键帧生成（Stable Diffusion XL / DALL-E 3）
│   ├── 视频片段生成（Runway Gen-3 / Pika / Kling）
│   ├── TTS 配音（ChatTTS / CosyVoice / Edge-TTS）
│   ├── AI 剪辑成片（FFmpeg 多片段拼接+配音+字幕）
│   ├── 生成任务管理（异步任务状态追踪）
│   └── 素材管理（人像/背景/关键帧/视频/音频）
│
├── 发布管理
│   ├── 发布时间推荐（基于历史数据分析最佳时段）
│   ├── 内容日历（按日/周展示发布计划和实际发布）
│   └── 发布记录（关联 ai_call_log_id 用于效果归因）
│
├── 复盘分析
│   ├── 视频数据看板（播放量/互动/转化趋势图）
│   ├── 发布后数据追踪（7 天内每日变化）
│   ├── AI 复盘报告（AI 分析表现+改进建议）
│   ├── 效果归因报告（AI 生成内容的实际表现）
│   └── 历史对比分析
│
├── 评论管理
│   ├── 评论列表（同步抖音评论）
│   ├── 评论情感分析（正面/中立/负面，情感分数）
│   ├── 负面评论预警（超阈值告警）
│   └── AI 回复建议（可选）
│
└── 分类管理
    ├── 视频分类 CRUD
    ├── 视频打标签
    └── 按分类筛选
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **数据同步** | | |
| BR-01 | 视频列表同步 | 绑定账号后自动拉取视频列表，每 6h 全量同步一次 |
| BR-02 | 数据快照同步 | 每日 02:00 定时从抖音 API 拉取所有已发布视频的最新统计数据，写入 sv_video_data |
| BR-03 | 发布后高频同步 | 视频发布后 1h 内每 10 分钟同步一次数据（捕捉初始流量） |
| BR-04 | 评论同步 | 每 6h 同步最新评论，新视频发布后 24h 内每 1h 同步一次 |
| BR-05 | 数据隔离 | talent 只能看到自己账号的视频和数据（owner_id）；institution 可查看自己+旗下达人的数据（DataScopeService）；admin 可查看全部 |
| **爆款与热点** | | |
| BR-06 | 爆款自动检测 | 每日 03:00 扫描 sv_video_data，播放量 > 该账号近 30 天均值 × 3 的视频自动标记为爆款 |
| BR-07 | 爆款拆解触发 | 新检测到的爆款视频自动触发 ai 模块的爆款拆解 Agent |
| BR-08 | 热点自动追踪 | 每 2h 从抖音热搜 API / 第三方数据源拉取热点话题，写入 sv_hot_topic |
| BR-09 | 热点过期下架 | expiryTime 到期的热点自动标记为 expired 状态，不再展示 |
| BR-10 | 爆款库来源 | sv_viral_video.source 区分 manual（手动录入）和 auto_detected（自动发现） |
| **AI 创作** | | |
| BR-11 | 创作需人设 | 所有 AI 创作需要激活的人设（douyin 模块），且人设必须属于当前用户 |
| BR-12 | 创作记录归因 | 每次 AI 创作记录 ai_call_log_id 到 sv_plan.ai_call_log_id，用于效果归因 |
| BR-13 | 方案版本管理 | 每次 AI 重新生成不覆盖原内容，新增版本（sv_plan_asset.version） |
| BR-14 | 视频制作异步 | 视频生成任务异步执行，通过 RabbitMQ 消息回调 + 前端轮询通知完成状态 |
| BR-15 | 视频制作超时 | 单个视频生成任务超时 30 分钟，超时标记为 failed |
| **发布管理** | | |
| BR-16 | 发布时间推荐 | 基于该账号历史视频的发布时间 vs 播放量，分析最佳发布时间段 |
| BR-17 | 发布关联归因 | 用户发布内容时，前端传入 ai_call_log_id，后端回填 linked_video_id（对接 ai 模块效果归因链） |
| **复盘分析** | | |
| BR-18 | 效果归因定时 | 每日 02:00 扫描「有 ai_call_log_id 且发布超过 7 天」的方案，从 sv_video_data 拉取数据计算 effect_score |
| BR-19 | 效果评分规则 | effect_score = 视频播放量 / 该账号近 30 天视频均值。> 1.5x 标记 high_perform，< 0.3x 标记 low_perform |
| BR-20 | 知识权重反向更新 | high_perform 的 referenced_chunk_ids 对应知识条目 boost_factor += 0.15；low_perform 对应 -= 0.05 |
| **评论管理** | | |
| BR-21 | 评论情感分析 | 新评论同步后自动进行情感分析（LLM 或规则引擎），标注 sentiment + sentiment_score |
| BR-22 | 负面评论预警 | 单条视频负面评论占比 > 30% 时触发告警 |
| **分类管理** | | |
| BR-23 | 分类唯一性 | 同一用户下分类名称不能重复 |
| BR-24 | 分类删除保护 | 有视频关联的分类不能删除，需先解除关联 |
| **通用** | | |
| BR-25 | 软删除 | 所有业务表使用逻辑删除（deleted 字段） |
| BR-26 | 跨模块 FK 校验 | account_id 必须属于当前用户（dy_account.owner_id = 当前用户） |

## 1.5 模块依赖

```
依赖关系：
auth ← douyin（账号/人设/产品）← shortvideo
ai（AI 生成：文案/脚本/图像/视频/TTS/剪辑/分析）← shortvideo
storage（文件存储）← shortvideo
script（违规检测）← shortvideo
```

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| douyin | 账号信息、人设信息、产品信息 | DouyinAccountService, DouyinPersonaService |
| ai | AI 文案/脚本/图像/视频/TTS/剪辑/分析 | AiGenerateService, AiMediaService |
| storage | 图片/视频/音频文件存储 | StorageService |
| script | 违规词检测 | ScriptViolationService |
