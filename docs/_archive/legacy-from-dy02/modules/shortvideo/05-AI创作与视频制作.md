# 短视频模块 — AI 创作与视频制作

> 版本：3.0 | 更新日期：2026-02-26

---

## 5.1 AI 创作总览

```
创作入口（4 种模式）
    ├─ 爆款复刻：选择爆款 → AI 分析方法论 → 生成同类型内容
    ├─ 热点策划：选择热点 → AI 结合人设 → 生成蹭热点内容
    ├─ 自主创作：输入主题 → AI 按人设+风格生成文案/脚本
    └─ 每日推荐：AI 根据日历+历史+热点推荐今日拍摄主题
    ↓
[AI 文案生成]
    ├─ 调用 ai 模块 AiGenerateService
    ├─ 传入人设+产品+主题+风格
    ├─ 记录 ai_call_log_id（效果归因）
    └─ 创建 sv_plan（方案）
    ↓
[AI 拍摄脚本]（可选）
    ├─ 基于文案生成分镜脚本
    └─ 场景/镜头/台词/时长/拍摄提示
    ↓
[AI 视频制作]（可选）
    ├─ 关键帧生成（Stable Diffusion XL / DALL-E 3）
    ├─ 视频片段生成（Runway Gen-3 / Pika / Kling）
    ├─ TTS 配音（ChatTTS / CosyVoice / Edge-TTS）
    ├─ AI 剪辑成片（FFmpeg 拼接+配音+字幕+BGM）
    └─ 素材存储到 storage 模块
    ↓
[发布与归因]
    ├─ 用户发布到抖音
    ├─ 回填 linked_video_id
    ├─ 调用 ai 模块关联 ai_call_log_id → video_id
    └─ 等待 7 天后自动归因
```

## 5.2 爆款复刻

### 5.2.1 流程

```
用户选择爆款视频（sv_viral_video）
    ↓
[数据准备]
    ├─ 爆款视频信息（标题/描述/标签/播放量）
    ├─ AI 拆解报告（success_factors + replicable_methods）
    ├─ 用户人设信息（dy_persona）
    └─ 用户选择的适配风格
    ↓
[AI 生成]
    ├─ 模板：sv_viral_copy
    ├─ Prompt 核心：「基于以下爆款视频的成功方法论，结合{人设}的风格，
    │   生成一条同类型但有差异化的短视频文案」
    ├─ 输入：爆款方法论 + 人设 + 风格
    └─ 输出：文案 + 标题候选 + 标签建议
    ↓
创建 sv_plan（plan_type=viral_copy, source_video_id=爆款ID）
```

### 5.2.2 Prompt 模板

```
你是一位{personaStyle}的抖音短视频创作者{personaName}。

参考爆款视频：
- 标题：{viralTitle}
- 播放量：{viewCount}
- 成功因素：{successFactors}
- 可复制方法论：{replicableMethods}

请基于以上爆款方法论，结合你的人设风格，生成一条同类型但有差异化的短视频文案。

要求：
1. 保留爆款的核心结构和节奏
2. 内容要符合{personaName}的人设定位
3. 有差异化，不是简单抄袭
4. 适合{targetAudience}观看
5. 包含：文案正文（200-500字）+ 3个标题候选 + 5个推荐标签
```

## 5.6 AI 拍摄脚本生成

### 5.6.1 脚本结构

```json
{
  "totalDuration": 60,
  "scenes": [
    {
      "sceneNo": 1,
      "shot": "近景",
      "content": "开场自我介绍，面带微笑看镜头",
      "dialogue": "嗨，大家好，我是小美...",
      "duration": 5,
      "notes": "背景干净，光线充足",
      "transition": "cut"
    },
    {
      "sceneNo": 2,
      "shot": "特写",
      "content": "展示产品外观，慢慢旋转",
      "dialogue": "今天给大家带来的是这款...",
      "duration": 8,
      "notes": "产品居中，背景虚化",
      "transition": "dissolve"
    }
  ],
  "bgmSuggestion": "轻快活泼的背景音乐",
  "overallNotes": "整体节奏明快，每个镜头不超过10秒"
}
```

### 5.6.2 镜头类型

| 镜头 | 代码 | 说明 |
|------|------|------|
| 远景 | wide | 展示环境、场景 |
| 中景 | medium | 人物半身、产品全貌 |
| 近景 | close | 人物面部、产品细节 |
| 特写 | extreme_close | 产品局部、表情特写 |
| 俯拍 | overhead | 桌面展示、开箱 |
| 跟拍 | tracking | 运动场景、使用过程 |

## 5.7 AI 视频制作链路

### 5.7.1 完整链路

```
拍摄脚本（sv_plan.script_content）
    ↓
[Step 1: 关键帧生成]
    ├─ 输入：每个分镜的场景描述 + 风格
    ├─ 调用 ai 模块：POST /api/v1/ai/media/generate-image
    ├─ 技术：Stable Diffusion XL / DALL-E 3
    ├─ 输出：每个分镜的关键帧图片
    ├─ 存储：storage 模块 → sv_plan_asset（asset_type=image）
    └─ 任务：sv_video_generation（task_type=image）
    ↓
[Step 2: 视频片段生成]
    ├─ 输入：关键帧图片 + 运动描述
    ├─ 调用 ai 模块：POST /api/v1/ai/media/generate-video
    ├─ 技术：Runway Gen-3 / Pika / Kling
    ├─ 输出：每个分镜的视频片段（3-10s）
    ├─ 存储：storage 模块 → sv_plan_asset（asset_type=video）
    └─ 任务：sv_video_generation（task_type=video_clip）
    ↓
[Step 3: TTS 配音]
    ├─ 输入：每个分镜的台词 + 音色选择
    ├─ 调用 ai 模块：POST /api/v1/ai/media/tts
    ├─ 技术：ChatTTS / CosyVoice / Edge-TTS（兜底）
    ├─ 输出：每个分镜的配音音频
    ├─ 存储：storage 模块 → sv_plan_asset（asset_type=audio）
    └─ 任务：sv_video_generation（task_type=tts）
    ↓
[Step 4: AI 剪辑成片]
    ├─ 输入：视频片段 + 配音 + 字幕 + BGM
    ├─ 调用 ai 模块：POST /api/v1/ai/media/edit-video
    ├─ 技术：FFmpeg
    ├─ 处理：多片段拼接 + 配音对齐 + 字幕叠加 + BGM 混音
    ├─ 输出：成片视频
    ├─ 存储：storage 模块 → sv_plan_asset（asset_type=composite）
    └─ 任务：sv_video_generation（task_type=composite）
```

### 5.7.2 异步任务管理

```
所有视频制作任务都是异步的：

1. 前端发起请求 → 创建 sv_video_generation（status=pending）
2. 发送消息到 RabbitMQ（queue: ai.media.{taskType}）
3. ai 模块消费消息，开始处理
4. 处理过程中更新 progress（0-100）
5. 完成后更新 status=completed, output_url=文件URL
6. 失败后更新 status=failed, error_message=错误信息

前端轮询任务状态：
GET /api/v1/shortvideo/production/tasks/{taskId}
轮询间隔：5s（processing 状态时）
超时：30 分钟（SV_VIDEO_GEN_TIMEOUT）
```

### 5.7.3 降级策略

| 步骤 | 失败降级 |
|------|---------|
| 关键帧生成 | DALL-E 3 失败 → Stable Diffusion XL → 使用占位图 |
| 视频片段 | Runway 失败 → Pika → Kling → 使用关键帧静态图+Ken Burns 效果 |
| TTS | ChatTTS 失败 → CosyVoice → Edge-TTS（兜底，永远可用） |
| 成片合成 | FFmpeg 失败 → 返回原始素材，用户手动剪辑 |

## 5.8 AI 文案优化

### 5.8.1 优化方向

| 方向 | 代码 | Prompt 侧重 |
|------|------|------------|
| 提高互动率 | engagement | 增加提问、投票、评论引导 |
| 提高完播率 | retention | 开头悬念、节奏紧凑、结尾反转 |
| 提高转化率 | conversion | 强化卖点、价格话术、CTA |
| 提高分享率 | sharing | 情感共鸣、实用价值、社交货币 |
| SEO 优化 | seo | 关键词密度、标题优化、标签优化 |

### 5.8.2 流程

```
用户选择方案 + 优化方向
    ↓
读取现有文案 + 视频数据（如已发布）
    ↓
调用 ai 模块（模板：sv_optimize）
    ├─ 传入：原文案 + 优化方向 + 历史数据
    └─ 输出：优化后的文案（新版本）
    ↓
创建 sv_plan_asset（asset_type=text, version=N+1）
```

## 5.10 效果归因闭环

### 5.10.1 完整链路

```
[创作阶段]
    ├─ AI 生成文案/脚本 → 记录 ai_call_log_id 到 sv_plan
    └─ ai_call_log 记录 referenced_chunk_ids（引用的知识条目）

[发布阶段]
    ├─ 用户发布到抖音
    ├─ 前端调用 POST /api/v1/shortvideo/plans/{id}/link-video
    ├─ 回填 sv_plan.linked_video_id
    └─ 调用 ai 模块 POST /api/v1/ai/call-log/link 关联

[数据回流阶段]
    ├─ sv_video_data 每日快照
    └─ 等待 SV_ATTRIBUTION_WAIT_DAYS（默认 7 天）

[归因阶段]
    ├─ 定时任务计算 effect_score
    ├─ 标记 content_effect（high_perform / normal / low_perform）
    └─ 触发知识权重反向更新

[进化阶段]
    ├─ 进化引擎感知高效知识 → 加大该方向进化力度
    └─ 下次 AI 生成时，高权重知识优先被检索引用
```
