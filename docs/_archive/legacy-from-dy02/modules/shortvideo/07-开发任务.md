## 7.3 任务依赖图

```
B01(DDL)
 ├─→ B02~B11(Entity × 10)
 │    ├─→ B12~B13(核心 Service)
 │    │    └─→ B14~B15(核心 Controller)
 │    ├─→ B16~B18(数据同步 Service)
 │    │    └─→ B19~B20(Scheduler + Controller)
 │    ├─→ B21~B23(爆款+热点 Service)
 │    │    └─→ B24~B26(Scheduler + Controller)
 │    ├─→ B27~B29(AI 创作 Service)
 │    │    └─→ B30~B31(Controller)
 │    ├─→ B32~B34(视频制作 Service)
 │    │    └─→ B33~B35(Controller)
 │    └─→ B36~B42(评论+归因+日历)
 │
F01(API) + F02(路由)
 ├─→ F03~F05(核心页面)
 ├─→ F06~F10(数据+分析页面)
 └─→ F11~F17(AI创作+制作页面)
```
