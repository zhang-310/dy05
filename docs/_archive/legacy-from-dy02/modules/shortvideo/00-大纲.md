## 模块定位

shortvideo 模块是平台的核心业务模块，围绕用户绑定的抖音账号，提供短视频全生命周期管理：

1. **数据同步与分析** — 抖音视频数据自动同步、每日快照、爆款自动发现、热点自动追踪、发布时间推荐
2. **AI 内容创作** — 爆款复刻、热门策划、自主创作、每日拍摄脚本、AI 视频制作完整链路
3. **效果归因闭环** — AI 生成 → 发布 → 数据回流 → 归因到知识条目 → 优化生成质量
4. **复盘分析** — 发布后数据追踪、AI 复盘报告、改进建议

所有 AI 能力通过调用 ai 模块实现，人设信息来自 douyin 模块，生成的图片/视频/音频存储到 storage 模块。

## 模块依赖

```
auth ← douyin（账号/人设/产品）← shortvideo
ai（AI 生成：文案/脚本/图像/视频/TTS/剪辑/分析）← shortvideo
storage（人像/背景/关键帧/视频/音频/成片等文件）← shortvideo
script（违规检测）← shortvideo
```

## 与 AI 模块的协同

| AI 模块能力 | shortvideo 模块配合 |
|------------|-------------------|
| 效果归因链（12-升级路线图） | sv_plan 发布时传入 ai_call_log_id，数据回流后自动归因 |
| 爆款拆解 Agent（12-升级路线图） | sv_video_data 提供爆款检测数据源，sv_viral_video 接收拆解结果 |
| 知识库混合检索（04-知识库系统） | 创作时检索同行业知识作为上下文 |
| 视频脚本生成（06-视频脚本与生成） | 调用 AI 生成分镜脚本、关键帧、视频片段 |
| 查询改写+用户画像（12-升级路线图） | DouyinAccount + sv_video_data 提供用户画像数据 |

## 数据规模预估

| 数据 | 预估量 | 增长速度 | 存储策略 |
|------|--------|---------|---------|
| sv_video | 每账号 ~500 条 | 每月 ~30 条/账号 | 热数据 |
| sv_video_data | 每视频 ~365 条/年 | 每日快照 | 超过 180 天归档 |
| sv_plan | 每用户 ~100 条 | 每月 ~10 条/用户 | 热数据 |
| sv_plan_asset | 每方案 ~20 条 | 跟随方案 | 保留最近 5 版本 |
| sv_viral_video | 平台级 ~1000 条 | 每月 ~50 条 | 热数据 |
| sv_hot_topic | 平台级 ~200 条 | 每日更新 | 过期自动下架 |
