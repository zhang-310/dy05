## 6.3 组件复用

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| VideoCard | 视频管理 | 视频卡片（封面+数据+标签） |
| TrendChart | 视频详情/数据看板 | ECharts 趋势折线图 |
| SentimentBar | 评论管理/视频详情 | 情感分布条形图 |
| ViralCard | 爆款库 | 爆款视频卡片（含拆解摘要） |
| HotTopicCard | 热点话题 | 热点卡片（热度+过期时间） |
| CreateModeSelector | 创作工作台 | 4种创作模式选择器 |
| ScriptTimeline | 方案详情/制作台 | 分镜脚本时间线 |
| ProductionPipeline | AI制作台 | 制作流程进度条 |
| CalendarGrid | 内容日历 | 月历网格（含计划标记） |
| AttributionChart | 效果归因 | 效果分布饼图+排行表 |
| PublishTimeHeatmap | 发布时间推荐 | 时段热力图 |
