# H-1：「电影级知识库」与当前实现差距

## 已有能力（代码）

`CinematicKnowledgeService`（`src/main/java/cn/gaifan/douyinOperations/module/ai/service/CinematicKnowledgeService.java`）：

- 基于 **`sv_scene_camera_mapping`** 的场景关键词 → 运镜类型推荐（含置信度排序）。
- 结合 **`sv_cinematic_preset`** 读取历史最佳模型与质量分。
- **`logGeneration`** 写入 **`sv_generation_log`**，支撑后续统计与闭环（若调用方接入）。

调用入口：`ShortVideoMaterialController` / `ShortVideoMaterialServiceImpl`；**图生视频** `processOneVideo` 与 **关键帧** `generateKeyframesWithProgress` 在成败时均写 **`sv_generation_log`**。**`app.milvus.enabled=true`** 时 `recommendCamera` 在关键词序外增加 **场景句向量 vs scene_keyword 向量** 的 **RRF 融合**（共用 `VectorService` embedding，不单独建 cinematic collection）。

**运营侧 API**（`CinematicOpsController`，需登录；写映射仅 admin）：

- `POST /api/v1/short-video/cinematic/scene-camera-mapping/list`：映射表只读列表  
- `POST /api/v1/short-video/cinematic/scene-camera-mapping/save`：新增/更新映射  
- `POST /api/v1/short-video/cinematic/scene-camera-mapping/delete`：删除（body `id`）  
- `POST /api/v1/short-video/cinematic/generation-log/summary`：按 `yearMonth` 或 `from`/`to` 聚合 **`sv_generation_log`**（`successRate`、`byCameraType`、`byProvider`、`avgGenerationTimeMs` 等；**`global=1` 仅 admin 全库**）

## 与「电影级知识库」产品表述的常见差距

| 维度 | 当前 | 典型「电影级」期望 |
|------|------|-------------------|
| 检索 | 关键词子串包含 | 向量/多模态语义、镜头语言本体 |
| 覆盖 | 依赖映射表数据量 | 行业通用运镜本体 + 持续运营扩充 |
| 闭环 | 日志表具备，全链路写入率视调用点 | 强制每次生成写日志 + 自动反哺预设 |
| 输出 | 运镜码 + 模型建议 | 分镜表、节奏曲线、参考片单、LUT/色彩意图（与本项目 **非 LUT 成片策略** 需区分域） |

## 推进建议（Epic）

3. 评估 Milvus/ES 语义检索与关键词的 **RRF 融合**（与大脑模块能力复用）。
