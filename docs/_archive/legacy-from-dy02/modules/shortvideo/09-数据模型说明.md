# 短视频模块 — 数据模型说明

> 版本：1.0 | 更新日期：2026-03-02

---

## 一、双轨模型概述

短视频模块存在两套数据模型，分别服务于不同阶段的业务需求：

| 模型 | 定位 | 表结构 | 使用场景 |
|------|------|--------|----------|
| **策划模型** | 早期设计，创作方案管理 | sv_plan + sv_plan_asset | 部分遗留能力、设计文档参考 |
| **制作模型** | 当前主流程，AI 视频制作流水线 | sv_project → sv_script → sv_shot_list → sv_shot → sv_material | **主流程**，前端页面实际使用 |

---

## 二、sv_plan 与 sv_project 关系

### 2.1 sv_plan（策划方案）

- **表**：`sv_plan`、`sv_plan_asset`
- **设计文档**：`sv_plan_scene` 在设计中有，**实现中未建表**
- **用途**：
  - 创作方案草稿（爆款复刻、热门策划、自主创作、每日拍摄脚本）
  - 方案级资产记录（sv_plan_asset）
- **状态**：**保留**，用于部分场景（如与 SvVideo 的 plan_id 关联），但**非主流程**

### 2.2 sv_project（制作项目）

- **表**：`sv_project`、`sv_script`、`sv_shot_list`、`sv_shot`、`sv_material`
- **用途**：
  - **主流程**：项目 → 脚本 → 分镜 → 素材 → 剪辑 → 发布
  - 快速生成、工作流执行、图生视频、TTS、BGM 等均基于此模型
- **关联**：
  - `sv_project.script_id` → `sv_script.id`
  - `sv_project.shot_list_id` → `sv_shot_list.id`
  - `sv_shot_list` 下挂 `sv_shot`
  - `sv_shot` 关联 `sv_material`（关键帧、视频片段、配音等）

### 2.3 关系示意

```
sv_plan (策划)                    sv_project (制作)
    │                                    │
    ├─ sv_plan_asset                    ├─ sv_script
    │                                    ├─ sv_shot_list
    └─ (sv_plan_scene 未建)              │   └─ sv_shot
                                          └─ sv_material
```

**结论**：`sv_plan` 与 `sv_project` **无直接外键关联**，是两套独立体系。新功能应基于 `sv_project` 体系开发。

---

## 三、迁移建议

1. **新功能**：统一使用 `sv_project` 体系
2. **sv_plan 使用**：仅保留与现有 SvVideo.planId、历史数据兼容
3. **sv_plan_scene**：设计中有，实现用 `sv_shot` 替代，无需新建表
4. **文档**：接口设计、开发任务以 `sv_project` 为准

| sv_shot_list | 分镜列表 |
