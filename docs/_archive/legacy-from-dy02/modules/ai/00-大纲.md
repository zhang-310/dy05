## 模块定位

ai 模块是整个平台的智能能力引擎，目标是成为**抖音短视频直播运营领域的专家级AI智能体**。

基于本地向量知识库系统升级为企业级抖音知识库服务，为 shortvideo、live、script、copy 等模块提供：

1. **抖音领域知识检索** — 混合检索（Milvus 语义 + Elasticsearch 关键词 → RRF 融合 → Cross-Encoder 重排）
2. **AI 内容生成** — 文案、话术、视频脚本、分析报告的生成能力
3. **AI 直播分析** — 实时直播数据分析、诊断、话术建议
4. **AI 视频生成** — 从脚本→分镜→视觉→音频→合成的完整链路
5. **知识自进化引擎** — 6 类自进化 Agent 24h 自动进化，持续积累成为最强抖音运营大脑
6. **大数据分析与BI** — 60个维度的全方位数据分析体系
7. **运维面板与监控** — 知识库健康度、系统性能、告警管理

## 技术栈

| 组件 | 技术 | 说明 |
|------|------|------|
| 文本生成 | DeepSeek API + Ollama 本地模型 | 3层回退（主模型→备用1→备用2） |
| 嵌入模型 | BGE-M3（Ollama） | 1024D 稠密+稀疏向量，维度可配置 |
| 重排模型 | BGE-reranker-v2（Ollama） | Cross-Encoder 重排 |
| 向量存储 | Milvus 2.4+ | HNSW 索引，COSINE 相似度，按 project 分区 |
| 全文检索 | Elasticsearch 8.x | BM25 + IK 中文分词 |
| 缓存 | Redis 7 Cluster | 热点查询/嵌入缓存/分布式锁 |
| 消息队列 | RabbitMQ | 异步摄入/进化/多媒体队列 + 死信队列 |
| 数据库 | PostgreSQL 15.x | 元数据存储 |
| 框架 | Spring Boot 3.3.7 | 后端框架 |
| 图像生成 | Stable Diffusion XL / DALL-E 3 | 分镜关键帧生成 |
| 视频生成 | Runway Gen-3 / Pika / Kling | 关键帧→视频片段 |
| 数字人 | HeyGen / D-ID / SadTalker | 虚拟主播/数字人播报 |
| 语音合成 | ChatTTS / CosyVoice / Edge-TTS | 多音色、情感控制 |
| AI音乐 | Suno / MusicGen | 背景音乐生成 |
