# AI 模块 — 基础设施降级策略

> 版本：1.0 | 更新日期：2026-02-28

---

## 一、依赖组件与降级行为

| 组件 | 用途 | 不可用时的降级策略 |
|------|------|---------------------|
| **Milvus** | 向量存储、语义检索 | 检索降级为仅 ES 关键词；写入失败直接报错，提示「向量库不可用」 |
| **Elasticsearch** | 全文检索、BM25 关键词召回 | 检索降级为仅 Milvus 向量；写入失败直接报错，提示「全文检索服务不可用」 |
| **Redis** | 热点查询缓存、会话上下文 | 跳过缓存，直接访问 Milvus/ES；不影响主流程 |
| **RabbitMQ** | 异步知识摄入管道 | 文档导入改为同步执行；队列积压时提示「消息积压超限」 |
| **Ollama** | 本地 LLM、Embedding | 进化/生成失败，提示「AI 模型不可用」；可配置云端 API 回退 |
| **BGE-reranker** | 精排 | 可选组件，无时跳过重排，直接返回融合结果 |

---

## 二、检索链路降级

### 2.1 混合检索（hybridSearch）

```
正常：Query → BGE-M3 向量化 → Milvus ANN + ES BM25 → RRF 融合 → Reranker 重排 → Top-K
```

| 场景 | 降级行为 |
|------|----------|
| Milvus 不可用 | 仅走 ES BM25，返回关键词匹配结果 |
| ES 不可用 | 仅走 Milvus 向量，返回语义相似结果 |
| Milvus + ES 均不可用 | 抛出 `AI_KNOWLEDGE_SEARCH_FAIL`，提示「知识库检索失败」 |
| Reranker 不可用 | 跳过重排，直接返回 RRF 融合结果 |

### 2.2 文档导入

| 场景 | 降级行为 |
|------|----------|
| RabbitMQ 不可用 | 同步执行：拆块 → Embedding → Milvus + ES 双写 |
| Milvus 写入失败 | 抛出 `AI_MILVUS_WRITE_FAILED`，ES 已写入部分需人工或定时补偿 |
| ES 写入失败 | 抛出 `AI_ES_INDEX_FAILED`，Milvus 已写入部分需人工或定时补偿 |

## 三、进化引擎降级

| 场景 | 降级行为 |
|------|----------|
| Ollama 不可用 | 进化任务失败，status=2，error_message 记录原因 |
| 知识库检索失败 | 进化上下文为空时，可跳过或使用兜底 prompt |
| 质量评分低于阈值 | 报告不入库，仅记录日志 |

---

## 四、配置开关

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `app.ai.hybrid.fallback-to-es-only` | Milvus 不可用时是否降级为仅 ES | true |
| `app.ai.hybrid.fallback-to-milvus-only` | ES 不可用时是否降级为仅 Milvus | true |
| `app.ai.import.sync-when-mq-down` | RabbitMQ 不可用时是否同步导入 | true |
| `app.ai.reranker.enabled` | 是否启用 Reranker | true |

## 五、错误码与用户提示

| 错误码 | 用户提示 |
|--------|----------|
| 4050 | 向量数据库不可用 |
| 4053 | 全文检索服务不可用 |
| 4006 | 知识库检索失败 |
| 4002 | AI 模型不可用 |
| 4005 | 知识库索引失败 |

前端 `error-codes.ts` 已映射上述错误码，请求拦截器会使用 `getErrorMessage(status)` 作为兜底提示。
