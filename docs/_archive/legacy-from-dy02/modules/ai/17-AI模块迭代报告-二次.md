## 五、问题清单（优先级）

### P0 - 高优先级

1. **API 方法不统一**：17 个 GET 接口需改为 POST（符合项目规范）
2. **进化页面数据源错误**：`/admin/ai/evolution` 使用 `listAiTasks`（生成任务），应改为进化任务列表（需先封装 GET→POST 后的 `/ai/admin/evolve/task/list`）
3. **知识库 vs 知识源混淆**：`/admin/ai/knowledge` 应展示知识库列表（ai_knowledge_base），当前用 searchKnowledgeSources 展示的是知识源（ai_knowledge_source）

### P1 - 中优先级

4. **前端 API 不完整**：知识库、进化主题、进化任务、额度、任务-模型配置、运维 dashboard、infra、call-log 等未封装
5. **缺失管理页面**：任务-模型配置、Prompt 模板、调用日志、调用统计、进化看板、进化主题、索引队列

### P2 - 优化建议

6. **00-大纲 文档状态**：07、08 应更新为「✅ 完成」
7. **07/08 文档表未建**：ai_query_log、ai_performance_metrics、ai_alert_rule、ai_alert_history、ai_daily_stats 等表需在后续迭代建表
8. **AI 工作台**：/admin/ai/dashboard 当前为通用 Dashboard，可考虑接入 AI 专用统计（call-volume-trend、quota-trend 等）
