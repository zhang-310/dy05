**Phase 1 核心维度数据采集 SQL 示例：**

```sql
-- 1. 知识库数据分析（定时采集，写入 ai_daily_stats）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_value, stat_count)
SELECT CURRENT_DATE, 'doc_total', COUNT(*), 0
FROM kb_document WHERE deleted = 0 AND status = 1;

-- 2. 查询成功率（日统计）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_value)
SELECT CURRENT_DATE, 'query_success_rate',
  ROUND(COUNT(CASE WHEN result_count > 0 THEN 1 END)::DECIMAL / NULLIF(COUNT(*), 0), 4)
FROM ai_query_log WHERE create_time >= CURRENT_DATE;

-- 5. 系统性能分析（P99 延迟）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_value)
SELECT CURRENT_DATE, 'query_avg_latency',
  PERCENTILE_CONT(0.99) WITHIN GROUP (ORDER BY duration_ms)
FROM ai_query_log WHERE create_time >= CURRENT_DATE;

-- 9. 成本效益分析（日成本）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_value, stat_count)
SELECT CURRENT_DATE, 'api_cost', COALESCE(SUM(cost_cny), 0), COUNT(*)
FROM ai_call_log WHERE create_time >= CURRENT_DATE AND status = 1;

-- 11. 自学习系统效果（进化平均评分）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_value, stat_count)
SELECT CURRENT_DATE, 'evolve_avg_score', COALESCE(AVG(score_total), 0), COUNT(*)
FROM ai_evolve_task WHERE create_time >= CURRENT_DATE AND status = 'completed';

-- 热门查询词 TOP 20（日统计）
INSERT INTO ai_daily_stats (stat_date, stat_type, stat_key, stat_count)
SELECT CURRENT_DATE, 'hot_query', query, COUNT(*)
FROM ai_query_log WHERE create_time >= CURRENT_DATE
GROUP BY query ORDER BY COUNT(*) DESC LIMIT 20;
```

#### 8.3.2 数据聚合表

##### ai_daily_stats — 日统计表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| stat_date | DATE | NOT NULL | — | 统计日期 |
| stat_type | VARCHAR(64) | NOT NULL | — | 统计类型 |
| stat_key | VARCHAR(128) | | — | 统计键（如查询词、文档ID） |
| stat_value | DECIMAL(12,4) | NOT NULL | — | 统计值 |
| stat_count | INTEGER | | 0 | 统计次数 |
| created_at | TIMESTAMP | | CURRENT_TIMESTAMP | |

索引：UNIQUE(stat_date, stat_type, stat_key)

统计类型清单：
- query_total — 查询总量
- query_success_rate — 查询成功率
- query_avg_latency — 平均查询延迟
- cache_hit_rate — 缓存命中率
- doc_total — 文档总数
- vector_total — 向量总数
- evolve_avg_score — 进化平均评分
- user_dau — 日活跃用户
- generate_total — 内容生成总量
- generate_success_rate — 生成成功率
- live_total — 直播场次
- live_avg_gmv — 平均直播GMV
- video_total — 视频生成总量
- api_cost — API调用成本
- hot_query — 热门查询词（stat_key=查询词，stat_count=次数）

### 8.5 专家级AI智能体评估体系

#### 8.5.1 智能体能力评分

| 能力维度 | 评估指标 | 权重 | 目标评分 |
|---------|---------|------|---------|
| 知识深度 | 抖音运营知识的深度和准确性 | 25% | > 85 |
| 知识广度 | 覆盖的运营主题范围 | 15% | > 80 |
| 生成质量 | AI生成内容的质量评分 | 20% | > 75 |
| 实时性 | 热点响应速度、知识更新速度 | 15% | > 80 |
| 用户满意度 | 用户反馈评分 | 15% | > 80 |
| 转化效果 | 生成内容的实际转化效果 | 10% | > 70 |

综合评分 = 各维度评分 x 权重之和

#### 8.5.2 智能体成长路径

| 阶段 | 综合评分 | 能力描述 |
|------|---------|---------|
| 初级 | 0-40 | 基础知识检索、简单内容生成 |
| 中级 | 40-60 | 混合检索、多类型内容生成、基础分析 |
| 高级 | 60-80 | 专业级知识、高质量生成、实时分析、话术优化 |
| 专家级 | 80-90 | 深度行业洞察、创新内容、精准预测、全链路视频 |
| 大师级 | 90-100 | 行业领先、自主进化、跨域融合、战略级建议 |

#### 8.5.3 持续进化目标

- Phase 1（1-3个月）：达到中级（评分 40-60）
  - 知识库基础建设完成
  - 混合检索上线
  - 基础内容生成能力

- Phase 2（3-6个月）：达到高级（评分 60-80）
  - 进化引擎持续运行
  - 直播分析上线
  - 视频生成链路打通

- Phase 3（6-12个月）：达到专家级（评分 80-90）
  - 知识库深度覆盖抖音运营全领域
  - AI生成内容质量达到专业水平
  - 实时分析和预测能力成熟

- Phase 4（12个月+）：冲击大师级（评分 90+）
  - 行业领先的知识深度
  - 自主发现新趋势、新机会
  - 跨域知识融合创新
