## 5. 验收标准

### 5.1 功能验收

- [ ] 分组树正确展示 4 大类 + 13 子分组
- [ ] 可新增/编辑/删除自定义分组
- [ ] 预设分组不可删除
- [ ] 分组下有配置时不可删除
- [ ] 配置项 CRUD 正常
- [ ] 配置键全局唯一
- [ ] 值类型校验正确（number/boolean/json）
- [ ] password 类型列表脱敏，详情返回原值
- [ ] 按 config_key 获取配置值正确（缓存优先）
- [ ] 按分组编码批量获取配置正确
- [ ] 配置修改后缓存立即刷新
- [ ] 配置导出功能正常，password 脱敏
- [ ] 行业分类树正确展示
- [ ] 行业 CRUD 正常
- [ ] 行业被引用时不可删除
- [ ] 行业层级限制为 2 级

### 5.2 技术验收

- [ ] 所有接口返回 RESTResult 格式，包含 traceId
- [ ] Entity 使用 `@SQLRestriction("deleted = 0")` 逻辑删除
- [ ] 写操作有 @Transactional
- [ ] 分页参数有上限校验（rows <= 1000）
- [ ] 无 SQL 注入风险（sortName 正则校验）
- [ ] ConcurrentHashMap 缓存启动加载 + 修改刷新
- [ ] 错误码 3601-3605 已在 ErrorCode.java 中注册
