# config 模块 — 接口设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 1. 接口总表

共计 **14 个端点**，分布在 3 个分组中。

### 1.1 配置分组接口（/api/v1/config/group）— 3 个端点

| # | 方法 | 路径 | 权限 | 说明 |
|---|------|------|------|------|
| 1 | POST | /api/v1/config/group/tree | 管理员 | 获取分组树（2 级） |
| 2 | POST | /api/v1/config/group/save | 管理员 | 新增/编辑分组 |
| 3 | POST | /api/v1/config/group/delete | 管理员 | 删除分组（预设不可删） |

### 1.2 配置项接口（/api/v1/config）— 7 个端点

| # | 方法 | 路径 | 权限 | 说明 |
|---|------|------|------|------|
| 4 | POST | /api/v1/config/search | 管理员 | 按分组查询配置列表 |
| 5 | POST | /api/v1/config/get | 管理员 | 配置项详情 |
| 6 | POST | /api/v1/config/save | 管理员 | 新增/编辑配置项 |
| 7 | POST | /api/v1/config/delete | 管理员 | 删除配置项 |
| 8 | POST | /api/v1/config/get-by-key | 登录 | 按 config_key 获取值（缓存优先） |
| 9 | POST | /api/v1/config/get-by-group | 登录 | 按分组编码批量获取配置 |
| 10 | POST | /api/v1/config/export | 管理员 | 导出配置（JSON） |

### 1.3 行业分类接口（/api/v1/config/industry）— 4 个端点

| # | 方法 | 路径 | 权限 | 说明 |
|---|------|------|------|------|
| 11 | POST | /api/v1/config/industry/tree | 登录 | 获取行业分类树 |
| 12 | POST | /api/v1/config/industry/save | 管理员 | 新增/编辑行业 |
| 13 | POST | /api/v1/config/industry/delete | 管理员 | 删除行业（有引用时禁止） |
| 14 | POST | /api/v1/config/industry/list | 登录 | 行业全量列表（无分页，下拉选择用） |

## 2. 关键接口详细设计

### 接口 1：获取分组树

```
POST /api/v1/config/group/tree
权限：管理员
```

**请求：**

```json
{}
```

**响应：**

```json
{
  "status": 200,
  "data": [
    {
      "id": 1,
      "groupCode": "system",
      "groupName": "系统配置",
      "parentId": 0,
      "isPreset": 1,
      "sortOrder": 1,
      "description": "系统基础配置",
      "children": [
        {
          "id": 5,
          "groupCode": "system.basic",
          "groupName": "基础设置",
          "parentId": 1,
          "isPreset": 1,
          "sortOrder": 1,
          "children": []
        }
      ]
    }
  ]
}
```

### 接口 2：新增/编辑分组

```
POST /api/v1/config/group/save
权限：管理员
```

**请求：**

```json
{
  "id": null,
  "groupCode": "custom.group",
  "groupName": "自定义分组",
  "parentId": 0,
  "sortOrder": 10,
  "description": "用户自定义的配置分组"
}
```

> `id` 为空时新增，非空时编辑。编辑时不可修改 `groupCode`。

**响应：**

```json
{
  "status": 200,
  "data": { "id": 18 }
}
```

### 接口 3：删除分组

```
POST /api/v1/config/group/delete
权限：管理员
```

**请求：**

```json
{
  "id": 18
}
```

**业务校验：**
- 预设分组（`is_preset = 1`）返回 3601
- 分组下有配置项返回 3602

### 接口 4：按分组查询配置列表

```
POST /api/v1/config/search
权限：管理员
```

**请求：**

```json
{
  "groupId": 5,
  "keyword": "",
  "page": 0,
  "rows": 20
}
```

> `keyword` 可选，模糊匹配 config_key 或 config_name。`groupId` 为空时跨分组搜索。

**响应：**

```json
{
  "status": 200,
  "data": {
    "content": [
      {
        "id": 1,
        "groupId": 5,
        "configKey": "system.basic.site_name",
        "configValue": "抖音运营管理系统",
        "valueType": "string",
        "configName": "系统名称",
        "description": "显示在页面标题和 Logo 旁",
        "sortOrder": 1
      },
      {
        "id": 2,
        "groupId": 5,
        "configKey": "system.basic.logo_url",
        "configValue": "/static/logo.png",
        "valueType": "string",
        "configName": "系统 Logo",
        "description": "Logo 图片 URL",
        "sortOrder": 2
      }
    ],
    "totalElements": 4,
    "totalPages": 1
  }
}
```

> **脱敏规则：** `valueType = password` 的配置项，`configValue` 返回 `"******"`。

### 接口 6：新增/编辑配置项

```
POST /api/v1/config/save
权限：管理员
```

**请求：**

```json
{
  "id": null,
  "groupId": 8,
  "configKey": "ai.knowledge.api_url",
  "configValue": "https://api.example.com/v1/embeddings",
  "valueType": "string",
  "configName": "嵌入模型 API 地址",
  "description": "Embedding 模型接口地址",
  "sortOrder": 1
}
```

**业务校验：**
- `configKey` 唯一性校验，重复返回 3603
- `valueType` 格式校验（BR-05）：number 必须为数字，boolean 必须为 true/false，json 必须为合法 JSON
- 保存成功后立即刷新内存缓存

### 接口 8：按 config_key 获取值

```
POST /api/v1/config/get-by-key
权限：登录
```

**请求：**

```json
{
  "configKey": "system.basic.site_name"
}
```

**响应：**

```json
{
  "status": 200,
  "data": {
    "configKey": "system.basic.site_name",
    "configValue": "抖音运营管理系统",
    "valueType": "string"
  }
}
```

> 优先从内存缓存获取，缓存未命中时查数据库并回填。`password` 类型通过此接口返回原值（供后端服务调用）。

### 接口 9：按分组编码批量获取

```
POST /api/v1/config/get-by-group
权限：登录
```

**请求：**

```json
{
  "groupCode": "ai.knowledge"
}
```

**响应：**

```json
{
  "status": 200,
  "data": [
    { "configKey": "ai.knowledge.api_url", "configValue": "https://api.example.com/v1/embeddings", "valueType": "string" },
    { "configKey": "ai.knowledge.api_key", "configValue": "sk-xxxx", "valueType": "password" },
    { "configKey": "ai.knowledge.dimension", "configValue": "1536", "valueType": "number" }
  ]
}
```

> 按分组编码查询该分组下所有配置项。`password` 类型返回原值（供后端服务调用）。

### 接口 10：导出配置

```
POST /api/v1/config/export
权限：管理员
```

**请求：**

```json
{
  "groupCode": "ai"
}
```

> `groupCode` 可选。为空时导出全部配置，非空时导出指定大类及其子分组下的配置。

**响应：**

```json
{
  "status": 200,
  "data": {
    "exportTime": "2026-02-26T10:00:00",
    "groups": [
      {
        "groupCode": "ai.knowledge",
        "groupName": "知识库",
        "configs": [
          { "configKey": "ai.knowledge.api_url", "configValue": "", "valueType": "string", "configName": "嵌入模型 API 地址" }
        ]
      }
    ]
  }
}
```

> **安全说明：** 导出时 `password` 类型的值显示为 `"******"`，防止敏感信息泄露。


## 3. 错误码表

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 3601 | PRESET_GROUP_CANNOT_DELETE | 预设分组不可删除 |
| 3602 | GROUP_HAS_CONFIGS | 分组下存在配置项，不可删除 |
| 3603 | CONFIG_KEY_DUPLICATE | 配置键已存在 |
| 3604 | CONFIG_VALUE_TYPE_INVALID | 配置值与类型不匹配 |
| 3605 | INDUSTRY_IN_USE | 行业分类正在被使用，不可删除 |

---

## 4. 通用说明

1. 所有接口返回 `RESTResult` 格式，包含 `traceId`
2. 写操作（save/delete）需管理员权限
3. 读操作中，`search`（管理端列表）需管理员权限，`get-by-key` / `get-by-group` / `industry/tree` / `industry/list` 仅需登录
4. 分页参数：`page`（从 0 开始）、`rows`（默认 20，上限 1000）
5. 排序参数：`sortName`（字段名，正则校验防注入）、`sortOrder`（asc/desc）
