# config 模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1. 功能清单

```
config 模块
├── 配置管理
│   ├── 配置分组
│   │   ├── 分组树查询（2 级层级）
│   │   ├── 新增/编辑分组
│   │   └── 删除分组（预设分组不可删除）
│   ├── 配置项
│   │   ├── 按分组查询配置列表
│   │   ├── 跨分组搜索配置
│   │   ├── 新增/编辑配置项
│   │   ├── 删除配置项
│   │   ├── 按 config_key 获取值（缓存优先）
│   │   ├── 按分组编码批量获取
│   │   └── 配置导入/导出
│   └── 缓存管理
│       ├── 启动时全量加载到内存
│       └── 修改时立即刷新缓存
│
└── 行业分类管理
    ├── 行业树查询
    ├── 新增/编辑行业
    ├── 删除行业（有引用时禁止删除）
    └── 预设行业数据（15 个一级行业）
```

## 2. 业务规则

| # | 规则 | 说明 |
|---|------|------|
| BR-01 | 分组编码全局唯一 | `group_code` 在 sys_config_group 中不可重复（含未删除记录） |
| BR-02 | 配置键全局唯一 | `config_key` 在 sys_config 中不可重复（含未删除记录） |
| BR-03 | 预设分组不可删除 | `is_preset = 1` 的分组禁止删除，返回错误提示 |
| BR-04 | 分组下有配置时不可删除 | 删除分组前检查是否存在关联配置项，有则拒绝 |
| BR-05 | 配置值类型校验 | 保存时根据 `value_type` 校验值格式：number 必须为数字，boolean 必须为 true/false，json 必须为合法 JSON |
| BR-06 | 敏感值脱敏 | `value_type = password` 的配置项，查询列表时值显示为 `******`，仅编辑时可见原值 |
| BR-07 | 缓存一致性 | 配置项增删改后，立即刷新内存缓存（ConcurrentHashMap） |
| BR-08 | 行业删除保护 | 行业被 douyin_account / script / short_video 等表引用时，禁止删除 |
| BR-09 | 行业层级限制 | 行业分类支持父子层级，最多 2 级（一级行业 + 二级子行业） |

## 3. 预设分组结构

config 模块预设 4 大分组，每个大分组下包含若干子分组。预设分组 `is_preset = 1`，不可删除。

### 3.1 系统配置（system）

| 子分组编码 | 子分组名称 | 典型配置项 |
|-----------|-----------|-----------|
| system.basic | 基础设置 | 系统名称、系统 Logo URL、版权信息、ICP 备案号 |
| system.security | 安全设置 | Token 过期时间(h)、密码最小长度、登录失败锁定次数 |
| system.notification | 通知设置 | 短信服务商、短信 API Key、邮件 SMTP 地址 |

### 3.2 AI 配置（ai）

| 子分组编码 | 子分组名称 | 典型配置项 |
|-----------|-----------|-----------|
| ai.knowledge | 知识库 | 嵌入模型 API 地址、嵌入模型 API Key、向量维度 |
| ai.copywriting | 文案生成 | 文案模型 API 地址、文案模型 API Key、默认温度 |
| ai.speech | 话术生成 | 话术模型 API 地址、话术模型 API Key |
| ai.image | 图像生成 | 图像模型 API 地址、图像模型 API Key、默认分辨率 |
| ai.video | 视频生成 | 视频模型 API 地址、视频模型 API Key |
| ai.tts | 语音合成 | TTS API 地址、TTS API Key、默认音色 |

### 3.3 存储配置（storage）

| 子分组编码 | 子分组名称 | 典型配置项 |
|-----------|-----------|-----------|
| storage.local | 本地存储 | 上传根目录、最大文件大小(MB)、允许的文件类型 |
| storage.oss | 对象存储 | OSS Endpoint、AccessKey ID、AccessKey Secret、Bucket 名称 |

### 3.4 抖音接口（douyin）

| 子分组编码 | 子分组名称 | 典型配置项 |
|-----------|-----------|-----------|
| douyin.open | 开放平台 | App ID、App Secret、回调地址 |
| douyin.data | 数据接口 | 数据同步频率(min)、数据保留天数 |

## 4. 模块依赖说明

### 4.1 config 模块依赖

| 依赖 | 说明 |
|------|------|
| common | BaseEntity、RESTResult、分页工具等基础设施 |

> config 模块不依赖任何其他业务模块。

### 4.2 被依赖关系

| 模块 | 依赖方式 | 说明 |
|------|---------|------|
| douyin | 引用 sys_config | 读取抖音开放平台 App ID/Secret 等配置 |
| douyin | 引用 sys_industry | 账号关联行业分类 |
| script | 引用 sys_industry | 脚本关联行业分类 |
| shortvideo | 引用 sys_industry | 短视频关联行业分类 |
| ai | 引用 sys_config | 读取各 AI 模型的 API 地址和密钥 |
| storage | 引用 sys_config | 读取存储配置（本地路径/OSS 参数） |

### 4.3 配置读取方式

其他模块通过 `SysConfigService.getValueByKey(String key)` 读取配置值，该方法优先从内存缓存获取，缓存未命中时查数据库并回填缓存。

## 5. 注意事项

1. **AI 模型配置不在 sys_config 中管理的部分：** AI 模块自身的模型实例（如 ai_model 表）管理的是模型元数据（名称、类型、能力标签等），而 sys_config 管理的是各 AI 接口的连接配置（API 地址、密钥、参数）。两者互补，不重叠。

2. **配置值加密：** `value_type = password` 的配置项在数据库中明文存储，仅在 API 返回列表时脱敏显示。如需数据库级加密，可后续扩展 AES 加密存储。

3. **分组编码命名规范：** 采用 `大类.子类` 的点分格式（如 `ai.knowledge`），便于按前缀批量查询同一大类下的所有配置。

4. **配置变更审计：** 当前版本不记录配置变更历史。如需审计，可通过 log 模块的操作日志实现（Controller 层已有 @OperationLog 注解支持）。
