## 2. 表结构（DDL）

### 2.1 sys_config_group — 配置分组表

> Entity 对齐：`SysConfigGroup.java`，注解 `@SQLRestriction("deleted = 0")`

```sql
CREATE TABLE sys_config_group (
    id              BIGSERIAL       PRIMARY KEY,
    group_code      VARCHAR(64)     NOT NULL,
    group_name      VARCHAR(128)    NOT NULL,
    parent_id       BIGINT          DEFAULT 0,
    is_preset       INTEGER         NOT NULL DEFAULT 0,
    sort_order      INTEGER         DEFAULT 0,
    description     VARCHAR(256),
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

-- 分组编码唯一索引（仅未删除记录）
CREATE UNIQUE INDEX uk_config_group_code ON sys_config_group (group_code) WHERE deleted = 0;
-- 父级查询索引
CREATE INDEX idx_config_group_parent ON sys_config_group (parent_id);
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| group_code | VARCHAR(64) | NOT NULL | -- | 分组编码（唯一），如 `ai.knowledge` |
| group_name | VARCHAR(128) | NOT NULL | -- | 分组名称，如「知识库」 |
| parent_id | BIGINT | | 0 | 父分组 ID，0 表示一级分组 |
| is_preset | INTEGER | NOT NULL | 0 | 是否预设：0=否 1=是（预设不可删除） |
| sort_order | INTEGER | | 0 | 排序序号 |
| description | VARCHAR(256) | | -- | 分组描述 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

### 2.2 sys_config — 配置项表

> Entity 对齐：`SysConfig.java`，注解 `@SQLRestriction("deleted = 0")`

```sql
CREATE TABLE sys_config (
    id              BIGSERIAL       PRIMARY KEY,
    group_id        BIGINT          NOT NULL,
    config_key      VARCHAR(128)    NOT NULL,
    config_value    TEXT,
    value_type      VARCHAR(16)     NOT NULL DEFAULT 'string',
    config_name     VARCHAR(128)    NOT NULL,
    description     VARCHAR(256),
    sort_order      INTEGER         DEFAULT 0,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

-- 配置键唯一索引（仅未删除记录）
CREATE UNIQUE INDEX uk_config_key ON sys_config (config_key) WHERE deleted = 0;
-- 分组查询索引
CREATE INDEX idx_config_group_id ON sys_config (group_id);
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| group_id | BIGINT | NOT NULL | -- | 所属分组 ID，关联 sys_config_group.id |
| config_key | VARCHAR(128) | NOT NULL | -- | 配置键（唯一），如 `ai.knowledge.api_url` |
| config_value | TEXT | | -- | 配置值 |
| value_type | VARCHAR(16) | NOT NULL | 'string' | 值类型：string / number / boolean / json / password |
| config_name | VARCHAR(128) | NOT NULL | -- | 配置名称（中文），如「嵌入模型 API 地址」 |
| description | VARCHAR(256) | | -- | 配置说明 |
| sort_order | INTEGER | | 0 | 排序序号 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

### 2.3 sys_industry — 行业分类表

> Entity 对齐：`SysIndustry.java`，注解 `@SQLRestriction("deleted = 0")`

```sql
CREATE TABLE sys_industry (
    id              BIGSERIAL       PRIMARY KEY,
    industry_name   VARCHAR(64)     NOT NULL,
    parent_id       BIGINT          DEFAULT 0,
    sort_order      INTEGER         DEFAULT 0,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

-- 行业名称+父级唯一索引（同一父级下名称不重复）
CREATE UNIQUE INDEX uk_industry_name_parent ON sys_industry (industry_name, parent_id) WHERE deleted = 0;
-- 父级查询索引
CREATE INDEX idx_industry_parent ON sys_industry (parent_id);
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| industry_name | VARCHAR(64) | NOT NULL | -- | 行业名称 |
| parent_id | BIGINT | | 0 | 父行业 ID，0 表示一级行业 |
| sort_order | INTEGER | | 0 | 排序序号 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

## 3. 索引设计说明

| 表 | 索引 | 类型 | 说明 |
|---|------|------|------|
| sys_config_group | uk_config_group_code | UNIQUE (partial) | `WHERE deleted=0`，保证未删除分组编码唯一 |
| sys_config_group | idx_config_group_parent | B-tree | 按 parent_id 查询子分组 |
| sys_config | uk_config_key | UNIQUE (partial) | `WHERE deleted=0`，保证未删除配置键唯一 |
| sys_config | idx_config_group_id | B-tree | 按 group_id 查询分组下的配置项 |
| sys_industry | uk_industry_name_parent | UNIQUE (partial) | `WHERE deleted=0`，同一父级下行业名称唯一 |
| sys_industry | idx_industry_parent | B-tree | 按 parent_id 查询子行业 |

> 所有 partial unique index 使用 PostgreSQL 的 `WHERE deleted = 0` 语法，确保逻辑删除后可重新创建同名记录。

---

## 4. Entity 注解说明

| Entity 类 | 表名 | @SQLRestriction | 说明 |
|-----------|------|-----------------|------|
| SysConfigGroup | sys_config_group | `"deleted = 0"` | 所有查询自动过滤已删除记录 |
| SysConfig | sys_config | `"deleted = 0"` | 所有查询自动过滤已删除记录 |
| SysIndustry | sys_industry | `"deleted = 0"` | 所有查询自动过滤已删除记录 |

> 使用 Hibernate 6 的 `@SQLRestriction` 注解（替代已废弃的 `@Where`），在 Entity 级别自动追加 `WHERE deleted = 0` 条件。
