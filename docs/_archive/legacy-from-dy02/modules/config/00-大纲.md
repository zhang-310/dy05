## 模块定位

config 模块是全平台的配置中心，提供**分组层级配置管理**和**行业分类管理**两大子系统。支持运行时动态修改配置，无需重启服务。

核心职责：
1. **分组层级配置** — 2 级分组树，按业务域组织配置项（系统/AI/存储/抖音）
2. **配置值类型系统** — 支持 string/number/boolean/json/password 五种类型
3. **内存缓存** — ConcurrentHashMap 缓存，修改时立即刷新，保证读取性能
4. **行业分类管理** — 全局共用的行业分类树，被 douyin/script/shortvideo 等模块引用

> **核心场景：** AI 模型接口众多（知识库嵌入、文案生成、话术生成、图像生成、视频生成、TTS 等），每个接口有不同的 API 地址、密钥、参数。通过分组配置可以直观管理这些配置项。

```

│  │  敏感值脱敏              │  │  全局共用                 │    │
│  │  跨分组搜索              │  │  删除保护                 │    │
│  │  导入/导出               │  │                          │    │
│  └────────────┬─────────────┘  └────────────┬─────────────┘    │
│               │                             │                  │
│  ┌────────────┴─────────────────────────────┴─────────────┐    │
│  │                    内存缓存层                             │    │
│  │  ConcurrentHashMap — 启动加载，修改立即刷新               │    │
│  └────────────────────────────────────────────────────────┘    │
│                                                                 │
│  ┌─────────────────────────────────────────────────────────┐    │
│  │                    配置查询 API                           │    │

│  └─────────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────────┘
```

| 维度 | 数量 | 说明 |

| 数据库表 | 3 张 | sys_config_group, sys_config, sys_industry |

| 前端任务 | 2 个 | F1-F2，系统配置页 + 行业分类页 |
| 业务规则 | 9 条 | BR-01 到 BR-09 |
| 错误码 | 5 个 | 3601-3605 |
| 预设分组 | 4 大类 13 子组 | 系统配置/AI 配置/存储配置/抖音接口 |
| 预设行业 | 15 个 | 一级行业分类 |

## 模块依赖关系

```
                    ┌─────────┐
                    │ common  │
                    │ config  │
                    │ vo/util │
                    │constant │
                    └────┬────┘
                         │
                    ┌────┴────┐
                    │ config  │  ← 不依赖其他业务模块
                    │ 配置中心 │
                    └────┬────┘
                         │
          ┌──────────────┼──────────────┐
          │              │              │
     ┌────┴────┐   ┌────┴────┐   ┌────┴────┐
     │ douyin  │   │ script  │   │shortvideo│
     │ 账号管理 │   │ 脚本管理 │   │ 短视频   │
     └─────────┘   └─────────┘   └─────────┘
          │              │              │
          └──────────────┴──────────────┘
                         │
              引用 sys_industry 行业分类
              引用 sys_config 配置值
```

> config 模块是被依赖的基础模块，不依赖任何其他业务模块。仅依赖 common 包（config/vo/util/constant）。
