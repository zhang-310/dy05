## 1. 后端任务（B1-B9）

## 4. 建议开发顺序

### 第一阶段：基础搭建（Day 1）

```
B1 → B2 → B3 → B4
```

### 第二阶段：核心服务（Day 2-3）

```
B5 → B6（ConfigService 依赖 ConfigGroupService 查分组编码）
B7（可与 B5 并行）
```

### 第三阶段：Controller + 前端（Day 4-5）

```
B8 → F1
B9 → F2（可与 B8 并行）
```

## 6. 关键实现要点

| 任务 | 要点 |
|------|------|
| B1 | 初始数据 SQL 中 parent_id 需要引用实际生成的 id，建议分批插入或使用 CTE |
| B6 | `@PostConstruct` 启动加载缓存；save/delete 后立即刷新 configCache 和 groupCache |
| B6 | 值类型校验：number → BigDecimal 解析，boolean → equals 判断，json → ObjectMapper 解析 |
| B6 | 列表查询脱敏：password 类型返回 `"******"`，详情查询返回原值 |
| B7 | 删除保护需注入 douyin/script/shortvideo 的 Repository，检查 countByIndustryId |
| F1 | 左侧树使用 el-tree 组件，右侧表格使用 el-table，编辑弹窗使用 el-dialog |
| F2 | 树形表格使用 el-table 的 row-key + tree-props 实现 |
