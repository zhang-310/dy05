### 2.2 交互说明

| 操作 | 说明 |
|------|------|
| 点击左侧分组 | 右侧加载该分组下的配置项列表 |
| 展开/折叠分组 | 一级分组可展开显示二级子分组 |
| 搜索配置项 | 输入关键词，跨分组模糊搜索 config_key 或 config_name |
| 新增配置 | 弹出编辑弹窗，分组默认为当前选中分组 |
| 编辑配置 | 弹出编辑弹窗，可修改值、名称、描述、排序 |
| 删除配置 | 二次确认后删除 |
| 新增分组 | 弹出弹窗，填写分组编码、名称、父分组、描述 |
| 导出 | 导出当前选中大类或全部配置为 JSON |
| password 类型 | 列表中显示 `******`，编辑弹窗中显示原值 |

### 3.2 交互说明

| 操作 | 说明 |
|------|------|
| 展开/折叠 | 点击行业名称前的箭头展开/折叠子行业 |
| 搜索 | 按行业名称模糊搜索，匹配时自动展开父级 |
| 新增行业 | 弹出编辑弹窗，可选择父行业（为空则为一级行业） |
| 编辑行业 | 弹出编辑弹窗，可修改名称和排序 |
| 删除行业 | 二次确认 → 检查引用 → 有引用时提示具体引用数量 |
| 新增子行业 | 在一级行业的操作列增加「新增子行业」按钮 |

│       └── useConfigSettings.ts
