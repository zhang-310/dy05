## 6.3 组件复用

| 组件 | 使用页面 | 说明 |

| FilePreviewModal | 文件管理 | 图片/视频/音频预览弹窗 |

| FileTypeIcon | 文件管理 | 按文件类型显示对应图标 |
| DateRangePicker | 文件管理 | 上传时间范围筛选器 |
| StatsCard | 文件管理 | 顶部统计卡片（总数/图片/视频/音频） |
