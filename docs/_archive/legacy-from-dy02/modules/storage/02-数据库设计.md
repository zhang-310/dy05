## 2. 表结构（DDL）

### 2.1 sys_file — 文件记录表

> Entity 对齐：`SysFile.java`，使用 `@SQLRestriction("deleted = 0")` 逻辑删除

```sql
CREATE TABLE sys_file (
    id              BIGSERIAL       PRIMARY KEY,
    owner_id        BIGINT,
    original_name   VARCHAR(256)    NOT NULL,
    storage_name    VARCHAR(256)    NOT NULL,
    storage_path    VARCHAR(512)    NOT NULL,
    file_url        VARCHAR(512)    NOT NULL,
    file_type       VARCHAR(32),
    file_ext        VARCHAR(16),
    file_size       BIGINT          DEFAULT 0,
    module          VARCHAR(64),
    provider        VARCHAR(32)     DEFAULT 'local',
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

-- 按用户+模块+时间查询
CREATE INDEX idx_file_owner_module ON sys_file (owner_id, module, create_time DESC);

-- 按文件类型查询
CREATE INDEX idx_file_type ON sys_file (file_type, create_time DESC);
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | | -- | 上传用户 ID |
| original_name | VARCHAR(256) | NOT NULL | -- | 原始文件名（用户上传时的文件名） |
| storage_name | VARCHAR(256) | NOT NULL | -- | 存储文件名（UUID + 扩展名） |
| storage_path | VARCHAR(512) | NOT NULL | -- | 存储路径（年/月/日/uuid.ext） |
| file_url | VARCHAR(512) | NOT NULL | -- | 访问 URL（完整 HTTP 地址） |
| file_type | VARCHAR(32) | | -- | 文件类型：image / video / audio |
| file_ext | VARCHAR(16) | | -- | 扩展名：jpg / png / mp4 / mp3 / wav |
| file_size | BIGINT | | 0 | 文件大小（字节） |
| module | VARCHAR(64) | | -- | 所属模块：auth / douyin / live / shortvideo / ai |
| provider | VARCHAR(32) | | 'local' | 存储提供商：local / bos / oss |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常 1=已删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 上传时间 |

---

## 3. 索引设计说明

| 索引 | 类型 | 列 | 说明 |
|------|------|---|------|
| idx_file_owner_module | B-tree | (owner_id, module, create_time DESC) | 按用户+模块查询文件列表 |
| idx_file_type | B-tree | (file_type, create_time DESC) | 按文件类型查询 |

---

## 4. Entity 注解说明

| Entity 类 | 表名 | @SQLRestriction | 说明 |
|-----------|------|-----------------|------|
| SysFile | sys_file | `@SQLRestriction("deleted = 0")` | 逻辑删除，删除时 deleted 置为 1 |

## 5. 文件路径组织

```
存储路径格式：{year}/{month}/{day}/{uuid}.{ext}

示例：
  2026/02/26/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg
  2026/02/26/b2c3d4e5-f6a7-8901-bcde-f12345678901.mp4

本地存储完整路径：
  /data/uploads/2026/02/26/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg

BOS/OSS 完整 URL：
  https://bucket.bos.baidu.com/uploads/2026/02/26/a1b2c3d4.jpg
  https://bucket.oss-cn-hangzhou.aliyuncs.com/uploads/2026/02/26/a1b2c3d4.jpg
```
