## 2. StorageProvider 接口设计

### 2.1 接口定义

```java
public interface StorageProvider {

    /**
     * 上传文件
     * @param inputStream 文件输入流
     * @param storagePath 存储路径（如 2026/02/26/uuid.jpg）
     * @param contentType MIME 类型（如 image/jpeg）
     * @return 文件访问 URL
     */
    String upload(InputStream inputStream, String storagePath, String contentType);

    /**
     * 删除文件（物理删除）
     * @param storagePath 存储路径
     */
    void delete(String storagePath);

    /**
     * 获取文件访问 URL
     * @param storagePath 存储路径
     * @return 完整的 HTTP 访问 URL
     */
    String getUrl(String storagePath);

    /**
     * 检查存储服务是否可用（健康检查）
     * @return true=可用
     */
    boolean isAvailable();
}
```

### 2.2 方法说明

| 方法 | 说明 | 异常处理 |
|------|------|---------|
| upload | 将文件流写入存储后端，返回访问 URL | 写入失败抛出 StorageException(3703) |
| delete | 物理删除存储文件（由定时任务调用） | 删除失败仅记录日志，不抛异常 |
| getUrl | 根据存储路径生成完整访问 URL | -- |
| isAvailable | 健康检查，system 模块调用 | 返回 boolean，不抛异常 |

## 3. 本地存储实现（LocalStorageProvider）

### 3.1 配置项

| 配置键（sys_config） | 默认值 | 说明 |
|---------------------|--------|------|
| storage.local.base-path | /data/uploads | 本地存储根目录 |
| storage.local.url-prefix | http://localhost:8080/uploads | URL 前缀 |

### 3.2 实现逻辑

```java
public class LocalStorageProvider implements StorageProvider {

    @Override
    public String upload(InputStream inputStream, String storagePath, String contentType) {
        // 1. 拼接完整路径：basePath + "/" + storagePath
        // 2. 创建目录（如不存在）
        // 3. 写入文件
        // 4. 返回 URL：urlPrefix + "/" + storagePath
    }

    @Override
    public String getUrl(String storagePath) {
        return urlPrefix + "/" + storagePath;
    }

    @Override
    public boolean isAvailable() {
        // 检查 basePath 目录是否存在且可写
    }
}
```

### 3.3 静态资源映射

## 6. 存储后端切换机制

### 6.1 配置项

```
sys_config 表：
  config_key = "storage.provider"
  config_value = "local" / "bos" / "oss"
```

### 6.2 Provider 工厂

```java
@Component
public class StorageProviderFactory {

    @Autowired private LocalStorageProvider localProvider;
    @Autowired private BosStorageProvider bosProvider;
    @Autowired private OssStorageProvider ossProvider;
    @Autowired private SysConfigService configService;

    public StorageProvider getProvider() {
        String provider = configService.getValue("storage.provider", "local");
        return switch (provider) {
            case "bos" -> bosProvider;
            case "oss" -> ossProvider;
            default -> localProvider;
        };
    }
}
```

### 6.3 切换注意事项

| 注意事项 | 说明 |
|---------|------|
| 已上传文件 | 切换后端后，已上传的文件 URL 不变（存储在 sys_file.file_url 中） |
| 新上传文件 | 使用新后端存储，sys_file.provider 记录实际使用的后端 |
| 混合存储 | 系统支持混合存储，不同文件可能在不同后端 |
| 迁移 | 如需迁移历史文件，需单独编写迁移脚本 |

## 7. 文件类型校验策略

### 7.1 白名单配置

```
sys_config 表：
  config_key = "storage.allowed.types"
  config_value = "jpg,jpeg,png,gif,webp,mp4,avi,mp3,wav"
```

### 7.2 类型映射

| 扩展名 | file_type | MIME 类型 |
|--------|-----------|----------|
| jpg / jpeg | image | image/jpeg |
| png | image | image/png |
| gif | image | image/gif |
| webp | image | image/webp |
| mp4 | video | video/mp4 |
| avi | video | video/x-msvideo |
| mp3 | audio | audio/mpeg |
| wav | audio | audio/wav |

### 7.3 校验流程

```
上传文件
  │
  ├── 提取扩展名（从 originalFilename 获取，转小写）
  │
  ├── 扩展名在白名单中?
  │   └── 否 → 3701（STORAGE_TYPE_NOT_ALLOWED）
  │
  ├── 映射 file_type（image/video/audio）
  │
  └── 通过 → 进入大小校验
```

## 8. 文件大小限制策略

### 8.1 配置项

| 配置键（sys_config） | 默认值 | 说明 |
|---------------------|--------|------|
| storage.max.image.size.mb | 10 | 图片最大 10MB |
| storage.max.video.size.mb | 200 | 视频最大 200MB |
| storage.max.audio.size.mb | 50 | 音频最大 50MB |

### 8.2 校验流程

```
文件类型已确定（image/video/audio）
  │
  ├── 从 sys_config 读取对应类型的大小限制
  │
  ├── file.getSize() > limit * 1024 * 1024?
  │   └── 是 → 3705（STORAGE_FILE_TOO_LARGE）
  │
  └── 通过 → 进入上传流程
```

## 9. 文件名防重策略

### 9.1 命名规则

```
存储文件名：UUID + 原始扩展名
  示例：a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg

存储路径：年/月/日/存储文件名
  示例：2026/02/26/a1b2c3d4-e5f6-7890-abcd-ef1234567890.jpg
```

### 9.2 生成逻辑

```java
public String generateStoragePath(String originalFilename) {
    // 1. 提取扩展名
    String ext = getExtension(originalFilename);

    // 2. 生成 UUID 文件名
    String storageName = UUID.randomUUID().toString() + "." + ext;

    // 3. 按日期组织目录
    LocalDate now = LocalDate.now();
    String datePath = String.format("%d/%02d/%02d",
        now.getYear(), now.getMonthValue(), now.getDayOfMonth());

    // 4. 拼接完整路径
    return datePath + "/" + storageName;
}
```

## 10. CDN 集成

### 10.1 CDN 配置

| 配置项 | 说明 |
|--------|------|
| storage.bos.cdn-domain | BOS CDN 域名（如 https://cdn.example.com） |
| storage.oss.cdn-domain | OSS CDN 域名 |

### 10.2 URL 生成优先级

```
CDN 域名已配置?
  ├── 是 → https://cdn.example.com/uploads/2026/02/26/uuid.jpg
  └── 否 → https://bucket.bos.baidu.com/uploads/2026/02/26/uuid.jpg
```

### 10.3 CDN 注意事项

| 注意事项 | 说明 |
|---------|------|
| 缓存刷新 | 文件使用 UUID 命名，不存在缓存冲突问题 |
| HTTPS | CDN 域名需配置 SSL 证书 |
| 跨域 | CDN 需配置 CORS 允许前端域名访问 |
