# storage 模块 — 接口设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 1. 接口总表

共计 **5 个端点**，均在 StorageController 中。

### 1.1 StorageController（/api/v1/storage）— 5 个端点

| # | 方法 | 路径 | 权限 | 说明 |
|---|------|------|------|------|
| 1 | POST | /api/v1/storage/upload | 登录 | 单文件上传 |
| 2 | POST | /api/v1/storage/upload-multi | 登录 | 多文件上传（最多 10 个） |
| 3 | POST | /api/v1/storage/list | 登录 | 我的文件列表（分页） |
| 4 | POST | /api/v1/storage/delete | 登录 | 删除文件（逻辑删除，仅限自己的文件） |
| 5 | POST | /api/v1/storage/admin/list | 管理员 | 全平台文件列表 |

---

## 2. 关键接口详细设计

### 接口 1：单文件上传

```
POST /api/v1/storage/upload
Content-Type: multipart/form-data
权限：登录
```

**请求参数：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | MultipartFile | 是 | 上传文件 |
| module | String | 否 | 所属模块（auth/douyin/live/shortvideo/ai），默认空 |

**校验流程（Controller 层前置校验，BR-06）：**

```
file 为空?
  → 1001（参数校验失败）

提取扩展名 → 在白名单中?（BR-01）
  → 否：3701（STORAGE_TYPE_NOT_ALLOWED）

判断文件类型 → 检查大小限制（BR-02）
  → 图片 > 10MB / 视频 > 200MB / 音频 > 50MB：3705（STORAGE_FILE_TOO_LARGE）

校验通过 → 调用 StorageService.upload()
```

**响应：**

```json
{
  "status": 200,
  "data": {
    "id": 1,
    "fileUrl": "https://bucket.bos.baidu.com/uploads/2026/02/26/a1b2c3d4.jpg",
    "originalName": "avatar.jpg",
    "fileType": "image",
    "fileExt": "jpg",
    "fileSize": 102400
  }
}
```

### 接口 2：多文件上传

```
POST /api/v1/storage/upload-multi
Content-Type: multipart/form-data
权限：登录
```

**请求参数：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| files | MultipartFile[] | 是 | 上传文件列表（最多 10 个） |
| module | String | 否 | 所属模块 |

**校验：** 每个文件独立校验类型和大小。文件数超过 10 个返回 1001。

**响应：**


### 接口 3：我的文件列表

```
POST /api/v1/storage/list
权限：登录
```

**请求参数（FileSearchVO，继承 BasicQueryDto）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 页码，默认 0 |
| rows | Integer | 否 | 每页条数，默认 30 |
| module | String | 否 | 按模块筛选 |
| fileType | String | 否 | 按文件类型筛选（image/video/audio） |

**业务逻辑：** 自动按当前用户 owner_id 过滤（BR-05 数据隔离）。

**响应（PageResultVO）：**

```json
{
  "status": 200,
  "data": {
    "total": 25,
    "list": [
      {
        "id": 1,
        "originalName": "avatar.jpg",
        "fileUrl": "https://bucket.bos.baidu.com/uploads/2026/02/26/a1b2c3d4.jpg",
        "fileType": "image",
        "fileExt": "jpg",
        "fileSize": 102400,
        "module": "auth",
        "createTime": "2026-02-26 10:30:00"
      }
    ],
    "pageNum": 0,
    "pageSize": 30
  }
}
```

### 接口 4：删除文件

```
POST /api/v1/storage/delete
权限：登录
```

**请求参数：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 文件 ID |

**业务逻辑：**
1. 查询文件记录，校验 owner_id 是否为当前用户（BR-05）
2. 非本人文件返回 1002（NO_PERMISSION）
3. 逻辑删除（deleted = 1）
4. 不删除实际存储文件（后续可通过定时任务清理）

**响应：**

```json
{
  "status": 200,
  "data": null
}
```

---

### 接口 5：全平台文件列表（管理端）

```
POST /api/v1/storage/admin/list
权限：管理员
```

**请求参数（FileSearchVO，继承 BasicQueryDto）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 页码，默认 0 |
| rows | Integer | 否 | 每页条数，默认 30 |
| ownerId | Long | 否 | 按上传用户筛选 |
| module | String | 否 | 按模块筛选 |
| fileType | String | 否 | 按文件类型筛选 |
| provider | String | 否 | 按存储提供商筛选 |

**业务逻辑：** 不限制 owner_id，管理员可查看所有用户文件。

## 3. 错误码表

| 错误码 | 常量名 | 说明 | 触发场景 |
|--------|--------|------|---------|
| 3701 | STORAGE_TYPE_NOT_ALLOWED | 文件类型不允许 | 上传的文件扩展名不在白名单中 |
| 3703 | STORAGE_UPLOAD_FAILED | 文件上传失败 | 存储后端写入异常 |
| 3705 | STORAGE_FILE_TOO_LARGE | 文件大小超限 | 图片>10MB / 视频>200MB / 音频>50MB |

> 通用错误码（来自 common 模块）：1001（参数校验失败）、1002（NO_PERMISSION）
