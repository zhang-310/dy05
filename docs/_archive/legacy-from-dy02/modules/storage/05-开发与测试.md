## 10. 验收标准

### 10.1 功能验收

- [ ] 单文件上传成功，返回 fileUrl 可访问
- [ ] 多文件上传成功（最多 10 个）
- [ ] 不允许的文件类型被拒绝（3701）
- [ ] 超大文件被拒绝（3705）
- [ ] 非 admin 角色用户只能查看/删除自己的文件
- [ ] 管理员可查看全平台文件
- [ ] 文件删除为逻辑删除
- [ ] 存储后端可通过 sys_config 切换

### 10.2 技术验收

- [ ] 所有接口返回 RESTResult 格式，包含 traceId
- [ ] Entity 使用 `@SQLRestriction("deleted = 0")` 逻辑删除
- [ ] 文件名使用 UUID 防重
- [ ] 文件路径按 年/月/日 组织
- [ ] 文件类型和大小限制从 sys_config 读取（可配置）
- [ ] StorageProvider 接口设计合理，三种实现可切换
