## 7.5 开发注意事项

| 事项 | 说明 |
|------|------|
| 错误码注册 | B03 需在开发启动前完成，避免其他任务使用硬编码错误码 |
| 公开接口 | `/event/track` 无需 JWT 认证，需在 Spring Security 配置中放行 |
| 并发安全 | ab_variant 计数字段更新使用 SQL 原子操作，禁止先读后写 |
| 跨模块校验 | B05 中 validateEntityOwnership 需调用对应模块 Service，注意循环依赖 |
| 卡方检验依赖 | commons-math3 需在 pom.xml 中添加，确认版本与项目其他依赖兼容 |
