# A/B 测试模块 — 接口设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 3.1 接口总览

| 分组 | 接口数 | 说明 |
|------|--------|------|
| 实验管理 | 6 | 实验 CRUD + 启动 + 停止 |
| 变体管理 | 3 | 变体 CRUD |
| 事件采集 | 1 | 事件追踪 |
| 结果分析 | 2 | 实验结果 + 结论设置 |
| **合计** | **12** | |

> 所有接口统一使用 POST 方法，路径前缀 `/api/v1/abtest`。
> 所有接口需携带 Authorization 头（JWT Token），未登录返回 401。
> 响应格式统一为 `{"code": 0, "msg": "success", "data": {...}}`，错误时 code 为对应错误码。

## 3.2 实验管理接口

### 3.2.1 实验列表

```
POST /api/v1/abtest/experiment/list
```

**请求体：**
```json
{
  "status": 1,
  "experimentType": "video",
  "keyword": "春季",
  "page": 1,
  "size": 20
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| status | Integer | 否 | 状态筛选：0=草稿 1=运行中 2=已完成 3=已暂停，不传返回全部 |
| experimentType | String | 否 | 类型筛选：video / live / copy |
| keyword | String | 否 | 实验名称关键词搜索 |
| page | Integer | 是 | 页码，从 1 开始 |
| size | Integer | 是 | 每页条数，最大 50 |

**响应：**
```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "total": 15,
    "list": [
      {
        "id": 1,
        "name": "春季护肤文案测试",
        "experimentType": "video",
        "status": 1,
        "startTime": "2026-02-20T10:00:00",
        "endTime": null,
        "variantA": { "id": 1, "variantName": "版本A", "conversionRate": 0.0523 },
        "variantB": { "id": 2, "variantName": "版本B", "conversionRate": 0.0381 },
        "runningDays": 6,
        "totalViews": 1200
      }
    ]
  }
}
```

### 3.2.4 删除实验

```
POST /api/v1/abtest/experiment/delete
```

**请求体：**
```json
{
  "id": 1
}
```

**业务规则：** 仅草稿状态（status=0）的实验可删除，同时软删除关联的变体。

**错误码：**
- 4201：实验不存在
- 4202：无权操作该实验
- 4203：实验状态不允许删除（非草稿状态）

---

### 3.2.5 启动实验

```
POST /api/v1/abtest/experiment/start
```

**请求体：**
```json
{
  "id": 1
}
```

**处理流程：**
1. 校验实验存在且属于当前用户
2. 校验当前状态为草稿（0）或已暂停（3）
3. 校验实验下有效变体数量恰好为 2
4. 更新 status=1，记录 start_time（首次启动时）
5. 返回成功

**错误码：**
- 4201：实验不存在
- 4202：无权操作该实验
- 4203：实验状态不允许启动（已完成状态不可启动）
- 4205：变体数量不合法（必须恰好 2 个）
- 4206：实验已在运行中

---

### 3.2.6 停止实验

```
POST /api/v1/abtest/experiment/stop
```

**请求体：**
```json

  "id": 1
```

**处理流程：**

**错误码：**
- 4201：实验不存在
- 4202：无权操作该实验
- 4203：实验状态不允许停止（非运行中状态）

### 3.3.2 创建/更新变体

```
POST /api/v1/abtest/variant/save
```

**请求体：**
```json
{
  "id": null,
  "experimentId": 1,
  "variantName": "版本A",
  "variantType": "A",
  "content": "春天来了，你的护肤品换季了吗？",
  "entityType": "sv_plan",
  "entityId": 101
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 否 | 为 null 时创建，有值时更新 |
| experimentId | Long | 是 | 所属实验 ID |
| variantName | String | 是 | 变体名称，最长 64 字符 |
| variantType | String | 是 | A 或 B |
| content | String | 否 | 变体内容文本 |
| entityType | String | 否 | sv_plan / live_session_script / cp_library |
| entityId | Long | 否 | 关联实体 ID |

**业务规则：**
- 实验必须处于草稿状态才可创建/更新变体
- 同一实验下同一 variant_type（A/B）只能有一个有效变体
- entityId 必须属于当前用户

**错误码：**
- 4201：实验不存在
- 4202：无权操作该实验
- 4203：实验状态不允许编辑变体（非草稿状态）
- 4204：变体不存在（更新时）

## 3.4 事件采集接口

### 3.4.1 事件追踪

```
POST /api/v1/abtest/event/track
```

> 此接口为高频接口，无需登录（公开接口），通过 user_fingerprint 标识用户。

**请求体：**
```json
{
  "experimentId": 1,
  "variantId": 2,
  "eventType": "click",
  "userFingerprint": "fp_a1b2c3d4e5f6",
  "sessionId": "sess_xyz789"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| experimentId | Long | 是 | 实验 ID |
| variantId | Long | 是 | 变体 ID |
| eventType | String | 是 | view / click / conversion |
| userFingerprint | String | 是 | 用户指纹，最长 64 字符 |
| sessionId | String | 否 | 会话 ID，最长 128 字符 |

**处理流程：**
1. 校验实验存在且状态为运行中（status=1），否则静默忽略
2. 校验 variantId 属于该实验
3. 查询 ab_event 是否已存在相同 (variant_id, event_type, user_fingerprint) 记录
4. 若不存在：写入 ab_event，更新 ab_variant 对应计数字段，重新计算 conversion_rate
5. 若已存在：静默忽略（去重）
6. 返回成功（无论是否去重）

**响应：**
```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

> 注意：此接口失败时不向前端抛出错误，静默处理，不影响主业务。

### 3.5.2 设置结论（结束实验）

```
POST /api/v1/abtest/experiment/conclude
```

**请求体：**
```json
{
  "id": 1,
  "winnerVariantId": 2,
  "conclusion": "变体B（敏感肌痛点切入）转化率显著更高，后续短视频文案优先采用痛点开头策略"
}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 实验 ID |
| winnerVariantId | Long | 是 | 获胜变体 ID |
| conclusion | String | 是 | 实验结论文字描述 |

**处理流程：**
1. 校验实验存在且属于当前用户
2. 校验实验状态为运行中（1）或已暂停（3）
3. 校验 winnerVariantId 属于该实验
4. 更新 ab_experiment：status=2，end_time=now，winner_variant_id，conclusion
5. 更新获胜变体：is_winner=1
6. 返回成功

**错误码：**
- 4201：实验不存在
- 4202：无权操作该实验
- 4203：实验状态不允许结束（草稿状态不可直接结束）
- 4204：获胜变体不存在或不属于该实验

## 3.6 错误码汇总

| 错误码 | 常量名 | HTTP 状态 | 说明 |
|--------|--------|-----------|------|
| 4201 | AB_EXPERIMENT_NOT_FOUND | 404 | 实验不存在或已删除 |
| 4202 | AB_EXPERIMENT_FORBIDDEN | 403 | 无权访问或操作该实验 |
| 4203 | AB_EXPERIMENT_STATUS_INVALID | 400 | 当前实验状态不允许该操作 |
| 4204 | AB_VARIANT_NOT_FOUND | 404 | 变体不存在或已删除 |
| 4205 | AB_VARIANT_COUNT_INVALID | 400 | 变体数量不合法（必须恰好 2 个） |
| 4206 | AB_EXPERIMENT_ALREADY_RUNNING | 400 | 实验已在运行中，不可重复启动 |

> 注意：abtest 模块使用 4200-4299 段错误码，已在 `docs/04-错误码注册表.md` 和 `ErrorCode.java` 中注册。
