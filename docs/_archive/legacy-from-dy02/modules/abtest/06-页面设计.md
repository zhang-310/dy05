# A/B 测试模块 — 页面设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 6.1 页面清单

| # | 页面 | 路由 | 说明 |
|---|------|------|------|
| 1 | 实验列表 | /abtest/experiments | 实验卡片列表，状态筛选，快速查看进度 |
| 2 | 实验详情 | /abtest/experiments/:id | 变体对比、转化漏斗、每日趋势、获胜徽章 |
| 3 | 创建实验 | /abtest/create | 选择类型、填写信息、添加变体、设置说明 |

**交互说明：**

| 元素 | 交互 |
|------|------|
| 状态标签 | 点击快速筛选对应状态的实验 |
| 进度条 | 宽度 = 转化率 / max(转化率A, 转化率B)，直观对比 |
| [推荐B获胜] | 置信度 ≥ 95% 时显示，点击跳转详情页 |
| [查看详情] | 跳转到 /abtest/experiments/:id |
| [暂停] | 运行中实验显示，点击弹确认框后暂停 |
| [启动] | 草稿实验显示，点击启动实验（需已有2个变体） |
| [删除] | 草稿实验显示，点击弹确认框后删除 |
| [+ 创建实验] | 跳转到 /abtest/create |

**状态徽章颜色：**
- 草稿：灰色（○）
- 运行中：绿色（●）
- 已暂停：橙色（⏸）
- 已完成：蓝色（✓）

**交互说明：**

| 元素 | 交互 |
|------|------|
| 置信度进度条 | 实时展示，颜色：< 90% 灰色，90-95% 橙色，≥ 95% 绿色 |
| [推荐 ✓] 徽章 | 置信度 ≥ 95% 时在推荐变体卡片右上角显示 |
| ▲ +xx% 标注 | 相对于另一变体的提升幅度，绿色显示 |
| Tab 切换 | 转化漏斗 / 每日趋势 / 原始数据（事件列表） |
| [设置结论并结束实验] | 弹出结束实验对话框 |
| [暂停实验] | 运行中时显示；已暂停时显示[恢复实验] |

## 6.3 路由配置

```typescript
// router/modules/abtest.ts
export default [
  {
    path: '/abtest',
    meta: { title: 'A/B 测试', icon: 'experiment' },
    children: [
      {
        path: 'experiments',
        name: 'AbTestList',
        component: () => import('@/views/abtest/ExperimentList.vue'),
        meta: { title: '实验列表' }
      },
      {
        path: 'experiments/:id',
        name: 'AbTestDetail',
        component: () => import('@/views/abtest/ExperimentDetail.vue'),
        meta: { title: '实验详情', hidden: true }
      },
      {
        path: 'create',
        name: 'AbTestCreate',
        component: () => import('@/views/abtest/CreateExperiment.vue'),
        meta: { title: '创建实验', hidden: true }
      }
    ]
  }
]
```
