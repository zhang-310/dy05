## 8.3 验收标准

### 功能验收

| 验收项 | 标准 |
|--------|------|
| 实验全生命周期 | 草稿→运行中→已暂停→运行中→已完成 全流程可正常执行 |
| 变体管理 | A/B 两个变体可正常创建、关联内容、删除 |
| 事件采集 | view/click/conversion 三类事件正确写入，去重逻辑有效 |
| 转化率计算 | conversion_rate = conversion_count / view_count，精度正确 |
| 统计显著性 | 卡方检验结果与手工计算误差 < 0.001 |
| 获胜推荐 | 置信度 ≥ 95% 时正确推荐转化率更高的变体 |
| 数据隔离 | 用户只能访问自己的实验，越权操作返回 4202 |
| 状态保护 | 运行中实验不可编辑变体，已完成实验不可重启 |

### 性能验收

| 验收项 | 标准 |
|--------|------|
| 事件追踪接口响应时间 | P99 < 100ms（含去重查询 + 写入 + 计数更新） |
| 实验列表接口响应时间 | P99 < 200ms |
| 实验结果接口响应时间 | P99 < 500ms（含卡方检验计算） |
| 并发事件追踪 | 100 并发写入同一变体，计数最终一致，无数据丢失 |

### 前端验收

| 验收项 | 标准 |
|--------|------|
| 实验列表页 | 状态筛选、进度条、操作按钮均正常工作 |
| 实验详情页 | 变体对比卡片、置信度进度条、漏斗图、趋势折线图正常渲染 |
| 创建实验页 | 三步骤流程、类型选择、内容关联、保存草稿/立即启动均正常 |
| 获胜徽章 | 置信度 ≥ 95% 时正确显示推荐徽章 |
