# A/B 测试模块 — 数据库设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 2.1 ER 关系总览

```
auth_user（auth 模块）
    │
    └─── ab_experiment（A/B 实验）
             │
             ├─── ab_variant（变体 A / 变体 B）
             │        │
             │        └─── ab_event（事件记录：view/click/conversion）
             │
             └─── ab_variant.winner_variant_id（获胜变体，回写到 ab_experiment）

外部关联（跨模块，无 FK 约束，业务层校验）：
ab_variant.entity_id → sv_plan.id         （entity_type = sv_plan）
ab_variant.entity_id → live_session.id    （entity_type = live_session_script）
ab_variant.entity_id → cp_library.id      （entity_type = cp_library）
```

---

## 2.2 表结构

### ab_experiment — A/B 实验表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID |
| name | VARCHAR(128) | NOT NULL | — | 实验名称 |
| description | TEXT | | — | 实验描述 |
| experiment_type | VARCHAR(16) | NOT NULL | — | 实验类型：video / live / copy |
| status | SMALLINT | NOT NULL | 0 | 状态：0=草稿 1=运行中 2=已完成 3=已暂停 |
| start_time | TIMESTAMP | | — | 实验启动时间 |
| end_time | TIMESTAMP | | — | 实验结束时间 |
| winner_variant_id | BIGINT | | — | 获胜变体 ID（结束时设置） |
| conclusion | TEXT | | — | 实验结论（手动填写） |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常 1=已删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(owner_id, status, create_time DESC)` — 用户实验列表按状态筛选
- `(owner_id, experiment_type)` — 按类型筛选
- `(winner_variant_id)` — 获胜变体反查

---

### ab_variant — 变体表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| experiment_id | BIGINT | NOT NULL | — | 所属实验 ID |
| variant_name | VARCHAR(64) | NOT NULL | — | 变体名称（如"版本A"、"版本B"） |
| variant_type | VARCHAR(2) | NOT NULL | — | 变体类型：A / B |
| content | TEXT | | — | 变体内容文本（冗余存储，方便展示） |
| entity_type | VARCHAR(32) | | — | 关联实体类型：sv_plan / live_session_script / cp_library |
| entity_id | BIGINT | | — | 关联实体 ID |
| view_count | BIGINT | NOT NULL | 0 | 曝光次数 |
| click_count | BIGINT | NOT NULL | 0 | 点击次数 |
| conversion_count | BIGINT | NOT NULL | 0 | 转化次数 |
| conversion_rate | DECIMAL(5,4) | | 0.0000 | 转化率（conversion_count / view_count） |
| is_winner | SMALLINT | NOT NULL | 0 | 是否获胜：0=否 1=是 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常 1=已删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(experiment_id, variant_type)` — 按实验查变体
- `(experiment_id, deleted)` — 查实验下有效变体
- `(entity_type, entity_id)` — 反查某内容参与的实验

---

### ab_event — 事件记录表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| experiment_id | BIGINT | NOT NULL | — | 所属实验 ID |
| variant_id | BIGINT | NOT NULL | — | 所属变体 ID |
| event_type | VARCHAR(16) | NOT NULL | — | 事件类型：view / click / conversion |
| user_fingerprint | VARCHAR(64) | NOT NULL | — | 用户指纹（用于去重，不存储真实用户 ID） |
| session_id | VARCHAR(128) | | — | 会话 ID（用于漏斗分析） |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 事件发生时间 |

索引：
- `(experiment_id, variant_id, event_type)` — 统计各变体各类型事件数
- `(variant_id, event_type, user_fingerprint)` — 去重查询（唯一性校验）
- `(experiment_id, create_time)` — 按时间范围查询事件（趋势图）
- `(create_time)` — 归档清理

> 注意：ab_event 不设 deleted 字段，事件记录不允许删除，仅支持归档。

## 2.3 完整 DDL

```sql
-- ============================================================
-- abtest 模块 DDL
-- 版本：3.0 | 日期：2026-02-26
-- ============================================================

-- A/B 实验表
CREATE TABLE ab_experiment (
    id                 BIGSERIAL       PRIMARY KEY,
    owner_id           BIGINT          NOT NULL,
    name               VARCHAR(128)    NOT NULL,
    description        TEXT,
    experiment_type    VARCHAR(16)     NOT NULL CHECK (experiment_type IN ('video', 'live', 'copy')),
    status             SMALLINT        NOT NULL DEFAULT 0 CHECK (status IN (0, 1, 2, 3)),
    start_time         TIMESTAMP,
    end_time           TIMESTAMP,
    winner_variant_id  BIGINT,
    conclusion         TEXT,
    deleted            INTEGER         NOT NULL DEFAULT 0,
    create_time        TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time        TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE  ab_experiment                  IS 'A/B 测试实验表';
COMMENT ON COLUMN ab_experiment.owner_id         IS '所属用户 ID';
COMMENT ON COLUMN ab_experiment.name             IS '实验名称';
COMMENT ON COLUMN ab_experiment.experiment_type  IS '实验类型：video=短视频 live=直播 copy=商品文案';
COMMENT ON COLUMN ab_experiment.status           IS '状态：0=草稿 1=运行中 2=已完成 3=已暂停';
COMMENT ON COLUMN ab_experiment.winner_variant_id IS '获胜变体 ID，结束时设置';
COMMENT ON COLUMN ab_experiment.conclusion       IS '实验结论，手动填写';

CREATE INDEX idx_ab_experiment_owner_status  ON ab_experiment (owner_id, status, create_time DESC);
CREATE INDEX idx_ab_experiment_owner_type    ON ab_experiment (owner_id, experiment_type);
CREATE INDEX idx_ab_experiment_winner        ON ab_experiment (winner_variant_id);

-- 变体表
CREATE TABLE ab_variant (
    id               BIGSERIAL       PRIMARY KEY,
    experiment_id    BIGINT          NOT NULL,
    variant_name     VARCHAR(64)     NOT NULL,
    variant_type     VARCHAR(2)      NOT NULL CHECK (variant_type IN ('A', 'B')),
    content          TEXT,
    entity_type      VARCHAR(32),
    entity_id        BIGINT,
    view_count       BIGINT          NOT NULL DEFAULT 0,
    click_count      BIGINT          NOT NULL DEFAULT 0,
    conversion_count BIGINT          NOT NULL DEFAULT 0,
    conversion_rate  DECIMAL(5,4)    NOT NULL DEFAULT 0.0000,
    is_winner        SMALLINT        NOT NULL DEFAULT 0,
    deleted          INTEGER         NOT NULL DEFAULT 0,
    create_time      TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP,
    update_time      TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE  ab_variant                  IS 'A/B 测试变体表';
COMMENT ON COLUMN ab_variant.experiment_id   IS '所属实验 ID';
COMMENT ON COLUMN ab_variant.variant_type    IS '变体类型：A 或 B';
COMMENT ON COLUMN ab_variant.content         IS '变体内容文本（冗余存储）';
COMMENT ON COLUMN ab_variant.entity_type     IS '关联实体类型：sv_plan / live_session_script / cp_library';
COMMENT ON COLUMN ab_variant.entity_id       IS '关联实体 ID（跨模块，无 FK 约束）';
COMMENT ON COLUMN ab_variant.conversion_rate IS '转化率 = conversion_count / view_count，精度 4 位小数';
COMMENT ON COLUMN ab_variant.is_winner       IS '是否获胜：0=否 1=是';

CREATE INDEX idx_ab_variant_experiment       ON ab_variant (experiment_id, variant_type);
CREATE INDEX idx_ab_variant_experiment_del   ON ab_variant (experiment_id, deleted);
CREATE INDEX idx_ab_variant_entity           ON ab_variant (entity_type, entity_id);

-- 事件记录表
CREATE TABLE ab_event (
    id               BIGSERIAL       PRIMARY KEY,
    experiment_id    BIGINT          NOT NULL,
    variant_id       BIGINT          NOT NULL,
    event_type       VARCHAR(16)     NOT NULL CHECK (event_type IN ('view', 'click', 'conversion')),
    user_fingerprint VARCHAR(64)     NOT NULL,
    session_id       VARCHAR(128),
    create_time      TIMESTAMP       NOT NULL DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE  ab_event                    IS 'A/B 测试事件记录表';
COMMENT ON COLUMN ab_event.experiment_id     IS '所属实验 ID';
COMMENT ON COLUMN ab_event.variant_id        IS '所属变体 ID';
COMMENT ON COLUMN ab_event.event_type        IS '事件类型：view=曝光 click=点击 conversion=转化';
COMMENT ON COLUMN ab_event.user_fingerprint  IS '用户指纹（浏览器指纹/设备指纹，用于去重，不存储真实用户 ID）';
COMMENT ON COLUMN ab_event.session_id        IS '会话 ID，用于漏斗分析';

CREATE INDEX idx_ab_event_variant_type       ON ab_event (experiment_id, variant_id, event_type);
CREATE INDEX idx_ab_event_dedup              ON ab_event (variant_id, event_type, user_fingerprint);
CREATE INDEX idx_ab_event_time               ON ab_event (experiment_id, create_time);
CREATE INDEX idx_ab_event_create_time        ON ab_event (create_time);
```

## 2.4 字段约束说明

| 约束 | 说明 |
|------|------|
| experiment_type CHECK | 仅允许 video / live / copy，新增类型需修改 CHECK 约束或改为应用层校验 |
| status CHECK | 0=草稿 1=运行中 2=已完成 3=已暂停，状态流转由 Service 层控制 |
| variant_type CHECK | 仅允许 A / B，固定两变体设计 |
| event_type CHECK | 仅允许 view / click / conversion |
| conversion_rate DECIMAL(5,4) | 最大值 9.9999，实际转化率不超过 1.0000（100%），精度满足需求 |
| ab_event 无 deleted | 事件记录不可删除，仅支持按 create_time 归档 |
| 跨模块 entity_id | 无数据库外键约束，由 Service 层在保存变体时校验 entity_id 归属 |
