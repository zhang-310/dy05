# douyin 模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

douyin 模块是平台的核心业务基础模块，负责抖音账号绑定、人设管理和产品管理。用户注册后绑定抖音账号，在此基础上创建人设和管理产品。

- 人设是短视频创作（shortvideo）和直播话术生成（live）的核心参数
- 产品是直播带货话术的基础数据
- 账号是所有业务数据的归属锚点

产品数据供 live 模块选品使用，AI 能力来自 ai 模块，行业分类来自 config 模块。

## 1.3 功能清单

```
douyin 模块
├── 账号管理
│   ├── 发起 OAuth2 授权绑定
│   ├── OAuth2 回调处理（获取 access_token/open_id）
│   ├── 同步账号基本信息（头像/昵称/粉丝数/获赞数）
│   ├── 刷新授权 Token（access_token 过期时）
│   ├── Token 自动刷新定时任务（每小时检查）
│   ├── 解除账号绑定
│   ├── 查看绑定账号信息
│   ├── 账号授权状态检查
│   └── 账号数据趋势（每日快照）
│
├── 人设管理
│   ├── 创建人设（定位/风格/标签/受众/口吻/简介）
│   ├── 编辑人设
│   ├── 删除人设（删除保护规则）
│   ├── 切换当前激活人设
│   ├── 获取当前激活人设
│   ├── 人设列表
│   └── 人设详情
│
├── 人设模板
│   ├── 模板列表（用户端，浏览可用模板）
│   ├── 从模板创建人设（复制模板内容为独立人设）
│   ├── 模板 CRUD（管理员）
│   └── 模板分类管理（按行业分类）
│
├── 产品管理
│   ├── 添加产品（名称/价格/卖点/图片/规格/场景/受众）
│   ├── 编辑产品
│   ├── 删除产品（级联逻辑删除话术）
│   ├── 产品列表（按账号筛选、分页）
│   ├── 产品详情
│   ├── AI 生成产品话术（调用 ai 模块，按人设+风格）
│   ├── 产品话术 CRUD（一个产品多套话术）
│   └── 产品分类/标签
│
└── 管理端
    ├── 全平台账号列表（管理员）
    ├── 账号详情
    ├── 人设模板管理（CRUD）
    └── 数据同步记录
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **账号管理** | | |
| BR-01 | 账号绑定数量限制 | 免费版 1 个、专业版 3 个、企业版无限。绑定时从 sys_config 读取对应套餐上限，查 dy_account 当前绑定数量做校验 |
| BR-02 | OAuth2 授权流程 | 使用抖音开放平台 OAuth2 授权码模式，state 参数防 CSRF |
| BR-03 | Token 自动刷新 | access_token 过期前自动用 refresh_token 刷新（定时任务每小时检查）。refresh_token 过期则标记 auth_status=0 |
| BR-07 | 解除绑定清理 | 解除绑定时不删除已有的视频/直播数据，但标记 auth_status=2（已解绑） |
| **人设管理** | | |
| BR-04 | 人设至少一个 | 绑定账号后必须创建至少一个人设才能使用 AI 功能 |
| BR-05 | 当前激活人设 | 用户有多个人设时，有且仅有一个激活人设（is_active=1），AI 生成默认使用激活人设 |
| BR-06 | 人设模板为只读 | 用户从模板创建人设时，复制模板内容生成独立记录，不影响原模板 |
| BR-12 | 人设删除保护 | 1) 若为唯一人设，拒绝删除；2) 若为激活人设，自动激活最早创建的其他人设；3) 已关联的 sv_plan / live_session 中的 persona_id 保留历史值不清空 |
| **产品管理** | | |
| BR-08 | 数据隔离 | talent 只能看到自己的数据（owner_id）；institution 可查看自己+旗下达人的数据（DataScopeService）；admin 可查看全部 |
| BR-09 | 产品属于账号 | 产品关联到抖音账号（account_id），一个账号下可有多个产品 |
| BR-10 | 产品多套话术 | 一个产品可有多套话术（种草/促销/专业讲解/亲切推荐），按风格区分 |
| BR-11 | 产品话术 AI 生成 | 生成话术时必须选择人设和风格，调用 ai 模块 `live_script_product` 模板生成 |
| BR-13 | 行业分类关联 | dy_account.industry_id 关联 sys_industry.id，行业被删除时置为 NULL（ON DELETE SET NULL） |

## 1.5 模块依赖

```
依赖关系：
common (config/vo/util) ← auth ← douyin
config（行业分类 sys_industry、套餐配额 sys_config）← douyin
ai（产品话术 AI 生成）← douyin
                                    ↑
              shortvideo, live 都依赖 douyin（账号/人设/产品）
```

| 依赖模块 | 依赖内容 | 接口 |
|---------|---------|------|
| auth | 用户认证、角色权限、owner_id | AuthTokenFilter |
| config | 行业分类（sys_industry）、套餐配额（sys_config） | SysIndustryService, SysConfigService |
| ai | 产品话术 AI 生成 | AiGenerateService（模板：live_script_product） |

| 被依赖模块 | 提供内容 | 接口 |
|-----------|---------|------|
| shortvideo | 账号信息、人设信息 | DouyinAccountService, DouyinPersonaService |
| live | 账号信息、人设信息、产品信息、产品话术 | DouyinAccountService, DouyinPersonaService, DouyinProductService |

## 1.6 环境变量

| 变量名 | 级别 | 默认值 | 说明 |
|--------|------|--------|------|
| DOUYIN_APP_ID | 🔴 必填 | — | 抖音开放平台应用 client_key |
| DOUYIN_APP_SECRET | 🔴 必填 | — | 抖音开放平台应用 client_secret |
| DOUYIN_REDIRECT_URI | 🔴 必填 | — | OAuth2 回调地址 |
| DOUYIN_TOKEN_REFRESH_CRON | 🟢 可选 | `0 0 * * * ?` | Token 自动刷新定时任务 cron 表达式（默认每小时） |
| DOUYIN_DATA_SYNC_CRON | 🟢 可选 | `0 30 2 * * ?` | 账号数据同步定时任务 cron 表达式（默认每天凌晨 2:30） |
| DOUYIN_ACCOUNT_LIMIT_FREE | 🟢 可选 | 1 | 免费版账号绑定上限 |
| DOUYIN_ACCOUNT_LIMIT_PRO | 🟢 可选 | 3 | 专业版账号绑定上限 |
