# douyin 模块 — 数据库设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 2.1 ER 关系总览

```
auth_user (auth 模块)
    │
    ├──(owner_id)──→ dy_account（抖音账号，一对多，按套餐限制）
    │                    │
    │                    ├─── dy_account_data（账号数据快照，每日一条）
    │                    │
    │                    └─── dy_product（产品，一对多）
    │                             │
    │                             └─── dy_product_script（产品话术，一对多）
    │
    ├──(owner_id)──→ dy_persona（人设，一对多）
    │                    │
    │                    └─── dy_persona.account_id → dy_account.id（可空，通用人设）
    │
    sys_industry (config 模块) ←── dy_account.industry_id（行业分类）

    dy_persona_template（系统模板，管理员维护，独立表）
```

---

## 2.2 表结构

### dy_account — 抖音账号表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| owner_id | BIGINT | NOT NULL | — | 所属用户 ID（auth_user.id） |
| open_id | VARCHAR(256) | NOT NULL | — | 抖音 open_id（OAuth2 授权后获取） |
| union_id | VARCHAR(256) | | — | 抖音 union_id（跨应用标识） |
| nickname | VARCHAR(128) | | — | 抖音昵称 |
| avatar | VARCHAR(512) | | — | 抖音头像 URL |
| douyin_id | VARCHAR(128) | | — | 抖音号（用户自定义的，可能为空） |
| industry_id | BIGINT | | — | 行业分类 ID（关联 sys_industry.id） |
| account_desc | VARCHAR(512) | | — | 账号简介 |
| access_token | VARCHAR(512) | | — | OAuth2 access_token |
| refresh_token | VARCHAR(512) | | — | OAuth2 refresh_token |
| token_expire_time | TIMESTAMP | | — | access_token 过期时间 |
| refresh_expire_time | TIMESTAMP | | — | refresh_token 过期时间（抖音为 30 天） |
| auth_status | INTEGER | NOT NULL | 1 | 授权状态：1=正常 0=过期 2=已解绑 |
| last_sync_time | TIMESTAMP | | — | 最后数据同步时间 |
| status | INTEGER | NOT NULL | 1 | 状态：1=正常 0=禁用 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

**索引：**
- `UNIQUE(owner_id, open_id) WHERE deleted=0` — 同一用户不重复绑定同一抖音号
- `(owner_id) WHERE deleted=0` — 用户账号列表
- `(industry_id) WHERE deleted=0` — 按行业查询
- `(auth_status) WHERE deleted=0` — Token 刷新定时任务查询

| 字段 | 类型 | 必填 | 默认值 | 说明 |

| id | BIGSERIAL | PK | 自增 | 主键 |

| total_favorited | BIGINT | | 0 | 总获赞数 |

## 2.3 完整 DDL（PostgreSQL）

```sql
-- ============================================================
-- douyin 模块 DDL
-- ============================================================

-- 1. 抖音账号表
CREATE TABLE dy_account (
    id              BIGSERIAL PRIMARY KEY,
    owner_id        BIGINT NOT NULL,
    open_id         VARCHAR(256) NOT NULL,
    union_id        VARCHAR(256),
    nickname        VARCHAR(128),
    avatar          VARCHAR(512),
    douyin_id       VARCHAR(128),
    industry_id     BIGINT,
    account_desc    VARCHAR(512),
    access_token    VARCHAR(512),
    refresh_token   VARCHAR(512),
    token_expire_time   TIMESTAMP,
    refresh_expire_time TIMESTAMP,
    auth_status     INTEGER NOT NULL DEFAULT 1,
    last_sync_time  TIMESTAMP,
    status          INTEGER NOT NULL DEFAULT 1,
    deleted         INTEGER NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE UNIQUE INDEX uk_dy_account_owner_open ON dy_account(owner_id, open_id) WHERE deleted = 0;
CREATE INDEX idx_dy_account_owner ON dy_account(owner_id) WHERE deleted = 0;
CREATE INDEX idx_dy_account_industry ON dy_account(industry_id) WHERE deleted = 0;
CREATE INDEX idx_dy_account_auth_status ON dy_account(auth_status) WHERE deleted = 0;

-- 2. 账号数据快照表
CREATE TABLE dy_account_data (
    id              BIGSERIAL PRIMARY KEY,
    account_id      BIGINT NOT NULL,
    follower_count  BIGINT DEFAULT 0,
    following_count BIGINT DEFAULT 0,
    total_favorited BIGINT DEFAULT 0,
    video_count     BIGINT DEFAULT 0,
    snapshot_date   DATE NOT NULL,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE UNIQUE INDEX uk_dy_account_data_date ON dy_account_data(account_id, snapshot_date);
CREATE INDEX idx_dy_account_data_trend ON dy_account_data(account_id, snapshot_date DESC);

-- 3. 人设表
CREATE TABLE dy_persona (
    id              BIGSERIAL PRIMARY KEY,
    owner_id        BIGINT NOT NULL,
    account_id      BIGINT,
    persona_name    VARCHAR(64) NOT NULL,
    positioning     VARCHAR(256),
    style           VARCHAR(128),
    tags            VARCHAR(512),
    target_audience VARCHAR(256),
    tone            VARCHAR(128),
    description     TEXT,
    is_active       INTEGER NOT NULL DEFAULT 0,
    sort_order      INTEGER DEFAULT 0,
    deleted         INTEGER NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_dy_persona_owner ON dy_persona(owner_id) WHERE deleted = 0;
CREATE INDEX idx_dy_persona_active ON dy_persona(owner_id, is_active) WHERE deleted = 0;
CREATE INDEX idx_dy_persona_account ON dy_persona(account_id) WHERE deleted = 0;

-- 4. 人设模板表
CREATE TABLE dy_persona_template (
    id              BIGSERIAL PRIMARY KEY,
    template_name   VARCHAR(64) NOT NULL,
    category        VARCHAR(64),
    positioning     VARCHAR(256),
    style           VARCHAR(128),
    tags            VARCHAR(512),
    target_audience VARCHAR(256),
    tone            VARCHAR(128),
    description     TEXT,
    sort_order      INTEGER DEFAULT 0,
    status          INTEGER NOT NULL DEFAULT 1,
    deleted         INTEGER NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_dy_persona_tpl_category ON dy_persona_template(category, status) WHERE deleted = 0;
CREATE INDEX idx_dy_persona_tpl_list ON dy_persona_template(status, sort_order) WHERE deleted = 0;

-- 5. 产品表
CREATE TABLE dy_product (
    id              BIGSERIAL PRIMARY KEY,
    owner_id        BIGINT NOT NULL,
    account_id      BIGINT NOT NULL,
    product_name    VARCHAR(128) NOT NULL,
    product_image   VARCHAR(512),
    price           DECIMAL(10,2),
    original_price  DECIMAL(10,2),
    category        VARCHAR(64),
    selling_points  TEXT,
    specifications  VARCHAR(512),
    usage_scenario  VARCHAR(512),
    target_audience VARCHAR(256),
    description     TEXT,
    sort_order      INTEGER DEFAULT 0,
    status          INTEGER NOT NULL DEFAULT 1,
    deleted         INTEGER NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_dy_product_owner ON dy_product(owner_id, account_id, status) WHERE deleted = 0;
CREATE INDEX idx_dy_product_account ON dy_product(account_id, status) WHERE deleted = 0;
CREATE INDEX idx_dy_product_category ON dy_product(category) WHERE deleted = 0;

-- 6. 产品话术表
CREATE TABLE dy_product_script (
    id              BIGSERIAL PRIMARY KEY,
    owner_id        BIGINT NOT NULL,
    product_id      BIGINT NOT NULL,
    persona_id      BIGINT,
    script_name     VARCHAR(128) NOT NULL,
    script_style    VARCHAR(64),
    content         TEXT NOT NULL,
    duration_hint   VARCHAR(32),
    is_ai_generated INTEGER NOT NULL DEFAULT 0,
    ai_call_log_id  BIGINT,
    sort_order      INTEGER DEFAULT 0,
    deleted         INTEGER NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_dy_product_script_product ON dy_product_script(product_id) WHERE deleted = 0;
CREATE INDEX idx_dy_product_script_owner ON dy_product_script(owner_id) WHERE deleted = 0;
CREATE INDEX idx_dy_product_script_persona ON dy_product_script(persona_id) WHERE deleted = 0;
```

## 2.5 Entity 注解说明

| 注解 | 用途 | 示例 |
|------|------|------|
| `@Entity` | 标记 JPA 实体 | 所有表对应的 Java 类 |
| `@Table(name = "dy_account")` | 指定表名 | 表名使用下划线命名 |
| `@Id` + `@GeneratedValue(strategy = GenerationType.IDENTITY)` | 主键自增 | PostgreSQL BIGSERIAL |
| `@Column(name = "xxx", nullable = false)` | 字段映射 | 驼峰 → 下划线 |
| `@SQLRestriction("deleted = 0")` | 逻辑删除过滤 | Hibernate 6.x 替代 @Where |
| `@PrePersist` | 插入前回调 | 自动设置 createTime/updateTime |
| `@PreUpdate` | 更新前回调 | 自动更新 updateTime |

**Entity 命名规范：**

| 表名 | Entity 类名 | 包路径 |
|------|------------|--------|
| dy_account | DouyinAccount | module.douyin.entity |
| dy_account_data | DouyinAccountData | module.douyin.entity |
| dy_persona | DouyinPersona | module.douyin.entity |
| dy_persona_template | DouyinPersonaTemplate | module.douyin.entity |
| dy_product | DouyinProduct | module.douyin.entity |
| dy_product_script | DouyinProductScript | module.douyin.entity |
