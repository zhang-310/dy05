# douyin 模块 — 页面设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 6.1 页面清单

| # | 页面 | 路由 | 入口 | 说明 |
|---|------|------|------|------|
| 1 | 账号绑定页 | /talent/douyin/bind | 工作台引导 / 侧栏 | 绑定流程引导、已绑定状态展示 |
| 2 | 账号详情页 | /talent/douyin/account | 侧栏菜单 | 账号信息 + 数据趋势 |
| 3 | 人设管理页 | /talent/douyin/persona | 侧栏菜单 | 人设列表 + 编辑 + 模板选择 |
| 4 | 产品管理页 | /talent/douyin/product | 侧栏菜单 | 产品列表 + 编辑 + 话术管理 |
| 5 | 机构账号总览 | /org/douyin/accounts | 机构侧栏 | 旗下达人账号列表（DataScope 过滤） |
| 6 | 机构人设/产品查看 | /org/douyin/overview | 机构侧栏 | 旗下达人人设与产品只读查看 |
| 7 | 账号管理（管理端） | /admin/douyin/accounts | 管理端菜单 | 全平台账号列表 |
| 8 | 模板管理（管理端） | /admin/douyin/templates | 管理端菜单 | 人设模板 CRUD |

## 6.3 组件复用表

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| AccountCard | 账号绑定页、账号详情页 | 账号信息卡片（头像/昵称/数据/状态） |
| PersonaCard | 人设管理页 | 人设信息卡片（名称/定位/标签/状态） |
| PersonaForm | 人设管理页（Offcanvas） | 人设编辑表单 |
| PersonaTemplateModal | 人设管理页 | 模板选择弹窗 |
| ProductCard | 产品管理页 | 产品信息卡片（图片/名称/价格/话术数） |
| ProductForm | 产品管理页（Offcanvas） | 产品编辑表单 |
| ScriptModal | 产品管理页 | 话术管理弹窗（列表+AI生成） |
| AuthStatusBadge | 多个页面 | 授权状态标签（绿/红/灰） |
| DataTrendChart | 账号详情页 | ECharts 折线图（粉丝/获赞/作品趋势） |
| TagInput | 人设表单、模板表单 | 标签输入组件（回车添加、x 删除） |
| ConfirmDialog | 解绑、删除操作 | 二次确认弹窗 |
| Pagination | 产品列表、管理端列表 | 分页组件 |
