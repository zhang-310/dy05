### 8.2.1 账号绑定

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T01 | 发起 OAuth2 授权 | 点击"绑定抖音号" | 302 重定向到抖音授权页，URL 包含 client_key/state/redirect_uri |
| T02 | OAuth2 回调成功 | 模拟回调 callback?code=xxx&state=yyy | 创建 dy_account 记录，同步基本信息，重定向到成功页 |
| T03 | 重复绑定同一 open_id | 同一用户再次授权同一抖音号 | 更新已有记录（token/昵称/头像），不重复创建 |
| T04 | state 无效 | 回调传入过期/伪造的 state | 重定向到失败页，提示"授权已过期" |
| T05 | 绑定数量超限 | 达人（talent）已绑定 1 个，再次绑定 | 返回 3104，提示升级套餐 |
| T06 | 查看账号信息 | POST /api/v1/douyin/account/info | 返回昵称/头像/粉丝数/授权状态等 |
| T07 | 手动刷新 Token | POST /api/v1/douyin/account/refresh | access_token 更新，token_expire_time 刷新 |
| T08 | Token 过期后刷新失败 | refresh_token 已过期时刷新 | auth_status 变为 0，返回 3102 |
| T09 | 解除绑定 | POST /api/v1/douyin/account/unbind | auth_status=2，token 清空，已有数据保留 |
| T10 | 解绑后重新绑定 | 解绑后再次 OAuth2 授权同一抖音号 | 更新已有记录，auth_status 恢复为 1 |
| T11 | 手动同步数据 | POST /api/v1/douyin/account/sync | dy_account 基本信息更新，dy_account_data 写入当日快照 |
| T12 | 数据趋势查询 | POST /api/v1/douyin/account/data | 返回最近 30 天粉丝/获赞/作品数趋势 |

## 8.5 验收标准

### 功能验收

- [ ] 达人（talent）可通过 OAuth2 绑定抖音账号
- [ ] 绑定后自动同步头像/昵称/粉丝数等基本信息
- [ ] 达人（talent）可查看账号基本信息和授权状态
- [ ] 达人（talent）可手动刷新授权 Token
- [ ] Token 自动刷新定时任务正常运行
- [ ] 达人（talent）可解除账号绑定，已有数据保留
- [ ] 达人（talent）可创建/编辑/删除人设
- [ ] 第一个人设自动激活
- [ ] 达人（talent）可切换激活人设
- [ ] 人设删除保护规则生效（唯一人设不可删、激活人设删除后自动切换）
- [ ] 达人（talent）可从系统模板创建人设
- [ ] 机构（institution）可管理旗下达人的账号
- [ ] 管理员（admin）可查看全平台账号列表
- [ ] 管理员（admin）可管理人设模板（CRUD）
- [ ] 达人（talent）可添加/编辑/删除产品
- [ ] 达人（talent）可为产品 AI 生成多套话术（按风格）
- [ ] 产品话术支持手动编辑和 AI 生成
- [ ] 删除产品时级联逻辑删除话术

### 技术验收

- [ ] OAuth2 Token 安全存储（接口不返回 token 原文）
- [ ] 数据隔离（所有查询/操作校验 owner_id）
- [ ] Entity 有 @SQLRestriction("deleted = 0")
- [ ] 写操作有 @Transactional
- [ ] 接口返回 RESTResult 格式
- [ ] 错误码 3101-3501 已在 ErrorCode.java 中注册
- [ ] 定时任务 cron 表达式可通过环境变量配置
- [ ] 抖音 API 调用有超时和重试机制
