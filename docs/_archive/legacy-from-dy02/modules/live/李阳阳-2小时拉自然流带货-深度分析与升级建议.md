## 一、需求与现状对照总览

### 1.1 拉自然流带货核心链路

| 环节 | 策略 | 话术侧重点 | 系统支持现状 |
|------|------|------------|--------------|
| **流量** | 微付费刺激自然流 | 少投流，靠内容与互动撬动 | ⚠️ 无显式「拉自然流」话术策略注入 |
| **留人** | 话术风格独特个性 | 人设鲜明、幽默/歇后语/名言/古诗 | ⚠️ 李阳阳当前为「精致生活达人」，缺东北、幽默 |
| **蓄水** | 拉高在线人数 | 聊家常、情感共鸣、不急于卖货 | ✅ chat 槽位已实现 |
| **转化** | 人气高时卖利润品 | 转化集中在高在线时段 | ✅ 时段已写入 requirement |

### 1.2 李阳阳人设对照

| 维度 | 需求 | 当前实现 | 差距 |
|------|------|----------|------|
| **定位** | 东北人、幽默、接地气 | 精致生活达人、知性优雅 | 风格不符 |
| **local_flavor** | 东北 | dy_persona 需人工配置，默认无 | 依赖人工 |
| **话术特征** | 歇后语、名言金句、古诗、接地气 | proverb/quote 有，但未强调东北梗 | 东北特色未注入 |
| **参考考古家** | 功能-优势-利益-证据、留人话术 | 高光话术文档有，prompt 未显式引用 | 结构未系统化 |

## 三、待升级项（按优先级）

### P0 — 李阳阳人设与拉自然流策略对齐

**问题**：需求是「李阳阳东北人、幽默、接地气、歇后语、名言金句」，当前 `buildHostPersonaStrategy("yangyang")` 返回「精致生活达人、知性优雅」，与 2 小时拉自然流场景不匹配。

**建议**：

1. **新增「李阳阳·拉自然流」策略分支**  
   - 在 `LivePromptBuilder` 中，当 `sessionType=chat_2h` 且 `hostCode=yangyang` 时，使用拉自然流专用策略：
   ```
   【主播策略：李阳阳·2小时拉自然流】
   - 路线：聊家常蓄水 + 人气高时卖利润品
   - 话术特征：东北人、幽默接地气、歇后语、名言金句、古诗格调
   - 留人侧重：情感共鸣、夫妻/婆媳/励志话题，不急于推销
   - 转化时机：高在线时段（45-105分钟）主推利润品
   - 风格：少用强推销话术，突出独特个性与情绪价值
   ```

2. **local_flavor 自动注入**  
   - 若 `personaName` 含「李阳阳」「阳阳」且未配置 `local_flavor`，默认补充「东北」到 prompt。

3. **ai_host_persona 扩展**  
   - 为 yangyang 增加 `style_vector` 或标签：`["东北","幽默","歇后语","名言金句","接地气"]`，供 RAG 与 prompt 使用。

**文件**：`LivePromptBuilder.java`、`ai_host_persona` 数据、`DyPersona` 配置

---

### P1 — 拉自然流话术策略显式注入

**问题**：需求明确「微付费刺激自然流」「少投流、靠内容留人」，但 prompt 中无显式「拉自然流」约束，易生成强推销话术。

**建议**：

1. **chat_2h 专用 system 片段**  
   - 在 `buildPrompt` 的 chat_2h 分支中增加：
   ```
   【拉自然流约束】
   - 本场以内容留人为主，不急于卖货
   - 聊家常话术禁止强推销、禁止频繁上链接
   - 突出主播独特个性（幽默、歇后语、金句），拉停留拉互动
   - 利润品话术集中在高在线时段，此前以蓄水为主
   ```

2. **产品话术分段策略**  
   - 利润品：强调「人气高时主推」「高流量转化窗口」
   - 备用品：强调「快速过品」「补充款」

**文件**：`LivePromptBuilder.java`、`LiveScriptGenerationServiceImpl`

---

### P2 — 知识库素材与 RAG 效果

**问题**：chat 生成依赖 huashu 知识库的歇后语、名言、古诗、夫妻/婆媳/励志，若素材不足 RAG 效果差。

**现状**：升级计划 Phase 1 验收中「huashu 知识库有歇后语、名言、古诗…」为未勾选，依赖人工导入。

**建议**：

1. **素材导入清单**（按优先级）  
   - 歇后语俗语（TianAPI 或进化主题）  
   - 名言金句、古诗（TianAPI 或手动）  
   - 夫妻感情、婆媳关系、人生励志、幽默段子  

2. **ChunkLabeler 标签**  
   - 已支持 `type:古诗`、`type:家庭爱情`，确认歇后语、名言标签完整。

3. **RAG 检索增强**  
   - chat 时放宽 `script_type` 过滤（已有建议），确保 type 标签检索生效。

**文件**：huashu 知识库、`ChunkLabeler.java`、`LiveScriptGenerationServiceImpl.buildCategoryQueries`

---

### P3 — 高光话术结构系统化（功能-优势-利益-证据）

**问题**：`李阳阳-高光话术-参考考古家.md` 中种草话术采用「功能-优势-利益-证据」四段式，当前 prompt 未显式要求此结构。

**建议**：

1. **利润品 prompt 增强**  
   - 在 `getProductTypePromptHint` 或 product 分支中，对 profit 类型增加：
   ```
   话术结构建议：功能（是什么）→ 优势（为什么好）→ 利益（对用户的价值）→ 证据（自用/案例/数据）
   ```

2. **留人话术**  
   - 参考文档中的「明天取鼻子、婚礼」等个人事件留人，可在 prompt 中提示「可融入主播近期日程、活动信息增强真实感」。

**文件**：`LivePromptBuilder.java`、`getProductTypePromptHint`

---

### P4 — 人气策略/时段在生成时的真实注入

**问题**：`ensureScriptSlotsForChat2h` 已在 requirement 中写入时段（如「45-75分钟」「高流量转化窗口」），但需确认 `buildPrompt` 是否将时段信息注入到 LLM prompt。

**建议**：

1. **检查 buildPrompt**  
   - product 槽位生成时，从 `slot.requirement` 解析时段关键词，注入到 prompt，例如：
   ```
   当前时段：第 45-75 分钟（高流量转化窗口），人气蓄水后主推，可适当加强转化话术。
   ```

2. **buildTimeSlotDesc 集成**  
   - chat_2h 的 product 槽位按 sequenceNo 映射到 0-15/15-45/45-75/75-105/105-120，确保 `buildTimeSlotDesc` 被调用。

**文件**：`LivePromptBuilder.java`、`LiveScriptGenerationServiceImpl`

---

### P5 — 李阳阳人设数据配置（人工）

**问题**：`local_flavor=东北` 需在 `dy_persona` 中为李阳阳配置，当前依赖人工。

**建议**：

1. **人设管理页面**  
   - 确保「李阳阳」人设可配置 `local_flavor` 下拉（东北/四川/上海/广东等）。

2. **种子数据**  
   - 若有默认人设初始化，可为「李阳阳」预设 `local_flavor='东北'`。

**文件**：`DouyinPersonaPage`、人设表单、`sql/douyin/` 种子数据

---

### P6 — 单句/单段微调（独立迭代）

**问题**：`话术生成与微调升级计划.md` 中的单句/单段微调未实现，影响话术精细打磨。

**建议**：按 `话术生成与微调升级计划.md` 独立迭代，不阻塞 2 小时拉自然流主流程。

## 六、总结

**核心差距**：李阳阳人设从「精致生活达人」升级为「东北人、幽默、接地气、歇后语/名言/古诗」，并显式注入「拉自然流」话术策略（少推销、重留人、蓄水后再转化）。

**优先动作**：P0（人设策略对齐）+ P1（拉自然流约束）+ P2（知识库素材），约 4–5h 可完成主链路升级。
