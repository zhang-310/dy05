## 一、模块概述

### 1.1 模块定位

**直播实时辅助面板** 是为直播主播设计的实时互动工具，支持在直播过程中实时显示话术、倒计时、观众数据等信息，帮助主播高效管理直播节奏和内容。

### 1.2 核心价值

- 🎙️ **提词器**：大字显示当前话术，主播无需低头看手机
- ⏱️ **倒计时**：精确控制话术讲解时长
- 📊 **实时数据**：观众数、点赞、评论等实时刷新
- 🔄 **话术导航**：前后切换话术段落
- ⚡ **实时推送**：SSE 服务端推送，毫秒级延迟

### 1.3 业务场景

**场景 1：开场话术**
```
主播启动直播 → 打开实时面板 → 显示开场话术
     ↓
主播讲述开场（倒计时 2:00）
     ↓
时间到 → 自动推进到产品介绍话术
```

**场景 2：产品讲解**
```
显示产品话术（从话术库引用）
     ↓
实时显示观众数、点赞、评论数量
     ↓
主播可手动前后切换话术段落
```

## 二、数据模型

### 2.1 核心表：live_session_script_slot

记录直播场次中的话术段落。

```sql
CREATE TABLE live_session_script_slot (
  id BIGSERIAL PRIMARY KEY,
  live_session_id BIGINT NOT NULL,      -- 直播场次 ID
  slot_index INTEGER NOT NULL,           -- 段落序号（从 0 开始）
  script_version_id BIGINT,              -- 话术版本 ID（可关联 W-02 的话术）
  content TEXT NOT NULL,                 -- 话术内容
  duration_seconds INTEGER DEFAULT 120,  -- 建议讲解时长（秒）
  script_type VARCHAR(32),               -- 类型（开场/产品/优惠/结尾）
  style VARCHAR(64),                     -- 风格（激情/专业/温柔/幽默）
  is_current BOOLEAN DEFAULT false,      -- 是否当前段落
  is_completed BOOLEAN DEFAULT false,    -- 是否已讲解完成
  started_at TIMESTAMP,                  -- 开始讲解时间
  completed_at TIMESTAMP,                -- 完成讲解时间
  owner_id BIGINT NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  deleted INTEGER DEFAULT 0,

  INDEX idx_live_session_id (live_session_id),
  INDEX idx_slot_index (live_session_id, slot_index),
  INDEX idx_is_current (live_session_id, is_current)
);

-- 直播实时数据表
CREATE TABLE live_session_realtime_data (
  id BIGSERIAL PRIMARY KEY,
  live_session_id BIGINT NOT NULL,
  watched_count INTEGER DEFAULT 0,       -- 观看人数
  viewer_count INTEGER DEFAULT 0,        -- 在线人数
  like_count INTEGER DEFAULT 0,          -- 点赞数
  comment_count INTEGER DEFAULT 0,       -- 评论数
  share_count INTEGER DEFAULT 0,         -- 分享数
  follow_count INTEGER DEFAULT 0,        -- 关注数
  gift_amount DECIMAL(10,2) DEFAULT 0,   -- 礼物金额（元）
  product_click_count INTEGER DEFAULT 0, -- 产品点击数
  product_purchase_count INTEGER DEFAULT 0, -- 商品购买数
  product_purchase_amount DECIMAL(10,2) DEFAULT 0, -- 购买金额
  current_slot_index INTEGER,            -- 当前话术段落序号
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  deleted INTEGER DEFAULT 0,

  INDEX idx_live_session_id (live_session_id)
);
```

### 2.2 关系图

```
直播场次 (LiveSession)
    ↓
直播话术段落 (LiveSessionScriptSlot) × N
    ├─→ 话术版本 (ProductScriptVersion，W-02)
    ├─→ 讲解时长
    └─→ 当前/完成状态

直播实时数据 (LiveSessionRealtimeData)
    ├─→ 观众数、点赞、评论
    ├─→ 商品点击和购买
    └─→ 当前段落序号
```

@GetMapping("/stream/{sessionId}")
public SseEmitter streamRealtimeData(@PathVariable Long sessionId) {
    SseEmitter emitter = new SseEmitter(5 * 60 * 1000L); // 5 分钟超时

    realtimePanelService.subscribe(sessionId, emitter);

### 6.2 前端订阅处理

```typescript
const subscribeToStream = (sessionId: number) => {
  const eventSource = new EventSource(
    `/api/v1/live/realtime-panel/stream/${sessionId}`
  );

  eventSource.addEventListener('data-update', (event) => {
    const data = JSON.parse(event.data);
    setRealtimeData(data);
  });

  eventSource.addEventListener('slot-change', (event) => {
    const slot = JSON.parse(event.data);
    setCurrentSlot(slot);
    startCountdown(slot.durationSeconds);
  });

  return eventSource; // 便于清理
};
```

## 九、风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|------|--------|
| SSE 连接断开 | 数据推送中断 | 中 | 自动重连机制 |
| 内存泄漏 | 服务内存溢出 | 低 | 定期清理连接 |
| 倒计时不准 | 提词器显示错误 | 低 | 使用 Date.now() 校准 |
| 话术导航并发 | 状态不一致 | 低 | 使用乐观锁或分布式锁 |
