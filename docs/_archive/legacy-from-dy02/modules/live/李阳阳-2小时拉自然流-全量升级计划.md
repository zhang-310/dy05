## 一、升级目标

将李阳阳 2 小时拉自然流带货能力从「基础可用」升级为「人设对齐、策略显式、结构系统化」，实现：

1. **人设对齐**：李阳阳从「精致生活达人」升级为「东北人、幽默、接地气、歇后语/名言/古诗」
2. **拉自然流策略**：显式注入「少推销、重留人、蓄水后再转化」话术约束
3. **高光话术结构**：利润品采用「功能-优势-利益-证据」四段式
4. **时段注入**：product 槽位生成时注入高流量时段信息
5. **文档对齐**：同步更新 04-文档代码同步清单、相关模块文档

## 三、P0 任务详情

### P0-1 李阳阳拉自然流策略分支

**文件**：`src/main/java/.../module/live/service/LivePromptBuilder.java`

**改动**：

1. 在 `buildHostPersonaStrategy` 或调用处，增加条件判断：
   - 若 `sessionType == "chat_2h"` 且 `hostCode == "yangyang"`，返回拉自然流专用策略
2. 拉自然流策略内容：
```
【主播策略：李阳阳·2小时拉自然流】
- 路线：聊家常蓄水 + 人气高时卖利润品
- 话术特征：东北人、幽默接地气、歇后语、名言金句、古诗格调
- 留人侧重：情感共鸣、夫妻/婆媳/励志话题，不急于推销
- 转化时机：高在线时段（45-105分钟）主推利润品
- 风格：少用强推销话术，突出独特个性与情绪价值
```

**验收**：创建 chat_2h 场次、选择李阳阳人设、生成话术时，prompt 含上述策略。

---

### P0-2 local_flavor 默认东北

**文件**：`LivePromptBuilder.buildPersonaDesc`

**改动**：在 `buildPersonaDesc` 中，若 `personaName` 含「李阳阳」或「阳阳」，且 `persona.getLocalFlavor()` 为空，则默认使用「东北」注入到 prompt。

**验收**：李阳阳人设未配置 local_flavor 时，生成话术仍带东北风格提示。

---

### P0-3 ai_host_persona yangyang 增加标签

**文件**：
- `src/main/resources/db/migration/V053__ai_host_persona_yangyang_tags.sql`（若需新字段）
- 或直接更新 `V010__ai_host_persona_data.sql` 的 yangyang 记录（若为 seed 可重复执行）

**改动**：为 yangyang 的 `style_vector` 或 `tags` 增加：东北、幽默、歇后语、名言金句、接地气。若无 tags 字段，可在 `description` 或 `strategy_json` 中体现。

**验收**：ai_host_persona 表中 yangyang 记录含东北/幽默相关描述。

## 四、P1 任务详情

### P1-1 chat_2h 拉自然流约束

**文件**：`LivePromptBuilder.buildPrompt`、`LiveScriptGenerationServiceImpl`

**改动**：在 `buildPrompt` 的 chat_2h 场次分支中，增加 system 或 user 片段：

```
【拉自然流约束】
- 本场以内容留人为主，不急于卖货
- 聊家常话术禁止强推销、禁止频繁上链接
- 突出主播独特个性（幽默、歇后语、金句），拉停留拉互动
- 利润品话术集中在高在线时段，此前以蓄水为主
```

**验收**：chat 槽位生成的话术不含强推销、上链接等。

---

### P1-2 利润品功能-优势-利益-证据结构

**文件**：`LivePromptBuilder.getProductTypePromptHint`

**改动**：对 `profit` 类型增加：
```
话术结构建议：功能（是什么）→ 优势（为什么好）→ 利益（对用户的价值）→ 证据（自用/案例/数据）
```

**验收**：利润品生成时 prompt 含四段式结构提示。

---

## 五、P2 任务详情

### P2-1 时段信息注入 product prompt

**文件**：`LivePromptBuilder`、`LiveScriptGenerationServiceImpl`

**改动**：
1. product 槽位生成时，从 `slot.getRequirement()` 解析时段关键词（如「45-75分钟」「高流量转化窗口」）
2. 注入到 prompt：`当前时段：第 X-Y 分钟（高流量转化窗口），人气蓄水后主推，可适当加强转化话术。`
3. 若 requirement 无时段，按 sequenceNo 映射 chat_2h 槽位到 0-15/15-45/45-75/75-105/105-120

**验收**：product 槽位生成时 prompt 含具体时段描述。

---

### P2-2 知识库素材导入清单

**文件**：`docs/modules/live/李阳阳-2小时拉自然流-知识库素材清单.md`（新建）

**内容**：
- 歇后语俗语：TianAPI 或进化主题「歇后语俗语话术」
- 名言金句、古诗：TianAPI 或手动整理
- 夫妻感情、婆媳关系、人生励志、幽默段子：手动或进化产出
- 导入目标：huashu 知识库
- 标签：type:歇后语、type:名言、type:古诗、type:家庭爱情、type:励志、type:幽默

**验收**：清单文档可执行，导入后 RAG 可检索到相关素材。
