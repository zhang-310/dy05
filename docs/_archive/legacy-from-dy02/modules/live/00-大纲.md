## 模块定位

live 模块是平台的核心业务模块，围绕直播全流程管理，目标是成为**AI 驱动的直播运营助手**：

1. **场次管理** — 直播场次创建、选品排序、状态机管理、开播准备清单
2. **AI 话术系统** — 开场/产品/转场/结尾话术 AI 生成、违规检测、话术效果归因
3. **数据同步与分析** — 抖音直播数据同步、实时监控（LiveMonitor 时序数据）、汇总数据
4. **AI 复盘与归因** — 直播结束后自动复盘、话术效果归因、改进建议、高效话术入库

产品数据来自 douyin 模块，AI 能力来自 ai 模块，违规检测来自 script 模块。

## 模块依赖

```
auth ← douyin（账号/人设/产品）← live
ai（AI 生成话术/分析/复盘）← live
script（违规检测/话术库）← live
```

---

## 与 AI 模块的协同

| AI 模块能力 | live 模块配合 |
|------------|-------------|
| AI 话术生成（05-直播分析与话术） | live_session_script 存储生成结果，关联 ai_call_log_id |
| 直播实时分析（05-直播分析与话术） | live_monitor 提供时序数据，WebSocket 推送到前端 |
| 直播复盘 Agent（12-升级路线图） | live_session_data 提供汇总数据，live_session_script + live_monitor 提供归因数据 |
| 效果归因链（12-升级路线图） | live_session_script.ai_call_log_id 关联 AI 调用，effectiveness_score 反馈话术质量 |
| 话术模板库（05-直播分析与话术） | 高效话术（effectiveness_score > 80）自动入库 live_script_template |

## 数据规模预估

| 数据 | 预估量 | 增长速度 | 存储策略 |
|------|--------|---------|---------|
| live_session | 每账号 ~100 场/年 | 每月 ~8 场/账号 | 热数据 |
| live_session_product | 每场 ~5-20 个产品 | 跟随场次 | 热数据 |
| live_session_script | 每场 ~10-30 条话术 | 跟随场次 | 热数据 |
| live_session_data | 每场 1 条汇总 | 跟随场次 | 热数据 |
| live_product_data | 每场 ~5-20 条 | 跟随场次 | 热数据 |
| live_monitor | 每场 ~720 条（1h/5s） | 高频写入 | 超过 90 天归档 |
| live_script_template | 每账号 ~50-200 条 | 高效话术入库 | 热数据 |

## 非功能需求

| 维度 | 要求 |
|------|------|
| 性能 | 场次列表 < 500ms；话术生成 < 30s；LiveMonitor 推送延迟 < 2s |
| 安全 | owner_id 强制过滤；DataScope 机构隔离；敏感数据脱敏 |
| 可用性 | AI 服务降级时支持手动编辑；数据同步失败自动重试 3 次 |
