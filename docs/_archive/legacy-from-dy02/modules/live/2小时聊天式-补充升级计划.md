## 三、P0 任务

### 3.1 chat_2h 槽位首次创建触发

**问题**：`useLiveScriptBuilder.loadData` 仅在 `products.length > 0 && scripts.length === 0` 时调用 `initScriptSlots`，chat_2h 不依赖 products，导致新建 chat_2h 场次进入工作台后为空。

**文件**：`frontend-react/src/pages/live/hooks/useLiveScriptBuilder.ts`

**修改**：在 `loadData` 中扩展初始化条件

```ts
// 原逻辑：有产品无话术时初始化
// 补充：chat_2h 场次无话术时也初始化（不依赖产品）
if (Array.isArray(sc) && sc.length === 0) {
  const needInit = (Array.isArray(p) && p.length > 0) || (s?.sessionType === 'chat_2h')
  if (needInit) {
    await initScriptSlots(sid)
    // ... 后续 reload scripts
  }
}
```

**验收**：创建 chat_2h 场次 → 进入工作台 → 自动出现 14 个槽位（无需先添加产品或一键生成）

---

### 3.2 数据迁移执行

**问题**：V043 脚本已存在，Flyway 默认关闭，需确保迁移已执行。

**操作**：

1. **开发环境**：启动时启用 Flyway
   ```powershell
   $env:FLYWAY_ENABLED="true"; mvn spring-boot:run
   ```

2. **或手动执行 SQL**：
   ```sql
   ALTER TABLE live_session ADD COLUMN IF NOT EXISTS session_type VARCHAR(32) DEFAULT 'standard';
   ```

3. **验证**：启动无 `Schema-validation: missing column [session_type]` 错误

**文档**：在 `docs/deployment/` 或部署说明中补充「首次部署需执行 V043 或启用 Flyway」

### 4.2 chat_2h 产品绑定提示

**场景**：5 个 product 槽位初始 `productId=null`，一键生成时会被跳过。用户需在排品面板绑定商品。

**文件**：
- `frontend-react/src/pages/live/components/ScriptSection.tsx` 或 `ScriptFlowPanel.tsx`：product 槽位且 `productId` 为空时显示「待绑定商品」提示
- `frontend-react/src/pages/live/components/GenerationFlowPanel.tsx` 或 `GenerateTabContent.tsx`：一键生成前若为 chat_2h 且 product 槽位未绑定，显示「建议先绑定 5 个商品（前 3 利润品、后 2 备用品）」

**修改**：
1. 在 product 槽位卡片（无 productId 时）显示「待绑定商品」Chip
2. 在生成面板顶部增加 chat_2h 说明文案（可选 Alert）

**验收**：chat_2h 场次中，未绑定商品的 product 槽位有明确提示；生成前有引导说明

## 六、P3 任务

### 6.1 人气策略/时段绑定

**需求**：将 3 个利润品安排在 45–75、75–105 分钟等高流量时段。

**现状**：`ensureScriptSlotsForChat2h` 为固定顺序，未与 `timeSlot` 绑定。

**方案**：
1. 在 chat_2h 槽位的 `requirement` 或 `extraPrompt` 中注入时段信息（如「第 45–75 分钟」「第 75–105 分钟」）
2. 或在 `LivePromptBuilder.buildPrompt` 中，chat_2h 场次按 slot 索引计算 `timeSlot` 并注入

**文件**：
- `LiveScriptServiceImpl.ensureScriptSlotsForChat2h`：为 product 槽位设置 `requirement` 包含时段
- `LivePromptBuilder`：chat_2h 时读取 `timeSlot` 并注入 prompt

**验收**：生成话术时，利润品槽位 prompt 含「高流量时段」或具体分钟信息

---
