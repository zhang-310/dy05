## 二、ChunkLabeler 标签

已支持标签（无需新增）：
- `type:古诗` — 古诗、诗词、唐诗、宋词
- `type:家庭爱情` — 夫妻、婆媳、婚姻
- `type:歇后语` — 歇后语、俗语
- `type:搞笑幽默` — 幽默、段子
- `type:正能量` — 励志、鸡汤

## 三、导入方式

1. **ContentMaterial → huashu 一键导入**：`POST /api/v1/ai/knowledge-base/huashu/import-content-material`（需登录）  
   - 将内置夫妻/婆媳/励志/名言等素材导入 huashu，自动打 type 标签
2. **TianAPI 定时入库**：配置 `tianapi.material-import-enabled=true` 后，定时任务会采集歇后语、名言、古诗、笑话等入库 copy_library + huashu
3. **进化主题**：`ai_evolve_topic` 已有「歇后语俗语话术」「名言金句话术」「古诗词话术」等，进化产出后导入 huashu
4. **手动导入**：知识库管理页面，上传或粘贴内容，ChunkLabeler 自动打 type 标签
