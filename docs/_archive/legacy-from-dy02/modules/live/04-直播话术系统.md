# 直播模块 — 直播话术系统

> 版本：3.0 | 更新日期：2026-02-26 | 与 00-大纲 对齐

---

## 4.1 话术系统总览

直播话术系统是 live 模块的核心 AI 能力，覆盖话术生成全流程：

```
直播前准备
    ↓
[输入信息收集]
    ├─ 人设信息（dy_persona：定位/风格/标签）
    ├─ 产品信息（dy_product：名称/价格/卖点/目标客户）
    ├─ 场次信息（主题/时间/风格偏好）
    └─ 已有产品话术（dy_product_script，可选引用）
    ↓
[AI 话术生成引擎]
    ├─ 开场话术（吸引注意、建立信任、引入产品）
    ├─ 产品话术（产品特点、使用场景、价格话术、促销话术）
    ├─ 转场话术（产品间自然过渡）
    └─ 结尾话术（感谢、预告、粉丝福利）
    ↓
[违规检测]
    ├─ 调用 script 模块（scope=live）
    ├─ 匹配 all + live_only 范围违规词
    ├─ 标红违规词 + 提供替换建议
    └─ 更新 violation_checked + violation_result
    ↓
[话术编辑与确认]
    ├─ 主播可自由编辑 AI 生成的话术
    ├─ 编辑后需重新违规检测
    └─ 确认后进入直播执行阶段
    ↓
[直播执行追踪]
    ├─ 标记话术已执行（executed=true）
    ├─ 记录实际执行时间点（actual_execution_time）
    └─ 用于直播后效果归因
    ↓
[效果归因]
    ├─ 关联 actual_execution_time 和 live_monitor 时序数据
    ├─ 计算执行后 30s 内观众/互动变化
    ├─ 生成 effectiveness_score
    └─ 高效话术自动入库 live_script_template
```

## 4.2 话术类型与生成策略

### 4.2.1 开场话术（opening）

**目标：** 3-5 秒内抓住观众注意力，建立信任，引出今天的主题和福利

**AI 生成输入：**
```json
{
  "templateCode": "live_script_opening",
  "variables": {
    "personaName": "美妆达人小美",
    "personaStyle": "亲切种草型",
    "sessionTitle": "春季新品首发",
    "productCount": 5,
    "mainBenefit": "全场 5 折起",
    "targetAudience": "18-35岁女性"
  }
}
```

**Prompt 模板：**
```
你是一位{personaStyle}的抖音直播主播{personaName}。
今天的直播主题是「{sessionTitle}」，共有{productCount}个产品。
主要福利：{mainBenefit}。目标观众：{targetAudience}。

请生成一段开场话术（100-200字），要求：
1. 前3秒有吸引力的开场白
2. 自我介绍（符合人设风格）
3. 今天直播的亮点预告
4. 引导关注和互动
5. 语气自然，像真人说话
```

---

### 4.2.2 产品话术（product）

**目标：** 清晰展示产品卖点，解决用户痛点，推动下单

**AI 生成输入：**
```json
{
  "templateCode": "live_script_product",
  "variables": {
    "personaStyle": "亲切种草型",
    "productName": "XX 精华液",
    "price": 199,
    "originalPrice": 399,
    "sellingPoints": ["玻尿酸成分", "48小时保湿", "敏感肌可用"],
    "targetAudience": "干性/敏感肌女性",
    "competitorComparison": "同类产品均价300+",
    "userReviews": "回购率85%"
  }
}
```

**Prompt 模板：**
```
你是{personaStyle}的主播，正在直播间介绍产品「{productName}」。

产品信息：
- 价格：直播价{price}元（原价{originalPrice}元）
- 核心卖点：{sellingPoints}
- 目标用户：{targetAudience}
- 竞品对比：{competitorComparison}
- 用户口碑：{userReviews}

请生成产品介绍话术（200-400字），包含：
1. 产品引入（痛点切入）
2. 核心卖点讲解（每个卖点展开说明）
3. 使用场景描述
4. 价格话术（价值感塑造 + 优惠力度）
5. 转化话术（CTA + 紧迫感）
6. 语气自然，有感染力
```

---

### 4.2.3 转场话术（transition）

**目标：** 自然过渡到下一个产品，保持观众注意力

**AI 生成输入：**
```json
{
  "templateCode": "live_script_transition",
  "variables": {
    "fromProductName": "XX 精华液",
    "toProductName": "YY 面霜",
    "transitionHook": "搭配使用效果翻倍"
  }
}
```

---

### 4.2.4 结尾话术（closing）

**目标：** 感谢观众，预告下场，引导关注

**AI 生成输入：**
```json
{
  "templateCode": "live_script_closing",
  "variables": {
    "personaName": "美妆达人小美",
    "totalProducts": 5,
    "nextLivePreview": "明天晚上8点，夏季防晒专场",
    "specialOffer": "关注后私信领取优惠券"
  }
}
```

## 4.3 整场话术流程编排

### 4.3.1 流程结构

```
开场话术（sequence_no=1）
    ↓
产品1话术（sequence_no=2）
    ↓
转场话术 1→2（sequence_no=3）
    ↓
产品2话术（sequence_no=4）
    ↓
转场话术 2→3（sequence_no=5）
    ↓
产品3话术（sequence_no=6）
    ↓
...
    ↓
结尾话术（sequence_no=N）
```

### 4.3.2 一键生成流程（generate-full）

```
1. 读取场次信息 + 人设 + 产品列表（按 position 排序）
2. 生成开场话术 → 记录 ai_call_log_id → 违规检测
3. FOR EACH product IN products:
   a. 生成产品话术 → 记录 ai_call_log_id → 违规检测
   b. IF NOT last product:
      生成转场话术（from=当前产品, to=下一产品）→ 违规检测
4. 生成结尾话术 → 记录 ai_call_log_id → 违规检测
5. 设置所有话术的 sequence_no（连续编号）
6. 返回完整话术列表
```

### 4.3.3 失败处理策略（BR-11）

```
单个产品话术生成失败：
    ├─ 不回滚已成功的话术
    ├─ 标记该话术 generation_status=failed
    ├─ 继续生成后续产品的话术
    ├─ 转场话术跳过失败的产品
    └─ 返回结果中标注失败项，允许用户手动重试
```

## 4.4 违规检测集成

### 4.4.1 检测流程

```
话术内容
    ↓
调用 script 模块 ScriptViolationService.check(content, scope="live")
    ↓
匹配规则：
    ├─ scope=all 的违规词（全局违规词）
    └─ scope=live_only 的违规词（直播专用违规词）
    ↓
返回结果：
    ├─ hasViolation: boolean
    ├─ violations: [{ word, level, suggestion, position }]
    │   ├─ level=danger：必须修改（如虚假宣传、绝对化用语）
    │   └─ level=warning：建议修改（如敏感词）
    └─ cleanContent: 自动替换后的内容（可选）
```

### 4.4.2 预计时长估算

- **单条话术：** `execution_time = ceil(字数 ÷ 3)` 秒（按中文约 3 字/秒语速）
- **整场话术：** 所有话术 execution_time 之和，前端展示为「整场预计时长：X 分钟」

### 4.4.3 直播常见违规词示例

| 类别 | 违规词 | 级别 | 替换建议 |
|------|--------|------|---------|
| 绝对化用语 | 最好的、第一、绝对 | danger | 非常好的、领先的、效果显著 |
| 虚假宣传 | 100%有效、永不过敏 | danger | 效果显著、温和不刺激 |
| 医疗暗示 | 治疗、治愈、药效 | danger | 改善、缓解、护理 |
| 价格欺诈 | 全网最低、亏本卖 | warning | 超值优惠、限时特价 |
| 诱导消费 | 不买后悔、错过就没了 | warning | 限量供应、活动限时 |

### 4.4.4 话术模板变量占位符规范

- 使用 `{变量名}` 格式，如 `{personaName}`、`{productName}`
- 变量名驼峰，与 AI 模块 templateCode 的 variables 一致
- 入库 live_script_template 时保留占位符，variables 字段存 JSON 数组列出可用变量

## 4.5 话术效果归因

### 4.5.1 归因原理

```
话术执行时间点（actual_execution_time）
    ↓
从 live_monitor 中取该时间点前后 30s 的数据
    ↓
计算变化量：
    ├─ viewer_delta = viewers(T+30s) - viewers(T)
    ├─ interaction_delta = (likes+comments+shares)(T+30s) - (likes+comments+shares)(T)
    └─ 如果 viewer_delta > 0 且 interaction_delta > 0 → 正面效果
    ↓
计算 effectiveness_score：
    ├─ 基础分 = 50
    ├─ 观众增长加分：viewer_delta > 10 → +20, > 50 → +30
    ├─ 互动增长加分：interaction_delta > 5 → +10, > 20 → +20
    ├─ 观众流失扣分：viewer_delta < -10 → -15, < -50 → -30
    └─ 最终分数 = clamp(0, 100)
```

### 4.5.2 回写 AI 效果归因链

话术效果评分计算完成后，**必须回写到 ai_call_log**，闭合 AI 效果归因链：

```
effectiveness_score 计算完成
    ↓
遍历所有已执行且有 ai_call_log_id 的话术
    ↓
调用 AI 模块效果回填接口：
    POST /api/v1/ai/call-log/link
    {
      "callLogId": live_session_script.ai_call_log_id,
      "sourceModule": "live",
      "sourceEntityId": live_session_script.id,
      "contentEffect": effectiveness_score > 70 ? "positive" : effectiveness_score > 40 ? "neutral" : "negative",
      "effectScore": effectiveness_score
    }
    ↓
AI 模块更新 ai_call_log 记录：
    ├─ source_module = "live"
    ├─ source_entity_id = live_session_script.id
    ├─ content_effect = "positive" / "neutral" / "negative"
    └─ effect_score = effectiveness_score
```

**归因链完整闭环：**
```
AI 生成话术 → ai_call_log（记录生成）
    ↓
live_session_script.ai_call_log_id（关联）
    ↓
直播执行 → live_monitor（时序数据）
    ↓
效果归因 → effectiveness_score（计算）
    ↓
回写 ai_call_log（闭环）→ AI 知识权重调整
```

### 4.5.3 归因时机

- 直播结束后自动触发（BR-18）
- 需要 live_monitor 有足够的时序数据（至少覆盖话术执行时间段）
- 归因完成后立即执行 4.5.2 的 ai_call_log 回写

### 4.5.4 高效话术入库

```
effectiveness_score > 80 的话术：
    ↓
自动入库到 live_script_template（ai 模块 05 中已设计）：
    ├─ template_name = "{场次主题} - {话术类型}"
    ├─ script_type = 话术类型
    ├─ category = 人设行业
    ├─ content = 话术内容（变量化处理）
    ├─ effectiveness_score = 效果评分
    └─ usage_count = 0（初始）
```

## 4.7 与 AI 模块的对接

### 4.7.1 调用方式

所有话术生成通过 ai 模块的统一生成接口：

```
POST /api/v1/ai/generate
{
  "templateCode": "live_script_opening",  // 模板代码
  "variables": { ... },                   // 变量
  "options": {
    "model": "deepseek",                  // 使用商业模型
    "maxTokens": 1000,
    "temperature": 0.8                    // 话术需要创造性
  }
}
```

### 4.7.2 Prompt 模板清单

| 模板代码 | 说明 | 输入变量 |
|---------|------|---------|
| live_script_opening | 开场话术 | personaName, personaStyle, sessionTitle, productCount, mainBenefit |
| live_script_product | 产品话术 | personaStyle, productName, price, sellingPoints, targetAudience |
| live_script_transition | 转场话术 | fromProductName, toProductName, transitionHook |
| live_script_closing | 结尾话术 | personaName, totalProducts, nextLivePreview, specialOffer |
| live_script_full | 整场话术（备用） | 所有变量 |
| live_analysis | 直播分析 | sessionData, productData, scriptData, monitorData |

### 4.7.3 AI 调用日志关联

每次话术生成都会在 ai_call_log 中创建记录，live_session_script.ai_call_log_id 关联该记录。

用于：
1. 追踪话术生成质量
2. 效果归因链（ai 模块 12-升级路线图）
3. 成本统计
