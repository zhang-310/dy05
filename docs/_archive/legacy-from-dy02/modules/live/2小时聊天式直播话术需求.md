# 2 小时聊天式直播话术需求

> 版本：1.0 | 创建日期：2026-03-17

---

## 一、需求概述

构建**2 小时全场直播话术**，以「聊家常 + 人气高时卖利润品」为核心模式，全场有独特主播风格（如李阳阳东北人），利用知识库注入幽默、歇后语、名言金句、古诗等高知识层面内容，话题涵盖夫妻感情、人生励志、婆媳关系等。

### 1.1 运营思路

| 环节 | 策略 | 话术侧重点 |
|------|------|------------|
| **流量** | 微付费刺激自然流 | 少投流，靠内容与互动撬动自然推荐 |
| **留人** | 话术风格独特个性 | 人设鲜明、幽默/歇后语/名言/古诗，拉停留、拉互动 |
| **蓄水** | 拉高在线人数 | 聊家常、情感共鸣、不急于卖货，先把人气做起来 |
| **转化** | 然后再卖产品 | 人气上来后再推利润品，转化窗口集中在高在线时段 |

**核心逻辑**：先内容留人、拉高在线 → 再卖货变现。话术需突出**独特个性**与**情绪价值**，而非一上来就强推销。

### 1.3 核心参数

| 维度 | 要求 | 说明 |
|------|------|------|
| **时长** | 约 2 小时 | 与现有 timeSlot 0-15/15-45/45-75/75-105/105-120 对齐 |
| **产品结构** | 3 利润品 + 2 备用品 | 常规场次标配 |
| **主基调** | 聊家常、聊天式 | 非强推销，以内容留人 |
| **卖货时机** | 人气高时卖利润品 | 转化集中在高流量时段 |
| **风格** | 主播独特人设 | 如李阳阳东北人、幽默、接地气 |

### 1.4 内容要素（知识库驱动）

| 要素 | 说明 | 现有支持 |
|------|------|----------|
| **幽默** | 段子、梗、轻松调侃 | `humor`、`proverb` 风格 |
| **歇后语** | 接地气、民间智慧 | `proverb`、TianAPI 歇后语、主题池 |
| **名言金句** | 励志、人生哲理、女性力量 | `quote`、TianAPI 名言警句 |
| **古诗** | 高知识层面、格调 | TianAPI 古诗词、需扩展 |
| **夫妻感情** | 婚姻、恋爱观 | `love`、`female_perspective` |
| **人生励志** | 成长、逆袭、希望 | `positive_energy`、`growth_comeback` |
| **婆媳关系** | 家庭话题 | `female_perspective` 子类 |

## 二、与现有系统对照

### 2.1 已具备能力

| 能力 | 位置 | 说明 |
|------|------|------|
| 产品类型 | `live_product.product_type` | `profit` 利润品、`flat` 平价品、`hot` 爆品、`loss` 亏品、`control` 控单 |
| 2 小时时段 | `LivePromptBuilder.buildTimeSlotDesc` | 0-15/15-45/45-75/75-105/105-120 分钟 |
| 人设地方特色 | `DyPersona.local_flavor` | 东北/四川/上海/广东等 |
| 李阳阳策略 | `LivePromptBuilder.buildHostPersonaStrategy("yangyang")` | 精致生活达人 |
| 情绪话术生成 | `LiveAiService.generateEmotional` | 名言/歇后语/鸡汤/婆媳等 |
| RAG 知识库 | `huashu` + `hybridSearch` | 话术案例检索注入 |
| 话术风格 | `LiveStylePreset`、`expandSingleStyleFallback` | proverb/quote/family/love 等 |

### 2.2 需扩展/新增

| 能力 | 说明 |
|------|------|
| **备用品** | 新增 `backup` 产品类型，或复用 `flat` 并加标签 |
| **chat 槽位** | 新增「聊家常」类槽位，穿插在产品之间 |
| **2 小时全场模板** | 固定结构：开场 → 聊家常×N → 利润品×3（人气高时）→ 备用品×2 → 收尾 |
| **古诗素材** | 扩展 `materialType` 或情绪话术 `category` |
| **李阳阳东北人** | 在 `AiHostPersona` 或 `DyPersona` 中明确 `local_flavor=东北` |

## 三、推荐实现方案

### 3.1 产品类型扩展

**方案 A（推荐）**：新增 `backup` 类型

```sql
-- live_product.product_type 已支持逗号分隔，新增 backup
-- 备用品：备用款/备用库存，过品节奏类似平价品，约 15 秒
```

- `profit`：利润品，人气高时主推，30-60 秒
- `backup`：备用品，标准过品约 15 秒，可作补充

**方案 B**：不新增类型，用 `flat` + 备注「备用品」，由排品顺序区分。

### 3.2 槽位结构：2 小时全场模板

建议新增「2 小时聊天式」场次模板，槽位结构如下：

```
开场（opening）约 2-3 分钟
├── 聊家常 1（chat/emotional）约 8-10 分钟 — 夫妻感情/人生励志
├── 利润品 1（product, profit）— 人气高时主推
├── 转场 1（transition）
├── 聊家常 2（chat/emotional）约 8-10 分钟 — 婆媳关系/幽默段子
├── 利润品 2（product, profit）
├── 转场 2（transition）
├── 聊家常 3（chat/emotional）约 8-10 分钟 — 歇后语/名言金句
├── 利润品 3（product, profit）
├── 转场 3（transition）
├── 备用品 1（product, backup）— 快速过品
├── 转场 4（transition）
├── 备用品 2（product, backup）
└── 收尾（closing）约 2-3 分钟
```

**人气策略**：将 3 个利润品安排在 45-75、75-105 分钟（高流量转化窗口），聊家常分布在 0-45、105-120 分钟拉停留。

### 3.3 聊家常槽位（chat 类型）

**新增话术类型**：`chat` 或复用 `emotional` 的扩展。

- **用途**：生成「聊家常」内容，不绑定产品
- **RAG 检索词**：夫妻感情、婆媳关系、人生励志、歇后语、名言金句、古诗、幽默段子
- **风格组合**：`proverb,quote,family,love,humor` + 人设 `local_flavor=东北`
- **时长**：每段 8-10 分钟（约 240-300 字/段，可拆成多段输出）

**实现路径**：

1. 在 `live_script` 中支持 `script_type='chat'`，不关联 `product_id`
2. 在 `LivePromptBuilder` 中新增 `case "chat"`，调用情绪话术逻辑 + 知识库检索
3. 在 `ensureScriptSlotsForSession` 中，当选择「2 小时聊天式」模板时，按上述结构创建槽位

### 3.4 知识库素材准备

在 **huashu** 知识库中确保有以下分类的文档/分块：

| 分类 | 建议导入来源 | 标签/元数据 |
|------|--------------|-------------|
| 歇后语俗语 | TianAPI 歇后语、进化主题「歇后语俗语话术」 | `type:歇后语` |
| 名言金句 | TianAPI 名言警句、名人名言 | `type:名言` |
| 古诗 | TianAPI 古诗词、手动整理 | `type:古诗` |
| 夫妻感情 | 手动整理、进化产出 | `type:夫妻` |
| 婆媳关系 | 女性视角话题、手动整理 | `type:婆媳` |
| 人生励志 | 鸡汤、成长逆袭、正能量 | `type:励志` |
| 幽默段子 | 搞笑、自黑、调侃 | `type:幽默` |

**ChunkLabeler** 已支持 `歇后语`、`俗语` 等标签，可扩展 `古诗`、`夫妻`、`婆媳`。

### 3.5 李阳阳东北人风格

1. **人设配置**：在 `dy_persona` 中为李阳阳设置 `local_flavor='东北'`
2. **主播策略**：在 `ai_host_persona` 中为 `yangyang` 增加 `style_vector`：东北、幽默、歇后语、名言金句
3. **Prompt 注入**：`buildPersonaDesc` 已支持 `local_flavor`，会输出「地方特色：东北，可适当融入方言或地域梗」

### 3.6 RAG 检索增强

在 `buildCategoryQueries` 中，当 `scriptType=chat` 时，扩展检索词：

```java
// 伪代码
if ("chat".equals(scriptType)) {
    queries.add("夫妻感情 婚姻 恋爱 话术");
    queries.add("婆媳关系 家庭 女性 话术");
    queries.add("人生励志 成长 逆袭 金句");
    queries.add("歇后语 俗语 幽默 接地气");
    queries.add("名言金句 古诗 格调");
}
```
