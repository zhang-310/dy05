## 三、缺口与补充建议

### 3.1 留人话术：个人事件注入（P4 建议）

**现状**：考古家高光话术中的留人话术示例：
> 「明天我休息一天，去郑州取鼻子…后天不一定播…明年4月27号我和老公举办婚礼，会直播记录…」

**缺口**：当前 prompt 未显式要求「可融入主播近期日程、活动信息增强真实感」，生成话术易缺「个人事件留人」这一高转化技巧。

**补充建议**：
- 在 chat_2h 的 **chat** 槽位 prompt 中增加可选提示：
  ```
  【留人技巧】可融入主播近期日程、活动信息（如「明天去XX」「下周有XX活动」）增强真实感与期待感，拉停留。
  ```
- 或在人设/场次中增加「近期日程」字段，由用户填写后注入 prompt。

**优先级**：P4（低，可后续迭代）

---

### 3.2 开场 / 收尾的拉自然流风格（P4 建议）

**现状**：`chat2hConstraint` 仅注入到 **chat** 和 **product** 槽位，**opening**、**closing**、**transition** 未注入。

**缺口**：开场若过于「促销向」会与拉自然流基调冲突；收尾若过于「强推销」也会削弱整场体验。

**补充建议**：
- 对 chat_2h 场次的 **opening** 增加轻量约束：`本场以聊家常蓄水为主，开场可预告福利但不过度推销。`
- 对 **closing** 增加：`收尾以感谢、预告为主，不强推最后一单。`
- 对 **transition**（chat→product）：`自然衔接，不突兀上链接。`

**优先级**：P4（低）

---

### 3.3 进化主题池：歇后语/名言/古诗（P3 建议）

**现状**：知识库素材清单建议从「进化主题」产出歇后语、名言、古诗，但 `EvolveDataInitializer` 或 `ai_evolve_topic` 中是否已有对应主题未确认。

**补充建议**：
- 在进化主题池中增加：
  - 「歇后语俗语话术」
  - 「名言金句 女性力量 人生哲理」
  - 「古诗词 唐诗宋词 格调话术」
- 通过进化产出后导入 huashu，形成可持续素材供给。

**优先级**：P3（中，依赖进化模块）

---

### 3.4 情绪曲线与 chat_2h（P3 可选）

**现状**：`EmotionCurveEngine` 已存在，主要用于直播/短视频情绪节奏设计。chat_2h 的 2 小时全场是否有情绪曲线设计未明确。

**缺口**：2 小时拉自然流有明确节奏：0–45 蓄水、45–105 转化、105–120 收尾。若将情绪曲线与时段绑定，可进一步优化话术节奏感。

**补充建议**：
- 为 chat_2h 预设情绪曲线模板：如「蓄水型」（前低后高）、「转化窗口型」（45–75 情绪峰值）
- 在 `injectRetentionNode` 或 product 生成时，按 slotIndex 映射到情绪曲线节点，注入「本段情绪目标：XX」

**优先级**：P3（可选，与 Phase 2 情绪引擎衔接）

---

### 3.5 RAG 检索：type 标签与 ChunkLabeler 对齐（P2 建议）

**现状**：`buildCategoryQueries` 用「歇后语 俗语 幽默 接地气」「名言金句 古诗 格调」等检索词；ChunkLabeler 支持 `type:歇后语`、`type:古诗`、`type:家庭爱情` 等。

**缺口**：若 huashu 中文档的 metadata/标签与检索词不完全匹配，RAG 效果可能打折扣。需确认：
- 导入时是否正确打上 `type:歇后语`、`type:名言`、`type:古诗` 等标签
- ES/Milvus 过滤是否因 `script_type` 放宽而正确命中 type 标签

**补充建议**：
- 在知识库素材清单中明确：导入时 metadata 需包含 `type` 字段
- 若有「从内容导入」功能，确保 ChunkLabeler 对歇后语、名言、古诗等能正确打标

**优先级**：P2（中，影响 RAG 效果）

---

### 3.6 转化话术：限单/价格/福利结构（P2 建议）

**现状**：利润品已有「功能-优势-利益-证据」四段式；考古家转化话术示例：
> 「今天只有五十单，39.9块…」「今天有活动，买胶原蛋白多送一盒…」「就20单！」

**缺口**：转化话术的「限单、价格锚定、福利叠加、倒计时」等要素，当前主要靠「制造稀缺/紧迫感」笼统描述，未拆分为结构化提示。

**补充建议**：
- 在 profit 类型的 `buildDurationHintForProductType` 或 `getProductTypePromptHint` 中增加：
  ```
  转化话术要素：限单数量、价格对比（正价vs活动价）、福利叠加、倒计时/活动截止日、行动号召（3/2/1上链接）
  ```
- 与「功能-优势-利益-证据」并列，作为利润品的第二层结构提示。

**优先级**：P2（中）

---

### 3.7 单句/单段微调（独立迭代）

**现状**：`话术生成与微调升级计划.md` 中单句/单段微调未实现。

**影响**：李阳阳拉自然流话术生成后，若某句过于「推销向」或某段不够「东北味」，用户只能整段重写，无法精准微调。

**建议**：按原计划独立迭代，不阻塞拉自然流主流程，但可作为后续体验提升项。

---

### 3.8 质量评估与 A/B 测试（P3 可选）

**现状**：`ScriptQualityEvaluator` 存在；`ScriptStyleAbService` 支持 A/B 风格分配。

**缺口**：
- chat 话术的评估维度（是否含歇后语、是否强推销、东北味浓度）是否在 ScriptQualityEvaluator 中体现？
- 李阳阳「拉自然流策略」vs「精致生活达人」的效果对比，是否有 A/B 实验设计？

**补充建议**：
- 为 chat 话术增加评估维度：`no_promotion`（无推销）、`has_local_flavor`（有地方特色）、`has_proverb_quote`（有歇后语/金句）
- 若有 A/B 能力，可设计实验：同一场次、同一槽位，一组用拉自然流策略、一组用原策略，对比停留率/转化率（需埋点支持）

**优先级**：P3（可选）

---

### 3.9 前端：chat 话题选择与即时反馈（P2 建议）

**现状**：chat 槽位有话题下拉（夫妻/婆媳/励志等），requirement 写入。

**缺口**：
- 话题选项是否覆盖「歇后语」「名言金句」「古诗」等独立选项？
- 用户选择话题后，生成前是否有「本段将围绕 XX 话题」的即时预览？

**补充建议**：
- 检查 `REQUIREMENT_OPTIONS` 或 chat 话题下拉是否包含：歇后语、名言金句、古诗、幽默段子
- 在槽位卡片上展示当前话题，生成前可编辑

**优先级**：P2（中，影响体验）

---

### 3.10 转场话术：chat→product 衔接（P3 建议）

**现状**：transition 的 from/to 已支持 chat 穿插（`resolveTransitionProducts` 按实际槽位序列计算）。

**缺口**：从「聊家常」过渡到「利润品」时，转场话术的 prompt 是否强调「自然衔接、不突兀上链接」？拉自然流场景下，转场应更柔和。

**补充建议**：
- 当 chat_2h 且 transition 的 from 为 chat 时，在 transition prompt 中增加：
  ```
  本场为拉自然流模式，从聊家常过渡到产品时需自然衔接，避免突兀上链接，可先总结话题再自然引出产品。
  ```

**优先级**：P3（低）

## 六、总结

**主链路已闭环**：人设对齐、拉自然流约束、利润品四段式、时段注入、知识库清单、配置引导均已完成。

**高价值补充**（建议优先）：
1. **转化话术结构**：限单/价格/福利/倒计时要素（P2）
2. **知识库导入执行**：按清单导入 huashu，并确保 type 标签正确（人工 + 文档）
3. **chat 话题选项**：前端覆盖歇后语、名言、古诗（P2）

**可选增强**：进化主题池、情绪曲线、转场衔接、质量评估、留人个人事件、开场收尾约束。

**独立迭代**：单句/单段微调。
