## 6.3 组件复用

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| StatusTag | API调用日志/数据同步日志 | HTTP状态码/同步状态彩色标签 |
| StatCard | API调用日志 | 统计数字卡片（含趋势箭头） |
| HealthCard | 系统状态 | 单组件健康状态卡片（UP/DOWN/超时） |
| MemoryBar | 系统状态 | JVM内存进度条（已用/最大/百分比） |
| DateRangePicker | API调用日志/数据同步日志 | 日期范围选择器 |
| LogDetailDrawer | 数据同步日志 | 侧边抽屉展示错误详情 |
