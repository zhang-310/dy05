## 2. API 调用日志拦截器设计

### 2.1 拦截器架构

```
业务代码调用外部 API
       │
       ▼
  RestTemplate / WebClient
       │
       ▼
  ApiCallLogInterceptor（ClientHttpRequestInterceptor）
       │
       ├── 1. 前置：记录开始时间、请求 URL、方法、参数
       │
       ├── 2. 执行：发送 HTTP 请求
       │
       ├── 3. 后置：记录响应状态、内容（截取）、耗时
       │   └── 异常：记录错误信息，status=0
       │
       ├── 4. 参数脱敏
       │
       └── 5. 异步写入 sys_api_call_log
```

### 2.2 拦截器实现

```java
@Component
public class ApiCallLogInterceptor implements ClientHttpRequestInterceptor {

    @Autowired
    private ApiCallLogService apiCallLogService;

    @Override
    public ClientHttpResponse intercept(HttpRequest request, byte[] body,
                                        ClientHttpRequestExecution execution) throws IOException {

        long startTime = System.currentTimeMillis();
        String module = resolveModule(request.getURI());
        String apiName = resolveApiName(request.getURI());

        ClientHttpResponse response = null;
        Integer responseStatus = null;
        String responseBody = null;
        String errorMessage = null;
        int status = 1;  // 默认成功

        try {
            response = execution.execute(request, body);
            responseStatus = response.getStatusCode().value();

            // 读取响应内容（截取前 2000 字符）
            responseBody = truncate(readBody(response), 2000);

            // HTTP 状态码非 2xx 视为失败
            if (responseStatus < 200 || responseStatus >= 300) {
                status = 0;
            }
        } catch (Exception e) {
            status = 0;
            errorMessage = e.getClass().getSimpleName() + ": " + e.getMessage();
            throw e;
        } finally {
            long durationMs = System.currentTimeMillis() - startTime;
            Long userId = SecurityContext.getUserId();

            // 异步写入日志
            apiCallLogService.asyncSaveLog(
                module, apiName,
                request.getURI().toString(),
                request.getMethod().name(),
                sanitizeParams(body),
                responseStatus, responseBody,
                status, errorMessage,
                durationMs, userId
            );
        }

        return response;
    }
}
```

### 2.3 模块识别规则

```java
private String resolveModule(URI uri) {
    String host = uri.getHost();
    if (host.contains("douyin.com") || host.contains("toutiao.com")) {
        return "douyin";
    }
    if (host.contains("localhost") && uri.getPort() == 11434) {
        return "ai";  // Ollama
    }
    // ... 其他规则
    return "unknown";
}
```

| URL 特征 | 模块 | 说明 |
|---------|------|------|
| `*.douyin.com` / `*.toutiao.com` | douyin | 抖音开放平台 API |
| `localhost:11434` | ai | Ollama 本地推理 |
| `*.milvus.*` | ai | Milvus 向量数据库 |
| `*.elasticsearch.*` | ai | Elasticsearch |
| 其他 | unknown | 未识别的外部 API |

### 2.4 RestTemplate 配置

```java
@Configuration
public class RestTemplateConfig {

    @Autowired

    @Bean
    public RestTemplate restTemplate() {
        RestTemplate restTemplate = new RestTemplate();
```

## 3. 日志脱敏策略

### 3.1 脱敏字段

| 字段名（不区分大小写） | 脱敏方式 | 示例 |
|----------------------|---------|------|
| access_token / accessToken | 替换为 `***` | `"access_token":"***"` |
| client_secret / clientSecret | 替换为 `***` | `"client_secret":"***"` |
| api_key / apiKey | 替换为 `***` | `"api_key":"***"` |
| Authorization（Header） | 保留前 10 字符 + `***` | `"Bearer eyJ***"` |
| password | 替换为 `***` | `"password":"***"` |

## 4. 日志保留与清理

### 4.1 清理策略

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| system.api-log.retention.days | 30 | API 调用日志保留天数 |

### 4.2 定时任务

```java
@Component
public class ApiCallLogCleanupTask {

    @Autowired
    private SysApiCallLogRepository repository;

    @Autowired
    private SysConfigService configService;

    /**
     * 每天凌晨 2:00 执行清理
     */
    @Scheduled(cron = "0 0 2 * * ?")
    public void cleanup() {
        int retentionDays = configService.getIntValue(
            "system.api-log.retention.days", 30);

        LocalDateTime cutoff = LocalDateTime.now().minusDays(retentionDays);

        // 分批删除，每批 1000 条，避免长事务
        int deleted;
        int totalDeleted = 0;
        do {
            deleted = repository.deleteByCreateTimeBefore(cutoff, 1000);
            totalDeleted += deleted;
        } while (deleted > 0);

        log.info("API 调用日志清理完成，删除 {} 条（保留 {} 天）",
            totalDeleted, retentionDays);
    }
}
```

### 4.3 清理 SQL

```sql
-- 分批删除（每批 1000 条）
DELETE FROM sys_api_call_log
WHERE id IN (
    SELECT id FROM sys_api_call_log
    WHERE create_time < :cutoff
    ORDER BY id
    LIMIT 1000
);
```

> 使用 idx_api_log_create_time 索引加速清理查询。

## 5. 数据同步日志追踪

### 5.1 SyncLogService 接口

```java
@Service
public class SyncLogService {

    @Autowired
    private SysSyncLogRepository repository;

    /**
     * 开始同步 — 创建 running 状态记录
     * @return syncLogId（后续更新用）
     */
    public Long startSync(String syncType, Long userId, Long accountId) {
        SysSyncLog log = new SysSyncLog();
        log.setSyncType(syncType);
        log.setUserId(userId);
        log.setAccountId(accountId);
        log.setStatus("running");
        log.setStartTime(LocalDateTime.now());
        return repository.save(log).getId();
    }

    /**
     * 更新同步进度
     */
    public void updateProgress(Long syncLogId, int totalCount,
                               int successCount, int failCount) {
        repository.updateProgress(syncLogId, totalCount, successCount, failCount);
    }

    /**
     * 完成同步 — 更新为 success
     */
    public void completeSync(Long syncLogId, int totalCount,
                             int successCount, int failCount) {
        repository.completeSync(syncLogId, "success",
            totalCount, successCount, failCount, LocalDateTime.now());
    }

    /**
     * 同步失败 — 更新为 failed
     */
    public void failSync(Long syncLogId, String errorMessage) {
        repository.failSync(syncLogId, "failed",
            errorMessage, LocalDateTime.now());
    }
}
```

### 5.2 业务模块调用示例

```java
// shortvideo 模块 — 视频同步
public void syncVideos(Long userId, Long accountId) {
    Long syncLogId = syncLogService.startSync("video_sync", userId, accountId);

    try {
        List<Video> videos = douyinApi.getVideoList(accountId);
        int success = 0, fail = 0;

        for (Video video : videos) {
            try {
                saveVideo(video);
                success++;
            } catch (Exception e) {
                fail++;
            }
            syncLogService.updateProgress(syncLogId, videos.size(), success, fail);
        }

        syncLogService.completeSync(syncLogId, videos.size(), success, fail);
    } catch (Exception e) {
        syncLogService.failSync(syncLogId, e.getMessage());
    }
}
```

|-----------|------|---------|

| live_data_sync | 直播数据同步 | live |

## 6. 系统健康检查

### 6.1 检查流程

```
POST /api/v1/system/health
       │
       ▼
  SystemHealthService.checkHealth()
       │
       ├── 并行检查 7 个组件（CompletableFuture）
       │
       ├── database    → SELECT 1
       ├── ollama      → HTTP GET /api/tags
       ├── milvus      → 检查连接
       ├── elasticsearch → HTTP GET /_cluster/health
       ├── redis       → PING
       ├── rabbitmq    → 检查连接
       └── storage     → StorageProvider.isAvailable()
       │
       ▼
  汇总结果，每个组件返回 {status, latency}
```

### 6.2 实现

```java
@Service
public class SystemHealthService {

    public Map<String, HealthStatus> checkHealth() {
        Map<String, CompletableFuture<HealthStatus>> futures = new LinkedHashMap<>();

        futures.put("database", CompletableFuture.supplyAsync(this::checkDatabase));
        futures.put("ollama", CompletableFuture.supplyAsync(this::checkOllama));
        futures.put("milvus", CompletableFuture.supplyAsync(this::checkMilvus));
        futures.put("elasticsearch", CompletableFuture.supplyAsync(this::checkElasticsearch));
        futures.put("redis", CompletableFuture.supplyAsync(this::checkRedis));
        futures.put("rabbitmq", CompletableFuture.supplyAsync(this::checkRabbitmq));
        futures.put("storage", CompletableFuture.supplyAsync(this::checkStorage));

        // 等待所有检查完成（最长 5 秒）
        Map<String, HealthStatus> result = new LinkedHashMap<>();
        futures.forEach((name, future) -> {
            try {
                result.put(name, future.get(5, TimeUnit.SECONDS));
            } catch (Exception e) {
                result.put(name, new HealthStatus("DOWN", null));
            }
        });

        return result;
    }

    private HealthStatus checkDatabase() {
        long start = System.currentTimeMillis();
        try {
            jdbcTemplate.queryForObject("SELECT 1", Integer.class);
            return new HealthStatus("UP", (System.currentTimeMillis() - start) + "ms");
        } catch (Exception e) {
            return new HealthStatus("DOWN", null);
        }
    }

    // ... 其他组件检查类似
}
```

### 6.3 HealthStatus 数据结构

```java
public record HealthStatus(
    String status,    // "UP" 或 "DOWN"
    String latency    // 响应延迟（如 "5ms"），DOWN 时为 null
) {}
```

## 7. 系统运行信息

### 7.1 JVM 内存信息

```java
private Map<String, Object> getJvmInfo() {
    Runtime runtime = Runtime.getRuntime();
    long maxMemory = runtime.maxMemory();
    long totalMemory = runtime.totalMemory();
    long freeMemory = runtime.freeMemory();
    long usedMemory = totalMemory - freeMemory;

    return Map.of(
        "maxMemory", formatBytes(maxMemory),
        "totalMemory", formatBytes(totalMemory),
        "freeMemory", formatBytes(freeMemory),
        "usedMemory", formatBytes(usedMemory),
        "usagePercent", round(usedMemory * 100.0 / maxMemory, 1)
    );
}
```

## 8. 调用统计

### 8.1 统计查询 SQL

```sql
-- 总体统计
SELECT
    COUNT(*)                                    AS total_calls,
    SUM(CASE WHEN status = 1 THEN 1 ELSE 0 END) AS success_count,
    SUM(CASE WHEN status = 0 THEN 1 ELSE 0 END) AS fail_count,
    ROUND(AVG(duration_ms))                     AS avg_duration_ms
FROM sys_api_call_log
WHERE create_time BETWEEN :startTime AND :endTime;

-- 按模块分组统计
SELECT
    module,
    COUNT(*)                                    AS total_calls,
    ROUND(SUM(CASE WHEN status = 1 THEN 1.0 ELSE 0 END) / COUNT(*) * 100, 2)
                                                AS success_rate,
    ROUND(AVG(duration_ms))                     AS avg_duration_ms
FROM sys_api_call_log
WHERE create_time BETWEEN :startTime AND :endTime
GROUP BY module
ORDER BY total_calls DESC;

-- 按接口分组统计（Top 20）
SELECT
    api_name,
    COUNT(*)                                    AS total_calls,
    ROUND(SUM(CASE WHEN status = 1 THEN 1.0 ELSE 0 END) / COUNT(*) * 100, 2)
                                                AS success_rate,
    ROUND(AVG(duration_ms))                     AS avg_duration_ms
FROM sys_api_call_log
WHERE create_time BETWEEN :startTime AND :endTime
GROUP BY api_name
ORDER BY total_calls DESC
LIMIT 20;
```

### 8.2 统计维度

| 维度 | 指标 | 说明 |
|------|------|------|
| 总体 | totalCalls / successRate / avgDurationMs | 全局调用概览 |
| 按模块 | 每个模块的调用量/成功率/平均耗时 | 识别问题模块 |
| 按接口 | Top 20 接口的调用量/成功率/平均耗时 | 识别慢接口和高频接口 |
