## 模块定位

system 模块负责系统级监控和审计，提供 API 调用日志、数据同步记录和系统健康检查。

核心职责：
1. **API 调用日志** — 记录所有外部 API 调用（抖音 API / AI 模型 API），含调用统计
2. **数据同步日志** — 记录数据同步任务（视频同步/直播数据同步/账号数据同步）
3. **系统健康检查** — 7 个组件健康状态（database/ollama/milvus/elasticsearch/redis/rabbitmq/storage）
4. **系统运行信息** — JVM 内存、线程数、运行时长

> system 模块与 log 模块的区别：log 记录业务操作日志（用户行为审计），system 记录系统级技术日志（API 调用、数据同步）。
