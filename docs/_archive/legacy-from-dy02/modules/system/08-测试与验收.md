## 8.2 功能测试用例

### 8.2.1 API 调用日志

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T01 | 成功调用记录 | 触发一次外部 API 调用（HTTP 200） | sys_api_call_log 写入一条记录，status=success，duration_ms > 0 |
| T02 | 失败调用记录 | 触发一次外部 API 调用（HTTP 500） | sys_api_call_log 写入一条记录，status=fail，error_message 非空 |
| T03 | 参数脱敏 | 请求参数含 token/password 字段 | request_params 中敏感字段已替换为 ****** |
| T04 | 响应截断 | 响应体超过 2000 字符 | response_body 截断至 2000 字符，末尾附加截断标记 |
| T05 | 分页查询 | POST /api/v1/system/api-log/list，pageSize=10 | 返回 10 条记录，total 正确 |
| T06 | 按模块筛选 | 筛选 module=douyin | 仅返回 module=douyin 的记录 |

### 8.2.2 API 调用统计

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T07 | 整体统计 | POST /api/v1/system/api-log/stats，不传 groupBy | 返回总调用次数、成功率、平均耗时 |
| T08 | 按模块统计 | POST /api/v1/system/api-log/stats，groupBy=module | 返回各模块的调用次数+成功率 |
| T09 | 按 API 名统计 | POST /api/v1/system/api-log/stats，groupBy=api_name | 返回各 API 名称的调用次数+平均耗时 |

### 8.2.3 数据同步日志

| # | 用例 | 步骤 | 预期结果 |

| T14 | 列表查询 | POST /api/v1/system/sync-log/list，按 sync_type 筛选 | 返回正确的分页结果 |

### 8.2.4 系统健康检查

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T15 | 全部 UP | 所有组件正常，POST /api/v1/system/health | status=UP，7个组件全部 status=UP |
| T16 | 某组件 DOWN | 停止 RabbitMQ，POST /api/v1/system/health | 整体 status=DEGRADED，rabbitmq.status=DOWN，其余组件不受影响 |
| T17 | 超时处理 | 模拟某组件响应超时（>3s） | 该组件 status=TIMEOUT，不阻塞其他组件检查，整体在合理时间内返回 |
| T18 | 系统信息 | POST /api/v1/system/info | 返回 heapUsed/heapMax/nonHeapUsed、activeThreads/daemonThreads/peakThreads、uptime/javaVersion/processors/systemLoad |

### 8.2.5 日志清理

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T19 | 自动清理 | 手动触发清理定时任务 | 30天前的 sys_api_call_log 记录已删除，30天内记录保留 |
| T20 | 可配置保留天数 | 修改配置 system.log.retention-days=7，触发清理 | 7天前的记录被清理 |

### 8.2.6 边界测试

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T21 | 并发调用记录 | 同时发起 50 个外部 API 调用 | 50 条日志全部写入，无丢失，无重复 |
| T22 | 拦截器异常不影响业务 | 模拟日志写入数据库失败 | 外部 API 调用正常返回，业务不受影响，异常仅打印日志 |
| T23 | 并发健康检查 | 7个组件并行检查，POST /api/v1/system/health | 总耗时接近最慢单个组件耗时，而非7个组件耗时之和 |
| T24 | 空数据统计 | 无任何日志时请求统计接口 | 返回 totalCount=0，successRate=0，avgDuration=0，不报错 |
