# 系统模块 — 开发任务

> 版本：3.0 | 更新日期：2026-02-26

---

## 7.1 后端任务

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B01 | 数据库初始化 | sys_api_call_log + sys_sync_log 2张表 DDL + 索引 | 无 |
| B02 | SysApiCallLog + SysSyncLog 实体 + Repository | 2个 Entity，2个 JpaRepository | B01 |
| B03 | ApiCallLogService + RestTemplate 拦截器 + 30天清理定时任务 | ApiCallLogService，ApiCallLogInterceptor，CleanupScheduler | B02 |
| B04 | SyncLogService | startSync / updateProgress / completeSync / failSync | B02 |
| B05 | SystemHealthService | 7组件并行健康检查 + JVM / 线程 / 运行时信息 | 无 |
| B06 | SystemController | 5个接口（api-log/list, api-log/stats, sync-log/list, health, info） | B03, B04, B05 |

---

## 7.2 前端任务

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| F01 | system API 模块 | api/system.ts | 无 |
| F02 | API 调用日志页 | SystemApiLogPage.vue | F01 |
| F03 | 数据同步日志页 | SystemSyncLogPage.vue | F01 |
| F04 | 系统状态页 | SystemHealthPage.vue | F01 |

