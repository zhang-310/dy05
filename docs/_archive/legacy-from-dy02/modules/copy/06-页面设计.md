# 文案模块 — 页面设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 6.1 页面清单

| # | 页面 | 路由 | 权限 | 说明 |
|---|------|------|------|------|
| 1 | 文案库 | /talent/copy/library | talent | 文案列表、搜索、新建、编辑、删除、提交审批 |
| 2 | 机构文案管理 | /org/copy/library | institution | 机构范围内文案查看与管理（DataScope 过滤） |
| 3 | 审批管理 | /admin/copy/approval | admin | 待审批列表、审批通过/拒绝 |
| 4 | 模板管理 | /talent/copy/template | admin + institution + talent | 模板列表、新建、编辑、启用/禁用 |

状态标签说明：
- `✅ 已审核` — 绿色标签，status = 1

- 编辑：所有状态均可编辑（编辑后重置为待审核）
- 删除：软删除，弹出确认对话框
- 提交审批：仅 status = 0（待审核）时显示

### 6.2.3 模板管理（/talent/copy/template）

```
┌─────────────────────────────────────────────────────────────────┐
│  模板管理                                          [+ 新建模板]  │
├─────────────────────────────────────────────────────────────────┤
│  搜索：[关键词...        ] 分类：[全部 ▼] 状态：[全部 ▼] [搜索]  │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  ┌──┬──────────────────┬──────┬──────────────┬──────┬────────┐  │
│  │# │ 模板名称          │ 分类  │ 描述          │ 状态  │ 操作   │  │
│  ├──┼──────────────────┼──────┼──────────────┼──────┼────────┤  │
│  │1 │ 电商促销通用模板  │ 电商  │ 适用于各类促销│ ✅有效│编辑 禁用│  │
│  ├──┼──────────────────┼──────┼──────────────┼──────┼────────┤  │
│  │2 │ 品牌故事模板      │ 品牌  │ 品牌历史介绍  │ ✅有效│编辑 禁用│  │
│  │  │ [系统]           │      │              │      │使用    │  │
│  ├──┼──────────────────┼──────┼──────────────┼──────┼────────┤  │
│  │3 │ 节日祝福模板      │ 节日  │ 节假日通用    │ 🚫禁用│编辑 启用│  │
│  └──┴──────────────────┴──────┴──────────────┴──────┴────────┘  │
│                                                                 │
│  共 50 条  < 1 2 3 >                                            │
└─────────────────────────────────────────────────────────────────┘
```

状态标签说明：
- `✅ 有效` — 绿色，status = 1
- `🚫 禁用` — 灰色，status = 0

标签说明：
- `[系统]` — admin 创建的系统模板，非管理员不可编辑/删除
- `[机构]` — institution 创建的机构模板，仅机构管理员和 admin 可编辑/删除

操作按钮规则：
- 编辑：系统模板仅 admin 可编辑；机构模板仅 institution 和 admin 可编辑；个人模板仅创建者和 admin 可编辑
- 禁用/启用：仅 admin 可操作
- 使用：点击后跳转到文案库新建页，并预填充模板内容

## 6.3 组件复用表

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| SearchBar | 文案库、审批管理、模板管理 | 关键词搜索 + 下拉筛选 |
| StatusTag | 文案库、审批管理、模板管理 | 状态标签（颜色区分） |
| PageTable | 文案库、审批管理、模板管理 | 分页表格 |
| ConfirmDialog | 文案库（删除）、模板管理（删除/禁用） | 操作确认弹窗 |
| FormModal | 文案库（新建/编辑）、模板管理（新建/编辑） | 表单弹窗 |
| ApprovalModal | 审批管理 | 审批操作弹窗（含文案预览） |
