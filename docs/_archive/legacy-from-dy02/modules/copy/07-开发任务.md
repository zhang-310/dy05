## 7.2 后端任务详情

### B04 — CopyTemplate 实体 + Repository

```

```

### B05 — CopyLibraryService

```
输出文件：module/copy/service/CopyLibraryService.java

方法：
  - PageResultVO<CopyLibraryVO> search(CopyLibrarySearchDTO dto)
      → 数据隔离：admin 查全部，institution 按机构过滤，talent 强制 userId = 当前用户
  - CopyLibraryVO get(Long id)
      → 校验存在性（3501）+ 权限（3502）
  - Long save(CopyLibrarySaveDTO dto)
      → 新建：设置 userId、wordCount、status=0
      → 更新：校验权限、重新计算 wordCount、已审核则重置 status=0
  - void delete(Long id)
      → 校验存在性（3501）+ 权限（3502）+ 软删除
  - void updateStatus(Long id, Integer status)
      → 仅 admin，校验存在性（3501）
  - void incrementUseCount(Long id)
      → 原子性 use_count + 1，校验存在性（3501）
```

### B06 — CopyApprovalService

```
输出文件：module/copy/service/CopyApprovalService.java

方法：
  - PageResultVO<CopyApprovalVO> search(CopyApprovalSearchDTO dto)
      → 仅 admin 可调用
  - CopyApprovalVO get(Long id)
      → 校验存在性（3503），返回含文案标题和内容
  - Long save(CopyApprovalSaveDTO dto)
      → 用户提交审批：创建 approval_status=2 的记录
      → 管理员审批：更新 approval_status（校验值合法性 3504）
                    + 更新 reviewer_id、approval_time
                    + 若通过则同步 cp_library.status=1
  - void delete(Long id)
      → 仅 admin，校验存在性（3503）+ 软删除
```

### B07 — CopyTemplateService

```
输出文件：module/copy/service/CopyTemplateService.java

方法：
  - PageResultVO<CopyTemplateVO> search(CopyTemplateSearchDTO dto)
      → talent：返回自己的模板 + 所属机构的有效模板 + 系统有效模板
      → institution：返回机构的模板 + 系统有效模板
      → admin：返回全部
  - CopyTemplateVO get(Long id)
      → 校验存在性（3505）+ 权限（3506）
  - Long save(CopyTemplateSaveDTO dto)
      → 新建：设置 userId、status=1
      → 更新：校验系统模板权限（3507）+ 机构模板权限 + 个人模板权限（3506）
  - void delete(Long id)
      → 校验存在性（3505）+ 系统模板权限（3507）+ 机构模板权限 + 个人模板权限（3506）+ 软删除
  - void updateStatus(Long id, Integer status)
      → 仅 admin，校验存在性（3505）
```

### B08 — CopyLibraryController

```
输出文件：module/copy/controller/CopyLibraryController.java

接口：
  POST /api/v1/copy/library/search           → search()
  POST /api/v1/copy/library/get              → get()
  POST /api/v1/copy/library/save             → save()
  POST /api/v1/copy/library/delete           → delete()
  POST /api/v1/copy/library/update-status    → updateStatus()  @PreAuthorize("hasRole('ADMIN')")
  POST /api/v1/copy/library/increment-use-count → incrementUseCount()
```

### B09 — CopyApprovalController + CopyTemplateController

```
输出文件：
  - module/copy/controller/CopyApprovalController.java
  - module/copy/controller/CopyTemplateController.java

CopyApprovalController 接口（全部 @PreAuthorize("hasRole('ADMIN')")，save 除外）：
  POST /api/v1/copy/approval/search  → search()
  POST /api/v1/copy/approval/get     → get()
  POST /api/v1/copy/approval/save    → save()
  POST /api/v1/copy/approval/delete  → delete()

CopyTemplateController 接口：
  POST /api/v1/copy/template/search         → search()
  POST /api/v1/copy/template/get            → get()
  POST /api/v1/copy/template/save           → save()
  POST /api/v1/copy/template/delete         → delete()
  POST /api/v1/copy/template/update-status  → updateStatus()  @PreAuthorize("hasRole('ADMIN')")
```

