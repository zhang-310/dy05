# 文案模块 — 数据库设计

> 版本：3.1 | 更新日期：2026-02-26
> 数据库：PostgreSQL

---

## 2.1 ER 关系总览

```
auth_user (auth 模块)
    │
    ├─── cp_library（文案库）
    │        │
    │        └─── cp_approval（审批记录）
    │                  │
    │                  └── reviewer_id → auth_user
    │
    └─── cp_template（文案模板）
```

---

## 2.2 表结构

### cp_library — 文案库表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| user_id | BIGINT | NOT NULL | — | 创建者用户 ID |
| title | VARCHAR(255) | NOT NULL | — | 文案标题 |
| content | TEXT | NOT NULL | — | 文案正文内容 |
| category | VARCHAR(64) | | — | 文案分类 |
| tags | VARCHAR(255) | | — | 标签（逗号分隔或 JSON） |
| word_count | INTEGER | | 0 | 字数（后端自动计算） |
| use_count | INTEGER | | 0 | 使用次数 |
| rating | INTEGER | | 0 | 评分 |
| status | INTEGER | NOT NULL | 0 | 状态：0=待审核，1=已审核 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除：0=正常，1=已删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(user_id, status)` — 用户文案列表按状态筛选
- `(category)` — 按分类筛选
- `(status, deleted)` — 审批管理查询
- `(use_count DESC)` — 热门文案排序
- `(create_time DESC)` — 最新文案排序

### cp_approval — 文案审批表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| copy_id | BIGINT | NOT NULL | — | 关联文案 ID（cp_library.id） |
| reviewer_id | BIGINT | | — | 审核人用户 ID |
| approval_status | INTEGER | NOT NULL | 2 | 审批状态：0=拒绝，1=通过，2=待审核 |
| comments | TEXT | | — | 审批意见/拒绝原因 |
| approval_time | TIMESTAMP | | — | 审批完成时间 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(copy_id)` — 按文案查审批记录
- `(approval_status, deleted)` — 待审核列表查询
- `(reviewer_id)` — 按审核人查询
- `(create_time DESC)` — 最新审批排序

---

### cp_template — 文案模板表

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| user_id | BIGINT | NOT NULL | — | 创建者用户 ID（admin 创建的为系统模板） |
| template_name | VARCHAR(255) | NOT NULL | — | 模板名称 |
| template_content | TEXT | NOT NULL | — | 模板内容（可含占位符） |
| category | VARCHAR(64) | | — | 模板分类 |
| description | VARCHAR(255) | | — | 模板描述 |
| status | INTEGER | NOT NULL | 1 | 状态：0=禁用，1=有效 |
| deleted | INTEGER | NOT NULL | 0 | 逻辑删除 |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 创建时间 |
| update_time | TIMESTAMP | | CURRENT_TIMESTAMP | 更新时间 |

索引：
- `(user_id, status)` — 用户模板列表
- `(category, status)` — 按分类筛选有效模板
- `(status, deleted)` — 有效模板列表查询

## 2.3 完整 DDL

```sql
-- ============================================
-- copy 模块数据库初始化脚本（PostgreSQL）
-- ============================================

-- 文案库表
CREATE TABLE IF NOT EXISTS cp_library (
    id          BIGSERIAL    PRIMARY KEY,
    user_id     BIGINT       NOT NULL,
    title       VARCHAR(255) NOT NULL,
    content     TEXT         NOT NULL,
    category    VARCHAR(64),
    tags        VARCHAR(255),
    word_count  INTEGER      NOT NULL DEFAULT 0,
    use_count   INTEGER      NOT NULL DEFAULT 0,
    rating      INTEGER      NOT NULL DEFAULT 0,
    status      INTEGER      NOT NULL DEFAULT 0,
    deleted     INTEGER      NOT NULL DEFAULT 0,
    create_time TIMESTAMP    DEFAULT CURRENT_TIMESTAMP,
    update_time TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_cp_library_user_status    ON cp_library(user_id, status);
CREATE INDEX idx_cp_library_category       ON cp_library(category);
CREATE INDEX idx_cp_library_status_deleted ON cp_library(status, deleted);
CREATE INDEX idx_cp_library_use_count      ON cp_library(use_count DESC);
CREATE INDEX idx_cp_library_create_time    ON cp_library(create_time DESC);

-- 文案审批表
CREATE TABLE IF NOT EXISTS cp_approval (
    id              BIGSERIAL PRIMARY KEY,
    copy_id         BIGINT    NOT NULL,
    reviewer_id     BIGINT,
    approval_status INTEGER   NOT NULL DEFAULT 2,
    comments        TEXT,
    approval_time   TIMESTAMP,
    deleted         INTEGER   NOT NULL DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_cp_approval_copy_id         ON cp_approval(copy_id);
CREATE INDEX idx_cp_approval_status          ON cp_approval(approval_status, deleted);
CREATE INDEX idx_cp_approval_reviewer_id     ON cp_approval(reviewer_id);
CREATE INDEX idx_cp_approval_create_time     ON cp_approval(create_time DESC);

-- 文案模板表
CREATE TABLE IF NOT EXISTS cp_template (
    id               BIGSERIAL    PRIMARY KEY,
    user_id          BIGINT       NOT NULL,
    template_name    VARCHAR(255) NOT NULL,
    template_content TEXT         NOT NULL,
    category         VARCHAR(64),
    description      VARCHAR(255),
    status           INTEGER      NOT NULL DEFAULT 1,
    deleted          INTEGER      NOT NULL DEFAULT 0,
    create_time      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP,
    update_time      TIMESTAMP    DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_cp_template_user_status     ON cp_template(user_id, status);
CREATE INDEX idx_cp_template_category_status ON cp_template(category, status);
CREATE INDEX idx_cp_template_status_deleted  ON cp_template(status, deleted);
```

## 2.4 状态值说明

### cp_library.status

| 值 | 含义 | 触发条件 |
|----|------|---------|
| 0 | 待审核 | 新建文案默认值；用户编辑已审核文案后重置 |
| 1 | 已审核 | 管理员审批通过后设置 |

### cp_approval.approval_status

| 值 | 含义 | 触发条件 |
|----|------|---------|
| 2 | 待审核 | 用户提交审批时默认值 |
| 1 | 通过 | 管理员审批通过 |
| 0 | 拒绝 | 管理员审批拒绝 |

### cp_template.status

| 值 | 含义 | 触发条件 |
|----|------|---------|
| 1 | 有效 | 模板创建默认值；管理员启用 |
| 0 | 禁用 | 管理员禁用模板 |
