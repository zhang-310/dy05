## 3.2 接口详细说明

### 3.2.1 文案库接口

#### POST /api/v1/copy/library/search — 分页搜索文案库

请求体：
```json
{
  "pageNum": 1,
  "pageSize": 20,
  "keyword": "春季护肤",
  "category": "美妆",
  "tags": "护肤,保湿",
  "status": 1,
  "userId": null
}
```

说明：
- `keyword`：模糊匹配 title 和 content
- `userId`：管理员可传指定用户 ID；机构可查看机构范围内达人的文案；达人只能查自己的（后端强制过滤）
- `status`：不传则查全部状态

响应体：
```json
{
  "code": 0,
  "data": {
    "total": 100,
    "list": [
      {
        "id": 1,
        "userId": 10,
        "title": "春季护肤文案",
        "content": "春天来了，皮肤也需要...",
        "category": "美妆",
        "tags": "护肤,保湿",
        "wordCount": 200,
        "useCount": 15,
        "rating": 4,
        "status": 1,
        "createTime": "2026-02-20T10:00:00",
        "updateTime": "2026-02-21T08:00:00"
      }
    ]
  }
}
```

---

请求体：

```json
{
  "id": 1
```

响应体：

```json
{
  "code": 0,
  "data": {
    "id": 1,

    "title": "春季护肤文案",
    "content": "春天来了，皮肤也需要...",
    "category": "美妆",
    "tags": "护肤,保湿",
    "wordCount": 200,
    "useCount": 15,
    "rating": 4,

    "createTime": "2026-02-20T10:00:00",

  }

```

错误码：
- `3501` COPY_LIBRARY_NOT_FOUND — 文案不存在
- `3502` COPY_LIBRARY_FORBIDDEN — 无权访问该文案

---

#### POST /api/v1/copy/library/save — 新建/更新文案

请求体（新建，id 为空）：
```json
{
  "title": "春季护肤文案",
  "content": "春天来了，皮肤也需要...",
  "category": "美妆",
  "tags": "护肤,保湿"
}
```

请求体（更新，id 不为空）：
```json
{
  "id": 1,
  "title": "春季护肤文案（修订版）",
  "content": "春天来了，皮肤也需要...",
  "category": "美妆",
  "tags": "护肤,保湿,春季"
}
```

响应体：
```json
{
  "code": 0,
  "data": 1
}
```

说明：
- 新建时 `user_id` 由后端从当前登录用户获取，`word_count` 自动计算，`status` 默认 0
- 更新时若文案原状态为 1（已审核），自动重置为 0（待审核）
- 返回值为文案 ID

错误码：
- `3501` COPY_LIBRARY_NOT_FOUND — 更新时文案不存在
- `3502` COPY_LIBRARY_FORBIDDEN — 无权编辑该文案

### 3.2.2 审批接口

#### POST /api/v1/copy/approval/search — 分页搜索审批记录

请求体：
```json
{
  "pageNum": 1,
  "pageSize": 20,
  "copyId": null,
  "approvalStatus": 2,
  "reviewerId": null
}
```

说明：
- `approvalStatus`：0=拒绝，1=通过，2=待审核；不传查全部
- 仅 admin 可访问

响应体：
```json
{
  "code": 0,
  "data": {
    "total": 10,
    "list": [
      {
        "id": 1,
        "copyId": 5,
        "copyTitle": "春季护肤文案",
        "reviewerId": null,
        "approvalStatus": 2,
        "comments": null,
        "approvalTime": null,
        "createTime": "2026-02-22T09:00:00"
      }
    ]
  }
}
```

---

#### POST /api/v1/copy/approval/get — 获取审批详情

请求体：
```json
{
  "id": 1
}
```

响应体：
```json
{
  "code": 0,
  "data": {
    "id": 1,
    "copyId": 5,
    "copyTitle": "春季护肤文案",
    "copyContent": "春天来了...",
    "reviewerId": 2,
    "approvalStatus": 1,
    "comments": "内容优质，审批通过",
    "approvalTime": "2026-02-22T10:30:00",
    "createTime": "2026-02-22T09:00:00"
  }
}
```

错误码：
- `3503` COPY_APPROVAL_NOT_FOUND — 审批记录不存在

---

#### POST /api/v1/copy/approval/save — 提交审批

请求体（用户提交审批）：
```json
{
  "copyId": 5
}
```

请求体（管理员审批）：
```json
{
  "id": 1,
  "approvalStatus": 1,
  "comments": "内容优质，审批通过"
}
```

响应体：
```json
{
  "code": 0,
  "data": 1
}
```

说明：
- 用户提交审批时，只需传 `copyId`，后端创建 approval_status=2 的记录
- 管理员审批时，传 `id`（审批记录 ID）、`approvalStatus`（1 或 0）、`comments`
- 审批通过时，后端同步更新 `cp_library.status=1`

错误码：
- `3503` COPY_APPROVAL_NOT_FOUND — 审批记录不存在
- `3504` COPY_APPROVAL_STATUS_INVALID — 审批状态值非法

---

### 3.2.3 模板接口

#### POST /api/v1/copy/template/search — 分页搜索模板

请求体：
```json
{
  "pageNum": 1,
  "pageSize": 20,
  "keyword": "促销",
  "category": "电商",
  "status": 1
}
```

说明：
- 达人查询时，后端自动过滤：返回自己创建的模板 + 所有系统级有效模板
- 机构查询时，后端返回：机构范围内的模板 + 所有系统级有效模板
- 管理员可查看全部

响应体：
```json
{
  "code": 0,
  "data": {
    "total": 30,
    "list": [
      {
        "id": 1,
        "userId": 1,
```

## 3.3 错误码表

| 错误码 | 常量名 | 说明 |
|--------|--------|------|
| 3501 | COPY_LIBRARY_NOT_FOUND | 文案不存在或已删除 |
| 3502 | COPY_LIBRARY_FORBIDDEN | 无权访问/编辑/删除该文案 |
| 3503 | COPY_APPROVAL_NOT_FOUND | 审批记录不存在或已删除 |
| 3504 | COPY_APPROVAL_STATUS_INVALID | 审批状态值非法（非 0/1/2） |
| 3505 | COPY_TEMPLATE_NOT_FOUND | 模板不存在或已删除 |
| 3506 | COPY_TEMPLATE_FORBIDDEN | 无权访问/编辑/删除该模板 |
| 3507 | COPY_TEMPLATE_SYSTEM_FORBIDDEN | 非管理员无权操作系统级模板 |
