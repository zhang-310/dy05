## 8.2 功能测试用例

### 8.2.1 文案库管理

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T01 | 新建文案 | 传入标题、内容、分类、标签，调用 save 接口 | 返回新建 ID，status=0，word_count 自动计算 |
| T02 | 更新文案 | 传入已有文案 ID 和修改内容，调用 save 接口 | 更新成功，若原 status=1 则重置为 0 |
| T03 | 删除文案 | 传入文案 ID，调用 delete 接口 | 软删除成功，deleted=1，后续查询不返回该条 |
| T04 | 搜索文案-关键词 | 传入 keyword="护肤"，调用 search 接口 | 返回 title 或 content 包含"护肤"的文案 |
| T05 | 搜索文案-分类筛选 | 传入 category="美妆"，调用 search 接口 | 返回 category="美妆" 的文案 |
| T06 | 搜索文案-状态筛选 | 传入 status=1，调用 search 接口 | 仅返回已审核文案 |
| T07 | 更新文案状态 | admin 调用 update-status?id=1&status=1 | 文案 status 更新为 1 |
| T08 | 递增使用次数 | 调用 increment-use-count?id=1 | use_count 原子性加 1 |

### 8.2.2 审批流程

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T09 | 提交审批 | 达人调用 approval/save（仅传 copyId） | 创建 approval_status=2 的审批记录 |
| T10 | 审批通过 | admin 调用 approval/save（id, approvalStatus=1, comments） | approval_status=1，cp_library.status=1，approval_time 有值 |
| T11 | 审批拒绝 | admin 调用 approval/save（id, approvalStatus=0, comments） | approval_status=0，cp_library.status 保持 0 |
| T12 | 审批列表-待审核筛选 | admin 调用 approval/search（approvalStatus=2） | 仅返回待审核记录 |
| T13 | 审批详情 | admin 调用 approval/get（id） | 返回含文案标题、内容、审批意见的完整信息 |
| T14 | 审批状态非法值 | 调用 approval/save（approvalStatus=9） | 返回错误码 3504 |

### 8.2.3 模板管理

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T15 | 新建模板 | 传入模板名称、内容、分类，调用 template/save | 返回新建 ID，status=1 |
| T16 | 更新模板 | 传入已有模板 ID 和修改内容，调用 template/save | 更新成功 |
| T17 | 删除模板 | 传入模板 ID，调用 template/delete | 软删除成功 |
| T18 | 禁用模板 | admin 调用 template/update-status?id=1&status=0 | 模板 status=0，搜索时不返回给达人和机构 |
| T19 | 启用模板 | admin 调用 template/update-status?id=1&status=1 | 模板 status=1，搜索时正常返回 |
| T20 | 使用模板 | 调用 template/get 获取模板内容，前端填充到文案编辑器 | 模板内容正确返回，可用于创建文案 |

### 8.2.4 数据隔离

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T21 | 达人只能查自己的文案 | 达人 A 调用 library/search，不传 userId | 仅返回 user_id = 达人 A 的文案 |
| T22 | 达人不能编辑他人文案 | 达人 A 调用 library/save（id 属于达人 B） | 返回错误码 3502 |
| T23 | 达人不能删除他人文案 | 达人 A 调用 library/delete（id 属于达人 B） | 返回错误码 3502 |
| T24 | 达人不能操作系统模板 | 达人调用 template/save（id 为系统模板） | 返回错误码 3507 |

### 8.2.5 边界测试

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T25 | 空内容文案 | 调用 library/save（content 为空） | 返回参数校验错误 |
| T26 | 空标题文案 | 调用 library/save（title 为空） | 返回参数校验错误 |
| T27 | 文案不存在 | 调用 library/get（id=99999） | 返回错误码 3501 |
| T28 | 审批记录不存在 | 调用 approval/get（id=99999） | 返回错误码 3503 |
| T29 | 模板不存在 | 调用 template/get（id=99999） | 返回错误码 3505 |
| T30 | 超长标题 | 调用 library/save（title 超过 255 字符） | 返回参数校验错误 |

### 8.2.6 并发与性能

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T31 | 并发递增使用次数 | 10 个并发请求同时调用 increment-use-count（id=1） | use_count 精确增加 10，无数据丢失 |
| T32 | 大量文案搜索 | 数据库有 10000 条文案，调用 search（pageSize=20） | 响应时间 < 500ms |
| T33 | 分页正确性 | 共 100 条数据，pageSize=20，查第 3 页 | 返回第 41-60 条，total=100 |
| T34 | 软删除不出现在搜索结果 | 删除文案后调用 search | 已删除文案不出现在结果中 |
| T35 | 禁用模板不出现在达人搜索结果 | 禁用模板后达人调用 template/search | 禁用的系统模板不出现在结果中 |

## 8.3 验收标准

| 类别 | 验收项 | 标准 |
|------|--------|------|
| 功能完整性 | 文案库 CRUD | 6 个接口全部可用，状态机流转正确 |
| 功能完整性 | 审批流程 | 提交→待审核→通过/拒绝，联动更新文案状态 |
| 功能完整性 | 模板管理 | 5 个接口全部可用，系统模板权限控制正确 |
| 数据安全 | 数据隔离 | 达人无法访问他人数据，机构只能访问机构范围内数据，T21-T24 全部通过 |
| 数据安全 | 权限控制 | admin 专用接口非 admin 调用返回 403 |
| 数据一致性 | 审批联动 | 审批通过后文案状态同步更新，无遗漏 |
| 数据一致性 | 软删除 | 删除后数据不出现在任何查询结果中 |
| 性能 | 搜索响应 | 万级数据量下搜索响应 < 500ms |
| 性能 | 并发安全 | use_count 并发递增无数据丢失 |
| 前端 | 页面加载 | 3 个页面正常渲染，无控制台报错 |
| 前端 | 权限显示 | 达人和机构不显示审批管理菜单；系统模板不显示编辑/删除按钮 |
