# log 模块 — 接口设计

> 版本：3.0 | 更新日期：2026-02-26

---

## 1. 接口总表

共计 **3 个端点**，均在 LogController 中。

### 1.1 LogController（/api/v1/log）— 3 个端点

| # | 方法 | 路径 | 权限 | 说明 |
|---|------|------|------|------|
| 1 | POST | /api/v1/log/operation/list | 管理员 | 操作日志列表（分页、筛选） |
| 2 | POST | /api/v1/log/operation/get | 管理员 | 日志详情 |
| 3 | POST | /api/v1/log/operation/export | 管理员 | 导出日志（CSV） |

> 所有接口仅管理员可访问。操作日志不提供删除和修改接口（BR-01：只记不删）。

---

## 2. 关键接口详细设计

### 接口 1：操作日志列表

```
POST /api/v1/log/operation/list
权限：管理员（role_code=admin）
```

**请求参数（OperationLogSearchVO，继承 BasicQueryDto）：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 页码，默认 0 |
| rows | Integer | 否 | 每页条数，默认 30 |
| sortName | String | 否 | 排序字段，默认 id |
| sortOrder | String | 否 | asc/desc，默认 desc |
| userId | Long | 否 | 按用户 ID 筛选 |
| username | String | 否 | 按用户名模糊搜索 |
| module | String | 否 | 按模块精确筛选（auth/douyin/live...） |
| operation | String | 否 | 按操作描述模糊搜索 |
| startTime | String | 否 | 开始时间（yyyy-MM-dd HH:mm:ss） |
| endTime | String | 否 | 结束时间（yyyy-MM-dd HH:mm:ss） |

**响应（PageResultVO）：**

```json
{
  "status": 200,
  "data": {
    "total": 1500,
    "list": [
      {
        "id": 1001,
        "userId": 1,
        "username": "admin",
        "module": "auth",
        "operation": "封禁用户",
        "method": "POST /api/v1/auth/user/ban",
        "responseStatus": 200,
        "ip": "192.168.1.100",
        "durationMs": 45,
        "createTime": "2026-02-26 10:30:00"
      }
    ],
    "pageNum": 0,
    "pageSize": 30
  }
}
```

> 列表接口不返回 requestParams 和 errorMessage（大字段），需查看详情获取。

### 接口 2：日志详情

```
POST /api/v1/log/operation/get
权限：管理员
```

**请求参数：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | Long | 是 | 日志 ID |

**响应：**

```json
{
  "status": 200,
  "data": {
    "id": 1001,
    "userId": 1,
    "username": "admin",
    "module": "auth",
    "operation": "封禁用户",
    "method": "POST /api/v1/auth/user/ban",
    "requestParams": "{\"userId\":2,\"ban\":true,\"reason\":\"违规操作\"}",
    "responseStatus": 200,
    "ip": "192.168.1.100",
    "userAgent": "Mozilla/5.0 ...",
    "durationMs": 45,
    "errorMessage": null,
    "createTime": "2026-02-26 10:30:00"
  }
}
```

### 接口 3：导出日志（CSV）

```
POST /api/v1/log/operation/export
权限：管理员
Content-Type: application/octet-stream（响应）
```

**请求参数（OperationLogSearchVO）：** 同接口 1 的筛选条件。

**响应：** 文件流（CSV 格式）

```
HTTP/1.1 200 OK
Content-Type: application/octet-stream
Content-Disposition: attachment; filename="operation-log-20260226.csv"
```

**CSV 列：**

```csv
ID,用户ID,用户名,模块,操作,请求方法,响应状态,IP,耗时(ms),操作时间
1001,1,admin,auth,封禁用户,POST /api/v1/auth/user/ban,200,192.168.1.100,45,2026-02-26 10:30:00
```

**业务逻辑：**
1. 按筛选条件查询日志（不分页，但限制最大导出 10,000 条）
2. 超过 10,000 条时提示缩小筛选范围
3. 生成 CSV 文件流返回
4. 导出失败返回 5001（LOG_EXPORT_FAILED）

---

## 3. 错误码表

| 错误码 | 常量名 | 说明 | 触发场景 |
|--------|--------|------|---------|
| 5001 | LOG_EXPORT_FAILED | 日志导出失败 | CSV 生成异常或数据量超限 |

> 通用错误码（来自 common 模块）：1001（参数校验失败）
