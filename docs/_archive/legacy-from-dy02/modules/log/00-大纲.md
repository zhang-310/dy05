## 模块定位

log 模块负责操作日志记录，为系统提供审计追踪能力。通过 `@OperationLog` 注解 + AOP 自动记录用户的关键业务操作（谁、在什么时间、做了什么），供管理员查询和审计。

核心职责：
1. **自动记录** — 通过 @OperationLog 注解 + AOP 拦截器自动记录关键操作
2. **日志查询** — 按用户/时间/模块/操作类型筛选，支持分页
3. **日志导出** — CSV 格式导出，供离线审计
4. **只记不删** — 操作日志只追加，不允许删除和修改

> log 模块与 system 模块的区别：log 记录业务操作日志（用户行为审计），system 记录系统级技术日志（API 调用、数据同步）。

## 核心架构

```
┌─────────────────────────────────────────────────────────────┐
│                    log 模块 — 操作日志                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────────────────────────────────────┐          │
│  │            @OperationLog 注解 + AOP            │          │
│  │                                               │          │
│  │  @OperationLog(module="auth", operation="登录") │          │
│  │       ↓                                       │          │
│  │  OperationLogAspect（@Around）                 │          │
│  │       ↓                                       │          │
│  │  异步写入 sys_operation_log                     │          │
│  └───────────────────────────────────────────────┘          │
│                                                             │
│  ┌───────────────────────────────────────────────┐          │
│  │              日志查询与导出                      │          │
│  │                                               │          │
│  │  日志列表（分页筛选）                            │          │
│  │  日志详情                                      │          │
│  │  日志导出（CSV）                                │          │
│  └───────────────────────────────────────────────┘          │
│                                                             │
│  ┌───────────────────────────────────────────────┐          │
│  │              日志记录流程                        │          │
│  │                                               │          │
│  │  业务方法 → AOP 前置 → 执行方法 → AOP 后置      │          │
│  │       → 参数脱敏 → 异步写入数据库                │          │
│  └───────────────────────────────────────────────┘          │
└─────────────────────────────────────────────────────────────┘
```
