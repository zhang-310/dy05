## 7. 功能测试（Functional Test）

### 7.1 AOP 日志记录（F01-F06）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| F01 | 正常操作记录 | 执行带 @OperationLog 的方法 | 日志表新增记录，module/operation 正确 |
| F02 | 用户信息记录 | 登录用户执行操作 | userId/username 正确记录 |
| F03 | 请求参数记录 | recordParams=true 的操作 | requestParams 包含序列化参数 |
| F04 | 参数不记录 | recordParams=false 的操作 | requestParams 为 null |
| F05 | 异常记录 | 方法抛出异常 | errorMessage 记录异常信息，responseStatus=-1 |
| F06 | 耗时记录 | 执行操作 | durationMs > 0 |

### 7.2 参数脱敏（F07-F09）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| F07 | 密码脱敏 | 登录操作（含 password 参数） | requestParams 中 password 显示为 `***` |
| F08 | Token 脱敏 | 含 token 字段的操作 | requestParams 中 token 显示为 `***` |
| F09 | 超长参数截取 | 参数超过 2000 字符 | requestParams 截取为 2000 字符 + `...` |

### 7.3 日志查询（F10-F14）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| F10 | 分页查询 | page=0, rows=10 | 返回 <=10 条，total 正确 |
| F11 | 按用户筛选 | userId=1 | 只返回该用户的日志 |
| F12 | 按模块筛选 | module=auth | 只返回 auth 模块日志 |
| F13 | 按时间范围筛选 | startTime + endTime | 只返回时间范围内的日志 |
| F14 | 日志详情 | 查看某条日志 | 返回完整信息含 requestParams |

### 7.4 日志导出（F15-F16）

| # | 场景 | 操作 | 预期 |
|---|------|------|------|
| F15 | 正常导出 | 导出 100 条日志 | 下载 CSV 文件，内容正确 |
| F16 | 超量导出 | 筛选结果超过 10,000 条 | 提示缩小筛选范围 |

## 8. 边界测试（Boundary Test）

| # | 场景 | 输入 | 预期 |
|---|------|------|------|
| E01 | 未登录用户操作 | 白名单接口（如登录）带 @OperationLog | userId 为 null，仍正常记录 |

| E03 | 并发写入 | 多用户同时操作 | 日志全部正确记录，无丢失 |

## 10. 验收标准

### 10.1 功能验收

- [ ] @OperationLog 注解标记的方法执行后，sys_operation_log 表自动新增记录
- [ ] 日志记录包含正确的 userId/username/module/operation/method/ip/durationMs
- [ ] 敏感参数（password/token/secret）已脱敏为 `***`
- [ ] 异步写入不影响业务方法性能和异常处理
- [ ] 管理员可查看日志列表，支持分页和多条件筛选
- [ ] 管理员可查看日志详情（含完整请求参数）
- [ ] 管理员可导出日志为 CSV 文件

### 10.2 技术验收

- [ ] 所有接口返回 RESTResult 格式，包含 traceId
- [ ] 日志写入使用 @Async 异步执行
- [ ] 分页参数有上限校验（rows <= 1000）
- [ ] 导出上限 10,000 条
- [ ] 无 SQL 注入风险（sortName 正则校验）
