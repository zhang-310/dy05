## 2. 表结构（DDL）

### 2.1 sys_operation_log — 操作日志表

> Entity 对齐：`SysOperationLog.java`，无逻辑删除（日志表只追加不删除）

```sql
CREATE TABLE sys_operation_log (
    id                BIGSERIAL       PRIMARY KEY,
    user_id           BIGINT,
    username          VARCHAR(64),
    module            VARCHAR(64)     NOT NULL,
    operation         VARCHAR(128)    NOT NULL,
    method            VARCHAR(256),
    request_params    TEXT,
    response_status   INTEGER,
    ip                VARCHAR(64),
    user_agent        VARCHAR(512),
    duration_ms       BIGINT,
    error_message     TEXT,
    create_time       TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

-- 按用户+时间查询
CREATE INDEX idx_op_log_user_time ON sys_operation_log (user_id, create_time DESC);

-- 按模块+时间查询
CREATE INDEX idx_op_log_module_time ON sys_operation_log (module, create_time DESC);
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| id | BIGSERIAL | PK | 自增 | 主键 |
| user_id | BIGINT | | -- | 操作用户 ID（未登录操作可为空） |
| username | VARCHAR(64) | | -- | 用户名（冗余，方便查询） |
| module | VARCHAR(64) | NOT NULL | -- | 模块：auth / douyin / live / shortvideo / ai / storage / system |
| operation | VARCHAR(128) | NOT NULL | -- | 操作描述（如"用户登录""创建直播场次"） |
| method | VARCHAR(256) | | -- | 请求方法+路径（如 POST /api/v1/auth/login） |
| request_params | TEXT | | -- | 请求参数（脱敏后，不含密码等敏感信息） |
| response_status | INTEGER | | -- | 响应状态码（200=成功，其他为业务错误码） |
| ip | VARCHAR(64) | | -- | 操作 IP 地址 |
| user_agent | VARCHAR(512) | | -- | 浏览器 User-Agent |
| duration_ms | BIGINT | | -- | 方法执行耗时（毫秒） |
| error_message | TEXT | | -- | 异常信息（方法抛出异常时记录堆栈摘要） |
| create_time | TIMESTAMP | | CURRENT_TIMESTAMP | 操作时间 |

---

## 3. 索引设计说明

| 索引 | 类型 | 列 | 说明 |
|------|------|---|------|
| idx_op_log_user_time | B-tree | (user_id, create_time DESC) | 按用户查询操作日志，时间倒序 |
| idx_op_log_module_time | B-tree | (module, create_time DESC) | 按模块查询操作日志，时间倒序 |

> 日志表数据量会持续增长，两个复合索引覆盖最常用的查询场景。如后续数据量过大，可考虑按月分区。

---

## 4. Entity 注解说明

| Entity 类 | 表名 | @SQLRestriction | 说明 |
|-----------|------|-----------------|------|
| SysOperationLog | sys_operation_log | 无 | 日志表无逻辑删除，只追加不删除 |

> 日志表不使用 `@SQLRestriction`，不设 deleted 字段。符合 BR-01（只记不删）规则。

---

## 5. 数据增长预估

| 场景 | 日均记录数 | 月增长 | 说明 |
|------|-----------|--------|------|
| 初期（10 用户） | ~200 条 | ~6,000 条 | 每用户日均 20 次关键操作 |
| 中期（100 用户） | ~2,000 条 | ~60,000 条 | 索引可支撑 |
| 后期（1000+ 用户） | ~20,000 条 | ~600,000 条 | 考虑按月分区或归档 |
