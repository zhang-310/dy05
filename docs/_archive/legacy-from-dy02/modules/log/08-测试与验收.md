## 8.2 功能测试用例

### 8.2.1 AOP 日志记录

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T01 | 正常记录 | 调用带 @OperationLog 的接口，请求成功 | sys_operation_log 写入一条记录，response_status=200 |
| T02 | 用户信息记录 | 已登录用户调用接口 | user_id、username 字段正确填充 |
| T03 | 请求参数记录 | 调用带 RequestBody 的接口 | request_params 字段记录请求体 JSON |
| T04 | 无参数接口 | 调用无参数的 GET 接口 | request_params 为 null 或空字符串，不报错 |
| T05 | 异常记录 | 调用接口触发业务异常 | response_status=500，error_message 记录异常信息 |
| T06 | 耗时记录 | 调用耗时较长的接口 | duration_ms 字段值与实际耗时误差 < 50ms |

### 8.2.2 敏感字段脱敏

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T07 | password 脱敏 | 请求体含 password 字段 | request_params 中 password 值替换为 *** |
| T08 | token/secret 脱敏 | 请求体含 token、secret 字段 | 对应字段值均替换为 *** |
| T09 | 超长参数截断 | 请求体超过 2000 字符 | request_params 截断至 2000 字符，不丢失其他字段 |

### 8.2.3 日志查询

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T10 | 分页查询 | POST /api/v1/log/operation/list，page=1&size=20 | 返回 20 条记录，total 正确 |
| T11 | 按用户名筛选 | 传入 username=admin | 仅返回 username=admin 的记录 |
| T12 | 按模块筛选 | 传入 module=auth | 仅返回 module=auth 的记录 |
| T13 | 按时间范围筛选 | 传入 startTime、endTime | 仅返回该时间段内的记录 |
| T14 | 查询详情 | POST /api/v1/log/operation/get，传入有效 id | 返回完整日志记录，含 request_params、error_message |

### 8.2.4 日志导出

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T15 | 正常导出 | POST /api/v1/log/operation/export，传入筛选条件 | 返回 Excel 文件，数据与查询结果一致 |
| T16 | 超量导出 | 导出条数超过系统上限（如 10000 条） | 返回 5002 LOG_EXPORT_FAIL 错误，提示超出限制 |

### 8.2.5 边界与安全

| # | 用例 | 步骤 | 预期结果 |
|---|------|------|----------|
| T17 | 未认证访问 | 不携带 token 调用 /list 接口 | 返回 401 Unauthorized |
| T18 | 非管理员访问 | 非 admin 角色用户调用 /list 接口 | 返回 5001 LOG_QUERY_FORBIDDEN |
| T19 | 异步写入失败 | 模拟 logExecutor 线程池满载 | 主请求正常返回，日志写入失败不影响业务，错误写入应用日志 |
| T20 | 并发写入 | 100 个并发请求同时触发 @OperationLog | 100 条记录全部写入，无数据丢失，无死锁 |
| T21 | SQL 注入防护 | username 参数传入 `' OR '1'='1` | 返回空列表或正常结果，不执行注入语句 |

## 8.4 上线检查清单

- [ ] sys_operation_log 表已创建，索引已建立（user_id、create_time、module）
- [ ] 3 个 API 接口可访问（list / get / export）
- [ ] @OperationLog 注解已标注到所有需要记录的接口
- [ ] OperationLogAspect 切面正常拦截，异步写入 logExecutor 线程池
- [ ] 敏感字段脱敏（password / token / secret → ***）验证通过
- [ ] 超长参数截断（2000 字符）验证通过
- [ ] 权限校验：非管理员返回 5001，未认证返回 401
- [ ] 导出超量保护：超限返回 5002
- [ ] 异步写入失败不影响主业务链路
- [ ] 前端操作日志页面可正常访问
- [ ] 错误码返回正确（5001 LOG_QUERY_FORBIDDEN / 5002 LOG_EXPORT_FAIL）
