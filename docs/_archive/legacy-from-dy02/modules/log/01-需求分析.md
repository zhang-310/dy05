# log 模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1. 模块定位

log 模块负责操作日志记录，为系统提供审计追踪能力。记录用户的关键业务操作（谁、在什么时间、做了什么），供管理员查询和审计。

---

## 2. 功能清单

```
log 模块
├── 操作日志记录
│   ├── 自动记录关键操作（通过 @OperationLog 注解 + AOP）
│   ├── 记录请求参数（脱敏后）
│   ├── 记录响应状态和耗时
│   └── 异常信息记录
│
├── 日志查询
│   ├── 日志列表（按用户/时间/模块/操作类型筛选，分页）
│   └── 日志详情（完整请求参数和响应信息）
│
└── 日志导出
    └── CSV 格式导出（按筛选条件）
```

> **说明：** 操作日志只追加，不提供删除和修改接口。系统异常日志通过 error_message 字段记录，不单独建表。

---

## 3. 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| BR-01 | 只记不删 | 操作日志只追加，不允许删除和修改，保证审计完整性 |
| BR-02 | 自动记录 | 通过 @OperationLog 注解标记需要记录的方法，AOP 自动拦截记录 |
| BR-03 | 关键操作 | 需记录的操作：登录/注册/修改密码/角色变更/资源变更/封禁解封/账号绑定/视频同步/直播操作/AI 任务等 |

---

## 4. @OperationLog 注解设计

### 4.1 注解定义

```java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface OperationLog {

    /** 模块名称：auth / douyin / live / shortvideo / ai / storage / system */
    String module();

    /** 操作描述：如"用户登录""创建直播场次" */
    String operation();

    /** 是否记录请求参数，默认 true */
    boolean recordParams() default true;
}
```

### 4.2 使用示例

```java
// auth 模块 — 用户登录
@OperationLog(module = "auth", operation = "用户登录")
public LoginResultVO login(LoginVO vo) { ... }

// auth 模块 — 封禁用户（记录参数）
@OperationLog(module = "auth", operation = "封禁用户")
public void banUser(AuthUserBanVO vo) { ... }

// douyin 模块 — 绑定抖音账号
@OperationLog(module = "douyin", operation = "绑定抖音账号")
public void bindAccount(bindVO vo) { ... }

// storage 模块 — 上传文件（不记录参数，避免大文件参数）
@OperationLog(module = "storage", operation = "上传文件", recordParams = false)
public FileVO upload(MultipartFile file) { ... }
```

## 6. 模块依赖

```
auth 模块不依赖任何其他业务模块（它是被依赖的基础）

依赖关系：
common (config/vo/util/constant) ← log
auth (SecurityContext 获取当前用户) ← log
                                      ↑
                      所有业务模块通过 @OperationLog 使用 log
```

| 依赖方向 | 模块 | 依赖内容 |
|---------|------|---------|
| log → common | vo | RESTResult, BasicQueryDto, PageResultVO |
| log → common | util | 工具类 |
| log → auth | 认证 | SecurityContext（获取当前用户 userId/username） |
| 所有模块 → log | 注解 | @OperationLog 注解 + AOP 自动记录 |
