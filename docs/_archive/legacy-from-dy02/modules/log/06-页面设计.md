### 6.2.2 详情弹窗

```
┌──────────────────────────────────────────────────────┐
│  操作日志详情                                    [×]  │
├──────────────────────────────────────────────────────┤
│  ID          │ 5                                      │
│  用户ID       │ 1                                      │
│  用户名       │ admin                                  │
│  模块         │ ai                                     │
│  操作         │ 生成文案                                │
│  请求方法     │ POST /api/v1/ai/generate/copy          │
│  响应状态     │ 500                                    │
│  耗时         │ 1205 ms                                │
│  IP 地址      │ 192.168.1.101                          │
│  User-Agent  │ Mozilla/5.0 (Windows NT 10.0...)       │
│  操作时间     │ 2026-02-26 09:20:33                    │
├──────────────────────────────────────────────────────┤
│  请求参数                                             │
│  ┌────────────────────────────────────────────────┐  │
│  │ {                                              │  │
│  │   "accountId": 3,                              │  │
│  │   "theme": "春季护肤",                          │  │
│  │   "password": "***",                           │  │
│  │   "style": "种草"                              │  │
│  │ }                                              │  │
│  └────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────┤
│  错误信息                                             │
│  ┌────────────────────────────────────────────────┐  │
│  │ AI service timeout after 1200ms                │  │
│  └────────────────────────────────────────────────┘  │
├──────────────────────────────────────────────────────┤
│                                          [关闭]       │
└──────────────────────────────────────────────────────┘
```

说明：
- 请求参数中 password / token / secret 字段自动脱敏显示为 `***`
- 响应状态 200 显示绿色，4xx 显示橙色，5xx 显示红色
- 错误信息仅在 error_message 非空时展示该区块

## 6.3 组件复用

| 组件 | 使用页面 | 说明 |
|------|---------|------|
| StatusTag | 操作日志查询 | 响应状态码色标（200绿/4xx橙/5xx红） |
| DateRangePicker | 操作日志查询 | 时间范围选择器 |
| LogDetailModal | 操作日志查询 | 日志详情弹窗（含请求参数+错误信息） |
| ExportButton | 操作日志查询 | 导出 Excel 按钮（带加载状态） |
