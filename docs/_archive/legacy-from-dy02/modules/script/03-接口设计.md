## 3.2 关键接口详细设计

### 接口 5：文本违规检测

```
POST /api/v1/script/violation/check
权限：登录
```

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| text | String | 是 | 待检测文本 |
| scope | String | 是 | 适用场景：all / live / video |

> scope 说明：all=检测所有违规词；live=直播场景，匹配 scope=all + live_only；video=短视频场景，匹配 scope=all + video_only

响应示例：

```json
{
  "status": 200,
  "data": {
    "hasViolation": true,
    "totalCount": 3,
    "violations": [
      {
        "word": "最好的",
        "position": 15,
        "length": 3,
        "category": "ad_law",
        "level": "forbidden",
        "scope": "all",
        "replacement": "非常好的",
        "description": "广告法禁止使用绝对化用语",
        "source": "public"
      },
      {
        "word": "秒杀全网",
        "position": 45,
        "length": 4,
        "category": "platform",
        "level": "warning",
        "scope": "all",
        "replacement": "优惠力度大",
        "source": "public"
      },
      {
        "word": "微信",
        "position": 80,
        "length": 2,
        "category": "platform",
        "level": "warning",
        "scope": "all",
        "replacement": "私信",
        "source": "user"
      }
    ]
  }
}
```

业务逻辑：

1. 加载公共违规词库（Caffeine 缓存，5 分钟 TTL）
2. 加载用户个人违规词库（无缓存，直接查询）
3. 按 scope 过滤违规词
4. 合并两个词库（同一词取更高等级）
5. 遍历文本，对每个违规词做字符串包含匹配（不区分大小写）
6. 记录匹配到的位置、等级、替换建议、来源
7. 返回结果

### 接口 6：批量文本违规检测

```
POST /api/v1/script/violation/check-batch
权限：登录
```

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| texts | List\<TextItem\> | 是 | 待检测文本列表 |
| texts[].key | String | 是 | 文本标识（如 "opening"、"product_1"） |
| texts[].text | String | 是 | 文本内容 |
| scope | String | 是 | 适用场景：all / live / video |

响应示例：

```json
{
  "status": 200,
  "data": {
    "results": {
      "opening": {
        "hasViolation": false,
        "violations": []
      },
      "product_1": {
        "hasViolation": true,
        "violations": [
          {
            "word": "最好的",
            "position": 10,
            "length": 3,
            "category": "ad_law",
            "level": "forbidden",
            "replacement": "非常好的",
            "source": "public"
          }
        ]
      }
    },
    "totalViolations": 1
  }
}
```

> 批量检测复用单文本检测逻辑，词库只加载一次，对每段文本分别匹配。

| 字段 | 类型 | 必填 | 说明 |

| personaId | Long | 否 | 关联人设 ID |
| style | String | 否 | 风格 |
| durationHint | String | 否 | 建议时长 |

### 接口 18：批量导入违规词（CSV）

```
POST /api/v1/script/admin/violation/import
权限：管理员
Content-Type: multipart/form-data
```

请求参数：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| file | MultipartFile | 是 | CSV 文件 |

CSV 格式：

```csv
word,category,level,scope,replacement,description
最好的,ad_law,forbidden,all,非常好的,广告法禁止使用绝对化用语
```

响应示例：

```json
{
  "status": 200,
  "data": {
    "imported": 45,
    "skipped": 5,
    "total": 50
  }
}
```

> 导入策略：逐行处理，word 已存在的行跳过（不报错），不存在的行插入。

## 3.3 错误码表

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| 50001 | 话术不存在 | 查询/编辑/删除不存在的话术 |
| 50002 | 话术不属于当前用户 | 操作他人话术 |
| 50003 | 违规词不存在 | 查询/编辑/删除不存在的违规词 |
| 50004 | 违规词已存在 | 新增重复违规词 |
| 50005 | 模板不存在 | 查询/编辑/删除不存在的模板 |
| 50006 | 模板不属于当前用户 | 操作他人个人模板 |
| 50007 | 无权操作系统模板 | 非管理员操作系统模板 |
| 50008 | CSV 格式错误 | 导入文件格式不正确 |
| 50009 | 检测文本为空 | 违规检测时未传入文本 |
| 50010 | scope 参数无效 | scope 不是 all/live/video |
