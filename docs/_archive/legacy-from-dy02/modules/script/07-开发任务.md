# script 模块 — 开发任务

> 版本：3.0 | 更新日期：2026-02-26

---

## 7.1 后端任务

### P0 — 基础设施

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B01 | 编写 SQL | schema.sql + demo.sql（含默认违规词） | 无 |
| B02 | Entity 层 | ScScript, ScViolationWord, ScUserViolationWord, ScScriptTemplate | B01 |
| B03 | Repository 层 | 4 个 JpaRepository | B02 |
| B04 | VO 层 | ScriptSaveVO, ViolationCheckVO, ViolationResultVO 等 | B02 |

### P1 — 核心服务

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B05 | ScScriptService | 话术 CRUD、搜索、分页 | B03, B04 |
| B06 | ScViolationService | 违规检测（合并公共+个人库、scope 过滤、文本匹配、Caffeine 缓存） | B03, B04 |
| B07 | ScViolationAdminService | 公共违规词 CRUD、CSV 导入导出 | B03, B04 |

### P2 — 接口层

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B08 | ScScriptController | 话术库 4 个接口（#1~#4） | B05 |
| B09 | ScViolationController | 违规检测 2 个 + 公共违规词 1 个 + 个人违规词 3 个接口（#5~#10） | B06 |
| B10 | ScTemplateController | 话术模板 4 个接口（#11~#14） | B05 |
| B11 | ScAdminController | 管理端 8 个接口（#15~#22） | B07 |

### P3 — 收尾

| # | 任务 | 输出 | 依赖 |
|---|------|------|------|
| B12 | resource-data.sql | script 模块资源注册 + 角色绑定 | B11 |

## 7.2 前端任务

| # | 任务 | 依赖 | 说明 |
|---|------|------|------|
| F01 | 话术库页面 | B08 | 话术列表+新增/编辑弹窗+搜索筛选 |
| F02 | 违规词库页面 | B09 | 公共库浏览（Tab1）+个人库管理（Tab2） |
| F03 | 违规检测页面 | B09 | 文本输入+场景选择+检测结果展示+一键替换 |
| F04 | 公共违规词管理（管理端） | B11 | 违规词 CRUD+CSV 导入导出 |
| F05 | 话术模板管理（管理端） | B11 | 系统模板 CRUD |
