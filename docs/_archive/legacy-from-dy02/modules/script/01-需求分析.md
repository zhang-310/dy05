# script 模块 — 需求分析

> 版本：3.0 | 更新日期：2026-02-26

---

## 1.1 模块定位

script 模块是话术和违规管理的基础服务，为 live 模块和 shortvideo 模块提供：话术库、违规词库、违规检测服务。

产品数据来自 douyin 模块，AI 替换建议来自 ai 模块，用户认证来自 auth 模块。

---

| 编号 | 角色 | 故事 | 验收条件 |
|------|------|------|----------|
| **话术库** | | | |

| **违规词库** | | | |
| SC-04 | 主播/达人 | 我要能查看公共违规词库 | 浏览公共违规词、了解违规等级和分类 |

| **管理端** | | | |

## 1.3 功能清单

```
script 模块
├── 话术库（用户私有）
│   ├── 话术 CRUD
│   ├── 话术分类（opening/product/transition/closing/general/interaction）
│   ├── 话术标签（自定义标签）
│   ├── 话术搜索（关键词+分类+标签）
│   ├── 话术收藏（从直播/AI生成中保存）
│   └── 话术列表（分页）
│
├── 违规词库
│   ├── 公共违规词库（平台级）
│   │   ├── 违规词 CRUD
│   │   ├── 违规分类（ad_law/platform/sensitive/vulgar）
│   │   ├── 违规等级（forbidden/warning/suggest）
│   │   ├── 适用范围（all/live_only/video_only）
│   │   ├── 替换建议（每个违规词可配置推荐替换词）
│   │   └── 批量导入/导出（CSV）
│   │
│   └── 个人违规词库（用户私有）
│       ├── 违规词 CRUD
│       ├── 自定义替换建议
│       └── 与公共库合并检测
│
├── 违规检测服务
│   ├── 单文本违规扫描（返回违规词+位置+等级+替换）
│   ├── 批量文本检测（整场直播话术一键检测）
│   └── AI 替换建议（调用 ai 模块推荐合规替代表达）
│
└── 话术模板
    ├── 系统预设话术模板 CRUD（管理员维护）
    ├── 个人话术模板 CRUD（用户从话术库保存）
    ├── 按行业/场景分类
    └── 从模板创建话术
```

## 1.4 业务规则

| 编号 | 规则 | 说明 |
|------|------|------|
| **违规检测** | | |
| BR-01 | 违规检测合并 | 检测时同时匹配公共库和用户个人库 |
| BR-02 | 违规等级优先 | 同一词在公共库和个人库都有时，取更高等级 |
| BR-06 | 违规词匹配 | 使用字符串包含匹配，不区分大小写 |
| BR-07 | 违规词适用范围 | 违规词按 scope 区分：all / live_only / video_only。检测时调用方传入场景类型进行过滤 |
| BR-08 | 直播场景检测 | 直播话术检测时匹配 scope=all 和 scope=live_only 的违规词 |
| BR-09 | 短视频场景检测 | 短视频文案检测时匹配 scope=all 和 scope=video_only 的违规词 |
| BR-13 | 违规词匹配策略 | 使用字符串包含匹配（LIKE），不区分大小写。PostgreSQL 使用 pg_trgm 扩展加速 ILIKE 查询 |
| **缓存策略** | | |
| BR-10 | 公共库缓存策略 | 公共违规词库 Caffeine 缓存 TTL=5 分钟。管理员修改公共库时不主动刷新缓存（等 TTL 自动过期），因修改频率低 |
| BR-11 | 个人库无缓存 | 个人违规词库不缓存（数据量小，直接查数据库），添加/修改后立即生效 |
| **数据管理** | | |
| BR-03 | 公共库只读 | 达人（talent）和机构（institution）只能浏览公共违规词库，不能修改 |
| BR-04 | 话术数据隔离 | talent 只能看到自己的话术库（owner_id）；institution 可查看自己+旗下达人的话术（DataScopeService）；admin 可查看全部 |
| BR-05 | 话术来源标记 | 话术记录来源：manual（手动创建）/ live（从直播保存）/ ai（AI 生成） |
| BR-12 | 批量导入策略 | CSV 批量导入采用"跳过重复"策略：逐行处理，word 已存在的行跳过（不报错），不存在的行插入。完成后返回导入成功数 + 跳过数 |

## 1.5 模块依赖

```
依赖关系：
auth ← script（用户认证、owner_id 数据隔离）

被依赖关系（script 作为基础服务）：
live       → script（话术库复用、违规检测）
shortvideo → script（违规检测）
ai         → script（AI 替换建议）
```

| 依赖模块 | 依赖内容 | 方向 |
|---------|---------|------|
| auth | 用户认证、owner_id | script 依赖 auth |
| live | 话术库复用、违规检测、高效话术入库 | live 依赖 script |
| shortvideo | 文案违规检测 | shortvideo 依赖 script |
| ai | AI 替换建议 | ai 依赖 script |
