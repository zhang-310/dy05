## 2.2 表结构 DDL

### sc_script — 话术表（用户私有）

```sql
CREATE TABLE sc_script (
    id              BIGSERIAL       PRIMARY KEY,
    owner_id        BIGINT          NOT NULL,
    title           VARCHAR(128)    NOT NULL,
    content         TEXT            NOT NULL,
    category        VARCHAR(32),
    tags            VARCHAR(512),
    source          VARCHAR(16)     DEFAULT 'manual',
    source_id       BIGINT,
    persona_id      BIGINT,
    style           VARCHAR(64),
    duration_hint   VARCHAR(32),
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP
);

COMMENT ON TABLE  sc_script IS '用户话术库';
COMMENT ON COLUMN sc_script.owner_id IS '所属用户 ID';
COMMENT ON COLUMN sc_script.title IS '话术标题';
COMMENT ON COLUMN sc_script.content IS '话术内容';
COMMENT ON COLUMN sc_script.category IS '分类：opening/product/transition/closing/general/interaction';
COMMENT ON COLUMN sc_script.tags IS '标签（JSON 数组）';
COMMENT ON COLUMN sc_script.source IS '来源：manual（手动创建）/live（从直播保存）/ai（AI 生成）';
COMMENT ON COLUMN sc_script.source_id IS '来源 ID（如直播场次 ID）';
COMMENT ON COLUMN sc_script.persona_id IS '关联的人设 ID';
COMMENT ON COLUMN sc_script.style IS '风格';
COMMENT ON COLUMN sc_script.duration_hint IS '建议时长';
COMMENT ON COLUMN sc_script.deleted IS '逻辑删除：0=正常 1=已删除';
```

### sc_violation_word — 公共违规词表

```sql

    category        VARCHAR(32)     NOT NULL,

    scope           VARCHAR(16)     NOT NULL DEFAULT 'all',
    replacement     VARCHAR(256),
    description     VARCHAR(256),
    status          INTEGER         NOT NULL DEFAULT 1,
    deleted         INTEGER         NOT NULL DEFAULT 0,
    create_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP       DEFAULT CURRENT_TIMESTAMP

COMMENT ON COLUMN sc_violation_word.level IS '等级：forbidden（禁止）/warning（警告）/suggest（建议修改）';
COMMENT ON COLUMN sc_violation_word.scope IS '适用范围：all（全场景）/live_only（仅直播）/video_only（仅短视频）';
COMMENT ON COLUMN sc_violation_word.replacement IS '推荐替换词';
COMMENT ON COLUMN sc_violation_word.description IS '说明（为什么违规）';
COMMENT ON COLUMN sc_violation_word.status IS '状态：1=启用 0=禁用';
COMMENT ON COLUMN sc_violation_word.deleted IS '逻辑删除：0=正常 1=已删除';
```

## 2.3 索引设计

| 表 | 索引 | 类型 | 说明 |
|----|------|------|------|
| sc_script | `(owner_id, category, create_time DESC) WHERE deleted=0` | B-Tree 部分索引 | 用户话术列表查询 |
| sc_violation_word | `(word) WHERE deleted=0 AND status=1` | B-Tree 部分索引 | 违规词精确查找 |
| sc_violation_word | `(category, level) WHERE deleted=0` | B-Tree 部分索引 | 按分类+等级筛选 |
| sc_violation_word | `(scope) WHERE deleted=0 AND status=1` | B-Tree 部分索引 | 按适用范围过滤 |
| sc_violation_word | `GIN(word gin_trgm_ops) WHERE deleted=0 AND status=1` | GIN (pg_trgm) | 加速 ILIKE 模糊匹配 |
| sc_user_violation_word | `(owner_id, word) WHERE deleted=0` | B-Tree 部分索引 | 用户个人违规词查询 |
| sc_script_template | `(template_type, category, industry_id) WHERE deleted=0` | B-Tree 部分索引 | 模板列表筛选 |
| sc_script_template | `(owner_id, create_time DESC) WHERE deleted=0` | B-Tree 部分索引 | 个人模板列表 |

索引创建 SQL：

```sql
-- pg_trgm 扩展（需超级用户执行一次）
CREATE EXTENSION IF NOT EXISTS pg_trgm;

-- sc_script
CREATE INDEX idx_sc_script_owner_category
    ON sc_script (owner_id, category, create_time DESC)
    WHERE deleted = 0;

-- sc_violation_word
CREATE INDEX idx_sc_vw_word
    ON sc_violation_word (word)
    WHERE deleted = 0 AND status = 1;

CREATE INDEX idx_sc_vw_category_level
    ON sc_violation_word (category, level)
    WHERE deleted = 0;

CREATE INDEX idx_sc_vw_scope
    ON sc_violation_word (scope)
    WHERE deleted = 0 AND status = 1;

CREATE INDEX idx_sc_vw_word_trgm
    ON sc_violation_word USING GIN (word gin_trgm_ops)
    WHERE deleted = 0 AND status = 1;

-- sc_user_violation_word
CREATE INDEX idx_sc_uvw_owner_word
    ON sc_user_violation_word (owner_id, word)
    WHERE deleted = 0;

-- sc_script_template
CREATE INDEX idx_sc_tpl_type_category
    ON sc_script_template (template_type, category, industry_id)
    WHERE deleted = 0;

CREATE INDEX idx_sc_tpl_owner
    ON sc_script_template (owner_id, create_time DESC)
    WHERE deleted = 0;
```
