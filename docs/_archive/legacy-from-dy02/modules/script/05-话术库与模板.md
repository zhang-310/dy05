> 版本：3.0 | 更新日期：2026-02-26

## 5.1 话术库设计

### 5.1.1 核心功能

| 功能 | 说明 |
|------|------|
| 话术 CRUD | 创建、查看、编辑、删除话术 |
| 分类管理 | opening / product / transition / closing / general / interaction |
| 标签管理 | 自定义标签（JSON 数组存储） |
| 搜索 | 关键词（标题+内容）+ 分类筛选 + 标签筛选 |
| 收藏 | 从直播/AI 生成中保存到话术库 |
| 分页列表 | 按创建时间倒序，支持分页 |

### 5.1.2 话术分类体系

| 分类 | 编码 | 说明 | 典型场景 |
|------|------|------|---------|
| 开场 | opening | 直播开场白、视频开头 | "大家好，欢迎来到直播间..." |
| 产品讲解 | product | 产品介绍、卖点讲解 | "这款面霜的核心成分是..." |
| 转场 | transition | 产品切换过渡 | "接下来给大家介绍另一款..." |
| 结尾 | closing | 直播结尾、视频结尾 | "感谢大家的陪伴..." |
| 通用 | general | 不限场景的通用话术 | "感谢关注，持续分享好物" |
| 互动 | interaction | 互动引导话术 | "觉得不错的朋友点个赞..." |

## 5.2 话术来源标记

### 5.2.1 来源类型（source）

| 来源 | 编码 | 说明 | 触发方式 |
|------|------|------|---------|
| 手动创建 | manual | 用户在话术库页面手动创建 | 话术库页面 → 新增话术 |
| 直播保存 | live | 从直播话术中保存到话术库 | live 模块 → 保存到话术库 |
| AI 生成 | ai | AI 生成的话术保存到话术库 | AI 生成 → 保存到话术库 |

### 5.2.2 来源关联

```
┌──────────────┐     source=live      ┌──────────────┐
│  live 模块    │ ──────────────────→  │  sc_script   │
│  直播话术     │     source_id=       │  话术库       │
│              │     session_id       │              │
└──────────────┘                      └──────────────┘

┌──────────────┐     source=ai        ┌──────────────┐
│  ai 模块      │ ──────────────────→  │  sc_script   │
│  AI 生成话术  │     source_id=       │  话术库       │
│              │     ai_call_log_id   │              │
└──────────────┘                      └──────────────┘
```

- `source_id` 记录来源的关联 ID，便于溯源
- 手动创建的话术 `source_id` 为空

## 5.3 话术与人设的关联

```
┌──────────────┐     persona_id       ┌──────────────┐
│ douyin 模块   │ ←─────────────────── │  sc_script   │
│ DouyinPersona│                      │  话术库       │
│  人设信息     │                      │              │
└──────────────┘                      └──────────────┘
```

- 话术可关联一个人设（persona_id），表示该话术是为特定人设风格创建的
- 搜索时可按人设筛选，快速找到匹配的话术
- 人设关联是可选的，不强制要求

## 5.4 话术模板系统

### 5.4.1 模板类型

| 类型 | 编码 | owner_id | 维护者 | 说明 |
|------|------|----------|--------|------|
| 系统预设 | system | NULL | 管理员 | 平台提供的标准话术模板 |
| 个人模板 | user | 用户 ID | 用户 | 用户从话术库保存的个人模板 |

### 5.4.2 模板属性

| 属性 | 说明 |
|------|------|
| template_name | 模板名称 |
| content | 模板内容 |
| category | 分类（与话术分类一致） |
| industry_id | 行业 ID（关联 sys_industry） |
| style | 风格（亲切/激情/专业等） |
| tags | 标签 |
| use_count | 使用次数（每次从模板创建话术时 +1） |
| sort_order | 排序（系统模板用，控制展示顺序） |

### 5.4.3 系统预设模板示例

| 模板名称 | 分类 | 行业 | 风格 |
|---------|------|------|------|
| 美妆直播开场白 | opening | 美妆 | 亲切 |
| 食品产品讲解 | product | 食品 | 专业 |
| 服装转场过渡 | transition | 服装 | 活泼 |
| 通用直播结尾 | closing | 通用 | 温暖 |
| 互动引导话术 | interaction | 通用 | 热情 |

## 5.6 话术收藏和复用机制

### 5.6.1 收藏入口

| 入口 | 来源模块 | source 值 | source_id |
|------|---------|-----------|-----------|
| 直播话术保存 | live | live | session_id |
| AI 生成保存 | ai | ai | ai_call_log_id |

### 5.6.2 复用出口

| 出口 | 目标模块 | 说明 |
|------|---------|------|

## 5.7 与 live 模块的集成

### 5.7.1 高效话术自动入库

```
┌──────────────┐                      ┌──────────────┐
│  live 模块    │                      │  script 模块  │
│              │                      │              │
│ 话术效果归因  │  effectiveness > 80  │  sc_script   │
│ effectiveness │ ──────────────────→  │  source=live │
│ _score       │     自动入库          │  话术库       │
└──────────────┘                      └──────────────┘
```

- live 模块在话术效果归因后，将高效话术（effectiveness_score > 80）自动保存到 script 模块的话术库
- source=live，source_id=session_id
- 用户可在话术库中查看和复用这些高效话术

### 5.7.2 违规检测集成

```
┌──────────────┐     check API        ┌──────────────┐
│  live 模块    │ ──────────────────→  │  script 模块  │
│  话术生成     │ ←────────────────── │  违规检测      │
│              │     violations       │  scope=live   │
└──────────────┘                      └──────────────┘
```

- live 模块生成话术后，调用 script 模块的违规检测接口（scope=live）
- 返回违规词列表，前端标红显示，提供替换建议
