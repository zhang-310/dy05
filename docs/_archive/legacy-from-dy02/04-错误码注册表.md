# 错误码注册表

> 版本：3.1 | 更新日期：2026-02-26
> 后端常量类：`cn.gaifan.douyinOperations.common.constant.ErrorCode`

---

## 规则

- 错误码为整数，按模块分段
- 200 = 成功
- 每个模块占用一个号段（100 个码位），新模块在此文档末尾追加
- 前端按 `status` 字段做条件判断，`message` 直接展示给用户
- 常量名全大写、下划线分隔，前缀为模块缩写

### 号段分配总览

| 号段 | 模块 | 说明 |
|------|------|------|
| 200 | — | 成功 |
| 1000-1099 | 系统 | 参数校验、系统异常、频率限制 |
| 2000-2099 | auth | 认证与鉴权 |
| 3100-3199 | douyin | 抖音账号 + 人设 + 产品 |
| 3200-3299 | shortvideo | 短视频 |
| 3300-3399 | live | 直播 |
| 3400-3499 | script | 话术 + 违规词 |
| 3500-3599 | copy | 文案库 + 审批 + 模板 |
| 3600-3699 | config | 系统配置 + 行业分类 |
| 3700-3799 | storage | 文件存储 |
| 3800-3899 | system | API 调用日志 + 同步日志 + 系统健康 |
| 3900-3999 | wecom | 企业微信对接 |
| 4000-4099 | ai | AI 知识库 + 生成 + 进化引擎 + 基础设施（Milvus/ES/Redis/RabbitMQ） |
| 4100-4199 | agent | AI 智能体 |
| 4200-4299 | abtest | A/B 测试实验 |

## 追加新错误码流程

1. 在本文档对应模块段中追加行
2. 同步到 `ErrorCode.java` 中增加常量
3. 提交时一起提交文档和代码
4. 每个号段预留 100 个码位，段内顺序递增
