### 1.3 价格/规格解析规则

- **纯数字**：如 `8`, `10`, `18` → 售价 8/10/18 元
- **带换行规格**：如 `39.9\n1水80ml+1乳80ml` → 售价 39.9 元，规格放 description
- **复合描述**：如 `玖美堂39.9 30%无赠品\nhttps://...` → 取第一个数字 39.9
- **带单位**：如 `76.9+礼品袋` → 取 76.9

## 2. 与 dy_product 表结构对比

### 2.1 字段映射

| dy_product 字段 | Excel 来源 | 映射规则 |
|-----------------|------------|----------|
| product_name | C 列（商品名称） | 直接映射 |
| sku | B 列（SKU） | 直接映射 |
| price | E 列（价格/规格） | 解析第一个数字为售价 |
| product_category | A 列（分类） | K/B/C/R 等 → 可映射为 category，或放 tags |
| profit_margin_pct | F 列（正数） | 利润百分比，如 0.45=45% |
| loss_per_unit | F 列（负数） | 每单亏损金额（元），如 8 |
| control_strategy | O 列（控库存） | 控3单、不控单1分钟下、控单憋单 等，拍品千次/密度成交策略 |
| description | E 规格 + 备注 + 效期 + 链接 | 拼接：规格、效期、备注、推广链接 |
| tags | A 列 + 品类关键词 | 如 "套盒,护肤品,直播" |
| cost_price | — | Excel 无，可留空 |
| image_url | 嵌入图片 | xlsx 中嵌入的图片会提取并上传到 BOS，按行关联到产品（需配置 BOS） |
| inventory | — | Excel 无库存数，可 0 |
| barcode | — | Excel 无 |
| manufacturer | — | Excel 无，可从名称提取品牌 |
| status | — | 默认 1（上架） |
| featured | — | 默认 0 |

### 2.2 Excel 有但 dy_product 无的字段

| Excel 字段 | 建议处理 |
|------------|----------|
| 佣金/比例 (F 列) | profit_margin_pct（正数）或 loss_per_unit（负数） |
| 控库存 (O 列) | control_strategy，拍品千次成交/密度成交关键策略 |
| 线上1/2/3、线下1/2/3 链接 | 放入 description，供运营查阅 |

| 效期 | 并入 description，如 "效期9个月" |

### 2.3 扩展建议（可选）

若需在系统内完整保留排品表能力，可考虑：

1. **dy_product 扩展**：新增 `promotion_links TEXT` 存 JSON `{ "online1": "url", "online2": "url", ... }`
2. **或新建 dy_product_paiping**：排品专属表，与 dy_product 一对一关联
3. **当前方案**：将链接、控库存、效期、备注全部拼入 `description`，满足导入与话术生成需求

## 3. 直播话术对接流程

```
Excel 排品表
    ↓ 导入脚本
dy_product（产品库）
    ↓ 直播场次选品
live_session_product（场次-产品关联）
    ↓ AI 生成 / 人工编辑
live_session_script（场次话术）
```

### 3.1 导入后使用步骤

1. **导入产品**：商品管理页 → 点击「导入排品表」→ 选择 `paiping-260303.xlsx`（或同格式 Excel）
2. **创建/选择场次**：直播 → 话术构建 → 选择场次
3. **从商品库添加**：点击「从商品库添加」，勾选导入的护肤品
4. **生成话术**：对每个产品槽位使用 AI 写作助手生成话术，或一键生成整场

**导入 API**：`POST /api/v1/product/import-paiping`，multipart/form-data，字段 `file`。返回 `{ total, success, fail }`。  
同 SKU 产品会更新而非新增（按 userId+sku 去重）。

**嵌入图片**：xlsx 中的产品图片会按行提取并上传到**本系统百度云 BOS**（路径 `{userId}/product/paiping/{sku}.png`），与存储模块共用 `storage.bos.*` 配置。.xls 格式不支持图片提取。

### 3.2 产品类型定义与映射

| Excel 分类 | 含义 | 佣金特征 | 直播 product_type |
|------------|------|----------|-------------------|
| **B** | 爆款品（卖得多） | 1%~60%，有微利也有高利 | hot |
| **R** | 利润品 | 35%~42%，高利润 | profit |
| **F** | 福利品 | 50% 等 | flat |
| **C** | 福利品 | 36%~51% | flat |
| **K** | 亏品套盒（引流） | 每单亏 5~17 元 | loss |

**规则**：高于 30% 佣金 = 利润品。**其他**（面膜、面霜、空等）按利润推断：亏单→K，≥30%→R，否则→B。

**爆款品细分**（本表大数据分析）：
- **微利润爆款**（0~30%）：10 个，如 1%、8%、13%、23% — 走量、拉 GMV
- **高利润爆款**（≥30%）：10 个，如 31%、40%、53%、60% — 既走量又赚钱

### 3.3 直播间类型：过品直播间

**此直播间为过品直播间**。

| 类型 | 特点 |
|------|------|
| **过品直播间** | 多品轮换、快速过品，控单/憋单做千次成交、密度成交 |
| **仓播直播间** | 仓库/库存清仓，单品深度讲解、长停留 |

## 4. 每一项数据说明

### 4.1 分类 (A 列)

- **B 爆款品**：卖得多，佣金 1%~60%，含微利润爆款(0~30%)与高利润爆款(≥30%)
- **R 利润品**：高利润，佣金 35%~42%
- **F/C 福利品**：福利/引流，佣金 36%~51%
- **K 亏品套盒**：引流亏品，每单亏 5~17 元，致朵/蜂壳等套盒 8~25 元
- **面膜/面霜/水/洗面奶**：按品类区分

### 4.2 价格/规格 (E 列)

- 低价引流：8~20 元（套盒、小样）
- 中价：39.9~79.9 元（水乳、精华）
- 高价：155~199 元（自然堂、礼盒）

### 4.3 佣金/比例 (F 列)

- **正数（百分比）**：0.01~0.53，表示利润百分比（1%~53%）
- **负数**：-5 ~ -14，表示每单亏多少钱（元）

### 4.4 链接列 (G~N)

- 抖音联盟 `alliance.jinritemai.com`
- 好货 `haohuo.jinritemai.com`
- 不同主播/渠道对应不同链接

### 4.5 控库存/控单策略 (O 列)

针对拍品实现**千次成交**（GMV/千次观看）、**密度成交**的关键战略策略：

- `3单`、`1单`：控单数量，限制放单节奏
- `不控单1分钟下`：不控单，1 分钟下架，快速过品
- `控单`、`控单憋单`、`不过品憋单`：憋单拉停留、控节奏

### 4.6 效期 (R 列)

- `9个月效期`、`1年1个月效期`：保质期，影响话术合规（不可宣称「永久」等）

## 5. 总结

| 维度 | Excel | dy_product | 处理方式 |
|------|-------|------------|----------|
| 商品名 | ✓ | ✓ | 直接映射 |
| SKU | ✓ | ✓ | 直接映射 |
| 价格 | 复杂格式 | 单一数字 | 解析首数字 |
| 分类 | B/R/F/C/K | product_category | 爆款/利润/福利/亏品 |
| 利润 | F 列 | profit_margin_pct / loss_per_unit | 正数=利润%，负数=亏元 |
| 控单策略 | O 列 | control_strategy | 千次/密度成交策略 |
| 规格/效期/链接 | ✓ | description | 拼入 |

导入后产品可正常参与直播选品与 AI 话术生成。**高于 30% 佣金视为利润品**。
