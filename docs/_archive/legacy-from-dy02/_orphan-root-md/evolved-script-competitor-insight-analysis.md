# evolved_script 和 competitor_insight 内容分析

## 统计时间
2026-04-04

## 一、evolved_script（进化话术片段）

### 基本信息
- **总数量**: 1,306 条
- **时间范围**: 2026-03-09 ~ 2026-04-04（持续更新）
- **标题**: 统一为"话术片段"
- **内容长度**: 约 900-1,200 字符

### 内容特点

#### 1. 结构化话术片段
每个文档包含 5-6 个场景化话术片段，格式为：
```
## 话术片段

- **（场景标签）** "具体话术内容..."
  *适用场景：使用说明*

- **（场景标签）** "具体话术内容..."
  *适用场景：使用说明*

...

## 使用建议
- **数字必须真实**: ...
- **讲解如分享**: ...
```

#### 2. 场景分类标签

**开场类**:
- 开场留人-共鸣引入
- 开场热场-知识分享

**产品讲解类**:
- 产品卖点-成分科学
- 产品卖点-技巧结合
- 产品讲解-机理剖析

**互动促单类**:
- 互动促单-数据量化
- 互动促单-场景化急救
- 互动促单-稀缺营造

**价值升华类**:
- 价值升华-理念传达
- 价值升华-理念共鸣

**收尾类**:
- 收尾预告
- 结束预告-锁定关注

#### 3. 话术示例

**示例 1: 开场留人**
```
"直播间有没有姐妹跟我以前一样，护肤品买了一大堆，瓶瓶罐罐用了不少，
但皮肤就是没什么起色？不是产品没用，很可能是你的皮肤'大门'没打开，
营养根本吃！不！进！去！今天别走，我分享几个亲测有效的'开胃'小秘诀，
让你手上的护肤品效果翻倍，这才是真正的把钱花在刀刃上！"
```

**示例 2: 产品卖点-成分科学**
```
"很多姐妹问我这个精华凭什么卖这个价，来，我给你们算笔实在账。
它核心是这个纯度高达99.8%的烟酰胺，市面上很多产品含量只有2%-3%，
而我们直接加到了5%的黄金浓度，这一瓶30ml，光是这个原料成本就要占掉一大块。
加上我们为了温和性做的缓释技术，确保你敏肌都能用。我们品牌方去年光在这个
配方上就测试了超过1000名亚洲肤质的志愿者，数据报告我直播后可以发粉丝群。
这不是一瓶简单的精华，这是一份经过千人验证的'安心白'方案。"
```

**示例 3: 互动促单-稀缺营造**
```
"运营老师刚刚跟我确认，后台库存真的已经飘红了！我们今天备的500组
正装加赠品套装，现在屏幕右下角显示，只剩下最后47组！注意，这47组是今天，
甚至可能是这个月最后一次这个赠品力度。刚刚扣了'1'说想要但还没下单的宝宝，
不要再犹豫了，护肤最怕的就是'等一等'，好价格和好皮肤一样，都是抢出来的！"

**示例 4: 价值升华**
```
"今天大家抢到的，不仅仅是一瓶精华，更是一套正确的护肤思路。
我们护肤，不是要把十层八层的东西糊在脸上，而是要像交朋友一样，
了解皮肤真正需要什么，然后精准地、有效地去给予。希望这瓶精华带给你的，
不仅是皮肤的改变，更是一种'少即是多'的从容和自信。"

#### 4. 使用建议（每个文档都包含）

**数据真实性**:
- "话术中所有具体数字（如剩余库存、倒计时、成分百分比、测试人数等）
  在口播前必须与后台运营实时核对，这是建立直播间信任的绝对底线。"

**语气节奏**:
- "在讲述产品机理、护肤技巧或生活痛点时，请放慢语速，使用如同与闺蜜
  交谈般自然、真诚的语气，将'讲解'转化为'分享'。"

### 内容质量分析

#### 优点
1. **场景化强**: 每个话术片段都有明确的使用场景标签
2. **结构完整**: 覆盖直播全流程（开场→讲解→促单→收尾）
3. **实战性强**: 包含具体数字、话术技巧、语气指导
4. **专业度高**: 强调数据真实性、信任建立
5. **可复用性**: 标准化格式便于检索和应用

#### 特点
1. **行业聚焦**: 主要针对美妆护肤品类
2. **风格统一**: 闺蜜式分享、知识科普、信任建立
3. **技巧丰富**: 包含比喻、数据量化、场景化描述
4. **持续更新**: 每天多次更新（最新至 2026-04-04 18:50）

### 生成机制推测
- 来源: 知识进化系统（evolved）
- 频率: 约每 15-30 分钟生成一条
- 方法: 可能基于优质直播话术提炼、LLM 生成、模板组合

## 二、competitor_insight（竞品洞察）

### 基本信息
- **总数量**: 92 条
- **时间范围**: 2026-03-28 ~ 2026-04-04
- **内容长度**: 约 20-70 字符（简短洞察）

### 内容分类

| 洞察类型 | 数量 | 占比 | 说明 |
|---------|------|------|------|
| industry_analysis | 69 | 75.0% | 行业分析洞察 |
| douyin_trends | 21 | 22.8% | 抖音趋势 |
| tianapi_hot | 2 | 2.2% | 热搜话题 |

### 标题格式
```
[竞品洞察] {品类} - {洞察类型}
```

**示例**:
- `[竞品洞察] 护肤 - industry_analysis`
- `[竞品洞察] 美容仪器 - industry_analysis`
- `[竞品洞察] general - douyin_trends`
- `[竞品洞察] 护肤 - tianapi_hot`

### 内容示例

#### 1. 行业分析类（industry_analysis）

**新兴品类机会**:
```
新兴品类机会如美容仪器，针对高端或细分受众（如抗衰或专业护肤人群），
可拓展新市场或调整受众定位以捕捉增长点。
```

**话术风格演变**:
```
主流话术风格演变趋向教育性和互动性，减少硬推销，更多采用信任建立和
场景化描述，建议更新话术以增强用户 engagement。
```

**排品策略**:
```
TOP直播间排品策略变化显示，优化产品展示顺序和频率（如先推爆品后推利润品）
成为提升转化率的关键，可借鉴此节奏调整推品计划。
```

**价格策略**:
```
竞品价格策略集中于1000-3000元均价区间，促销力度大（常见5-7折优惠），
并搭配赠品或捆绑销售以增强吸引力。
```

#### 2. 抖音趋势类（douyin_trends）

内容长度约 50-60 字符，简短趋势描述。

#### 3. 热搜话题类（tianapi_hot）

**示例**:
```
热搜话题：浪姐7直播乱成一锅粥了（标签：24）
```

### 内容特点

#### 优点
1. **简洁精炼**: 每条洞察 20-70 字，快速获取关键信息
2. **实战导向**: 直接给出可操作建议
3. **多维度**: 覆盖品类、话术、排品、价格等多个维度
4. **时效性强**: 持续更新至最新（2026-04-04）

#### 局限
1. **内容较短**: 缺乏详细分析和数据支撑
2. **数量较少**: 仅 92 条，覆盖面有限
3. **品类集中**: 主要聚焦护肤、美容仪器

### 应用场景
1. **策略调整**: 根据竞品动态调整直播策略
2. **话术优化**: 参考主流话术风格演变
3. **选品决策**: 发现新兴品类机会
4. **定价参考**: 了解竞品价格区间和促销力度

## 四、数据来源推测

### evolved_script 生成机制

可能的生成流程：
1. **数据采集**: 抓取优质直播间话术
2. **知识提炼**: 通过 LLM 提炼关键话术片段
3. **结构化**: 按场景分类、添加标签和使用建议
4. **入库**: 自动写入知识库（每 15-30 分钟）

相关代码位置：
- `module/ai/service/impl/EvolutionServiceImpl.java`
- `module/ai/config/EvolveScheduler.java`

### competitor_insight 生成机制

1. **竞品监控**: 监控 TOP 直播间数据
2. **趋势分析**: 分析话术风格、排品策略、价格等
3. **洞察提炼**: 通过 LLM 生成简短洞察
4. **分类入库**: 按品类和洞察类型入库

- `module/ai/service/impl/CompetitorInsightServiceImpl.java`
