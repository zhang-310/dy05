## 风格融合模式详解

### 核心逻辑

```
用户选择多个风格 + 开启融合模式
  ↓
为每个风格生成独立片段（时长平分）
  ↓
使用 AI 融合多个片段
  ↓
合规检测
  ↓
保存融合话术（style 字段记录所有风格）
  ↓
返回单条融合话术
```

### 技术实现

**后端核心方法**：
- `generateFusionScript()` - 风格融合生成逻辑
- `fuseStyleContents()` - AI 融合多个风格片段
- 同步生成支持融合模式
- SSE 异步生成支持融合模式

**前端核心功能**：
- 融合模式开关
- 按钮文案动态变化："融合生成（3 种风格 → 1 条话术）"
- 融合模式要求至少选择 2 个风格
- 进度展示支持融合模式标识

### 使用场景

1. **长时段直播**：避免单一风格疲劳
2. **混合讲解**：开场专业 → 中段热情 → 结尾温暖
3. **风格过渡**：自然融合，避免生硬切换
4. **个性化定制**：根据主播特点定制风格组合

### 技术优势

- **智能融合**：AI 自动处理风格冲突，确保话术连贯
- **时长控制**：自动平分时长，确保各风格均衡
- **合规保障**：融合后的话术仍需通过合规检测
- **灵活组合**：支持任意风格组合，最多 10 种
- **实时反馈**：SSE 推送融合进度

## API 接口

### 多风格生成（SSE）
```
GET /api/v1/product/script/generate-multi-sse
参数：
  - productId: 商品 ID
  - styles: 风格列表（逗号分隔）
  - scriptType: 话术类型
  - fusionMode: 是否融合模式（新增）
  - personaId: 人设 ID（可选）
  - duration: 时长（秒）
  - scene: 场景（可选）
  - useKbRef: 是否使用知识库参考
  - kbCategories: 知识库分类（逗号分隔，可选）
```

### 风格推荐

## 性能考虑

### Token 消耗
- **普通模式**：N 个风格 = N 次 AI 调用
- **融合模式**：N 个风格 = N+1 次 AI 调用（N 次片段生成 + 1 次融合）

### 生成时间
- 融合模式比普通模式多 1 次 AI 调用
- 但最终只生成 1 条话术，总体时间可能更短

### 建议
- 融合模式适合 2-4 个风格
- 超过 4 个风格，融合效果可能下降
