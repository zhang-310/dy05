## 使用场景

### 场景 1: 高端护肤品
- **风格**: 专业 + 优雅 + 温暖
- **权重**: 主次分明（70% + 20% + 10%）
- **策略**: 混合融合
- **效果**: 专业严谨为主，优雅高端点缀，温暖亲和收尾

### 场景 2: 功效型产品
- **风格**: 专业 + 热情 + 温暖
- **权重**: 渐进过渡（50% + 30% + 20%）
- **策略**: 顺序融合
- **效果**: 开场专业 → 中段热情 → 结尾温暖

### 场景 3: 彩妆产品
- **风格**: 时尚 + 热情 + 随意
- **权重**: 均衡融合（33% + 33% + 34%）
- **策略**: 交替融合
- **效果**: 三种风格交替，节奏感强
