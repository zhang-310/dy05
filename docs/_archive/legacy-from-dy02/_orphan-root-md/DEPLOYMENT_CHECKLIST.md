# 抖音运营平台 - 上线检查清单

## 部署前检查

### 环境准备

- [ ] Docker 版本 >= 20.10
- [ ] Docker Compose 版本 >= 2.0
- [ ] 可用内存 >= 4GB
- [ ] 可用磁盘 >= 20GB
- [ ] 操作系统：Windows 10/11 或 Linux

### 端口检查

- [ ] 8888 (Nginx) 未被占用
- [ ] 8189 (后端应用) 未被占用
- [ ] 5433 (PostgreSQL) 未被占用
- [ ] 6380 (Redis) 未被占用
- [ ] 5672 (RabbitMQ) 未被占用
- [ ] 15672 (RabbitMQ 管理) 未被占用
- [ ] 9200 (Elasticsearch) 未被占用

### 配置文件

- [ ] 已创建 `docker/.env` 文件
- [ ] 已修改数据库密码 `POSTGRES_PASSWORD`
- [ ] 已修改 JWT 密钥 `APP_TOKEN_SECRET` (至少 32 位)
- [ ] 已修改 RabbitMQ 密码 `RABBITMQ_PASS`
- [ ] 已配置 CORS 允许的源 `CORS_ALLOWED_ORIGINS`

### 可选配置

- [ ] 抖音 API 密钥 `DOUYIN_CLIENT_KEY` 和 `DOUYIN_CLIENT_SECRET`
- [ ] OpenAI API 密钥 `OPENAI_API_KEY`
- [ ] DeepSeek API 密钥 `DEEPSEEK_API_KEY`
- [ ] Ollama URL `OLLAMA_URL`

## 部署执行

### 构建和启动

- [ ] 执行 `docker compose build` 成功
- [ ] 执行 `docker compose up -d` 成功
- [ ] 所有容器状态为 `Up` (运行 `docker compose ps`)

### 数据库初始化

- [ ] 数据库连接成功 (`docker compose exec postgres pg_isready`)
- [ ] 执行 `init.sql` 脚本成功
- [ ] 数据库表创建成功 (至少 50+ 张表)
- [ ] 基础数据导入成功

### 服务验证

- [ ] PostgreSQL 服务正常
- [ ] Redis 服务正常
- [ ] RabbitMQ 服务正常
- [ ] Elasticsearch 服务正常
- [ ] 后端应用服务正常
- [ ] Nginx 服务正常
