# 商品话术与优化链路（领域模型摘要）

## 实体关系

| 概念 | 表 / 说明 | 主键 |
|------|-----------|------|
| 商品 | `dy_product` | `id` |
| 主话术 | `dy_product_script` | `id`（业务称 scriptId） |
| 优化镜像版本 | `product_script_version` | `id`（供 analyze / suggestions / regenerate） |
| 分析结果 | `script_analysis_result` 等 | 与 `ScriptAnalysisResultVO.id` 对应 |
| 话术使用统计 | `dy_product_script_usage` | 排品绑定 `productScriptId` 时回写 |

## ID 打通规则

1. **直播排品**：保存 `live_product` 时携带 `productScriptId`（指向 `dy_product_script.id`），由 `ProductScriptUsageSyncService` 写入 usage，供效果摘要与评分使用。
2. **优化分析**：`POST /api/v1/product/script/analyze` 可传 `scriptVersionId` **或** `scriptId`（主话术）。传 `scriptId` 时后端调用 `ensureOptimizationVersion`，在 `product_script_version` 上创建或复用与主话术对应的镜像行，再进行分析。
3. **前端入口**：话术管理「优化建议」跳转 `/admin/product/script-optimization?scriptId=`；已知镜像 ID 时可传 `?scriptVersionId=`。

## 关键 API（节选）

| 路径 | 说明 |
|------|------|
| `POST /product/script/ensure-optimization-version` | 仅 ensure 镜像，返回 `scriptVersionId` |
| `POST /product/script/active-by-style-and-scene` | 按风格 + `scene` 取激活主话术 |
| `POST /product/script/analyze` | 分析（scriptId 或 scriptVersionId） |
| `POST /product/extract-job-status` | 商品链接异步提取任务状态（Redis） |

## 商品库高级筛选

`ProductSearchVO`：`hasSellingPoints`、`hasProductLink`、`minScriptCount`（至少 N 条 `dy_product_script` 未删除）。
