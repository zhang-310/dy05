# 系统总览

多租户抖音运营一站式 SaaS 平台，覆盖账号管理、短视频策划、直播话术、AI 内容生成、知识自进化等场景。

**产品目标**：打造护肤品与彩妆类直播场次 GMV 千万级，并持续向更高目标迈进。详见 [业务范围](../00-业务范围.md)。
