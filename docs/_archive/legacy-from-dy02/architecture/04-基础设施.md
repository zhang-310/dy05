# 基础设施

## Redis

| 配置项 | 值 |
|--------|-----|
| 端口 | 6380（映射容器 6379） |
| 最大内存 | 256MB |
| 淘汰策略 | allkeys-lru |
| 持久化 | AOF + RDB（900s/1、300s/10） |
| 连接池 | max-active=20, max-idle=10, min-idle=5 |
| TTL | 默认 600s（10 分钟） |

**用途**：
- 认证 Token 存储（`RedisAuthTokenStore`）
- 业务缓存（Spring Cache 注解）
- 搜索缓存（`KbSearchCacheService`）
- 限流计数器
- 向量缓存预热（`VectorCacheWarmup`）

## RabbitMQ

| 配置项 | 值 |
|--------|-----|
| AMQP 端口 | 5672 |
| 管理端口 | 15672 |
| 用户名 | guest（开发） |

**队列**：
- `ai-index-queue`：AI 知识库索引队列（`IndexQueueAmqpConfig`）
- `shortvideo.video.generation`：图生视频任务主队列（`application.yml` 默认；死信 → `shortvideo.video.generation.dlx` / `shortvideo.video.generation.dlq`）。
- **本地 `dev` profile**（`application-dev.yml`）默认改为 `shortvideo.video.generation.v2` 及对应 DLX/DLQ，避免与无 DLX 的旧队列同名冲突。

名称均可通过 `app.shortvideo.video-task.amqp.*`（或 `SV_VIDEO_TASK_AMQP_*`）覆盖。

**排错**：若 AMQP 报 `406 PRECONDITION_FAILED - inequivalent arg 'x-dead-letter-exchange'`，说明 Broker 上已有同名队列但参数与当前声明不一致。处理：删旧队列后重启；或启用 `dev` / 配置 `SV_VIDEO_TASK_AMQP_QUEUE` 等为一套新名称。

## Elasticsearch

| 配置项 | 值 |
|--------|-----|
| 端口 | 9200 |
| 版本 | 8.15 |
| 认证 | 开发环境关闭 |
| 内存 | ES_JAVA_OPTS=-Xms512m -Xmx512m（docker-compose 默认） |

**用途**：
- BM25 关键词检索（话术、文案、知识库）
- 混合搜索（结合 Milvus 向量检索）
- 搜索分析与统计

## Milvus（可选）

| 配置项 | 值 |
|--------|-----|
| 端口 | 19530（gRPC） |
| 依赖 | etcd + MinIO |
| 默认状态 | 关闭（`MILVUS_ENABLED=false`） |
| Embedding | BGE-M3（1024 维） |

启用命令：
```bash
docker compose -f docker/docker-compose.yml --profile ai-builtin up -d
```

**用途**：
- 知识库向量检索
- 语义相似度搜索
- 与 Elasticsearch 配合实现 RRF 混合检索

## Ollama

| 配置项 | 值 |
|--------|-----|
| 端口 | 11434 |
| 默认模型 | DeepSeek V3 / Qwen 2.5 |

**用途**：
- 本地 LLM 推理
- 话术生成
- 知识进化分析

## 百度 BOS

文件存储服务，通过系统配置动态管理密钥：
- 商品图片上传
- 视频素材存储
- 关键帧图片管理

## 监控（可选）

启用命令：
```bash
docker compose -f docker/docker-compose.yml --profile monitoring up -d
```

| 服务 | 端口 | 说明 |
|------|------|------|
| Prometheus | 9090 | 指标采集 |
| Grafana | 3001 | 可视化仪表盘 |

## Docker Compose 编排

```bash
# 基础服务
docker compose -f docker/docker-compose.yml up -d

# + Milvus 全套
docker compose -f docker/docker-compose.yml --profile ai-builtin up -d

# + 监控
docker compose -f docker/docker-compose.yml --profile monitoring up -d

# 高配覆盖
docker compose -f docker/docker-compose.yml -f docker/docker-compose.override.high-end.yml up -d

# Redis 高可用
docker compose -f docker/docker-compose.yml -f docker/docker-compose.redis-ha.yml up -d
```

## Nginx 网关

配置文件：`docker/nginx/gateway.conf`

职责：
- 前端静态文件服务
- `/api/*` 反向代理到后端 8080
- SSL 终结（生产）
- 请求限流与安全头
