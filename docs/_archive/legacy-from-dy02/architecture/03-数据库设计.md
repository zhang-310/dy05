## 通用字段约定

所有业务表必须包含以下字段：

```sql
id               BIGSERIAL PRIMARY KEY,
create_time      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
update_time      TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
deleted          INTEGER DEFAULT 0,          -- 逻辑删除标记
owner_id         BIGINT                       -- 数据所有者（用户私有表）
```

## Entity 注解约定

```java
@Entity
@Table(name = "xxx_table")
@SQLRestriction("deleted = 0")
public class XxxEntity {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private LocalDateTime createTime;
    private LocalDateTime updateTime;
    private Integer deleted = 0;

    @PrePersist
    protected void onCreate() {
        this.createTime = LocalDateTime.now();
        this.updateTime = LocalDateTime.now();
    }

    @PreUpdate
    protected void onUpdate() {
        this.updateTime = LocalDateTime.now();
    }
}
```

## Flyway 迁移

迁移脚本位于 `src/main/resources/db/migration/`。**当前最高版本 V066**（详见 `docs/database/00-迁移管理.md` 完整区间说明）。

| 脚本 | 说明 |
|------|------|
| V001–V018 | 索引、类型、直播/AI 基础补全（见迁移管理文档） |
| V019–V048 | 进化、外部 API、直播生成/审批/AB、短视频与知识图谱等 |
| V049–V061 | 认知画像、竞品、SV 模板与 BGM、缺失表补全等 |
| V062–V066 | 话术 `scene`、usage 补列、方舟模型种子、**ai_inference_audit** |

Flyway 在根配置默认关闭（`FLYWAY_ENABLED=false`）；**本地开发** `application-dev.yml` 中 `spring.flyway.enabled: true`。生产启用 Flyway 并配合 `ddl-auto: validate`。

## 设计原则

1. **SQL 先行**：先写 SQL 建表（`sql/<模块>/schema.sql`），再写 Entity，`ddl-auto: validate` 仅校验
2. **无外键**：跨模块关联不使用数据库外键，改为应用层校验
3. **逻辑删除**：所有表使用 `deleted` 字段，Entity 使用 `@SQLRestriction`
4. **数据隔离**：用户私有数据通过 `owner_id` 字段 + Service 层过滤实现
5. **分页防护**：`BasicQueryDto.rows` 限制 1-1000，防止全表扫描
6. **排序防注入**：`sortName` 通过正则校验，防止 SQL 注入
