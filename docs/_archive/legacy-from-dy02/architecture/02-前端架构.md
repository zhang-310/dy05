## HTTP 客户端

`utils/request.ts` 基于 Axios 封装：
- **baseURL**: `/api/v1`
- **请求拦截器**: 自动添加 `Authorization: Bearer <token>`
- **响应拦截器**: 自动解包 `RESTResult.data`（调用方直接拿到 data）
- **错误处理**: 401/403 自动跳转登录
- **暴露方法**: `post`、`get`、`put`、`delete`

实际使用分布：

| 方法 | 数量 | 使用场景 |
|------|------|----------|
| `request.post` | 绝大多数 | 主要调用方式 |
| `request.get` | 6 处 | agent 对话、payment 统计、upload 分块查询 |
| `request.delete` | 4 处 | ai 知识库/进化模块删除 |
| `ssePost` | 10 处 | 流式生成（话术/Agent/批量） |
| `EventSource` | 4 处 | 实时数据订阅（直播面板/监控） |
| `fetch` 直连 | 1 处 | AI 模型流式对话（绕过 Axios 拦截器） |
| `fetchExport` | 3 处 | CSV 文件导出 |

## SSE 客户端

`utils/sse-client.ts` 提供两个核心函数：

### ssePost(url, body, callbacks, options)
- 基于 POST 的 SSE 连接（非标准 EventSource，使用 fetch + ReadableStream）
- 支持事件类型：`progress`、`done`、`error`、`slot_done`、`slot_failed`、`chunk`、`status`
- 支持 Last-Event-Id 重连、背压控制、requestAnimationFrame 批量更新、空闲超时
- 返回 `AbortController` 用于取消

### fetchExport(url, params?)
- 基于 POST 的文件导出（返回 Blob）
- 避免 Axios 响应拦截器的 JSON 解析

### EventSource 使用
前端部分 SSE 使用浏览器原生 `EventSource`（GET），主要在 `live-realtime.ts` 和 `monitoring.ts`：
- `subscribeToRealtimeStream` — 直播实时面板
- `subscribeToRealtimeMetrics` — 实时监控指标
- `subscribeToAlerts` — 告警通知
