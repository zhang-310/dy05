# 多行业合规规则（IndustryComplianceService）

## 1. 检测如何叠加

对任意文案执行 `checkCompliance(text, industryCode)` 时，规则按顺序合并为：

1. **全业通用摘要**（`GENERAL_AD_RULES`，`source=industry`）：广告法倾向的夸大、投资收益暗示、不当「国家级/领军」表述等。
2. **垂直行业包**（`VERTICAL_RULES`，`source=industry`）：由 `industryCode` 决定；编码见下文。
3. **抖音公开摘要正则**（`DOUYIN_PUBLIC_RULE_PATTERNS`，`source=douyin_public_summary`）：交易秩序、假货刷量、网暴、价格促销、发票等（与 `sc_compliance_word` V067/V108 互补）。

- **`industryCode` 为空或空白**：按 **`cosmetics`** 处理（与历史默认一致）。
- **未知 `industryCode`**（未在垂直表中注册）：**仅** 套用「全业通用 + 抖音公开」，**不**套用任一垂直包（避免误用护肤规则扫食品文案等）。

## 2. 垂直行业编码一览

| `industryCode` | 侧重归纳（非穷尽） | 主要法规/规则依据类型 |
|----------------|-------------------|------------------------|
| `cosmetics` | 速效、药妆、天数功效、绝对化用语 | 《化妆品监督管理条例》、化妆品广告 |
| `food` | 普通食品涉疾病治疗、抗癌降血糖等宣称 | 《食品安全法》第七十三条 |
| `health_supplement` | 保健食品替代药物、疾病预防治疗声称 | 保健食品广告审查、市监要求 |
| `apparel` | 材质造假、伪功能性纺织宣传 | 纺织品标识、广告法 |
| `digital_3c` | 三无 3C、山寨破解 | CCC、知识产权 |
| `mother_baby` | 配方奶替代母乳、婴儿食品治病暗示 | 婴配乳粉广告、母婴食品 |
| `jewelry` | 千足金/万足金等易误导纯度、假钻仿钻 | GB 11887、珠宝命名国标 |
| `pet` | 宠粮治病、兽药级饲料 | 宠物饲料标签与广告 |
| `medical_device` | 家械包治、治愈率绝对化 | 《医疗器械广告审查办法》 |
| `education` | 包过保过、命题人授课 | 《广告法》第二十四条 |
| `finance` | 保本保息、刚性兑付、违规荐股诱导 | 金融监管、证券期货广告 |
| `real_estate` | 买房送户口、学位包过、返本销售等 | 《房地产广告发布规定》 |

## 3. 配置与 API

| 项 | 说明 |
|----|------|
| 直播话术 | `app.live.compliance.industry-code` / `APP_LIVE_COMPLIANCE_INDUSTRY_CODE` |
| 短视频 AI 文案 | `ShortVideoAiServiceImpl` 使用同一配置项 |
| 在线检测 | `POST /api/v1/script/compliance/check`，body：`text`、`industryCode` |
| 拉取规则列表 | `POST /api/v1/script/compliance/rules` |
| **垂直编码列表** | `POST /api/v1/script/compliance/industry-codes` |

## 4. 维护与扩展

- 新增垂直行业：在 `IndustryComplianceServiceImpl` 的 `VERTICAL_RULES` 静态块中 `put` 新 key；同步更新本文件与 `docs/development/04-文档代码同步清单.md`。
- 全业通用调整：改 `GENERAL_AD_RULES`，影响所有行业。
- 仍以 **子串/正则** 实现，不能理解语境；重要发布前需 **人工复核**。

详见 `docs/compliance/00-抖音官方规范与词库同步.md`。
