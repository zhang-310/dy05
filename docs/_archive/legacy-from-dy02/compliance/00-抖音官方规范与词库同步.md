# 抖音官方公开规范与本地违规检测对齐说明

## 1. 原则

- **检测方式**：词库与行业规则以 **子串 / 正则** 为主（`contains`、`Pattern.find`），**不是**语义模型；可能出现叙事场景误报（已通过正则收窄部分情形，如「第一」不命中「第一名」「第一天」等）或复杂宣称漏报，需运营与法务人工复核。
- **官方正文以各平台官网为准**：协议、规则中心、电商学习中心会改版，**禁止**在生产环境对官网做高频 HTML 爬取作为唯一数据源（易失效、易触达 robots/条款风险）。
- **本系统做法**：
  1. **配置化官方入口**：`app.compliance.douyin.reference-urls`（`application.yml`），接口 `POST /api/v1/script/compliance/douyin-official-references` 返回列表供运营跳转核对。
  2. **归纳词库**：`sc_compliance_word` 增量由 **Flyway** 维护（**V067** 交易秩序/功效；**V108** 社区公约与电商规则中心常见情形归纳），词条为运营/法务依据公开说明归纳，非实时镜像网页。
  3. **正则摘要**：`IndustryComplianceServiceImpl` 中 `DOUYIN_PUBLIC_RULE_PATTERNS` 与词库互补，规则项 `source=douyin_public_summary`。

## 2. 建议运营对照的公开入口（可改 yml）

| 说明 | 示例 URL（请在浏览器验证最新有效链接） |
|------|----------------------------------------|
| 抖音协议列表 | `https://www.douyin.com/agreements` |
| 抖音电商学习中心 | `https://school.jinritemai.com/` |
| 抖店/电商后台入口 | `https://fxg.jinritemai.com/` |

更新规则后：在库内增删 `sc_compliance_word` 或调整 Java 正则 → 管理员调用 **`POST /api/v1/script/admin/compliance/refresh`** 刷新 `ComplianceWordService` 内存缓存，或重启应用。

## 3. 检测链路（加强后）

| 组件 | 作用 |
|------|------|
| `ComplianceWordService` | 绝对化 / 医疗及 V067 补充词（私下交易、脱离平台等） |
| `IndustryComplianceService` | **全业通用摘要** + **垂直行业规则**（`industryCode`，见 `docs/compliance/01-多行业合规规则.md`）+ **抖音公开摘要正则**；未知编码仅通用+抖音公开 |
| `LiveScriptQualityServiceImpl.checkViolation` | **直播话术**：合并 `ViolationWordService` + `ComplianceWordService` + `IndustryComplianceService`（与商品/大脑侧词库与规则一致）；行业码 `app.live.compliance.industry-code`（默认 `cosmetics`） |
| `RiskWarningServiceImpl` | 扫描 + `ComplianceWordService` |
| `ContentSecurityScanner` | 隐私、静态违禁短语（与 DB 词库并行） |

## 4. 文档与迁移同步

- 新增/修改 `sc_compliance_word`：**新增 Flyway**（勿改已执行脚本），并更新 `docs/development/04-文档代码同步清单.md` 第四节合规表。
- 修改 `IndustryComplianceServiceImpl` 正则：同步本文件「摘要」描述。

## 5. 免责声明

本地词库与正则仅为**辅助风控**，不构成法律意见；处罚与认定以平台及监管部门为准。

## 6. 抖音近年公开规则文献：短视频 vs 直播违规要点（运营摘要）

> **说明**：本节依据抖音 **协议列表**（[`https://www.douyin.com/agreements`](https://www.douyin.com/agreements)）、**抖音电商学习中心 / 规则中心**（[`https://school.jinritemai.com/`](https://school.jinritemai.com/)）、抖店经营侧公开说明，以及平台多次公开的《**抖音社区自律公约**》修订与治理通报等 **归纳主题**；**不是**对某一篇 PDF/HTML 的全文摘录，条文序号与措辞以你打开时的官网版本为准。近年公开治理中反复出现的方向包括：未成年人保护、网暴与虚假信息、交易秩序（禁止私下交易/脱离平台）、虚假宣传与绝对化功效、直播互动与营销合规等。

### 6.1 建议优先阅读的公开文献类型

| 类型 | 典型内容 | 与本系统关系 |
|------|-----------|----------------|
| 社区类 | 《社区自律公约》、社区规范、创作者公约 | 短视频内容红线、价值观与秩序类 |
| 协议类 | 用户服务协议、隐私政策、知识产权声明 | 权责边界、投诉与处置 |
| 电商 / 带货 | 创作者管理、商品分享、直播行为、营销推广规则 | **直播话术 + 带货脚本** 主对齐面 |
| 行业 / 商品 | 化妆品、食品等类目宣传规范（电商学习中心专题） | `industryCode=cosmetics` 行业规则 |

### 6.2 短视频（含种草、商品分享短视频）常见违规点

下列为公开规则与平台通报中 **高频出现** 的违规主题，便于运营自查；与「是否带货」叠加时往往适用更严的电商规则。

1. **危害国家安全与社会稳定、违法犯罪教唆**（绝对红线）。
2. **色情低俗、赌博毒品、恐怖主义与极端主义**（绝对红线）。
3. **侵害未成年人**：不当利用未成年人形象、危及未成年人安全的内容；**注意**：平台对「未成年人参与直播」通常有专门限制——本系统对 **直播场次** 已单独配置「儿童/未成年人直播」类主题拦截（见 §7），**短视频策划**不在该拦截内，但仍须遵守社区与电商对未成年人的公开要求。
4. **危险行为**：易导致模仿受伤的行为、无安全保障的危险挑战等。
5. **虚假与不实信息**：造谣传谣、伪造权威、误导性科普与「伪科学」。
6. **侵犯他人合法权益**：侮辱诽谤、泄露隐私、侵犯著作权/商标/肖像等。
7. **不良营销与交易秩序**：引导 **私下交易、脱离平台、私域导流**（微信/群二维码等），在公开治理与电商规则中反复出现；本地已通过 **词库 + `DOUYIN_PUBLIC_RULE_PATTERNS`** 做摘要级命中。
8. **医疗健康与特殊品类误导**：违规医疗宣称、夸大功效、普通商品冒充医疗效果；化妆品赛道对应 **广告法 + 化妆品条例** 类规则，见 `INDUSTRY_RULES.cosmetics` 与 `sc_compliance_word`。
9. **虚假宣传与绝对化承诺**：「百分百治愈」「一定美白」等；已部分纳入 `DOUYIN_PUBLIC_RULE_PATTERNS` 与行业规则。
10. **低质与作弊**：搬运、刷量、诱导互动（如不规范抽奖表述）等；公开通报中常见「诱导互动/虚假抽奖」类表述，本地有一条 **warning** 级正则摘要。

### 6.3 直播（含带货直播）在短视频基础上的增量风险点

直播除适用与短视频相通的社区与内容底线外，公开规则与电商学习中心通常还强调：

1. **实时互动中的违规**：口播、弹幕互动、连麦中出现的导流、辱骂、虚假宣传，**瞬时发生**，需话术生成与质检链路覆盖；本系统 **`LiveScriptQualityServiceImpl.checkViolation`** 合并多源词库与行业规则，对齐直播侧检测。
2. **价格与促销表述**：虚假原价、不实「全网最低」、未标明条件的限时限量等（具体以电商规则中心为准）；本地对「绝对化用语」有 **收窄正则**（避免误伤「第一天」等叙事），复杂价格欺诈需 **法务模板 + 人工**。
3. **抽奖与福利互动**：不规范抽奖、刷礼物中奖、虚假福利等；本地有一条 **warning** 级摘要正则，细粒度仍以官方专题为准。
4. **商品展示与资质**：需展示的信息、禁售类目、对比贬损竞品等，多在 **电商规则** 中规定；本系统以 **护肤彩妆** 为主战场，行业码默认 `cosmetics`。
5. **主播与场景合规**：未成年人直播、违规场景直播等；本系统对 **场次标题/简介** 使用 `app.live.content-policy` 做组合词拦截（见 §7）。

### 6.4 融合本系统：从「公开规则」到「可执行能力」

| 公开规则主题 | 本系统能力 | 配置 / 代码锚点 |
|--------------|------------|-----------------|
| 私下交易、脱离平台、加微信下单等 | 正则摘要 + 词库 | `IndustryComplianceServiceImpl.DOUYIN_PUBLIC_RULE_PATTERNS`、`sc_compliance_word`（**V067**、**V108**） |
| 化妆品绝对化、药妆、天数功效等 | 垂直行业 + 词库 | `VERTICAL_RULES.cosmetics`、`ComplianceWordService` |
| 食品/保健/3C/教培/金融/房产等 | 切换 `industryCode` | 见 `docs/compliance/01-多行业合规规则.md` |
| 全业通用夸大、无风险收益暗示等 | 恒生效 | `GENERAL_AD_RULES` |
| 直播话术综合违规 | 合并检测 | `LiveScriptQualityServiceImpl.checkViolation`、`app.live.compliance.industry-code` |
| 短视频 AI 文案合规 | 行业 + 词库（与直播行业码对齐） | 如 `ShortVideoAiServiceImpl` 生成链路中的 `IndustryComplianceService`（见 `04` 文档 CONTENT-03） |
| 自动二创不浪费算力、高风险题材不进 LF-06 | 子串策略（非全文合规替代） | `app.shortvideo.auto-orchestration.content-policy`、`ViralAutoOrchestrationService` |
| 禁止「儿童/未成年人直播」类直播主题 | 场次保存拦截 | `app.live.content-policy`、`LiveSessionServiceImpl` |
| 官方 URL 书签 | 运营跳转 | `app.compliance.douyin.reference-urls`、`POST .../compliance/douyin-official-references` |

### 6.5 与公开规则的差距（建议产品后续补齐）

- **语义级违规**（讽刺、影射、变体规避）仅靠词库/正则 **无法** 全覆盖，需人工抽检或接入平台/第三方审核 API（若合作）。
- **价格促销、医疗、金融** 等强规则域，建议在运营后台提供 **话术模板白名单** 与 **发布前二次确认**。
- **短视频成片与画面**（OCR、商标、未成年人出镜）未在本文档所列 Java 正则中覆盖，若上线需单独能力。
