### 3. 外部 API 网络错误（环境/网络）

| 现象 | 来源 | 说明 |
|------|------|------|
| `TianAPI 请求失败: path=hotword/index` | TianApiClient | `Unexpected end of file from server`、`SSLHandshakeException: Remote host terminated the handshake`，多为网络不稳定或 TianAPI 限流 |
| `LLM 超时/网络错误`、`Premature EOF` | OpenAiCompatibleLlmClient (DeepSeek) | `api.deepseek.com` 连接异常，可能为网络/代理/限流 |
| `LLM 调用失败: provider=deepseek, model=deepseek-reasoner` | evolve-task | 同上，进化任务会触发降级链 |

**建议**：检查网络、代理、API Key 配额；必要时增加重试与超时配置。

### 4. 内存泄漏告警（WARN）

| 现象 | 说明 |
|------|------|
| `The web application [ROOT] appears to have started a thread named [BatchSpanProcessor_WorkerThread-1] but has failed to stop it` | OpenTelemetry 批处理线程，应用异常退出时未正确关闭 |
| `Thread-9` (ResolverConfigurationImpl$AddressChangeListener) | JDK DNS 监听线程 |
| `lettuce-timer-3-1`、`HikariPool-1 housekeeper` 等 | Redis/Hikari 等组件线程，应用快速重启时未完全回收 |

**说明**：多为 DevTools 热重启或异常退出时的常见告警，生产环境正常停机时较少出现。
