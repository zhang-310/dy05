![1772213622764](image/主题库导入指南/1772213622764.png)# 进化主题库导入指南

从老系统导入进化主题到 `ai_evolve_topic` 表。

---

## API

```
POST /api/v1/ai/admin/evolve/topic/import-from-file
```

**请求体：**
```json
{
  "sourcePath": "C:\\path\\to\\evolve_queries.json",
  "kbId": null
}
```

- `sourcePath`：本地 JSON 或 TXT 文件路径
- `kbId`：可选，知识库 ID；为 null 时导入为**全局主题**

---

## 支持格式

### 1. JSON

**纯字符串数组：**
```json
["抖音运营 直播 话术", "短视频 黄金3秒", "算法推荐 爆款"]
```

**对象数组（可带 category、priority）：**
```json
[
  {"topic": "抖音运营 直播 话术", "category": "live"},
  {"topic": "短视频 黄金3秒", "category": "basic", "priority": 80},
  {"query": "算法推荐 爆款", "category": "algorithm"}
]
```

- `topic` / `query` / `text` 均可作为主题文本
- `category`：live/ai/vertical/commercial/algorithm/data/team/compliance/basic 等
- `priority`：数值越小越优先，默认 100

### 2. TXT

每行一个主题，空行和 `#` 开头的行忽略：
```
抖音运营 直播 话术 粉丝互动
短视频 脚本 黄金3秒 内容创作
# 这是注释
数据分析 关键指标 优化决策
```

## 调用示例

### curl

```bash
# 先登录获取 token
TOKEN=$(curl -s -X POST "http://localhost:8188/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"你的密码"}' | jq -r '.data.token')

# 导入主题
curl -X POST "http://localhost:8188/api/v1/ai/admin/evolve/topic/import-from-file" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"sourcePath":"C:\\opencode\\cursor\\knowledge-base\\douyin\\evolve_queries.json","kbId":null}'
```

### Swagger

访问 `http://localhost:8188/swagger-ui.html` → AI 进化引擎 → 从老系统导入主题库。

---

## 响应示例

```json
{
  "status": 200,
  "data": {
    "total": 15,
    "success": 12,
    "skipped": 3,
    "errors": []
  }
}
```

- `skipped`：已存在或空行跳过
- `errors`：导入失败的条目及原因
- `hint`：成功 0 条时的说明（如「均已存在」或「解析后为空」）

**常见情况：成功 0 条**
- **均已存在**：EvolveDataInitializer 启动时已插入默认主题，与导入文件重叠则全部跳过
- **解析后为空**：JSON 格式不匹配，支持根数组 `["a","b"]` 或 `{"queries":[...]}`、`{"topics":[...]}`
