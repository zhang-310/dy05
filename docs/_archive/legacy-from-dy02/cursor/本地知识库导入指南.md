# 本地知识库导入指南

将 `C:\opencode\cursor\knowledge-base\douyin\evolved` 导入到 douyin 知识库。

---

## 一、前置条件

1. **Ollama**：已拉取 `qwen3-embedding:4b`，输出 1024 维
   ```bash
   ollama pull qwen3-embedding:4b
   ```

2. **Milvus + ES**：已启动，`app.milvus.enabled=true`

3. **知识库**：douyin 知识库已创建（启动时自动创建）

4. **维度一致性**：若 douyin 知识库此前用 768 维创建，需先删除该知识库，重启后由系统以 1024 维重新创建

---

## 二、配置

`application.yml` 中确认：

```yaml
app.ai:
  embedding:
    model: qwen3-embedding:4b
    dimension: 1024
```

---

## 三、导入方式

### 方式 1：Swagger / 接口

`POST /api/v1/ai/knowledge-base/import-from-path`

**请求体：**
```json
{
  "sourcePath": "C:\\opencode\\cursor\\knowledge-base\\douyin\\evolved",
  "kbName": "douyin"
}
```

**说明**：
- `sourcePath`：本地目录路径（支持子目录递归）
- `kbName`：知识库名称，如 `douyin`
- `kbId`：可选，指定知识库 ID 时可替代 `kbName`

**响应示例：**
```json
{
  "status": 200,
  "data": {
    "total": 25,
    "success": 24,
    "failed": 1,
    "errors": ["xxx.md: 具体错误信息"]
  }
}
```

### 方式 2：curl

```bash
# 先登录获取 token
TOKEN=$(curl -s -X POST "http://localhost:8188/api/v1/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"你的密码"}' | jq -r '.data.token')

# 发起导入
curl -X POST "http://localhost:8188/api/v1/ai/knowledge-base/import-from-path" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"sourcePath":"C:\\opencode\\cursor\\knowledge-base\\douyin\\evolved","kbName":"douyin"}'
```

---

## 四、支持格式

- `.md`：Markdown
- `.txt`：纯文本

递归扫描目标目录及子目录。

---

## 五、处理流程

1. 按路径扫描 `.md`、`.txt`
2. 读取并分块（512 字符 + 50 重叠）
3. 调用 Ollama `qwen3-embedding:4b` 生成 1024 维向量
4. 写入 Milvus + ES
