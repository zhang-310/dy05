# 通过本系统为李阳阳生成高光话术 - 操作指南

## 一、系统能力说明

本系统支持「参考话术 → 知识库 → RAG 检索 → AI 生成」的完整链路：

1. **话术知识库（huashu）**：导入考古家高光话术、全场话术等参考素材
2. **RAG 检索**：生成时从知识库检索相似话术，注入到 AI Prompt
3. **AI 生成**：基于人设、产品、风格，参考案例生成原创话术

## 二、一键生成（推荐）

**API**：`POST /api/v1/ai/knowledge-base/huashu/generate-highlight`

**请求体**：
```json
{
  "hostName": "李阳阳",
  "sourcePath": "C:\\Users\\Administrator\\Desktop\\01",
  "query": "可选，默认 hostName + 高光话术 开场 种草 转化 留人"
}
```

**流程**：若提供 `sourcePath`，会先将该目录下的 `.txt`/`.md` 导入到 huashu，再 RAG 检索 + LLM 生成，返回高光话术内容。

**PowerShell 脚本**（需先登录获取 token）：
```powershell
$env:HUASHU_TOKEN = "你的JWT"
.\docs\cursor\通过话术知识库生成高光话术-执行脚本.ps1
```
生成结果会写入 `李阳阳-高光话术-知识库生成.md`。

## 三、手动操作步骤

### 步骤 1：创建/确认话术知识库（若未使用一键生成）

1. 登录系统 → **AI 模块** → **知识库管理**
2. 新建或找到名为 **「huashu」** 的知识库（系统 RAG 默认按此名称检索）
3. 若已有 huashu 知识库，可跳过

### 步骤 2：导入参考主播素材

**方式 A：手动上传**

1. 进入 huashu 知识库 → **导入文档**
2. 将 `C:\Users\Administrator\Desktop\01\kaogujia-高光话术.txt` 内容复制粘贴，标题填写「考古家高光话术-参考」
3. 将 `kaigujia-全场话术.txt` 内容分段导入（内容较长可拆成多篇），标题如「考古家全场话术-开场」「考古家全场话术-情感」等

**方式 B：路径导入（若支持）**

- 调用 `POST /api/v1/ai/knowledge-base/import-from-path` 或 `import-from-path-async`
- 参数：`sourcePath` = `C:\Users\Administrator\Desktop\01`，`kbId` 或 `kbName` = huashu

**注意**：图片、视频需先转为文字（如 OCR、语音转文字）再导入；系统当前主要处理文本。

### 步骤 3：配置李阳阳人设

1. 进入 **人设管理**（dy_persona 或 persona 模块）
2. 新建人设「李阳阳」：
   - 姓名：李阳阳
   - **地方特色（local_flavor）**：选择 **东北**（2 小时拉自然流场景下，若未配置则系统默认使用东北）
   - 风格：可参考「亲切」「姐妹」「专业」等（与因果因子配置一致）
   - 目标品类：护肤/彩妆/美妆（与业务范围一致）
   - 若有直播风格字段（live_style）：可填 high_energy / deep_value / emotional

### 步骤 4：创建直播场次并生成话术

1. 进入 **直播中心** → 新建直播场次
2. 关联人设「李阳阳」、选择要带货的产品
3. 进入 **话术生成** 或 **一键生成**：
   - 勾选「引用知识库」
   - 选择风格（如：亲切、种草、情感）
   - 系统会自动从 huashu 知识库 RAG 检索参考话术，注入到生成 Prompt
4. 生成后即可得到适配李阳阳的高光话术

### 步骤 5：导出高光话术

- 生成的话术可保存到话术库、模板
- 支持导出为 PDF/Word（若系统支持）或直接复制使用

可直接打开使用，也可按上述步骤导入系统后，作为后续 RAG 的补充素材。
