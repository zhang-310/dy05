# 快速开始

## 环境要求

| 工具 | 版本 | 说明 |
|------|------|------|
| JDK | 21+ | LTS 版本 |
| Maven | 3.9+ | 后端构建 |
| Node.js | 18+ | 前端构建 |
| Docker | 24+ | 依赖服务 |
| Docker Compose | v2+ | 服务编排 |

## 第一步：启动依赖服务

```bash
# 启动 PostgreSQL、Redis、RabbitMQ、Elasticsearch
docker compose -f docker/docker-compose.yml up -d postgres redis rabbitmq elasticsearch
```

等待所有服务健康：

```bash
docker compose -f docker/docker-compose.yml ps
```

## 第二步：初始化数据库

```bash
# 进入 PostgreSQL 容器
docker exec -it dy-postgres psql -U postgres -d douyin_operations

# 执行初始化（按顺序）
\i sql/init-all.sql
```

数据库连接信息：
- 主机：localhost
- 端口：5433
- 数据库：douyin_operations
- 用户：postgres
- 密码：postgresql

## 第三步：启动后端

```bash
# Windows 控制台先设置编码
chcp 65001

# 编译
mvn compile

# 运行（自动使用 dev profile）
mvn spring-boot:run
```

**启动成功标志**：8080 端口被占用即代表启动成功（可用 `netstat -ano | findstr 8080` 或访问 http://localhost:8080 验证）。

后端启动在 http://localhost:8080

API 文档：http://localhost:8080/swagger-ui.html

## 第四步：启动前端

```bash
cd frontend-react

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

前端启动在 http://localhost:3000，`/api` 自动代理到后端 8080。

## 第五步：登录

打开 http://localhost:3000，使用初始化脚本创建的管理员账号登录。

## 可选：启用 AI 能力

### 启动 Milvus（向量数据库）

```bash
docker compose -f docker/docker-compose.yml --profile ai-builtin up -d
```

### 启动 Ollama（本地 LLM）

```bash
# 安装 Ollama
# 拉取模型
ollama pull deepseek-v3
ollama pull qwen2.5

# 启动（默认端口 11434）
ollama serve
```

## 常用命令速查

```bash
# === 后端 ===
mvn compile                                    # 编译
mvn spring-boot:run                            # 运行
mvn test                                       # 全部测试
mvn test -Dtest=AuthUserServiceTest             # 单个测试类
mvn test -Dtest="AuthUserServiceTest#testSearch" # 单个方法
mvn package -DskipTests                        # 打包

# === 前端 ===
npm run dev                                    # 开发服务器
npm run build                                  # 构建
npm run type-check                             # 类型检查
npm run test                                   # 测试
npm run test:watch                             # 监听测试
npm run test:coverage                          # 覆盖率
npm run test:e2e                               # E2E 测试

# === Docker ===
docker compose -f docker/docker-compose.yml up -d                  # 基础服务
docker compose -f docker/docker-compose.yml --profile ai-builtin up -d  # + AI
docker compose -f docker/docker-compose.yml --profile monitoring up -d  # + 监控
docker compose -f docker/docker-compose.yml down                   # 停止
docker compose -f docker/docker-compose.yml logs -f postgres       # 查看日志
```

## IDE 配置

### IntelliJ IDEA / Cursor

- 打开项目根目录
- 设置 JDK 21
- Maven 自动导入依赖
- 前端项目在 `frontend-react/` 子目录

### 路径别名

前端 `@/` 映射到 `src/`（Vite resolve alias），IDE 中 `tsconfig.json` 也配置了对应路径。
