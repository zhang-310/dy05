# 开发规范

## 命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 数据库表 | 蛇形 + 模块前缀 | `auth_user`, `sv_video_data` |
| Entity 类 | 大驼峰 | `AuthUser`, `SvVideoData` |
| Controller | 资源名 + Controller | `AuthUserController` |
| Service | 资源名 + Service | `AuthUserService` |
| ServiceImpl | 资源名 + ServiceImpl | `AuthUserServiceImpl` |
| Repository | 资源名 + Repository | `AuthUserRepository` |
| VO (查询) | 资源名 + SearchVO | `AuthUserSearchVO` |
| VO (保存) | 资源名 + SaveVO | `AuthUserSaveVO` |
| VO (返回) | 资源名 + VO | `AuthUserVO` |
| API 路径 | `/api/v1/模块/资源/动作` | `/api/v1/auth/user/list` |
| 错误码常量 | 全大写下划线 | `AI_QUOTA_EXCEEDED` |
| 前端 API 文件 | 模块名.ts | `auth.ts`, `product.ts` |
| 前端页面 | 大驼峰 + Page | `LoginPage.tsx` |
| 前端组件 | 大驼峰 | `FormDialog.tsx` |
| 前端 Hook | use + 驼峰 | `useApiCall.ts` |
| 前端 Store | use + 名称 + Store | `useUserStore` |

## 后端编码规范

### Controller

```java
@RestController
@RequestMapping("/api/v1/auth/user")
public class AuthUserController {

    @PostMapping("/list")
    public RESTResult<PageResultVO<AuthUserVO>> list(
            @RequestBody @Valid AuthUserSearchVO vo) {
        return RESTResult.success(authUserService.search(vo));
    }

    @PostMapping("/save")
    public RESTResult<Void> save(
            @RequestBody @Valid AuthUserSaveVO vo,
            @CurrentUserId Long userId) {
        authUserService.save(vo, userId);
        return RESTResult.success();
    }
}
```

规则：
- 统一 `@PostMapping`
- 请求体使用 `@Valid` 校验
- 返回 `RESTResult<T>`
- 通过 `@CurrentUserId` 获取当前用户

### Service

```java
@Service
public class AuthUserServiceImpl implements AuthUserService {

    @Override
    public PageResultVO<AuthUserVO> search(AuthUserSearchVO vo) {
        Specification<AuthUser> spec = (root, query, cb) -> {
            List<Predicate> predicates = new ArrayList<>();
            if (StringUtils.hasText(vo.getKeyword())) {
                predicates.add(cb.like(root.get("username"),
                    "%" + vo.getKeyword() + "%"));
            }
            return cb.and(predicates.toArray(new Predicate[0]));
        };

        Pageable pageable = PageRequest.of(vo.getPage(), vo.getRows(),
            Sort.by(Sort.Direction.fromString(vo.getSortOrder()),
                vo.getSortName()));

        Page<AuthUser> page = repository.findAll(spec, pageable);
        return PageResultVO.of(page, this::toVO);
    }
}
```

规则：
- 使用 JPA Specification 动态查询
- `owner_id` 数据隔离强制过滤
- 逻辑删除通过 `@SQLRestriction` 自动处理

### Entity

```java
@Entity
@Table(name = "auth_user")
@SQLRestriction("deleted = 0")
public class AuthUser {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String username;
    private Integer deleted = 0;
    private LocalDateTime createTime;
    private LocalDateTime updateTime;

    @PrePersist
    protected void onCreate() {
        createTime = updateTime = LocalDateTime.now();
    }

    @PreUpdate
    protected void onUpdate() {
        updateTime = LocalDateTime.now();
    }
}
```

## 前端编码规范

### API 调用

```typescript
// api/auth.ts
import request from '@/utils/request'

export function searchUsers(params: UserSearchVO) {
  return request.post<PageResultVO<UserVO>>('/auth/user/list', params)
}
```

注意：`request` 响应拦截器已自动解包 `RESTResult.data`，调用方直接获得 data。

### 页面组件

```typescript
// pages/crud/UsersPage.tsx
export function UsersPage() {
  const { data, loading, execute } = useApiCall(searchUsers)

  useEffect(() => {
    execute({ page: 0, rows: 20 })
  }, [])

  return (
    <DataTable data={data} loading={loading} ... />
  )
}
```

### 状态管理

使用 Zustand，按业务域拆分 Store：

```typescript
// stores/user.ts
export const useUserStore = create<UserState>((set) => ({
  user: null,
  token: null,
  setUser: (user) => set({ user }),
  logout: () => set({ user: null, token: null }),
}))
```

## 质量检查要点

1. `mvn compile` 编译通过
2. 无 SQL 注入、XSS、硬编码密钥
3. 分页上限检查（rows ≤ 1000）
4. N+1 查询预防（使用 `@EntityGraph` 或 join fetch）
5. `RESTResult` 统一返回 + 错误码正确
6. `owner_id` 数据隔离强制过滤
7. 错误码三处一致（文档 / Java / 前端）
8. **升级/约束变更时文档同步**：修改业务范围、因果因子、合规词、品类标签等时，更新 `docs/development/04-文档代码同步清单.md` 及对应文档
9. SSE 流式接口路径包含 `-sse` 或 `chat-stream`
