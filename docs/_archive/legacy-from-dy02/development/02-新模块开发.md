# 新模块开发流程

从零开发一个新业务模块的完整步骤。

## 1. 撰写模块设计文档

在 `docs/modules/<模块名>/` 下创建 `README.md`，包含：
- 模块概述
- 后端结构
- 数据库表
- 前端页面
- API 接口
- 核心业务流程

## 2. 编写 SQL

在 `sql/<模块名>/` 下创建：

```
sql/<模块名>/
├── schema.sql           # 建表语句
├── sample-data.sql      # 示例数据（可选）
└── resource-data.sql    # 权限资源数据（菜单项）
```

建表模板：

```sql
CREATE TABLE IF NOT EXISTS xx_example (
    id              BIGSERIAL PRIMARY KEY,
    name            VARCHAR(200) NOT NULL,
    description     TEXT,
    status          INTEGER DEFAULT 1,
    owner_id        BIGINT NOT NULL,
    deleted         INTEGER DEFAULT 0,
    create_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    update_time     TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_xx_example_owner ON xx_example(owner_id) WHERE deleted = 0;
```

## 3. 执行 SQL 建表

```bash
docker exec -it dy-postgres psql -U postgres -d douyin_operations -f /path/to/schema.sql
```

## 4. 创建 Entity

```java
@Entity
@Table(name = "xx_example")
@SQLRestriction("deleted = 0")
public class Example {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 200)
    private String name;

    private String description;
    private Integer status = 1;
    private Long ownerId;
    private Integer deleted = 0;
    private LocalDateTime createTime;
    private LocalDateTime updateTime;

    @PrePersist
    protected void onCreate() {
        this.createTime = LocalDateTime.now();
        this.updateTime = LocalDateTime.now();
    }

    @PreUpdate
    protected void onUpdate() {
        this.updateTime = LocalDateTime.now();
    }
}
```

## 7. 创建 Service

```java
// 接口
public interface ExampleService {
    PageResultVO<ExampleVO> search(ExampleSearchVO vo, Long userId);
    void save(ExampleSaveVO vo, Long userId);
    void delete(Long id, Long userId);
}

// 实现
@Service
public class ExampleServiceImpl implements ExampleService {

    private final ExampleRepository repository;

    @Override
    public PageResultVO<ExampleVO> search(ExampleSearchVO vo, Long userId) {
        Specification<Example> spec = (root, query, cb) -> {
            List<Predicate> predicates = new ArrayList<>();
            predicates.add(cb.equal(root.get("ownerId"), userId));
            if (StringUtils.hasText(vo.getKeyword())) {
                predicates.add(cb.like(root.get("name"),
                    "%" + vo.getKeyword() + "%"));
            }
            if (vo.getStatus() != null) {
                predicates.add(cb.equal(root.get("status"), vo.getStatus()));
            }
            return cb.and(predicates.toArray(new Predicate[0]));
        };

        String sortField = vo.getSortName() != null ? vo.getSortName() : "createTime";
        Sort sort = Sort.by(
            "asc".equalsIgnoreCase(vo.getSortOrder())
                ? Sort.Direction.ASC : Sort.Direction.DESC,
            sortField);
        Pageable pageable = PageRequest.of(vo.getPage(), vo.getRows(), sort);

        Page<Example> page = repository.findAll(spec, pageable);
        return PageResultVO.of(page, this::toVO);
    }

    @Override
    public void save(ExampleSaveVO vo, Long userId) {
        Example entity;
        if (vo.getId() != null) {
            entity = repository.findById(vo.getId())
                .orElseThrow(() -> new BusinessException(ErrorCode.DATA_NOT_FOUND, "数据不存在"));
            if (!entity.getOwnerId().equals(userId)) {
                throw new BusinessException(ErrorCode.FORBIDDEN, "无权操作");
            }
        } else {
            entity = new Example();
            entity.setOwnerId(userId);
        }
        BeanUtils.copyProperties(vo, entity, "id", "ownerId");
        repository.save(entity);
    }

    @Override
    public void delete(Long id, Long userId) {
        Example entity = repository.findById(id)
            .orElseThrow(() -> new BusinessException(ErrorCode.DATA_NOT_FOUND, "数据不存在"));
        if (!entity.getOwnerId().equals(userId)) {
            throw new BusinessException(ErrorCode.FORBIDDEN, "无权操作");
        }
        entity.setDeleted(1);
        repository.save(entity);
    }

    private ExampleVO toVO(Example entity) {
        ExampleVO vo = new ExampleVO();
        BeanUtils.copyProperties(entity, vo);
        return vo;
    }
}
```

## 8. 创建 Controller

```java
@RestController
@RequestMapping("/api/v1/example")
public class ExampleController {

    private final ExampleService exampleService;

    @PostMapping("/list")
    public RESTResult<PageResultVO<ExampleVO>> list(
            @RequestBody @Valid ExampleSearchVO vo,
            @CurrentUserId Long userId) {
        return RESTResult.success(exampleService.search(vo, userId));
    }

    @PostMapping("/save")
    public RESTResult<Void> save(
            @RequestBody @Valid ExampleSaveVO vo,
            @CurrentUserId Long userId) {
        exampleService.save(vo, userId);
        return RESTResult.success();
    }

    @PostMapping("/delete")
    public RESTResult<Void> delete(
            @RequestBody Map<String, Long> body,
            @CurrentUserId Long userId) {
        exampleService.delete(body.get("id"), userId);
        return RESTResult.success();
    }
}
```

## 9. 前端开发

### API 文件

```typescript
// api/example.ts
import request from '@/utils/request'

export function searchExamples(params: any) {
  return request.post('/example/list', params)
}

export function saveExample(data: any) {
  return request.post('/example/save', data)
}

export function deleteExample(id: number) {
  return request.post('/example/delete', { id })
}
```

### 页面组件

在 `pages/` 下创建页面，使用 `DataTable` 或自定义布局。

在 `router/index.tsx` 中添加路由：

```typescript

}
```

在 `sql/<模块名>/resource-data.sql` 中插入菜单资源数据，关联到角色。

## 10. 注册错误码

如果模块需要自定义错误码：

1. 在 `ErrorCode.java` 中添加常量
2. 在 `frontend-react/src/utils/error-codes.ts` 中添加映射
3. 在 `docs/development/03-错误码注册表.md` 中记录
