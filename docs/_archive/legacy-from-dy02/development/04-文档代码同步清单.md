## 六.2、产品话术数据模型与双表关系

| 表/实体 | 说明 | 使用场景 |
|---------|------|----------|
| `dy_product_script` | 商品库话术主表（产品维度多套话术，按 scriptType+style 维度版本） | 生成/保存/激活/列表/更新/删除；话术管理抽屉以本表为主 |
| `script_version_history` | 更新前快照，用于版本历史与回滚 | 每次 updateScript 写入一条；版本历史弹窗 |
| `dy_product_script_usage` | 话术使用与效果记录；`product_script_id` = **dy_product_script.id** | 效果摘要：使用次数、平均效果分、转化率、总销售额；P0 效果展示与 P1 效果回写 |
| `live_product.product_script_id` | 排品引用的话术 ID = **dy_product_script.id** | 效果摘要「被引用场次/条数」；统计 countByProductScriptId |
| `product_script_version` | 优化链路镜像表；`script_id` 指向 **dy_product_script.id**；**V099** `ai_generated` | `ensureOptimizationVersion` / `analyze(scriptId)` 会创建或复用镜像；`POST /product/script/analyze` 的 `scriptVersionId` 即本表主键；效果排行榜 `POST .../script-effectiveness/ranking` 支持 `source=ai\|human` |

**全局搜索 D1-04**：`POST /api/v1/search/global`（`module/search`）跨 `live_session` / `dy_product` / `dy_product_script` / `sv_video`，数据范围 `DataScopeService.getVisibleUserIds`。

**经营驾驶舱 CSV D5-02**：`POST /api/v1/dashboard/cockpit-export`（`CockpitExportServiceImpl`）场次维度导出，筛选：日期、账号、状态、开播时段桶、商品品类（`live_session` + `live_product` + `dy_product`）。

**驾驶舱场次预览 D5-02 下钻**：`POST /api/v1/dashboard/cockpit-preview`，返回 `CockpitPreviewVO`（`rows`/`rowCount`），与导出同源筛选与行集；前端 `getCockpitPreview` + `UnifiedKpiPage` 表格预览。

**前端 i18n D7-03**：`src/i18n/`（`dy-lang` localStorage）、`main.tsx` 引入；登录页语言切换、BaseLayout 语言菜单；约 20 个高频页 `useTranslation`。

**前端 a11y D8-04**：`eslint.config.js`（`eslint-plugin-jsx-a11y` 规则多为 warn）、`npm run lint`（`--max-warnings 500` 渐进收紧）；`e2e/a11y-i18n.spec.ts`（axe wcag2a/2aa 无 critical + 登录页 EN 标题）；`index.html` viewport 允许缩放以通过 `meta-viewport`。

**当前约定**：效果摘要依赖 `dy_product_script` + `dy_product_script_usage` + `live_product.product_script_id`（排品保存时 `ProductScriptUsageSyncService` 回写 usage）。优化分析依赖 `product_script_version` 镜像；入口可传主话术 `scriptId` 由后端自动 ensure。领域说明见 `docs/architecture/05-商品话术与优化链路.md`。

**商品库搜索扩展**：`ProductSearchVO.hasSellingPoints`、`hasProductLink`、`minScriptCount`（`ProductServiceImpl` + `DyProductScriptRepository.findProductIdsHavingAtLeastScriptCount`）。

**SSE 接口**：`/product/script/generate-multi-style-sse`、`/product/script/refine-with-ai-sse`（路径含 `-sse` 避免 OperationLogFilter 缓冲全响应）。

**规则**：新增话术相关表/字段或效果回写逻辑时，同步本表及 `docs/analysis/产品库话术-P0-P4-执行计划.md`。
