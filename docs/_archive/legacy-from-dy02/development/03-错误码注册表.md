## 全部错误码

### 200 — 成功
| 码 | 常量 | 说明 |
|----|------|------|
| 200 | SUCCESS | 成功 |

### 1000 — 系统/参数
| 码 | 常量 | 说明 |
|----|------|------|
| 1001 | VALIDATION_FAIL / INVALID_PARAMS | 参数校验失败 |
| 1002 | SYSTEM_BUSY / INTERNAL_ERROR | 系统繁忙/服务器错误 |
| 1003 | RATE_LIMIT | 请求频率超限 |
| 1004 | DUPLICATE_SUBMIT | 重复提交 |
| 1005 | DATA_NOT_FOUND / NOT_FOUND | 数据不存在 |
| 1006 | DATA_ALREADY_EXISTS | 数据已存在 |
| 1007 | OPERATION_NOT_ALLOWED | 操作不允许 |
| 1008 | TIANAPI_QUOTA_EXCEEDED | TianAPI 配额用尽 |

### 2000 — 认证鉴权
| 码 | 常量 | 说明 |
|----|------|------|
| 2001 | UNAUTHORIZED | 未登录或会话过期 |
| 2002 | FORBIDDEN / PERMISSION_DENIED | 无权限 |
| 2003 | TOKEN_INVALID | Token 无效 |
| 2004 | CAPTCHA_REQUIRED | 需要验证码 |
| 2005 | LOGIN_FAILED | 用户名或密码错误 |
| 2006 | USER_DISABLED | 账号已禁用 |
| 2007 | USER_NOT_FOUND | 用户不存在 |
| 2008 | ROLE_NOT_FOUND | 角色不存在 |
| 2009 | RESOURCE_NOT_FOUND | 资源不存在 |
| 2010 | PASSWORD_MISMATCH | 原密码不正确 |
| 2011 | USERNAME_EXISTS | 用户名已存在 |
| 2012 | OAUTH_ALREADY_BOUND | 三方账号已绑定 |
| 2013 | CAPTCHA_INVALID | 验证码错误 |
| 2014 | VERIFY_CODE_INVALID | 短信验证码错误 |
