# ADR 005：API 鉴权白名单单一来源

## 状态

已采纳（2026-03-19，upgrade-plan-v3 Phase1）

## 背景

`SecurityConfig` 与 `AuthTokenFilter` 各自维护一份 `/api/v1` 免登录路径，易产生漂移（一侧放行、另一侧仍拦）。

## 决策

- 白名单路径集中在 `cn.gaifan.douyinOperations.common.constant.ApiAuthWhitelist`（`PATHS` 数组 + `contains(String)`）。
- `SecurityConfig`、`AuthTokenFilter` 仅引用该类，不再重复字面量。

## 后果

- 新增 OAuth/Webhook 等免登录接口时：**只改** `ApiAuthWhitelist` + 文档（`docs/api/00` / `04-文档代码同步清单`）。
- 可选单测：`ApiAuthWhitelistTest`。

## 与 Phase1.2（Spring Security authenticated）关系

本仓库坚持 **Filter 返回业务码 2001**、**不将未登录映射为 HTTP 401**（见 `SecurityConfig` 注释）。**不**按 v3 原文启用「全站 `authenticated()` + CSRF」，以免破坏现有前端与 OpenAPI 约定；安全兜底仍依赖 `AuthTokenFilter` + 本白名单。
