# ADR 006：P0/P1 部分「降级」能力采纳为规则版终局

**状态**：已采纳（2026-03-22）  
**范围**：`docs/upgrade-plan-20260320/P0-P1-完成度对照表.md` 中下列条目由 ⚠️ 调整为 **✅（规则版/代理版）**，直至另有立项替换为官方 API / 真 ML / 跨集视觉模型。

## 决策

在**不引入新外部数据契约**的前提下，产品接受以下实现为**当前版本终局口径**，并在主对照表标记为 ✅，备注保留与理想终局的差距说明（便于后续 Epic 替换）。

| ID | 采纳口径 |
|----|----------|
| **L-3** | 完播率以 **`LiveOfficialCompletionRateProvider`**（如有）+ **监控/双点代理推算**为主；UI/文档区分 `official_proxy` / `monitor_derived`；**非**平台官方完播字段值仍以标注为准。 |
| **D-2** | 人设一致性以 **`PersonaConsistencyCheckerImpl`**（JSON 约束、截断、`persona-consistency.*` 配置）为终局；**非**跨集视觉模型。 |
| **H-3** | 同 D-2（复用人设校验链路）。 |
| **N-2** | A/B 分析以 **`statistics` + 事件 list + 无 experimentId 时 `recentExperiments`** 为终局；深化漏斗另排期。 |
| **N-3** | 受众画像以 **derived / placeholder + CSV import（V093）** 为终局；官方画像仍可选增强。 |
| **H-2** | 热点以 **`HotspotWindowService`** 分档、窗口与 **`recencySignals`** 代理为终局；**非** Prophet。 |
| **H-4** | 效果预测以 **`ContentEffectPredictor`** + **`calibration-factor`/`calibration-note`** 为终局；**非**统计回归。 |

## 后果

- **完成度对照表**中上述条目计为 **✅**，减少「长期 ⚠️」悬停；剩余 ⚠️ 以 **⚠️-MVP**（能力边界）与 **P2** 深化为主。
- 若将来接入抖音官方完播、平台受众画像、时序预测模型等，应**新开 Epic** 并修订本 ADR 或新增 ADR，而非回改历史迁移。
