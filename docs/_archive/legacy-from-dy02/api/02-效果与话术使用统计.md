# 效果评分与话术使用统计 — 单一路径说明

> 前端展示「效果 / 使用次数」时，请只走下列接口，避免混用历史或实验路径导致数据不一致。

## 1. 单条主话术效果摘要（抽屉、列表角标）

| 用途 | 方法 | 路径 | Body 要点 |
|------|------|------|-----------|
| 单条话术效果汇总 | POST | `/api/v1/product/script/effect-summary` | `{ "scriptId": <long> }` |
| 批量（同一页多条） | POST | `/api/v1/product/script/effect-summary-batch` | `{ "scriptIds": [ ... ] }` |

**说明**：与 `ProductScriptManageDialog`、列表批量拉取一致；不要与「脚本优化」分析接口混用。

## 2. 话术版本库（镜像版本）效果字段

| 用途 | 方法 | 路径 |
|------|------|------|
| 列表/详情中的效果分、转化率等 | POST | `/api/v1/product/script-version/list` 等版本库 CRUD |
| 人工更新效果分 | POST | `/api/v1/product/script-version/update-effectiveness` |
| 使用次数递增（一般由服务端在合法场景调用） | POST | `/api/v1/product/script-version/increase-usage` |

## 3. 直播排品与使用次数可信性

- 排品保存时携带 **`productScriptId`**（绑定到具体主话术），后端通过 **`dy_product_script_usage`** 记录，并按 **`live_product_id` + `product_script_id`**（或场次级回退）**幂等去重**。
- 仅绑定**已激活**话术时，「使用次数」与效果归因与话术一致；未绑定或绑定错误会导致指标不可信。

## 4. 商品链接批量提取任务状态

| 用途 | 方法 | 路径 |
|------|------|------|
| 单商品 | POST | `/api/v1/product/extract-job-status` |
| 批量进度轮询 | POST | `/api/v1/product/extract-job-status-batch` |

## 5. 商品库就绪度汇总（看板 / 工具栏）

| 用途 | 方法 | 路径 |
|------|------|------|
| 与「商品搜索」**同一套筛选条件**下的汇总计数（忽略分页） | POST | `/api/v1/product/readiness-summary` |

**Body**：与 `POST /api/v1/product/search` 相同字段（`keyword`、`hasProductLink`、`minScriptCount` 等）；`page`/`rows` 仅占位满足校验，可传 `0`/`1`。

**返回字段**：`totalProducts`、`withProductLink`、`withSellingPoints`、`withAtLeastOneScript`、`withActiveScript`。

**说明**：数据权限与 `search` 一致（`DataScopeService` 注入 `userIds`）。**链接提取进行中任务数**未在此接口统计（请用 `extract-job-status-batch` 对已知 `productIds` 轮询）。

## 6. 相关前端页面

- 商品库：`/{admin|org|talent}/product`
- 商品就绪看板：`/{admin|org|talent}/product/readiness`
- 话术版本库：`/{admin|org|talent}/product/script-versions`
- 话术优化（分析/建议，非效果汇总主路径）：`/{admin|org|talent}/product/script-optimization`
