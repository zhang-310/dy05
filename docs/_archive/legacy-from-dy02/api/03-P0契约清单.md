# P0 API 契约清单

> **目的**：固化「高优先级路径 + 最小请求体」，配合契约冒烟测试与 OpenAPI，降低前后端路径/方法漂移。  
> **机器可读清单**：`src/test/resources/p0-api-contract/p0-endpoints.json`（与本文档同步维护）。  
> **自动化**：`P0ApiContractSmokeTest`（`src/test/java/.../contract/P0ApiContractSmokeTest.java`）。

## 约定

| 项 | 说明 |
|----|------|
| 受保护 POST | 无 `Authorization` 时须 **HTTP 200** 且 `RESTResult.status === 2001`（未登录），**不得** 404/5xx |
| 白名单 POST | 如登录接口：无 Token 调用须 **非 5xx**（业务错误可接受） |
| OpenAPI | `GET /v3/api-docs` 可访问，供导出与文档生成（见 `scripts/export-openapi.ps1`） |

## OpenAPI 导出

后端启动后执行：

```powershell
.\scripts\export-openapi.ps1 -BaseUrl http://localhost:8080 -OutFile openapi\p0-snapshot.json
```

可将快照纳入 Code Review 或 CI 比对（按需接入 `diff` / Spectral）。

## 测试运行说明

- `P0ApiContractSmokeTest` 使用 **Testcontainers** 启动 Redis，并设置 `auth.token-store=memory`。  
- 注解 `@Testcontainers(disabledWithoutDocker = true)`：**本机无可用 Docker 时整类跳过**（Maven 仍成功）；**CI 建议启用 Docker** 以执行契约冒烟。  
- 依赖：`pom.xml` 中 `testcontainers` + `junit-jupiter`。

## 维护规则

1. 增删 P0 路径时：**同时改** `p0-endpoints.json` 与本表。  
2. 若审批、直播、短视频等模块变更 Controller 路径：**先改后端与前端 `api/*`，再更新本清单与 JSON**。  
3. Live 审批 `approve` / `reject`：**必须** `sessionId` + `scriptId`（见 `LiveApprovalController` 与 `frontend-react/src/api/live-approval.ts`）。
