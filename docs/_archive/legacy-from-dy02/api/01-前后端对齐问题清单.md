## 待关注 / 待产品决策

### 1. 退款双路径（后端设计如此）

| 路径 | 用途 |
|------|------|
| `POST /payment/refund` + query `orderNo`/`reason` | `PaymentController` 快捷申请 |
| `POST /payment/refund/create` + body `RefundSaveVO` | `RefundController` 完整创建 |

前端 `requestRefund` 与 `createRefund` 并存；**非 bug**，文档与运营需约定何时用哪条。

### 2. 粉丝画像同步路径

后端 `POST /douyin/fan-profile/sync/{accountId}` 使用 **PathVariable**（与多数「纯 POST body」略有不同）。前端已封装为单 URL 调用。

### 3. 后端有、前端未接页面或少量调用

以下仍为**能力预留**或待页面接入（非阻塞契约错误）：

- Live：`material/*`、`script-navigation/*`、`danmaku/*`、`rhythm/*`、`collaboration/*`、`ab-analysis/*`、部分 `generation-task` 管理接口
- AI：`evolution/*` 部分、`media/*` 部分、知识库分片上传等
- Shortvideo：`contrast-template/*`、`cross/*`、部分 `short-video/*` 前缀与 `shortvideo/*` 并存（见下节）
