## 关键原则

1. **每个任务必须 `mvn compile` + `npx tsc --noEmit` 通过**
2. **硬编码参数一律迁移到 `BusinessParamConfig`**（application.yml `app.business.*`）
3. **新增/修改表结构必须同步 Flyway 迁移**（`V<序号>__<描述>.sql`）
4. **跨模块依赖用 `@Autowired(required = false)` + null 检查**
5. **SSE 路径必须含 `-sse` 或 `chat-stream`**
6. **错误码三处同步**：ErrorCode.java ↔ error-codes.ts ↔ 错误码注册表
