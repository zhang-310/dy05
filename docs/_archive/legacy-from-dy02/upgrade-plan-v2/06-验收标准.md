# 验收标准

> 每阶段完成后的检查清单，全部通过方可进入下一阶段

---

## 通用检查（每个任务必过）

- [ ] `mvn compile` — 0 错误
- [ ] `cd frontend-react && npx tsc --noEmit` — 0 错误
- [ ] 新增/修改的 Entity 与数据库表结构一致（`ddl-auto: validate` 不报错）
- [ ] 新增错误码已同步三处（ErrorCode.java / error-codes.ts / 错误码注册表）
- [ ] 跨模块依赖使用 `@Autowired(required = false)` + null 检查
- [ ] 无硬编码密钥、无 SQL 注入风险
- [ ] owner_id 数据隔离已强制过滤

---

## Phase 1 验收（消除空壳 + 打通闭环）

### 1.1 自进化规则引擎
- [ ] `POST /api/v1/ai/evolution/evaluate-rules` 返回非空结果
- [ ] evaluateUpdateRule 返回过期文档列表（含 reason、staleDays）
- [ ] evaluateArchivalRule 返回冷文档列表
- [ ] evaluateDedupRule 返回重复文档列表

### 1.2 知识质量评分
- [ ] 对 3 个不同文档调用质量评分 API，返回不同分数
- [ ] 新导入文档的 freshness 分数 > 90
- [ ] 超过 180 天未更新的文档 freshness 分数 < 30
- [ ] 综合评分 = 各维度加权（权重可通过 application.yml 调整）

### 1.3 进化仪表盘
- [ ] 健康度评分来自 ai_knowledge_quality_score 聚合
- [ ] 知识覆盖率 = 有文档的主题数 / 总主题数
- [ ] 进化速度 = 最近 7 天完成的任务数
- [ ] 刷新页面后数据随实际情况变化

### 1.4 话术效果闭环
- [ ] 话术评分 < 40 时，自动创建新版本（status=draft, source=auto_improve）
- [ ] 新版本 parent_version_id 指向原版本
- [ ] 话术评分 < 25 时，原版本自动归档
- [ ] 改进日志记录完整（原评分、改进原因、新版本ID）

### 1.5 爆款结构化分析
- [ ] analyzeViral 返回 JSON 格式（含 opening/climax/ending/emotionCurve/bgm/viralElements）
- [ ] 前端展示情绪曲线折线图
- [ ] 前端展示开场/高潮/结尾三段式卡片
- [ ] 旧的纯文本分析结果仍可正常显示（向后兼容）
- [ ] 二创建议列表包含 3-5 条具体建议

### 1.6 硬编码参数迁移
- [ ] 修改 application.yml 中 attribution.viewer-weight 后，归因计算结果随之变化
- [ ] 修改 effectiveness.conversion-weight 后，效果评分随之变化
- [ ] 修改 version-comparison.high-similarity-threshold 后，版本对比判断随之变化
- [ ] 所有权重/阈值均可通过配置调整，无需改代码

### 1.7 搜索日志
- [ ] 执行混合搜索后，ai_search_log 表有新记录
- [ ] 记录包含 query_text、hit_doc_ids、hit_count、latency_ms
- [ ] 异步写入不影响搜索响应时间

## Phase 2 验收（核心能力补齐）

### 2.1 情绪过山车引擎
- [ ] ScriptPlanningPage 显示情绪曲线选择器（5+ 预设模板）
- [ ] 选择"过山车型"模板后，生成的脚本内容体现高低起伏
- [ ] 情绪曲线可拖拽编辑节点
- [ ] 生成结果附带 BGM 节奏建议

### 2.2 Cross-Encoder 重排
- [ ] 搜索结果经过重排（日志中可见 rerank 步骤）
- [ ] Ollama 可用时使用 bge-reranker，不可用时降级到 LLM 打分
- [ ] 重排耗时 < 2 秒（5 条文档）
- [ ] 重排后 top-1 结果的相关性优于重排前

### 2.3 RAG 自适应权重
- [ ] 短查询（<5字）使用 keyword 偏重权重（0.6）
- [ ] 长查询（>20字）使用 vector 偏重权重（0.8）
- [ ] 权重可通过 application.yml 配置
- [ ] 搜索日志记录实际使用的权重

### 2.4 实时话术推荐
- [ ] 停留率 < 40% 时，实时面板弹出"切换互动话术"建议
- [ ] 互动率 < 2% 时，弹出"注入互动话术"建议
- [ ] 建议通过 SSE 推送（路径含 `-sse`）
- [ ] 用户可点击"采纳"或"忽略"
- [ ] 阈值可通过 application.yml 配置

### 2.5 A/B 测试
- [ ] 可创建 A/B 测试（指定两个版本和流量分配）
- [ ] 记录曝光次数（A/B 分别计数）
- [ ] 效果指标自动更新（转化率、停留率、互动率）
- [ ] 样本量 > 100 且 p_value < 0.05 时自动判定胜者
- [ ] 胜出版本可一键设为推荐版本

### 2.6 版本语义对比
- [ ] 对比结果包含字符相似度和语义相似度两个指标
- [ ] 语义相似度基于向量余弦距离计算
- [ ] 效果指标对比（如有数据）
- [ ] 差异摘要由 LLM 生成（50字以内）

### 2.7 BGM 推荐
- [ ] 生成脚本时自动推荐 3 个 BGM 风格
- [ ] 推荐结果包含匹配度评分和推荐理由
- [ ] 情绪曲线不同时，推荐的 BGM 风格不同

### 2.8 多级审批
- [ ] 低风险话术自动通过（无需人工审批）
- [ ] 高风险话术需要两级审批
- [ ] 审批流转记录完整（每级审批人、时间、意见）
- [ ] 审批超时无告警（Phase 4 再做）

## Phase 3 验收（智能化升级）

### 3.1 知识图谱
- [ ] 知识库导入文档时，自动抽取实体和关系
- [ ] ai_graph_node 表有数据（entity_type 包含 product/ingredient/effect 等）
- [ ] ai_graph_edge 表有数据（relation_type 包含 contains/treats/suits 等）
- [ ] 单跳查询：输入"玻尿酸"，返回相关功效和适合人群
- [ ] 多跳查询：输入"玻尿酸"到"干性肌肤"，返回路径
- [ ] GraphRAG 检索结果包含图上下文信息

### 3.2 因果推理
- [ ] 反事实查询：输入 {scriptType: "种草"} → 干预 {scriptType: "促销"}，返回预测变化
- [ ] 返回结果包含影响路径和置信区间
- [ ] 因果因子每周自动更新（从 live_script_effectiveness 聚合）
- [ ] 更新日志记录旧因子和新因子

### 3.3 用户画像
- [ ] ai_user_cognitive_profile 表有数据
- [ ] 用户生成话术后，preferred_script_types 自动更新
- [ ] 用户编辑 AI 内容后，avg_edit_ratio 自动更新
- [ ] 不同用户生成的话术风格有差异（基于画像）

### 3.4 趋势预测
- [ ] 热点列表显示生命周期阶段（emerging/rising/peak/declining）
- [ ] 显示时间窗口类型（golden/silver/bronze/expired）
- [ ] 黄金窗口热点排在列表前面
- [ ] emerging 阶段热点附带 LLM 分析的内容角度建议

### 3.5 战略规划
- [ ] 战略规划基于账号真实数据（粉丝数、增长率、转化率）
- [ ] 不同账号的规划内容不同
- [ ] 包含诊断、目标、行动项、时间线
- [ ] 无数据时给出合理的冷启动建议

### 3.6 账号诊断
- [ ] clarity 指标基于人设描述与内容关键词的重合度
- [ ] competitiveness 指标基于与行业基准的对比
- [ ] 不同账号的诊断结果不同
- [ ] 行业基准可通过 application.yml 配置

## Phase 4 验收（差异化壁垒）

### 4.1 二创模板库
- [ ] 可从爆款分析结果一键生成二创模板
- [ ] 4 种二创类型（形式模仿/内容翻转/元素重组/升维创新）均可生成脚本
- [ ] 模板使用次数自动累计
- [ ] 模板推荐基于产品类型和内容目标

### 4.2 BGM 引擎增强
- [ ] sv_bgm_library 表有预设数据
- [ ] 推荐基于爆款数据统计（avg_viral_score 排序）
- [ ] 过滤已过期版权的 BGM
- [ ] 不重复推荐近 7 天已用的 BGM

### 4.3 竞品监测
- [ ] 可添加竞品账号
- [ ] 可手动触发数据采集
- [ ] 对标分析显示优劣势对比（粉丝/播放/点赞率等维度）
- [ ] 竞品粉丝异常增长时触发告警

### 4.4 工作流引擎
- [ ] 可创建工作流模板（JSON 定义）
- [ ] 自动步骤按依赖顺序执行
- [ ] 人工步骤暂停等待操作
- [ ] 进度通过 SSE 实时推送
- [ ] 失败步骤可重试

### 4.5 跨域知识迁移
- [ ] 质量评分 > 80 的知识自动沉淀到公共知识库（owner_id=0）
- [ ] 新用户可检索到公共知识
- [ ] 迁移时自动去除个人信息
- [ ] 迁移后的知识经过质量评分验证

- [ ] RAG 检索 P95 延迟 < 3 秒
- [ ] 话术生成 P95 延迟 < 30 秒
- [ ] 实时面板 SSE 推送延迟 < 2 秒
- [ ] 爆款分析 P95 延迟 < 60 秒

### 数据完整性
- [ ] 所有 mock 数据已替换为真实数据
- [ ] 所有硬编码参数已迁移到配置
- [ ] 搜索日志、质量评分、进化日志正常记录

- [ ] 话术生成 → 效果评分 → 低分自动迭代 → 新版本生成 ✅

- [ ] 知识导入 → 实体抽取 → 图谱构建 → GraphRAG 检索 ✅
- [ ] 实时数据 → 阈值触发 → AI 建议 → 用户采纳 ✅
- [ ] 用户行为 → 画像更新 → 个性化生成 ✅
