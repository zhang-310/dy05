【关键指标】
  API 指标:
    - api.requests.total (API 请求总数)
    - api.response.time (响应时间 p50/p95/p99)

  业务指标:
    - user.login.attempts (登录尝试)
    - data.operation.duration (数据操作耗时)
    - business.errors (业务错误)
    - cache.operations (缓存操作)

  系统指标:
    - jvm.memory.used (JVM 内存)
    - jvm.threads.live (活跃线程)
    - database.pool.active (数据库连接)
    - method.execution.time (方法执行时间)

【告警规则】(8 条)
  1. HighErrorRate - 错误率 > 5% (5 分钟)
  2. SlowApiResponse - API p95 > 1s (5 分钟)
  3. LowCacheHitRate - 缓存命中率 < 50% (10 分钟)
  4. HighDatabasePoolUsage - 连接池 > 80% (5 分钟)
  5. HighJvmMemoryUsage - JVM 堆内存 > 85% (5 分钟)
  6. SlowDataOperation - 数据操作 p95 > 500ms (5 分钟)
  7. HighLoginFailureRate - 登录失败率 > 10% (5 分钟)
  8. BackendDown - 后端应用不可用 (1 分钟)

【仪表板面板】(9 个)
  1. API 请求速率 (requests/sec)
  2. 平均响应时间 (ms)
  3. 错误率 (%)
  4. 缓存命中率 (%)
  5. 数据库连接池使用率
  6. JVM 内存使用 (bytes)
  7. 线程数
  8. 用户登录指标
  9. 业务操作指标

【在代码中使用】
  @Autowired
  private BusinessMetrics businessMetrics;

  // 记录登录
  businessMetrics.recordLogin("password", true);

  // 记录数据操作
  businessMetrics.recordDataOperation("save", "AuthUser", duration);

  // 记录业务错误
  businessMetrics.recordBusinessError("NullPointerException", "AuthService");

  // 记录缓存操作
  businessMetrics.recordCacheOperation("hit", "redis", duration);

  // 记录 API 请求
  businessMetrics.recordApiRequest("/api/v1/auth/login", "POST", 200, duration);
