# 抖音运营 SaaS 平台 — 产品需求总览（PRD）

> 版本：3.0 | 更新日期：2026-03-27

---

## 一、产品定位

**抖音 AI 运营系统** 是面向主播、达人和内容创作者的 SaaS 平台。帮助用户管理抖音账号、短视频创作和直播运营，核心能力由 AI 知识库驱动。

**一句话**：让每个人都能成为专业的抖音运营者。

**核心差异化**：

1. **爆款视频 AI 复刻** —— 看到爆款 → AI 分析结构 → 按人设生成方案 → 快速复刻出片
2. **AI 全流程视频制作** —— 分镜脚本 → AI 生成关键帧 → AI 生成视频片段 → TTS 配音 → AI 自动剪辑成片
3. **AI 驱动的直播话术** —— 按人设 + 风格 + 产品，AI 自动生成开场、产品讲解、结尾话术
4. **企业级抖音知识库** —— 基于向量检索的抖音运营知识体系，持续自进化，为所有 AI 能力提供领域知识支撑

## 二、目标用户

| 角色 | 痛点 | 核心场景 |
|------|------|----------|
| 短视频达人 | 不知道拍什么、模仿爆款靠猜、出片效率低 | 爆款复刻、热点追踪、AI 文案、视频策划 |
| 直播主播 | 话术准备耗时、违规风险高、不懂数据分析 | 话术库、违规检测、直播策划、数据复盘 |
| 电商商家 | 产品展示没章法、转化低、多品直播混乱 | 产品话术、带货策划、直播数据分析 |
| MCN 运营 | 多达人管理混乱、内容质量不一 | 统一账号管理、数据汇总、模板复用 |

### 4.3 模块依赖关系

```
auth ← 所有模块（认证鉴权基础）
config ← ai, storage, douyin（系统配置 + 行业分类）
storage ← shortvideo, live, ai, copy（文件上传、AI 生成资产存储）
log ← 所有模块（操作日志记录）

douyin ← shortvideo, live（账号 + 人设 + 产品）
ai ← shortvideo, live, script, copy, agent（AI 生成能力 + 知识库）
script ← live, shortvideo（话术库 + 违规检测）
product ← live（直播关联商品）
agent ← ai（智能体依赖 AI 模型能力）
wecom ← auth（企微机器人推送，依赖用户体系）
abtest ← shortvideo, live, copy（A/B 实验关联变体内容）
```

> **注意：** 产品管理（dy_product）属于 douyin 模块，不是独立模块。AI 模型的具体接口配置通过 ai 模块的 `ai_model_config` + `ai_task_model_config` 两张表管理，不在 sys_config 中。

## 五、核心业务流程

### 5.1 首次使用

```
注册账号 → 登录 → 绑定抖音号(OAuth2) → 创建人设（定位/风格/标签）→ 进入工作台
```

### 5.2 短视频创作流程

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 发现爆款 │───→│ 分析结构 │───→│ 策划方案 │───→│ AI生成   │───→│ AI视频   │───→│ 发布复盘 │
│ /热点    │    │ (AI拆解) │    │ (按人设) │    │ 文案脚本 │    │ 制作     │    │ 数据追踪 │
└─────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘

具体路径：
a. 爆款复刻：浏览爆款库 → AI分析视频结构 → 按人设改编 → 生成拍摄方案 + 文案
b. 热门策划：追踪热门话题 → AI推荐选题 → 生成创作方案
c. 自主创作：选择主题 → AI按人设生成多版文案 → 选定 → 拍摄指导
d. AI视频制作：上传人像/背景 → AI按分镜生成关键帧 → AI生成视频片段 → TTS配音 → AI剪辑成片
e. 数据复盘：同步视频数据 → AI分析表现 → 推荐改进方向
```

### 5.3 直播运营流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 创建场次 │───→│ 选品排序 │───→│ 生成话术 │───→│ 开播执行 │───→│ 数据复盘 │
│ 绑定账号 │    │ 绑定产品 │    │ AI+人设  │    │ 数据监控 │    │ AI分析   │
└──────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘

具体路径：
a. 场次准备：创建直播场次 → 关联产品（排序）→ AI按人设+风格生成整场话术
b. 话术生成：开场话术 + 每个产品讲解话术 + 转场话术 + 结尾话术
c. 违规检测：话术生成后自动检测违规词（公共库+个人库）→ 标红提示 → 修改
d. 开播执行：话术提词 → 实时数据监控（通过抖音API）
e. 数据复盘：直播结束 → 同步数据 → AI分析（观看、互动、转化）→ 改进建议
```

### 5.4 话术管理流程

```
┌──────────┐    ┌──────────┐    ┌──────────┐
│ 话术生成 │───→│ 违规检测 │───→│ 入库管理 │
│ AI+人设  │    │ 公共+个人│    │ 话术库   │
└──────────┘    └──────────┘    └──────────┘

- 话术可按人设+风格生成不同版本
- 同一产品可有多套话术（正式/种草/促销）
- 公共违规词库由平台维护，个人违规词库用户自定义
- 话术库支持分类、搜索、收藏、复用
```

## 六、各模块功能概要

### 6.1 douyin 模块（抖音账号）

```
douyin 模块
├── 账号管理
│   ├── OAuth2 绑定抖音号（用户默认绑定一个主账号）

│
├── 人设管理
│   ├── 创建/编辑人设（定位/风格/标签/目标受众）
│   ├── 人设模板（系统预设 + 用户自定义）
│   └── 人设关联账号
│
├── 产品管理
│   ├── 添加/编辑/删除产品（名称/价格/卖点/图片）

### 6.2 ai 模块（AI 知识库 + 生成引擎 + 知识自进化）

```
ai 模块（从 cursor 知识库系统升级）
├── 知识库引擎
│   ├── 抖音领域向量知识库（Milvus + BGE-M3 嵌入）
│   ├── 知识索引（全量/增量）
│   ├── 混合检索（Milvus 语义 + ES 关键词 → RRF 融合 → 重排 + Redis 缓存）
│   └── 多租户隔离（企业/个人知识空间）
│
├── 知识自进化引擎（核心差异化 —— 最强抖音运营大脑）
│   ├── 进化管线（主题采样→上下文收集→LLM生成→质量评分→主题扩展→异步入库）
│   ├── 主题池管理（1000 上限，13 分类，均衡采样，自动扩展，去重轮换）
│   ├── 质量评分（11 维度 100 分制，低分不入库，极低分深化队列）
│   ├── 11 种进化角度（失败复盘/可执行步骤/数据量化/行业标准/跨域迁移/...）
│   ├── 3 层 LLM 回退（Ollama → DeepSeek API → Ollama 备用，99.5%+ 可用性）
│   └── 异步索引队列（高分报告→分块→嵌入→Milvus + ES 双写入库）
│
├── 生成能力
│   ├── 短视频文案生成（按人设 + 选题 + 风格）
│   ├── 视频方案生成（结构/分镜/文案一体化）
│   ├── 直播话术生成（开场/产品/转场/结尾）
│   ├── 爆款分析（拆解视频结构/话术/节奏）
│   └── 数据分析报告生成（视频复盘/直播复盘）
│
├── 多媒体生成
│   ├── AI 图像生成（按分镜描述+人像+背景生成关键帧）
│   ├── AI 视频生成（从首尾帧关键帧生成视频片段）
│   ├── AI 语音合成 TTS（话术文本转语音配音）
│   └── AI 视频剪辑（视频片段+配音→合成最终成片）
│
├── 模型管理
│   ├── 多模型支持（DeepSeek / Ollama 本地 / 其他 API）
│   ├── 3 层模型回退机制（指数退避重试，429/502 特殊处理）
│   └── API 调用额度管理（按套餐限制）
│
└── 管理端（平台管理员）
    ├── 知识库管理（索引状态/数据量/健康检查）
    ├── 进化引擎看板（任务历史/评分趋势/主题分布/深化队列）
    ├── 进化主题管理（主题池 CRUD + 批量导入 + 分类权重）
    ├── 模型配置（模型切换/参数调整）
    ├── 调用日志（谁调了什么/耗时/Token数）
    └── Prompt 模板管理（系统级提示词模板）
```

│   └── 违规词导入/导出
│
├── 违规检测
│   ├── 文本违规扫描（输入文本 → 返回违规词列表 + 位置）
│   ├── 批量检测（整场话术一键检测）
│   └── 替换建议（AI 推荐合规替代词）
│
└── 话术模板
    ├── 系统预设模板（按行业/场景）
    └── 用户自定义模板
```

### 6.6 基础模块概要

| 模块 | 核心功能 |
|------|----------|
| **auth** | 注册/登录、Token 鉴权、RBAC 权限（角色→资源）、用户管理、资源管理 |
| **log** | 操作日志（谁在什么时间做了什么）、系统异常日志 |
| **config** | 分组层级配置管理（2 级分组树 + 配置表单）、支持 5 种值类型（含密码脱敏）、行业分类管理（全局共用） |
| **storage** | 文件上传（头像/产品图/视频封面/AI生成图片/视频/音频）、对象存储对接（BOS/OSS） |
| **system** | 审计日志、API 调用统计、数据同步记录、系统健康检查 |
