🚀 快速启动命令
================================================================================

1. 准备环境:
   cp .env.example .env

2. 自动化启动（推荐）:
   chmod +x setup-docker.sh
   ./setup-docker.sh

3. 手动启动:
   docker-compose build
   docker-compose up -d
   docker-compose ps

4. 验证服务:
   curl http://localhost/health
   curl http://localhost:8080/actuator/health

5. 查看日志:
   docker-compose logs -f backend

6. 停止服务:
   docker-compose down -v
