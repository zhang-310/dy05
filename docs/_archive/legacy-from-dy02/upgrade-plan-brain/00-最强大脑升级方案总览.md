## 二、11 个 Brain Service 现状（与代码一致）

| 服务 | 实现程度 | 实现要点 / 剩余短板 |
|------|----------|---------------------|
| **HostPersonaService** | ✅ 完整 | `ai_host_persona`、贝叶斯因子、风格向量、流程位 `flow_phase` |
| **IpGrowthStageService** | ✅ 完整 | `BusinessParamConfig.IpGrowth` 等 |
| **TrendMonitorService** | ✅ 完整 | 真实趋势数据 |
| **IndustryCausalEngine** | ✅ 生产可用 | `BusinessParamConfig.CausalEngine` / `application.yml` 基准率与因子；主播 `bayes_factors`；效果库自适应话术因子；**LLM 与贝叶斯融合**；无模型时贝叶斯-only |
| **IndustryKnowledgeGraph** | ✅ 分层回退 | **Neo4j**（`NEO4J_URI`）→ **知识库检索** → **JPA** `AiGraphNode`/`AiGraphEdge` 上下文；未部署 Neo4j 仍可运行 |
| **UserCognitiveProfile** | ✅ 数据驱动 | `ai_user_cognitive_profile` + 直播话术/效果等聚合（**非**固定 0.8/0.6/0.7 Mock） |
| **StrategicPlanning** | ✅ LLM+数据 | 收集账号/场次/项目/视频/趋势等上下文；**`skincare` 模板**；依赖 `LlmClient` 与模型配置 |
| **GrowthPath** | ⚠️ 依赖战略 | **优先**委托 `StrategicPlanningService.generateGrowthPath`；战略不可用时 **三阶段默认里程碑**（仍为模板） |
| **AccountDiagnosis** | ✅ 多源真实 | 抖音账号、短视频播放量、知识质量分、直播效果等；**clarity/competitiveness/growth** 可计算并标注「部分估算」 |
| **HostStyleConsistency** | ✅ 向量优先 | `VectorService` 嵌入余弦相似度；失败回退 **关键词匹配** |
| **RiskWarning** | ✅ 合规贯通 | `ContentSecurityScanner` + **`ComplianceWordService`**（医疗违禁、绝对化替换） |
| **FiveHostsSynergy** | ⚠️ 半数据 | `flow_phase` 来自人设表；**流量路径中文描述**、`ResourceTransferPlan` 触发词/渠道等 **仍有硬编码运营文案** |
