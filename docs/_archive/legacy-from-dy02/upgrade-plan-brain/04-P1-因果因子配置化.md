# P1：因果因子配置化

## 现状

**文件**：`module/ai/service/impl/brain/IndustryCausalEngineImpl.java`

```java
// computeBayesianScore 中硬编码
if (scriptType.contains("种草") || scriptType.contains("安利")) rate *= 1.15;
else if (scriptType.contains("促销") || scriptType.contains("秒杀")) rate *= 1.08;
else if (scriptType.contains("产品")) rate *= 1.05;
// ...
if (persona.contains("专业") || persona.contains("达人")) rate *= 1.12;
// ...
if (productType.contains("护肤") || productType.contains("美妆")) rate *= 1.10;
// ...
if (timeSlot.contains("晚") || timeSlot.contains("20")) rate *= 1.08;
```

**已有**：`ai_host_persona.bayes_factors` 已接入，主播因子动态。

## 方案

### 1. BusinessParamConfig 扩展

在 `CausalEngine` 中增加默认因果因子映射：

```java
@Data
public static class CausalEngine {
    private double baseRate = 0.35;
    /** 话术类型因子：匹配关键词 -> 乘数 */
    private Map<String, Double> scriptTypeFactors = Map.of(
        "种草", 1.15, "安利", 1.15,
        "促销", 1.08, "秒杀", 1.08,
        "产品", 1.05
    );
    /** 人设因子 */
    private Map<String, Double> personaFactors = Map.of(
        "专业", 1.12, "达人", 1.12,
        "亲切", 1.05, "姐妹", 1.05
    );
    /** 产品类型因子（仅护肤彩妆） */
    private Map<String, Double> productTypeFactors = Map.of(
        "护肤", 1.10, "美妆", 1.10,
        "精华", 1.12, "面膜", 1.08, "眼霜", 1.10, "套盒", 1.15
    );
    /** 时段因子 */
    private Map<String, Double> timeSlotFactors = Map.of(
        "晚", 1.08, "20", 1.08, "21", 1.08,
        "午", 1.02, "12", 1.02
    );
}
```

### 2. application.yml

```yaml
app.business.causal-engine:
  base-rate: 0.35
  script-type-factors:
    种草: 1.15
    安利: 1.15
    促销: 1.08
    秒杀: 1.08
    产品: 1.05
  persona-factors:
    专业: 1.12
    达人: 1.12
    亲切: 1.05
    姐妹: 1.05
  product-type-factors:
    护肤: 1.10
    美妆: 1.10
    精华: 1.12
    面膜: 1.08
    眼霜: 1.10
    套盒: 1.15
  time-slot-factors:
    晚: 1.08
    20: 1.08
    21: 1.08
    午: 1.02
    12: 1.02
```

### 3. computeBayesianScore 改造

- 遍历 `scriptTypeFactors`，若 `scriptType.contains(key)` 则 `rate *= value`
- 人设、产品、时段同理
- 取匹配到的最大乘数（或首次匹配），避免重复叠加

### 4. 可选：sys_config 动态配置

若需运营在线修改，可增加 `ai.causal-engine.script-type-factors` 等 JSON 配置，从 ConfigService 读取，覆盖 BusinessParamConfig 默认值。
