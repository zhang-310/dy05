# P0 + P4：贝叶斯基准率参数化 | 风险预警合规词集成

## P0 贝叶斯基准率参数化

### 现状

**文件**：`module/ai/service/impl/brain/IndustryCausalEngineImpl.java`

```java
/** 贝叶斯先验：基准转化率 */
private static final double BASE_RATE = 0.35;
```

### 方案

1. **BusinessParamConfig 新增**：`app.business.causal-engine.base-rate`

```java
// BusinessParamConfig.java
@Data
public static class CausalEngine {
    private double baseRate = 0.35;
}

private CausalEngine causalEngine = new CausalEngine();
```

2. **application.yml 默认值**：

```yaml
app.business.causal-engine:
  base-rate: 0.35
```

3. **IndustryCausalEngineImpl 修改**：

```java
@Autowired(required = false)
private BusinessParamConfig businessParamConfig;

private double getBaseRate() {
    return businessParamConfig != null && businessParamConfig.getCausalEngine() != null
        ? businessParamConfig.getCausalEngine().getBaseRate()
        : 0.35;
}
// computeBayesianScore 中：double rate = getBaseRate();
```

### 工时

约 1h

## P4 风险预警合规词集成

### 现状

**文件**：`module/ai/service/impl/brain/RiskWarningServiceImpl.java`

- 已调用 `ContentSecurityScanner.scan`（隐私、违禁词、编码）
- 已注入 `ComplianceWordService`，但未调用

```java
if (complianceWordService != null && complianceWordService.isLoadedFromDb()) {
    // 可扩展：调用合规词检测
}
```

### 方案

在 `warn` 方法中，在 ContentSecurityScanner 之后增加合规词检测：

```java
if (complianceWordService != null && complianceWordService.isLoadedFromDb()) {
    for (String v : complianceWordService.getMedicalViolations()) {
        if (content.contains(v)) {
            items.add(new RiskItem(3, "medical", "医疗违禁: " + v, 0, 0, "建议移除或替换"));
            violationCount.incrementAndGet();
        }
    }
    if (complianceWordService.getAbsoluteReplacements() != null) {
        for (String abs : complianceWordService.getAbsoluteReplacements().keySet()) {
            if (content.contains(abs)) {
                items.add(new RiskItem(2, "compliance", "绝对化用语: " + abs, 0, 0,
                    "建议替换为: " + complianceWordService.getAbsoluteReplacements().get(abs)));
                violationCount.incrementAndGet();
            }
        }
    }
}
```

### 工时

约 0.5h
