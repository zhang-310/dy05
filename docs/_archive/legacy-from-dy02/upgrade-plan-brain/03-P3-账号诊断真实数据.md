# P3：账号诊断真实数据

## 现状

**文件**：`module/ai/service/impl/brain/AccountDiagnosisServiceImpl.java`

```java
return douyinAccountRepository.findById(accountId)
    .map(acc -> {
        double clarity = 0.7;        // 固定
        double competitiveness = 0.65;  // 固定
        double growth = 0.6;       // 固定
        String risk = "低";
        List<String> priorities = new ArrayList<>();
        priorities.add("人设强化");
        priorities.add("内容密度提升");
        if (acc.getDescription() == null || acc.getDescription().isBlank()) {
            clarity = 0.5;
            priorities.add(0, "完善账号简介与定位");
        }
        // ...
    })
```

**可用数据**：`douyin_account` 表含 `fan_count`、`video_count`、`total_likes`、`description`。

## 方案

### 1. clarity（清晰度）

- `description` 为空：0.3
- `description` 长度 < 20：0.5
- `description` 长度 20–100：0.7
- `description` 含「定位」「品类」「人设」等关键词：+0.1

### 2. competitiveness（竞争力）

- 基础分 0.5
- `video_count > 0` 时：`avgLikeRate = total_likes / video_count`，按 `avgLikeRate` 分档（如 1k/5k/10k/50k）加分
- `fan_count` 分档：1k/1w/10w/50w 对应加分

### 3. growth（增长潜力）

- 若无历史数据：用 `fan_count`、`total_likes` 做静态评分
- 若有 `live_monitor` 或 `sv_video_data` 等增长数据：可计算环比增长率

### 4. priorities 动态生成

- clarity 低 → 补「完善账号简介与定位」
- clarity 高且 competitiveness 低 → 「人设强化」「内容密度提升」
- competitiveness 高 → 「商业化」「矩阵扩展」
- 根据得分组合生成 2–4 条优先级

### 5. 实现要点

```java
double clarity = computeClarity(acc.getDescription());
double competitiveness = computeCompetitiveness(acc.getFanCount(), acc.getVideoCount(), acc.getTotalLikes());
double growth = computeGrowth(acc);
List<String> priorities = buildPriorities(clarity, competitiveness, growth);
```
