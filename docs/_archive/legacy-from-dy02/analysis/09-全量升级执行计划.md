### 🔴 第三批 - 高复杂度（Opus 执行）

#### 任务 #8：abtest 统计显著性检验

**目标**：实现统计学上的 T 检验和卡方检验，自动判断 A/B 测试胜者

**文件**：
- `module/abtest/service/impl/AbTestServiceImpl.java`（修改）
- `module/abtest/util/StatisticalAnalyzer.java`（新建）

**核心工作**：
1. 添加依赖：Apache Commons Math 3
2. 实现 performTTest()：计算 p-value，若 < 0.05 则显著
3. 实现 performChiSquareTest()：用于转化率对比
4. setWinner() 前自动执行检验，只有达到 95% 置信度才自动判赢
5. 返回结果包含：{winner: "A"/"B", pValue: 0.03, confidence: 0.97, sampleSizeNeeded: 5000}

**预期代码量**：~200 行
