## 目标

## 下一轮执行顺序

1. `live`：拆大文件、补页面测试、补核心生成链路集成测试。
2. `shortvideo`：建立页面分组 smoke 测试，优先覆盖工作台、素材、发布链。
3. `ai`：按外部依赖分层，隔离可选组件，减少测试环境耦合。
4. `auth` + `system`：继续做权限矩阵与监控页回归。
5. `product` + `script` + `benchmark`：收敛 VO、补 API 测试、稳定推荐/相似度链。
