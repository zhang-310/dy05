## 优先级分级

| 优先级 | 定义 | 修复时间 | 示例 |
|--------|------|---------|------|
| **P0** | 阻塞级 - 影响核心功能或存在严重安全漏洞 | 1 周内 | XSS 漏洞、数据隔离缺失、测试覆盖率 0% |
| **P1** | 高优先级 - 影响用户体验或存在中等安全风险 | 2 周内 | API 限流、N+1 查询、VO 字段缺失 |
| **P2** | 中优先级 - 代码质量问题或性能优化 | 1 个月内 | 大文件拆分、代码重复、缓存优化 |
| **P3** | 低优先级 - 文档完善或持续改进 | 2 个月内 | JavaDoc、API 文档、代码风格 |
