# ADR-002：无数据库外键

## 状态

已采纳

## 上下文

跨模块表之间存在逻辑关联（如 live_product 关联 dy_product），需要决定是否使用数据库外键约束。

## 决策

不使用数据库外键，改为应用层校验。

## 理由

- 逻辑删除（`deleted` 字段）与外键约束冲突
- 跨模块解耦，避免模块间数据库级依赖
- 便于分库分表（未来水平扩展）
- 简化数据迁移和测试数据准备

## 后果

- 正面：模块独立性强，可独立部署
- 正面：数据迁移简单，无外键依赖链
- 负面：需要在 Service 层手动校验关联数据是否存在
- 负面：存在数据不一致风险（孤儿数据），需要定期清理
