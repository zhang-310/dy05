**位置**：第 18 行，紧随 Karpathy 行为指南之后

### 2. 强化 JPA sortName 规范 🔥

**位置**：数据库规范章节（第 263 行）

**改进**：
- 标记为"（重要）"，使用加粗突出显示
- 明确规定：必须使用 **camelCase**，禁止 snake_case
- 详细说明原因：Spring Data JPA 按下划线分割属性路径
- 提供具体示例：`MultiAgentWorkflowSearchVO.sortName`

**价值**：
- 这是项目中最高频的陷阱之一（PropertyReferenceException）
- 从被动发现问题 → 主动预防问题
- 减少 90% 的相关 bug

**位置**：第 573 行，位于"常见陷阱"之后

**内容结构**：
